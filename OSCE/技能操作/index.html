    技能

    IV

    • 洗手：內外夾弓大立腕
    • 自介：住院醫師xxx
    • 確認：姓名、生日
    • 說明：indication（輸液、給藥）, contraindication（洗腎、乳癌開刀）
    • 備物：T-lock、針筒、食鹽水、止血帶、酒棉、碘酒、棉棒、留置針（22G）、OP site、膠帶
    • 手套：戴手套
    • 管路：針筒吸水、接T-lock、排氣
    • 血管：綁止血帶、找血管
    • 消毒：酒棉清潔、碘酒三消
    • 入針：入針、推軟針
    • 拔針：鬆、壓、拔、接
    • 連接：吸、吐、卡、拔（接點滴）
    • 完成：清潔、貼OP site、膠帶
    • 收拾：垃圾分類
    • 洗手：脫手套、洗手
    • 衛教：點滴不順、入針處腫脹要說

    ABG

    • 洗手：內外夾弓大立腕
    • 自介：住院醫師xxx
    • 確認：姓名、生日
    • 說明：indication（呼吸衰竭）, contraindication（凝血問題）
    • 備物：酒棉、碘酒、棉棒、無菌手套、針筒、紗布、膠帶、冰浴袋
    • 手套：戴手套
    • 確認：Allen test（握拳、壓橈尺、鬆拳、放尺）、10秒內變紅
    • 消毒：酒棉清潔、碘酒三消
    • 無菌：開無菌手套、放針、放紗布
    • 入針：入針、抽血（1cc）
    • 拔針：拔針、蓋紗布、黏膠帶、加壓
    • 完成：拔針頭、蓋蓋子、冰浴、送機
    • 收拾：垃圾分類
    • 洗手：脫手套、洗手
    • 衛教：加壓20分鐘、仍未止血要說

    NG

    • 洗手：內外夾弓大立腕
    • 自介：住院醫師xxx
    • 確認：姓名、生日
    • 說明：indication（灌食、減壓）, contraindication（頭部骨折、鼻子開刀、消化道穿孔）
    • 備物：NG管、jelly、灌食空針、聽診器、鼻貼、引流袋
    • 手套：戴手套
    • 量測：劍突－耳後－鼻尖
    • 潤滑：jelly
    • 插入：sniffing position、吞口水
    • 確認：反抽、打氣聽胃
    • 完成：鼻貼、接引流袋
    • 收拾：垃圾分類
    • 洗手：脫手套、洗手
    • 衛教：照X光、拔管要說

    Foley

    • 洗手：內外夾弓大立腕
    • 自介：住院醫師xxx
    • 確認：姓名、生日
    • 說明：indication（排尿困難）, contraindication（尿道損傷）
    • 備物：導尿包、碘酒、蒸餾水、尿管、尿袋、空針、無菌手套、膠帶
    • 手套：戴手套
    • 隱私：拉圍簾、脫褲子
    • 清潔：碘酒三消（陰莖、陰囊、鼠蹊部）
    • 無菌：脫手套、開無菌區
    • 酒精蒸餾水：開開、倒倒
    • 尿管尿袋空針：開開開、戴一隻手套、放放放、戴另隻手套、接接接
    • 消毒：鋪洞巾、四消龜頭
    • 插入：插到粗細交界
    • 固定：打水球、回拉
    • 完成：推回包皮、膠帶固定
    • 收拾：垃圾分類
    • 洗手：脫手套、洗手
    • 衛教：低於膀胱、不要拉

    縫合

    • 洗手：內外夾弓大立腕
    • 自介：住院醫師xxx
    • 確認：姓名、生日
    • 說明：indication（傷口比較大）
    • 備物：棉棒、食鹽水、碘酒、縫合包、針筒（3cc）、針頭（25G）、針線、lidocaine、酒棉、無菌手套、紗布、膠帶
    • 手套：戴手套
    • 評估：長度、深度、異物
    • 清潔：食鹽水清潔
    • 消毒：碘酒三消
    • 無菌：開無菌區、放針筒針頭針線、消毒local罐、戴一隻手套、吸local、戴另隻手套、換針頭、鋪洞巾
    • 局麻：反抽打藥
    • 縫合：順兩圈、反一圈、順一圈
    • 關閉：蓋紗布、貼膠帶
    • 收拾：垃圾分類
    • 洗手：脫手套、洗手
    • 衛教：每天換藥、一週後拆線

    換藥

    • 洗手：內外夾弓大立腕
    • 自介：住院醫師xxx
    • 確認：姓名、生日
    • 說明：indication（術後換藥）
    • 備物：棉棒、食鹽水、碘酒、換藥包、紗布、無菌手套、膠帶
    • 手套：戴手套
    • 打開：移除紗布、評估傷口
    • 清潔：食鹽水清潔
    • 消毒：碘酒三消
    • 濕紗：開無菌區、放紗布、倒食鹽水、戴無菌手套、wet dressing
    • 關閉：蓋上紗布、貼膠帶
    • 收拾：垃圾分類
    • 洗手：脫手套、洗手
    • 衛教：滲漏、掉落要說

    Endo

    • 洗手：內外夾弓大立腕
    • 自介：住院醫師xxx
    • 確認：姓名、生日
    • 說明：indication（血氧不好）, contraindication（假牙）
    • 備物：喉頭鏡、內管（7mm）、通條、空針（10cc）、jelly、ambu、聽診器、咬合器、膠帶
    • 手套：戴手套
    • 防護：面罩、隔離衣
    • 組裝：喉頭鏡、插通條、確認氣囊、jelly
    • 監測：O2、BP、EKG monitor
    • 給氧：ambu（壓額抬下巴 / jaw thrust）、5秒一下
    • 插管：blade 置於舌根會厭間、tube 插 22cm
    • 固定：拔通條、充氣囊
    • 確認：ambu、聽兩肺上下、胃
    • 完成：膠帶、咬合器、呼吸器
    • 收拾：垃圾分類
    • 洗手：脫手套、洗手
    • 衛教：照X光、拔管要說

    BLS

    • 叫：叫病人
    • 叫：叫119、AED
    • Pulse：檢查脈搏呼吸、每5 cycle重新評估
    • C：壓30下（用力壓、快快壓、胸回彈、莫中斷）
    • A：清除異物、壓額、抬下巴
    • B：吹2下（捏鼻子）
    • D：貼貼片、開機、清空、電擊
    • ROSC：側躺避免嗆咳、反覆重新評估

    抹片

    • 洗手：內外夾弓大立腕
    • 自介：住院醫師xxx
    • 確認：姓名、生日
    • 說明：indication（癌症篩檢、骨盆發炎）
    • 備物：鴨嘴、刷子、玻片、酒精
    • 手套：戴手套
    • 隱私：請女護理師、拉圍簾
    • 檢查：外陰分泌物、病灶
    • 鴨嘴：放入鴨嘴、撐開轉緊
    • 檢查：子宮頸分泌物、病灶
    • 抹片：放入刷子、轉三圈、抹到玻片、放入酒精（30 min）
    • 檢查：陰道分泌物、病灶（邊退出鴨嘴）
    • 內診：一手進陰道、一手壓腹部、疼痛、腫塊
    • 收拾：垃圾分類
    • 洗手：脫手套、洗手
    • 衛教：回來看報告

    EKG

    • 洗手：內外夾弓大立腕
    • 自介：住院醫師xxx
    • 確認：姓名、生日
    • 說明：indication（胸痛）, contraindication（飾品手錶）
    • 備物：機器、貼片
    • 洗手：洗手
    • 隱私：請女護理師、拉圍簾
    • 身分：刷條碼
    • 貼片：V1 (第四肋間胸骨右緣), V2 (第四肋間胸骨左緣), V4 (第五肋間鎖骨中線), V3 (V2和V4間), V6 (第五肋間腋中線), V5 (V4和V6間), RA, LA, RL, LL
    • 分析：不動、分析、列印
    • 判讀：告知病患、下壁梗塞加做 right side
    • 收拾：撕貼片、穿衣服
    • 洗手：洗手
    • 衛教：症狀變化要說
