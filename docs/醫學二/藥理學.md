## 一、藥理學總論（General Pharmacology）

### 1.1 藥物動力學（Pharmacokinetics）— ADME

#### 吸收（Absorption）

- 大多數藥物經**被動擴散**吸收，取決於：脂溶性、分子量、解離度（pKa）
- **弱酸性藥物（如 Aspirin, pKa ≈ 3.5）**：在酸性環境（胃）中呈非解離態 → 較易吸收
- **弱鹼性藥物（如 Morphine）**：在鹼性環境（小腸）中呈非解離態 → 較易吸收
- **Ion trapping**：弱酸在鹼性環境中解離被困住（如 aspirin 中毒 → 鹼化尿液加速排除）
- **生體可用率（Bioavailability, F）**：口服藥物到達全身循環的比例
    - IV 給藥 F = 100%
    - **首渡效應（First-pass effect）**：經肝臟代謝後 F 降低（如 Nitroglycerin 口服 F 極低 → 改用舌下）

#### 分布（Distribution）

- **血漿蛋白結合**：Albumin（結合酸性藥物）、α1-acid glycoprotein（結合鹼性藥物）
    - 高蛋白結合率的藥物（如 Warfarin >99%）→ 被其他藥物競爭置換時游離濃度↑ → 藥效↑/毒性↑
- **分布體積（Vd）**：Vd = 藥量 / 血漿濃度
    - Vd 小（<10 L）→ 藥物留在血漿中（如 Warfarin、Heparin）
    - Vd 大（>40 L）→ 藥物廣泛分布到組織（如 Chloroquine Vd ≈ 13,000 L）
- **血腦障壁（BBB）**：脂溶性高者可通過（如 Diazepam）；P-glycoprotein 會將藥物泵出

#### 代謝（Metabolism）

- **Phase I（functionalization）**：氧化、還原、水解 → 引入或暴露官能基
    - 最重要：**Cytochrome P450（CYP）系統**（肝臟微粒體）
    - 重要亞型：**CYP3A4**（代謝最多藥物）、CYP2D6、CYP2C9、CYP2C19、CYP1A2、CYP2E1
- **Phase II（conjugation）**：glucuronidation（最常見）、sulfation、acetylation、methylation、glutathione conjugation
    - **Acetylation 多態性**：慢乙醯化者 → INH 毒性↑（周邊神經炎）、Procainamide → drug-induced lupus↑
- **酵素誘導劑（CYP inducers）**：加速代謝 → 藥效↓
    - 口訣：**Chronic alcoholism、Rifampin、Barbiturates、Phenytoin、Carbamazepine、St. John's Wort、Griseofulvin**
    - Rifampin 是最強的 CYP inducer
- **酵素抑制劑（CYP inhibitors）**：減慢代謝 → 藥效/毒性↑
    - 口訣：**Acute alcohol、Cimetidine、Ketoconazole/Itraconazole、Erythromycin/Clarithromycin、Grapefruit juice、Ciprofloxacin、Ritonavir、Fluoxetine/Fluvoxamine、Verapamil/Diltiazem、Amiodarone、Valproate、Isoniazid**

#### 排泄（Excretion）

- **腎臟排泄**：
    - 腎絲球過濾：游離（未結合蛋白）的藥物
    - 腎小管主動分泌：有機陰離子轉運體（OAT）→ 如 Penicillin、Methotrexate、Uric acid；**Probenecid** 競爭 OAT → 延長 Penicillin 半衰期
    - 腎小管再吸收：脂溶性藥物被動再吸收
    - **鹼化尿液**（NaHCO₃）→ 加速弱酸排除（Aspirin、Barbiturate、MTX）
    - **酸化尿液**（NH₄Cl）→ 加速弱鹼排除（Amphetamine）
- **膽汁排泄**：部分藥物經膽汁排入腸道 → 可能被**腸肝循環**再吸收（如 Estrogen、Digoxin、Morphine）

### 1.2 藥效學（Pharmacodynamics）

- **效力（Potency）**：達到相同效果所需劑量 → 由 **EC₅₀**（半最大效應濃度）決定
- **效能（Efficacy）**：藥物能達到的最大效應 → 由 **Emax** 決定
- **Agonist**：與受體結合並活化
    - Full agonist：產生最大反應（Emax = 1）
    - **Partial agonist**：即使占滿所有受體，也只能產生次最大反應 → 在有 full agonist 存在時可表現為拮抗劑
- **Antagonist**：
    - **Competitive（可逆性）**：與 agonist 競爭同一結合位 → 右移劑量反應曲線，但 Emax 不變（可被增加 agonist 濃度克服）
    - **Non-competitive（不可逆性）**：結合不同位點或共價結合 → **降低 Emax**，無法被增加 agonist 克服
- **治療指數（Therapeutic Index, TI）**：TI = TD₅₀ / ED₅₀（或 LD₅₀ / ED₅₀）→ TI 越大越安全
    - **窄治療指數藥物**：Warfarin、Digoxin、Lithium、Theophylline、Aminoglycosides、Phenytoin、Carbamazepine、Valproic acid、Cyclosporine

### 1.3 特殊藥理學概念

- **Tachyphylaxis**：快速耐受性（如 Ephedrine 反覆使用後效果↓，因 NE 耗竭）
- **Tolerance**：長期使用後效果減弱（如 Opioids、Benzodiazepines、Nitrates）
- **Spare receptors（受體儲備）**：不需佔滿所有受體即可達到最大效應
- **Up-regulation / Down-regulation**：長期拮抗 → 受體上調（如 β-blocker 突然停藥 → rebound tachycardia）；長期激動 → 受體下調

## 二、自律神經藥理學（Autonomic Pharmacology）

### 2.1 基礎架構

| | 交感神經（Sympathetic） | 副交感神經（Parasympathetic） |
|--|------------------------|---------------------------|
| 神經傳導物質 | 節前：**ACh**（nicotinic）；節後：**NE**（adrenergic） | 節前：**ACh**（nicotinic）；節後：**ACh**（muscarinic） |
| 例外 | 汗腺交感節後用 ACh（muscarinic）；腎上腺髓質直接受節前神經支配分泌 Epi/NE | — |

### 2.2 Adrenergic 受體

| 受體 | 位置 | 功能 | 臨床意義 |
|------|------|------|----------|
| **α₁** | 血管平滑肌、瞳孔擴張肌、膀胱括約肌、攝護腺 | 血管收縮 → BP↑；散瞳（mydriasis）；膀胱頸/攝護腺收縮 | α₁-blocker（Prazosin）→ 降壓、BPH 治療 |
| **α₂** | 突觸前膜、CNS | **負回饋抑制 NE 釋放**；中樞降壓 | Clonidine（α₂ agonist）→ 降壓、戒斷治療 |
| **β₁** | **心臟** | **心跳↑、收縮力↑、傳導↑、腎素分泌↑** | β₁-blocker → 降壓、心衰、抗心律不整 |
| **β₂** | **支氣管平滑肌、子宮、血管、肝/骨骼肌** | **支氣管擴張**、子宮鬆弛、血管擴張、肝醣分解↑ | β₂-agonist（Salbutamol）→ 氣喘急性期 |
| **β₃** | 脂肪組織、膀胱逼尿肌 | 脂肪分解↑、膀胱鬆弛 | Mirabegron → 膀胱過動症 |

### 2.3 Muscarinic 受體

| 受體 | 位置 | 功能 |
|------|------|------|
| **M₁** | CNS、胃壁細胞 | 認知；胃酸分泌↑ |
| **M₂** | **心臟（SA node、AV node）** | **心跳↓、傳導↓** |
| **M₃** | 平滑肌、腺體、血管內皮 | 支氣管收縮、腸蠕動↑、唾液/淚液分泌↑、瞳孔縮小（miosis）、睫狀肌收縮（近視調節）、內皮 NO 釋放 → 血管擴張 |

### 2.4 擬交感神經藥（Sympathomimetics）

#### 直接作用型

| 藥物 | 受體選擇性 | 臨床用途 | 重要備註 |
|------|-----------|----------|----------|
| **Epinephrine（Adrenaline）** | α₁ = α₂ > β₁ = β₂ | **Anaphylaxis 首選**、心跳停止（ACLS）、與局麻合用延長作用 | 低劑量 β₂ 為主（血管擴張）→ 高劑量 α₁ 為主（血管收縮） |
| **Norepinephrine** | α₁ = α₂ > β₁；**β₂ 弱** | **Septic shock 首選升壓藥** | 強血管收縮；反射性心搏過緩 |
| **Isoproterenol** | **β₁ = β₂**（無 α） | 心搏過緩（歷史用途） | 不縮血管，BP↓（β₂ 擴張） |
| **Phenylephrine** | **α₁ 選擇性** | 鼻充血解除、升壓、散瞳 | 反射性心搏過緩 |
| **Dobutamine** | **β₁ 選擇性** | **急性心衰（cardiogenic shock）** | 強心不強縮血管 |
| **Dopamine** | 劑量依賴：低 D₁ → 中 β₁ → 高 α₁ | 休克升壓 | 低劑量：腎血管擴張（D₁）→ 中劑量：心臟↑（β₁）→ 高劑量：血管收縮（α₁） |
| **Salbutamol（Albuterol）** | **β₂ 選擇性** | **急性氣喘首選** | SABA；副作用：tremor、tachycardia、hypokalemia |
| **Salmeterol / Formoterol** | **β₂ 長效** | 氣喘/COPD 維持治療 | LABA；需搭配 ICS 使用，不可單用 |
| **Terbutaline** | β₂ | 安胎（子宮鬆弛） | — |
| **Clonidine** | **α₂ 選擇性** | 降壓（中樞作用）、opioid 戒斷、ADHD | 突然停藥 → **rebound hypertension** |
| **Brimonidine** | α₂ | 青光眼（降低房水分泌） | — |
| **Midodrine** | α₁ | 姿勢性低血壓 | — |
| **Mirabegron** | β₃ | 膀胱過動症 | 逼尿肌鬆弛 |

#### 間接作用型及混合型

| 藥物 | 機制 | 臨床意義 |
|------|------|----------|
| **Amphetamine** | 促進 NE/DA 釋放 + 抑制再回收 + 抑制 MAO | ADHD、嗜睡症；濫用風險 |
| **Ephedrine** | 促進 NE 釋放 + 微弱直接作用 | 低血壓；tachyphylaxis（NE 耗竭） |
| **Cocaine** | **阻斷 NE/DA/5-HT 再回收** | 局部麻醉（唯一具血管收縮的局麻藥）；濫用 → 冠狀動脈痙攣/心肌梗塞（**禁用 β-blocker**，改用 Phentolamine + BZD + NTG） |
| **Tyramine** | 促進 NE 釋放（食物中存在） | 使用 **MAO inhibitor** 時食用含 tyramine 食物 → **高血壓危象**（cheese reaction） |

### 2.5 抗腎上腺素藥（Adrenergic Antagonists）

#### α-Blockers

| 藥物 | 選擇性 | 臨床用途 | 重要副作用 |
|------|--------|----------|-----------|
| **Phentolamine** | α₁ = α₂（非選擇性） | Pheochromocytoma 診斷/術前、NE 外滲、Cocaine 中毒 | 反射性心搏過速（因 α₂ 也被阻斷 → NE 釋放↑） |
| **Phenoxybenzamine** | α₁ = α₂（不可逆） | **Pheochromocytoma 術前準備首選** | 持續性低血壓、鼻塞 |
| **Prazosin / Doxazosin / Terazosin** | **α₁ 選擇性** | 高血壓、**BPH** | **首劑低血壓（first-dose syncope）** |
| **Tamsulosin** | **α₁A 選擇性** | **BPH**（攝護腺/膀胱頸選擇性高） | 較少血壓降低；**術中虹膜鬆弛症候群（IFIS）** |

- **Pheochromocytoma 手術順序**：先 α-blocker（Phenoxybenzamine）→ 再 β-blocker → 手術
    - **絕不可先用 β-blocker**（α 未阻斷時，阻斷 β₂ → 失去血管擴張 → 惡性高血壓）

#### β-Blockers

| 藥物 | 選擇性 | 特色 | 臨床用途 |
|------|--------|------|----------|
| **Propranolol** | β₁ = β₂（非選擇性） | 脂溶性高 → 穿越 BBB；膜穩定作用 | 高血壓、甲亢症狀控制、essential tremor、migraine 預防、portal HTN（降低門脈壓）、焦慮 |
| **Metoprolol / Atenolol / Bisoprolol** | **β₁ 選擇性** | 較少支氣管收縮 | 高血壓、心衰（Metoprolol succinate, Bisoprolol）、MI 後 |
| **Carvedilol** | α₁ + β₁ + β₂ | 血管擴張 + 抗氧化 | **心衰**（與 Metoprolol succinate、Bisoprolol 並列心衰首選） |
| **Labetalol** | α₁ + β₁ + β₂ | α：β = 1：3 | **妊娠高血壓/子癇前症首選 IV 降壓藥** |
| **Nebivolol** | β₁ 高選擇性 | 促進 NO 釋放 → 血管擴張 | 高血壓 |
| **Esmolol** | β₁ 選擇性，**超短效** | 半衰期約 9 分鐘 | 術中心搏過速、SVT 急性控制 |
| **Timolol** | 非選擇性 | 眼用製劑 | **青光眼**（降低房水分泌） |
| **Sotalol** | 非選擇性 + **Class III 抗心律不整**（K⁺ channel blocker） | 延長 QT | 心房/心室心律不整 |
| **Pindolol** | 非選擇性 + ISA | 具 partial agonist 活性 → 休息時心跳不太降 | — |

- **β-blocker 共同副作用**：心搏過緩、低血壓、支氣管痙攣（非選擇性 → 氣喘禁忌）、遮蔽低血糖症狀（tachycardia）、脂質代謝異常（TG↑、HDL↓）、性功能障礙、疲倦、抑鬱
- **β-blocker 突然停藥** → **rebound tachycardia / 心絞痛加重 / MI**（受體上調）→ 需漸減

### 2.6 擬副交感神經藥（Cholinomimetics）

#### 直接作用型

| 藥物 | 特色 | 臨床用途 |
|------|------|----------|
| **Bethanechol** | M₃ 選擇性，不被 AChE 水解 | **術後尿滯留、神經性膀胱** |
| **Carbachol** | M + N，不被 AChE 水解 | 青光眼（眼用） |
| **Pilocarpine** | **M₃** | **青光眼**（縮瞳 → 打開 Schlemm's canal）；**口乾（Sjögren's）** |
| **Methacholine** | M 選擇性，被 AChE 緩慢水解 | **支氣管激發試驗**（診斷氣喘） |

#### 間接作用型（AChE inhibitors）

| 藥物 | 可逆/不可逆 | 臨床用途 |
|------|-----------|----------|
| **Neostigmine** | 可逆 | **重症肌無力（MG）治療**、術後腸麻痺/尿滯留、神經肌肉阻斷劑拮抗 |
| **Pyridostigmine** | 可逆 | **MG 長期治療首選**（作用較長） |
| **Edrophonium** | 可逆（超短效） | MG 診斷（Tensilon test，已少用） |
| **Physostigmine** | 可逆，穿越 BBB | **Atropine 中毒解毒**（因可進入 CNS） |
| **Donepezil / Rivastigmine / Galantamine** | 可逆 | **Alzheimer's disease** |
| **有機磷（Organophosphates）** | **不可逆** | 殺蟲劑/神經毒氣中毒 |

- **有機磷中毒**：
    - DUMBBELSS：Diarrhea、Urination、Miosis、Bradycardia、Bronchospasm/Bronchorrhea、Emesis、Lacrimation、Salivation、Sweating
    - 治療：**Atropine**（阻斷 muscarinic 症狀）+ **Pralidoxime（2-PAM）**（在 aging 前重新活化 AChE）
    - Pralidoxime 必須在中毒後 24–48 小時內使用（aging 後無效）

### 2.7 抗副交感神經藥（Anticholinergics / Parasympatholytics）

| 藥物 | 選擇性 | 臨床用途 |
|------|--------|----------|
| **Atropine** | 非選擇性 M | 心搏過緩（ACLS）、有機磷中毒、術前減少分泌物、散瞳（眼科） |
| **Scopolamine（Hyoscine）** | 非選擇性 M，穿越 BBB | **暈動症（motion sickness）**首選（貼片） |
| **Ipratropium** | 非選擇性 M，吸入型 | **COPD 急性期**（與 SABA 合用）；不穿越 BBB → 少全身副作用 |
| **Tiotropium** | 非選擇性 M，長效吸入型 | **COPD 維持治療首選** LAMA |
| **Glycopyrrolate** | 非選擇性 M，**不穿越 BBB** | 術前減少分泌物（比 Atropine 少 CNS 副作用） |
| **Benztropine / Trihexyphenidyl** | 中樞 M | **藥物引起的錐體外症候群（EPS）**、Parkinson's（輔助） |
| **Oxybutynin / Tolterodine / Solifenacin** | M₃ | **膀胱過動症（OAB）** |
| **Tropicamide** | M | 短效散瞳（眼底檢查） |
| **Homatropine / Cyclopentolate** | M | 中效散瞳/睫狀肌麻痺 |

- **Anticholinergic 副作用口訣**："Hot as a hare（發燒）, Dry as a bone（口乾/皮膚乾）, Red as a beet（血管擴張潮紅）, Blind as a bat（散瞳/視力模糊）, Mad as a hatter（譫妄/幻覺）, Full as a flask（尿滯留）"

### 2.8 神經肌肉接合處藥物

#### 去極化型肌肉鬆弛劑

- **Succinylcholine**：
    - Phase I block：持續去極化 → 肌肉鬆弛
    - Phase II block：長期使用後呈現非去極化型阻斷特徵
    - 特色：起效最快（30–60 秒）、超短效（被 pseudocholinesterase 水解）
    - 用途：**RSI（快速序列插管）**
    - 副作用：**惡性高熱（Malignant Hyperthermia）**（合併吸入性麻醉劑）、高血鉀（禁用於燒傷/壓碎傷/脊髓損傷/神經肌肉疾病）、肌肉震顫、顱內壓/眼內壓↑、心搏過緩
    - **Pseudocholinesterase 缺乏** → 作用時間顯著延長
    - **Malignant Hyperthermia**：RyR1 突變 → 鈣離子大量釋放 → 骨骼肌持續收縮 → 體溫極高 + 肌強直 + 橫紋肌溶解 + 代謝性酸中毒
        - 治療：**Dantrolene**（阻斷 RyR → 降低肌漿 Ca²⁺）

#### 非去極化型肌肉鬆弛劑

| 藥物 | 特色 |
|------|------|
| **Tubocurarine** | 歷史上首個；可致組胺釋放 → 低血壓/支氣管痙攣 |
| **Pancuronium** | 長效；vagolytic → tachycardia |
| **Vecuronium / Rocuronium** | 中效；Rocuronium 起效較快，可替代 Succinylcholine 用於 RSI |
| **Atracurium / Cisatracurium** | 經 **Hofmann elimination**（自發降解，不經肝腎）→ 適用肝腎功能不全 |

- 拮抗：**Neostigmine + Atropine**（Atropine 預防 muscarinic 副作用）；或 **Sugammadex**（選擇性包裹 Rocuronium/Vecuronium，快速逆轉）

### 2.9 神經節阻斷劑

- **Hexamethonium / Mecamylamine**：阻斷自律神經節 nicotinic receptor → 同時阻斷交感/副交感
- 臨床已很少用；考試重點：理解 Nicotinic receptor（N_N）在神經節的角色

## 三、心血管藥理學（Cardiovascular Pharmacology）

### 3.1 抗高血壓藥物

#### ACE Inhibitors（-pril）

- 代表：**Captopril、Enalapril、Lisinopril、Ramipril**
- 機制：抑制 ACE → Angiotensin II↓ + Bradykinin↑ → 血管擴張 + 醛固酮↓
- 用途：高血壓、**心衰（HFrEF 首選之一）**、**糖尿病腎病變（首選腎保護）**、MI 後
- 副作用：
    - **乾咳**（bradykinin 累積，最常見副作用）
    - **高血鉀**（醛固酮↓）
    - **血管性水腫**（bradykinin 媒介，antihistamine 無效）
    - 急性腎衰竭（雙側腎動脈狹窄禁忌）
    - **致畸性** → **孕婦絕對禁忌**

#### ARBs（-sartan）

- 代表：**Losartan、Valsartan、Candesartan、Irbesartan、Telmisartan**
- 機制：阻斷 AT₁ receptor → 效果類似 ACEi
- 優點：**不引起乾咳**（不影響 bradykinin）；血管性水腫罕見
- 副作用：高血鉀、孕婦禁忌（同 ACEi）
- Losartan 額外促進尿酸排泄

#### ARNI

- **Sacubitril / Valsartan**：Sacubitril 抑制 Neprilysin → BNP/ANP 不被降解 → 利鈉利尿、血管擴張
- 用途：**HFrEF（優於單用 ACEi）**
- 注意：不可與 ACEi 併用（血管性水腫風險↑）；須停 ACEi 36 小時後才可換用

#### Calcium Channel Blockers（CCBs）

| 類別 | 藥物 | 作用 | 用途 |
|------|------|------|------|
| **Dihydropyridines（-dipine）** | **Nifedipine、Amlodipine、Felodipine** | 血管平滑肌選擇性 > 心肌 → **血管擴張**為主 | 高血壓、Raynaud's；Nifedipine 短效型 → 反射性心搏過速（少用） |
| **Non-dihydropyridines** | **Verapamil** | 心肌選擇性 > 血管 → **負變時/負變力** | SVT（首選之一）、心絞痛、高血壓；**便秘**（最常見副作用） |
| | **Diltiazem** | 介於中間 | SVT、心絞痛、高血壓 |

- **Verapamil / Diltiazem 禁忌**：HFrEF（負變力加重心衰）、與 β-blocker 併用（嚴重心搏過緩/AV block）
- Amlodipine 可安全用於心衰（血管選擇性高，不影響心肌）

#### 其他降壓藥

| 藥物 | 機制 | 特色 |
|------|------|------|
| **Hydralazine** | 直接血管擴張（動脈）| 常合併 Isosorbide dinitrate 用於 HFrEF（尤其非裔）；副作用：**drug-induced lupus**、反射性心搏過速 |
| **Minoxidil** | K⁺ channel opener → 動脈擴張 | 嚴重高血壓；副作用：**多毛症（外用治禿髮）**、鈉水滯留、心包膜積液 |
| **Nitroprusside** | 釋放 NO → 動脈 + 靜脈擴張 | **高血壓急症 IV 首選**；副作用：**氰化物中毒**（長期使用）→ 解毒：Thiosulfate、Hydroxocobalamin |
| **Fenoldopam** | D₁ receptor agonist | 高血壓急症（維持腎灌流） |
| **Methyldopa** | 中樞 α₂ agonist | **妊娠高血壓口服首選**；副作用：Coombs'(+) hemolytic anemia、肝毒性 |

### 3.2 利尿劑（Diuretics）

| 類別 | 藥物 | 作用位置 | 機制 | 效力 | 副作用 |
|------|------|---------|------|------|--------|
| **Carbonic anhydrase inhibitor** | **Acetazolamide** | PCT | 抑制 CA → HCO₃⁻ 排泄↑ | 弱 | 代謝性酸中毒、低血鉀；用於：**青光眼、高山症、代謝性鹼中毒** |
| **Osmotic diuretic** | **Mannitol** | PCT、descending loop | 滲透壓效應 | 中 | 血漿容積先擴張（禁用於心衰/肺水腫）；用於：**降腦壓、急性青光眼** |
| **Loop diuretic** | **Furosemide、Bumetanide、Torsemide、Ethacrynic acid** | **Thick ascending limb** | 抑制 **Na⁺-K⁺-2Cl⁻ cotransporter（NKCC2）** | **最強** | **低血鉀、低血鈣**、低血鎂、代謝性鹼中毒、高尿酸、**耳毒性**（尤其 Ethacrynic acid，唯一非 sulfonamide → 磺胺過敏者可用）；用於：**急性肺水腫、心衰、高血鈣** |
| **Thiazide** | **Hydrochlorothiazide（HCTZ）、Chlorthalidone、Indapamide** | **DCT 早段** | 抑制 **Na⁺-Cl⁻ cotransporter（NCC）** | 中 | **低血鉀、高血鈣**（與 loop 相反）、高血糖、高尿酸、高血脂、代謝性鹼中毒；用於：**高血壓首選之一、腎結石（Ca 結石預防）、NDI** |
| **K⁺-sparing** | **Spironolactone、Eplerenone** | **CD** | **醛固酮拮抗劑** | 弱 | **高血鉀**、Spironolactone：**男性女乳症、月經異常**（抗雄性激素作用）；Eplerenone 較少此副作用；用於：**心衰（降低死亡率）、肝硬化腹水、Conn's syndrome、hirsutism** |
| | **Triamterene、Amiloride** | CD | 阻斷 **ENaC** | 弱 | 高血鉀；Amiloride 用於 **Liddle syndrome** |

- **利尿劑與電解質口訣**：
    - Loop → 低鉀低鈣（**Loops Lose calcium**）
    - Thiazide → 低鉀高鈣（**Thiazide：鈣 reabsorption↑**）
    - K⁺-sparing → 高鉀

### 3.3 抗心絞痛藥（Anti-Anginal Drugs）

| 類別 | 藥物 | 機制 | 備註 |
|------|------|------|------|
| **Nitrates** | **Nitroglycerin（NTG）、Isosorbide dinitrate/mononitrate** | 釋放 NO → **靜脈擴張為主** → preload↓ → 心肌耗氧↓ | 舌下或 IV 用於急性心絞痛；頭痛（最常見副作用）；**Nitrate tolerance** → 需留 nitrate-free interval（8–12 hr）；**禁忌：併用 PDE5 inhibitor（Sildenafil）→ 嚴重低血壓** |
| **β-Blockers** | Metoprolol、Atenolol 等 | 降低心跳/收縮力 → 心肌耗氧↓ | **慢性穩定型心絞痛一線**；MI 後降低死亡率 |
| **CCBs** | Amlodipine、Verapamil、Diltiazem | 血管擴張 + 降低耗氧 | **Variant angina（Prinzmetal's）首選**（冠脈痙攣；此時 β-blocker 可能加重痙攣 → 避免） |
| **Ranolazine** | 抑制 late Na⁺ current → 降低胞內 Ca²⁺ | 慢性心絞痛輔助藥 | 延長 QT |

### 3.4 心衰藥物

#### HFrEF 四大支柱（Quadruple Therapy / GDMT）

| 類別 | 藥物 | 降低死亡率 |
|------|------|-----------|
| **ARNI（或 ACEi/ARB）** | Sacubitril/Valsartan | ✓ |
| **β-Blocker** | Carvedilol、Metoprolol succinate、Bisoprolol | ✓ |
| **MRA** | Spironolactone、Eplerenone | ✓ |
| **SGLT2 inhibitor** | Dapagliflozin、Empagliflozin | ✓ |

#### 其他心衰藥物

| 藥物 | 機制 | 用途 |
|------|------|------|
| **Digoxin** | 抑制 Na⁺/K⁺-ATPase → 胞內 Na⁺↑ → NCX 反轉 → Ca²⁺↑ → 正性肌力；迷走神經↑ | 心衰症狀改善（不降死亡率）、心房顫動心率控制 |
| **Hydralazine + ISDN** | 血管擴張 | ACEi/ARB 不耐受或非裔美國人 |
| **Ivabradine** | 抑制 If current（SA node）→ 心跳↓（不影響收縮力） | 竇性心律 HR ≥70 且已用最大耐受 β-blocker |
| **Milrinone** | PDE3 inhibitor → cAMP↑ → 正性肌力 + 血管擴張 | 急性失代償心衰（inotrope + vasodilator）；長期使用增加死亡率 |
| **Vericiguat** | sGC stimulator → cGMP↑ | 慢性心衰 worsening |

- **Digoxin 重點**：
    - 治療指數極窄（0.5–2.0 ng/mL）
    - **中毒危險因子**：低血鉀（最重要！）、低血鎂、高血鈣、腎功能不全、藥物交互作用（Amiodarone、Verapamil、Quinidine 增加 Digoxin 濃度）
    - **中毒表現**：消化道（噁心嘔吐最常見）、心律不整（**任何心律不整皆可能**，典型：**PAT with block**、bidirectional VT）、視覺異常（黃視）
    - **中毒處理**：停藥、補鉀（若低血鉀）、**Digoxin-specific antibody Fab fragments（Digibind/DigiFab）**
    - 低血鉀促進 Digoxin 中毒的原因：K⁺ 與 Digoxin 競爭 Na⁺/K⁺-ATPase 結合位

### 3.5 抗心律不整藥（Vaughan-Williams Classification）

| Class | 機制 | 藥物 | 備註 |
|-------|------|------|------|
| **Ia** | Na⁺ channel blocker（中等阻斷）+ K⁺ channel blocker → **延長 AP 和 QT** | **Quinidine、Procainamide、Disopyramide** | Quinidine：腹瀉、金雞納反應、延長 QT → TdP；Procainamide：**drug-induced lupus**（anti-histone Ab）；Disopyramide：負性肌力最強（禁用 HFrEF）、anticholinergic |
| **Ib** | Na⁺ channel blocker（弱阻斷）→ **縮短 AP** | **Lidocaine、Mexiletine** | Lidocaine：**急性 VT/VF 的替代選擇**（IV only）；對缺血心肌選擇性高；CNS 毒性（seizure）；Mexiletine：口服 Lidocaine 類似物 |
| **Ic** | Na⁺ channel blocker（強阻斷）→ 對 AP 影響小 | **Flecainide、Propafenone** | **禁用於結構性心臟病/CAD**（CAST trial：增加 MI 後死亡率）；用於正常心臟的 AF/SVT |
| **II** | **β-Blocker** | Metoprolol、Esmolol、Propranolol 等 | 降低 SA/AV node 自動性和傳導 |
| **III** | **K⁺ channel blocker** → **延長 AP 和 QT** | **Amiodarone、Sotalol、Dofetilide、Ibutilide** | 見下方詳述 |
| **IV** | **Non-DHP CCB** | **Verapamil、Diltiazem** | 降低 AV node 傳導 → SVT/AF rate control |

#### Amiodarone 重點

- 兼具 Class I/II/III/IV 所有作用 → **最廣效的抗心律不整藥**
- 用途：幾乎所有心律不整（AF、VT、VF），**心臟停止時 VF/pVT 用藥**
- **半衰期極長**（40–55 天）
- **副作用（幾乎影響每個器官）**：
    - **肺纖維化**（最嚴重，需定期 CXR/PFT）
    - **甲狀腺**：甲亢或甲低（含碘量高，Wolff-Chaikoff / Jod-Basedow effect）
    - **肝毒性**
    - **角膜微沉積**（corneal microdeposits，幾乎所有人都有，通常無症狀）
    - **皮膚光敏感 → 藍灰色皮膚變色**
    - **周邊神經病變**
    - **延長 QT**（但 TdP 發生率相對低）
    - **增加 Digoxin 和 Warfarin 濃度**（CYP inhibition）

#### 其他 Class III

- **Sotalol**：β-blocker + K⁺ channel blocker；延長 QT → TdP 風險；腎排泄
- **Dofetilide**：純 K⁺ channel blocker；延長 QT → TdP；需住院起始 + 監測 QTc
- **Ibutilide**：IV 用於 AF/Flutter 急性轉復；延長 QT → TdP

#### 其他抗心律不整藥

| 藥物 | 機制 | 用途 |
|------|------|------|
| **Adenosine** | A₁ receptor → 極短暫 AV block（半衰期 <10 秒） | **PSVT 首選**（診斷 + 治療）；副作用：短暫胸悶/face flushing/心跳停頓；Theophylline/Caffeine 拮抗其作用；Dipyridamole 增強作用 |
| **MgSO₄** | 穩定膜電位 | **Torsades de Pointes（TdP）首選** |
| **Atropine** | 阻斷 M₂ → 心跳↑ | 症狀性心搏過緩 |
| **Isoproterenol** | β₁ agonist | Bradycardia-dependent TdP（暫時性使用） |

### 3.6 抗血脂藥物

| 類別 | 藥物 | 機制 | 效果 | 副作用 |
|------|------|------|------|--------|
| **Statins** | Atorvastatin、Rosuvastatin、Simvastatin、Lovastatin、Pravastatin | **HMG-CoA reductase inhibitor** → 肝臟 cholesterol 合成↓ → LDL receptor↑ | **LDL↓↓（最有效）**、TG↓、HDL↑ | **Myopathy / Rhabdomyolysis**（CK↑）→ 與 Fibrate/Niacin 併用風險↑；肝毒性；**CYP3A4 代謝者**（Simvastatin, Lovastatin, Atorvastatin）注意交互作用；**孕婦禁忌** |
| **Ezetimibe** | 抑制小腸 NPC1L1 → cholesterol 吸收↓ | LDL↓（中等） | 腹瀉；常與 Statin 合用 |
| **PCSK9 inhibitors** | **Evolocumab、Alirocumab** | 抗 PCSK9 Ab → LDL receptor 不被降解 → LDL↓↓ | LDL↓↓↓ | 注射部位反應；Statin 不耐受或極高風險患者 |
| **Bile acid resins** | **Cholestyramine、Colestipol、Colesevelam** | 結合膽酸 → 肝臟利用更多 cholesterol 合成膽酸 → LDL receptor↑ | LDL↓ | GI 不適、**TG↑**（高 TG 禁忌）；干擾其他藥物吸收（如 Warfarin、Digoxin、Thyroid hormone）→ 間隔服用 |
| **Fibrates** | **Gemfibrozil、Fenofibrate** | PPAR-α agonist → TG↓↓ | **TG↓↓（最有效）**、HDL↑ | Myopathy（與 Statin 併用風險↑，尤其 Gemfibrozil）；膽結石↑；Fenofibrate 與 Statin 併用較安全 |
| **Niacin（Nicotinic acid）** | 抑制脂肪分解 → VLDL↓ | TG↓、LDL↓、**HDL↑↑（最有效升 HDL）** | **Flushing**（prostaglandin 媒介 → 用 Aspirin 或 Laropiprant 預防）、高血糖、高尿酸（痛風禁忌）、肝毒性 |
| **Omega-3 fatty acids** | Icosapent ethyl（EPA） | TG↓ | 高 TG 輔助；REDUCE-IT trial 顯示 CV benefit |
| **Bempedoic acid** | ACL inhibitor → HMG-CoA 合成↓（肝臟選擇性） | LDL↓ | 不活化於肌肉 → 不引起 myopathy；可與 Statin 合用 |
| **Inclisiran** | siRNA → PCSK9 mRNA 降解 | LDL↓↓ | 每半年注射一次 |

### 3.7 抗血栓藥物

#### 抗血小板藥物

| 藥物 | 機制 | 用途 | 備註 |
|------|------|------|------|
| **Aspirin（低劑量）** | **不可逆抑制 COX-1 → TXA₂↓ → 血小板凝集↓** | ACS、CAD 二級預防、PCI 後 | 不可逆（血小板壽命 7–10 天）；副作用：GI 出血、Reye syndrome（兒童禁忌） |
| **Clopidogrel** | **不可逆抑制 P2Y₁₂ receptor（ADP receptor）** | ACS、PCI 後 DAPT（Aspirin + Clopidogrel） | **前驅藥（prodrug）**：需 CYP2C19 活化 → **CYP2C19 poor metabolizer 效果差** → 改用 Prasugrel/Ticagrelor |
| **Prasugrel** | 不可逆 P2Y₁₂ | PCI 後 ACS | 起效較快；出血風險較高；禁忌：**TIA/stroke 病史** |
| **Ticagrelor** | **可逆性 P2Y₁₂** | ACS（不需 PCI 也可用） | 不需 CYP 活化；副作用：**呼吸困難（dyspnea）**、心搏過緩 |
| **Cangrelor** | 可逆性 P2Y₁₂（IV） | PCI 術中 | 超短效 |
| **Dipyridamole** | 抑制 PDE → cAMP↑ + 抑制 adenosine 再回收 | 合併 Aspirin 用於 stroke 預防 | 增強 Adenosine 作用；用於心臟壓力測試（冠脈擴張） |
| **Cilostazol** | PDE3 inhibitor → cAMP↑ | **間歇性跛行（PAD）** | 正性肌力 → **心衰禁忌** |
| **Abciximab、Eptifibatide、Tirofiban** | **GPIIb/IIIa receptor antagonist** | 高風險 PCI | 血小板凝集最終共同路徑阻斷 |
| **Vorapaxar** | PAR-1（thrombin receptor）antagonist | MI 後二級預防（輔助 DAPT） | 出血風險高；**stroke/TIA 禁忌** |

#### 抗凝血藥

| 藥物 | 機制 | 監測 | 拮抗劑 | 備註 |
|------|------|------|--------|------|
| **Unfractionated Heparin（UFH）** | 增強 **Antithrombin III** → 抑制 **IIa（thrombin）= Xa** | **aPTT** | **Protamine sulfate** | IV/SC；HIT（見下）；不過胎盤 → 孕婦可用 |
| **LMWH（Enoxaparin、Dalteparin）** | 增強 AT III → 主要抑制 **Xa > IIa** | **Anti-Xa level**（通常不需監測） | Protamine（部分拮抗） | SC；較少 HIT；較可預測的藥動學 |
| **Fondaparinux** | 增強 AT III → **選擇性抑制 Xa** | Anti-Xa | 無特定拮抗劑 | **不引起 HIT**（HIT 患者可用） |
| **Warfarin** | 抑制 **Vitamin K epoxide reductase（VKORC1）** → 抑制 Vitamin K 依賴凝血因子合成（**II、VII、IX、X** + Protein C、Protein S） | **PT / INR** | **Vitamin K（phytonadione）**；急性：FFP 或 PCC（prothrombin complex concentrate）或 **4F-PCC** | 口服；起效慢（需 3–5 天因既有因子半衰期）→ 初期需 bridge with heparin；Protein C/S 半衰期短 → 初期可能暫時性 **hypercoagulable → Warfarin-induced skin necrosis**（尤其 Protein C 缺乏者）；**孕婦禁忌（致畸）** |
| **DOACs** | — | 通常不需常規監測 | 見下 | — |
| **Dabigatran** | **Direct thrombin（IIa）inhibitor** | — | **Idarucizumab** | 腎排泄為主 → 腎功能不全慎用 |
| **Rivaroxaban、Apixaban、Edoxaban** | **Direct Factor Xa inhibitor** | — | **Andexanet alfa** | Apixaban 較少腎排泄 |

- **Warfarin 交互作用**：
    - 增強效果（INR↑）：CYP inhibitors（Amiodarone、Fluconazole、Metronidazole、TMP-SMX）、Aspirin、抗生素（減少腸道 Vit K 合成菌）
    - 減弱效果（INR↓）：CYP inducers（Rifampin、Barbiturates、Carbamazepine、Phenytoin）、Vitamin K 攝取增加
- **HIT（Heparin-Induced Thrombocytopenia）**：
    - Type II（免疫性，重要）：Anti-PF4/heparin Ab → 血小板活化 → **paradoxical thrombosis**（血小板↓ 但血栓↑）
    - 通常在使用 Heparin 5–10 天後（或曾暴露者 <24 hr）
    - 血小板下降 >50%
    - 處理：**立即停所有 Heparin**（包括 flush）→ 替代抗凝：**Argatroban**（direct thrombin inhibitor，肝代謝）或 **Bivalirudin**（直接凝血酶抑制劑）或 Fondaparinux
    - **不可用 Warfarin** 作為初始治療（加重血栓/壞死）→ 待血小板回復後才可轉換

#### 血栓溶解劑（Fibrinolytics）

| 藥物 | 特色 |
|------|------|
| **Alteplase（tPA）** | **纖維蛋白選擇性** → 選擇性溶解血栓中的 fibrin；STEMI、急性缺血性中風（4.5 hr 內）、大面積 PE |
| **Tenecteplase** | 改良型 tPA → 更長半衰期、可單次 bolus | 
| **Streptokinase** | 非選擇性；免疫原性 → 過敏反應；不可重複使用 |
| **Urokinase** | 非選擇性 | 

- 禁忌：活動性出血、近期手術/外傷、顱內出血史、主動脈剝離、血小板 <100,000
- 共同副作用：出血
- 解毒：**Aminocaproic acid / Tranexamic acid**（抗纖溶藥，抑制 plasminogen → plasmin）

## 四、呼吸系統藥理學

### 4.1 氣喘藥物

#### 控制型（Controllers）

| 藥物 | 機制 | 備註 |
|------|------|------|
| **Inhaled Corticosteroid（ICS）** | 抗發炎（抑制多種發炎細胞和細胞激素） | **氣喘長期控制最重要的藥物**；Beclomethasone、Budesonide、Fluticasone；副作用：口咽念珠菌、聲音嘶啞 → 用後漱口 |
| **LABA** | β₂ agonist（長效） | Salmeterol、Formoterol；**必須搭配 ICS，不可單用**（單用增加死亡率）；ICS/LABA 合用：Symbicort（Budesonide/Formoterol）、Advair（Fluticasone/Salmeterol） |
| **LTRA** | **Leukotriene receptor antagonist** | **Montelukast、Zafirlukast**；用於輕度持續性氣喘或 exercise-induced asthma；Zafirlukast 為 CYP inhibitor |
| **Zileuton** | **5-LOX inhibitor** → 抑制 leukotriene 合成 | 肝毒性 → 需監測 LFT |
| **Cromolyn / Nedocromil** | Mast cell stabilizer → 預防 degranulation | 預防性使用（exercise-induced）；兒童可用；效果弱於 ICS |
| **Omalizumab** | **Anti-IgE mAb** | 嚴重過敏性氣喘（IgE↑）；SC injection |
| **Mepolizumab / Reslizumab / Benralizumab** | Anti-IL-5 / Anti-IL-5R | 嚴重嗜酸性球性氣喘 |
| **Dupilumab** | Anti-IL-4Rα（阻斷 IL-4 和 IL-13） | 嚴重嗜酸性球性氣喘、異位性皮膚炎、CRSwNP |

| **Theophylline** | PDE inhibitor → cAMP↑ → 支氣管擴張 + 抗發炎 | **窄治療指數**；副作用：seizure、tachyarrhythmia、GI upset；CYP1A2 代謝 → Cimetidine、Erythromycin、Ciprofloxacin 增加濃度 |

| 藥物 | 機制 | 備註 |
|------|------|------|
| **SABA** | β₂ agonist（短效） | **Salbutamol（Albuterol）**：**急性氣喘發作首選**；副作用：tremor、tachycardia、hypokalemia |
| **SAMA** | Anticholinergic（短效） | **Ipratropium**：急性氣喘常與 SABA 合用；COPD 急性首選之一 |

### 4.2 COPD 藥物

- **穩定期治療**：
    - GOLD A：PRN SABA 或 SAMA
    - GOLD B：**LABA（Salmeterol、Indacaterol）** 或 **LAMA（Tiotropium）**
    - GOLD E：**LAMA + LABA**；若嗜酸性球↑ → + ICS（LABA/LAMA/ICS triple therapy）
- **急性惡化**：SABA + SAMA + 口服 Corticosteroid + 抗生素（若感染徵象）
- **Roflumilast**：口服 PDE4 inhibitor → 嚴重 COPD + 頻繁惡化 + 慢性支氣管炎表型

### 4.4 抗組織胺（Antihistamines）

| 世代 | 藥物 | 特色 |
|------|------|------|
| **第一代（H₁）** | **Diphenhydramine、Chlorpheniramine、Hydroxyzine、Promethazine、Dimenhydrinate、Meclizine、Cyproheptadine** | 穿越 BBB → **鎮靜**、anticholinergic 副作用；Promethazine 兼有抗多巴胺（antiemetic）；Meclizine → **暈動症**；Cyproheptadine → **serotonin syndrome 輔助治療、食欲促進** |

### 5.1 抑酸藥物

## 六、內分泌藥理學

### 6.1 糖尿病藥物

#### 胰島素（Insulin）

| 類型 | 代表 | Onset | Peak | Duration |
|------|------|-------|------|----------|
| **Rapid-acting** | **Lispro、Aspart、Glulisine** | 15 min | 1–2 hr | 3–5 hr |
| **Short-acting** | **Regular insulin** | 30 min | 2–4 hr | 6–8 hr |
| **Intermediate** | **NPH** | 1–2 hr | 6–12 hr | 12–18 hr |
| **Long-acting** | **Glargine、Detemir** | 1–2 hr | Flat（無明顯 peak） | **~24 hr** |
| **Ultra-long** | **Degludec** | 1 hr | Flat | **>42 hr** |

- Regular insulin 是唯一可 **IV 給藥** 的胰島素 → 用於 DKA
- 胰島素最嚴重副作用：**低血糖**
- Insulin + glucose → 治療**高血鉀**（將 K⁺ 驅入細胞）

#### 口服/非胰島素注射降血糖藥

| 類別 | 藥物 | 機制 | 副作用 | 備註 |
|------|------|------|--------|------|
| **Biguanide** | **Metformin** | 活化 AMPK → 肝臟糖質新生↓ + 周邊胰島素敏感性↑ | **乳酸酸中毒**（腎功能不全/缺氧狀態時）、GI upset、Vit B12↓ | **T2DM 一線首選**；不引起低血糖/體重增加；造影劑前需停藥（eGFR <30 禁用） |
| **Sulfonylureas** | **Glipizide、Glyburide、Glimepiride** | 阻斷 K_ATP channel → β-cell 去極化 → Insulin 分泌↑ | **低血糖**、體重↑ | 作用不依賴血糖濃度 → 低血糖風險；Glyburide 低血糖風險最高（活性代謝物、腎排泄） |
| **Meglitinides** | **Repaglinide、Nateglinide** | 類似 SU（K_ATP blocker）但短效 | 低血糖（較 SU 輕） | 餐前服用 |
| **Thiazolidinediones（TZD）** | **Pioglitazone、Rosiglitazone** | **PPAR-γ agonist** → 增加胰島素敏感性 | **體重↑、水腫、心衰惡化（禁用 NYHA III-IV）**、骨折↑（女性）、膀胱癌風險?（Pioglitazone） | — |
| **α-Glucosidase inhibitors** | **Acarbose、Miglitol** | 抑制小腸 α-glucosidase → 延緩碳水化合物消化 | 脹氣、腹瀉 | 降低餐後血糖 |
| **DPP-4 inhibitors（-gliptin）** | **Sitagliptin、Saxagliptin、Linagliptin** | 抑制 DPP-4 → GLP-1 不被降解 → 葡萄糖依賴性 Insulin↑ + Glucagon↓ | 鼻咽炎、胰臟炎（罕見） | 不引起低血糖（glucose-dependent） |
| **GLP-1 receptor agonists（-tide）** | **Exenatide、Liraglutide、Semaglutide、Dulaglutide** | 活化 GLP-1R → Insulin↑ + Glucagon↓ + 胃排空↓ + 食慾↓ | 噁心嘔吐（最常見）、胰臟炎、甲狀腺 C-cell tumor（動物實驗 → **MTC 家族史禁忌**） | **體重↓↓**；心血管保護（Liraglutide、Semaglutide）；口服 Semaglutide 可用 |
| **SGLT2 inhibitors（-gliflozin）** | **Empagliflozin、Dapagliflozin、Canagliflozin** | 抑制腎臟近端小管 SGLT2 → 尿糖排泄↑ | **泌尿道/生殖器黴菌感染**（最常見）、**正常血糖 DKA（euglycemic DKA）**、脫水/低血壓、Fournier's gangrene（罕見） | **心衰保護（HFrEF + HFpEF）**、**腎臟保護（延緩 CKD 進展）**；體重↓ |
| **Amylin analogue** | **Pramlintide** | 與 Insulin 共分泌 → 延緩胃排空 + Glucagon↓ + 飽足感↑ | 低血糖（與 Insulin 併用時） | SC injection |

### 6.2 甲狀腺藥物

#### 甲狀腺功能亢進治療

| 藥物 | 機制 | 備註 |
|------|------|------|
| **Methimazole（MMI）** | 抑制 TPO → T3/T4 合成↓ | **首選**（除懷孕第一孕期外）；副作用：**顆粒球缺乏症（agranulocytosis）**（最嚴重，需衛教發燒喉嚨痛立即就醫）、皮疹 |
| **Propylthiouracil（PTU）** | 抑制 TPO + **抑制周邊 T4→T3 轉換** | **懷孕第一孕期首選**（MMI 致畸：aplasia cutis）；副作用：agranulocytosis、**肝毒性**（比 MMI 嚴重） |
| **β-Blocker（Propranolol）** | 控制交感症狀 + 抑制 T4→T3 | 症狀控制 |
| **放射性碘（¹³¹I）** | 破壞甲狀腺組織 | Graves' disease 根治治療之一；**孕婦/哺乳禁忌** |
| **Lugol's solution / SSKI（飽和碘化鉀）** | **Wolff-Chaikoff effect** → 暫時抑制 T4 釋放 | **甲狀腺風暴急性期**使用；術前準備（降低甲狀腺血管豐富度） |

- **甲狀腺風暴（Thyroid storm）治療順序**：β-Blocker → PTU（或 MMI）→ 1 小時後給碘劑 → Corticosteroid（抑制 T4→T3）→ 支持療法

#### 甲狀腺功能低下

- **Levothyroxine（T4）**：**首選替代治療**
- **Liothyronine（T3）**：起效快但不穩定，少用於長期治療
- **Myxedema coma**：IV Levothyroxine（或 Liothyronine）+ IV Hydrocortisone

### 6.3 腎上腺皮質類固醇

#### 糖皮質素（Glucocorticoids）

| 藥物 | 抗發炎效力 | 鹽皮質素效力 | 半衰期 |
|------|-----------|-------------|--------|
| **Hydrocortisone（Cortisol）** | 1 | 1 | 短效（8–12 hr） |
| **Prednisone / Prednisolone** | 4 | 0.8 | 中效（12–36 hr） |
| **Methylprednisolone** | 5 | 0.5 | 中效 |
| **Dexamethasone** | 30 | 0 | 長效（36–72 hr） |
| **Fludrocortisone** | 10 | 125 | — |

- **用途**：抗發炎/免疫抑制（自體免疫、移植、過敏）、腎上腺功能不全替代、腦水腫（Dexamethasone）、早產肺部成熟（Betamethasone/Dexamethasone）
- **副作用（Cushing-like）**：
    - 代謝：高血糖、脂質異常、向心性肥胖、月亮臉、水牛肩
    - 骨骼：**骨質疏鬆**（最常見長期嚴重副作用）、**股骨頭缺血性壞死（AVN）**
    - 免疫：感染風險↑
    - 消化：消化性潰瘍（與 NSAIDs 併用風險↑）
    - 眼：白內障、青光眼
    - 心血管：高血壓、鈉水滯留
    - 皮膚：紫斑、皮膚萎縮、傷口癒合差
    - 精神：euphoria、insomnia、psychosis
    - **HPA axis suppression** → 長期使用不可突然停藥 → **Adrenal crisis**
    - 兒童：生長遲滯

### 6.4 骨質疏鬆藥物

| 類別 | 藥物 | 機制 | 備註 |
|------|------|------|------|
| **Bisphosphonates** | **Alendronate、Risedronate、Zoledronic acid** | 抑制 osteoclast（焦磷酸鹽類似物 → 嵌入骨質 → 被 osteoclast 攝取 → 誘導 apoptosis） | **一線治療**；口服需直立 30 分鐘 + 大量清水（預防食道潰瘍）；副作用：**下顎骨壞死（ONJ）**、非典型股骨骨折、食道炎 |
| **Denosumab** | Anti-RANKL mAb → 抑制 osteoclast 分化 | 每 6 月 SC；停藥後快速骨流失（rebound） |
| **Teriparatide（PTH 1-34）** | 間歇性 PTH → **促進造骨（anabolic）** | 嚴重骨質疏鬆/多處骨折；最多使用 2 年；禁忌：Paget's、骨肉瘤風險↑（大鼠） |
| **Raloxifene** | **SERM**（selective estrogen receptor modulator）→ 骨骼上 agonist、子宮/乳房上 antagonist | 停經後女性骨鬆；降低乳癌風險；副作用：**DVT/PE**（血栓風險↑）、潮熱 |
| **Calcitonin** | 抑制 osteoclast | 效力弱；用於急性椎體骨折止痛 |
| **Romosozumab** | Anti-sclerostin mAb → 促造骨 + 抑蝕骨 | 新藥；CV 風險需注意 |

### 6.5 痛風藥物

#### 急性發作

| 藥物 | 機制 | 備註 |

### 6.6 性荷爾蒙藥物

#### 雌激素/黃體素

| 藥物 | 用途 | 備註 |

## 七、中樞神經藥理學（CNS Pharmacology）

### 7.1 鎮靜安眠藥

#### Benzodiazepines（BZD）

- 機制：增強 **GABA_A receptor** 功能（增加 Cl⁻ channel **開啟頻率，frequency**）
- 代表：

| 藥物 | 特色 | 用途 |
|------|------|------|
| **Diazepam** | 長效、脂溶性高（快速穿越 BBB） | 焦慮、癲癇重積狀態、肌肉痙攣、酒精戒斷 |
| **Lorazepam** | 中效、**不經 CYP 代謝（直接 glucuronidation）** | **癲癇重積狀態 IV 首選**；肝功能不全首選 BZD |
| **Midazolam** | 短效、水溶性 | 術前鎮靜、程序性鎮靜 |
| **Alprazolam** | 中效 | 焦慮症、恐慌症 |
| **Triazolam** | 超短效 | 失眠 |
| **Chlordiazepoxide** | 長效 | **酒精戒斷首選** |
| **Clonazepam** | 長效 | 癲癇、恐慌症 |

- 副作用：鎮靜、失憶（anterograde amnesia）、呼吸抑制（與 opioid/alcohol 併用時）、依賴/戒斷
- **解毒劑：Flumazenil**（competitive GABA_A antagonist）→ 但可能誘發 seizure（長期 BZD 使用者）

#### Barbiturates

- 機制：增強 GABA_A receptor（增加 Cl⁻ channel **開啟時間，duration**）→ 高劑量直接打開通道（無 GABA 亦可）
- 代表：**Phenobarbital**（長效，抗癲癇）、**Thiopental**（超短效，全身麻醉誘導）
- 比 BZD 更危險：呼吸抑制強、治療指數窄、CYP inducer

#### 非 BZD 安眠藥（Z-drugs）

- **Zolpidem、Zaleplon、Eszopiclone**：選擇性 BZ₁（GABA_A α₁ subunit）→ 鎮靜為主，較少肌肉鬆弛/抗焦慮
- 較少依賴性，但仍有（尤其 Zolpidem 引起夢遊行為）

#### 其他

| 藥物 | 機制 | 用途 |
|------|------|------|
| **Ramelteon** | **Melatonin receptor agonist（MT₁/MT₂）** | 入睡困難型失眠；不列管 |
| **Suvorexant** | **Orexin（Hypocretin）receptor antagonist** | 失眠 |
| **Buspirone** | **5-HT₁A partial agonist** | **廣泛性焦慮症（GAD）**；起效慢（1–2 週）；不鎮靜、不成癮、不與 alcohol 交互 |

### 7.2 抗癲癇藥（Antiepileptic Drugs, AEDs）

| 藥物 | 主要機制 | 適應症 | 重要副作用 |
|------|---------|--------|-----------|
| **Phenytoin** | Na⁺ channel blocker | 全身強直-陣攣（GTCS）、局部發作 | **Zero-order kinetics** → 劑量微調引起大濃度變化；**牙齦增生（gingival hyperplasia）**、多毛症、巨母紅血球貧血（folate↓）、骨軟化（Vit D↓）、小腦萎縮、**SJS/TEN**（HLA-B*1502）、**Purple glove syndrome**（IV外滲）；CYP inducer；蛋白結合率高；**孕婦致畸（fetal hydantoin syndrome）** |
| **Carbamazepine** | Na⁺ channel blocker | GTCS、局部發作、**三叉神經痛首選** | **SIADH（低血鈉）**、agranulocytosis、aplastic anemia、**SJS/TEN**（HLA-B*1502）；CYP inducer（且自身代謝也被誘導 → autoinduction） |
| **Oxcarbazepine** | Na⁺ channel blocker | 類似 Carbamazepine | 低血鈉（比 CBZ 少其他副作用） |
| **Valproic acid（VPA）** | Na⁺ channel blocker + GABA↑ + T-type Ca²⁺ channel blocker | **廣效**：GTCS、absence、myoclonic、局部 | **肝毒性（兒童 <2 歲）**、胰臟炎、**致畸（neural tube defect → 補充 folic acid）**、血小板↓、tremor、體重↑、多囊卵巢、脫髮；CYP inhibitor |
| **Ethosuximide** | **T-type Ca²⁺ channel blocker** | **Absence seizure（失神發作）首選** | GI upset、嗜睡；不治療 GTCS |
| **Lamotrigine** | Na⁺ channel blocker | 廣效（GTCS、局部、absence、bipolar maintenance） | **SJS/TEN**（緩慢增量以減少風險；VPA 會升高 Lamotrigine 濃度 → 更需慢慢加量） |
| **Levetiracetam** | SV2A protein 結合 | 廣效、add-on therapy | 精神行為副作用（易怒）；藥物交互作用少 → 優勢 |
| **Topiramate** | Na⁺ channel + GABA↑ + AMPA/Kainate antagonist + CA inhibitor | 廣效；migraine 預防 | **腎結石**、代謝性酸中毒、體重↓、認知障礙（word-finding difficulty）、青光眼 |
| **Gabapentin / Pregabalin** | α₂δ Ca²⁺ channel subunit 結合 → Ca²⁺ influx↓ → glutamate↓ | 局部發作 add-on；**neuropathic pain**、Fibromyalgia（Pregabalin）、postherpetic neuralgia | 鎮靜、頭暈、水腫；腎排泄 |
| **Vigabatrin** | 不可逆抑制 GABA transaminase → GABA↑ | **Infantile spasms（West syndrome）** 首選之一 | **永久性視野缺損**（需定期眼科追蹤） |
| **Benzodiazepines（Diazepam, Lorazepam）** | GABA_A 增強 | **Status epilepticus 首選** | 鎮靜、呼吸抑制 |
| **Phenobarbital** | GABA_A（延長開啟時間）| Status epilepticus 二/三線 | 鎮靜、CYP inducer |

- **Status Epilepticus 治療順序**：**BZD（Lorazepam IV）** → **Fosphenytoin/Phenytoin IV** 或 **Valproic acid IV** 或 **Levetiracetam IV** → Phenobarbital → 全身麻醉（Propofol、Midazolam infusion、Pentobarbital）
- **孕婦首選 AED**：**Lamotrigine**（致畸風險較低）或 Levetiracetam

### 7.5 抗精神病藥

#### 典型（First-generation, FGA）

- 機制：**D₂ receptor antagonist**
- 高效價：**Haloperidol、Fluphenazine** → EPS 風險↑↑，鎮靜↓
- 低效價：**Chlorpromazine** → EPS 風險↓，鎮靜↑↑、anticholinergic↑、hypotension↑

| 副作用 | 說明 |
|--------|------|
| **EPS（錐體外症狀）** | 急性肌張力障礙（dystonia，數小時-天 → 治療：**Benztropine/Diphenhydramine**）；靜坐不能（akathisia → β-blocker/BZD）；Parkinsonism（數週 → Benztropine）；**遲發性運動障礙（Tardive dyskinesia, TD）**（數月-年，可能不可逆 → 治療：**Valbenazine/Deutetrabenazine**（VMAT2 inhibitor）） |
| **高泌乳素血症** | 乳漏、月經異常、性功能障礙、男性女乳症 |
| **Neuroleptic Malignant Syndrome（NMS）** | 高燒 + 肌肉僵硬（lead-pipe rigidity）+ 自律神經失調 + 意識改變 + CK↑↑ → 治療：停藥 + **Dantrolene**（+ Bromocriptine） |
| **QT 延長 → TdP** | 尤其 Thioridazine、Droperidol |
| **抗膽鹼作用** | 低效價較多 |
| **α₁ 阻斷** | 姿勢性低血壓 |

#### 非典型（Second-generation, SGA）

| 藥物 | 特色 | 重要副作用 |
|------|------|-----------|
| **Clozapine** | **治療抵抗型思覺失調症唯一有效藥物**；EPS 風險最低 | **Agranulocytosis**（需定期 CBC/ANC 監測）；體重↑↑；代謝症候群；**seizure**（劑量相關）；myocarditis；流涎（paradoxical） |
| **Risperidone** | D₂ + 5-HT₂A | EPS（SGA 中最高）；高泌乳素血症（SGA 中最高） |
| **Olanzapine** | D₂ + 5-HT₂A + M + H₁ | **體重↑↑↑（SGA 中最多）**；代謝症候群（高血糖、DM、dyslipidemia）；鎮靜 |
| **Quetiapine** | D₂ + 5-HT₂A + H₁ + α₁ | 鎮靜↑↑；體重↑；用於 bipolar depression、insomnia（低劑量） |
| **Aripiprazole** | D₂ **partial agonist** + 5-HT₂A antagonist + 5-HT₁A partial agonist | EPS 低；體重影響小；akathisia |
| **Ziprasidone** | D₂ + 5-HT₂A | **QT 延長**；體重影響最小 |
| **Lurasidone** | D₂ + 5-HT₂A + 5-HT₇ | Bipolar depression（與食物併服增加吸收）；代謝影響小 |

### 7.6 抗鬱藥

| 類別 | 藥物 | 機制 | 副作用 | 備註 |
|------|------|------|--------|------|
| **SSRI** | **Fluoxetine、Sertraline、Paroxetine、Citalopram、Escitalopram、Fluvoxamine** | 選擇性抑制 5-HT 再回收 | **GI（噁心）**、性功能障礙、失眠/鎮靜、**SIADH（低血鈉，老人）**、Serotonin syndrome、初期焦慮↑ | **MDD 一線首選**；Fluoxetine 半衰期長（停藥戒斷少）、CYP2D6 inhibitor；Paroxetine：anticholinergic 最強、孕婦避免（心臟畸形） |

| **Atypical** | — | — | — | — |
| | **Bupropion** | NE + DA 再回收抑制 | **不引起性功能障礙和體重增加**（反而可能體重↓）；降低 seizure threshold → **seizure disorder/eating disorder 禁忌** | MDD + 戒菸 |
| | **Mirtazapine** | α₂ antagonist + 5-HT₂/5-HT₃ antagonist + H₁ antagonist | **鎮靜↑↑（H₁）、體重↑↑（食慾↑）** | MDD + 失眠 + 體重低的患者 |

- **Serotonin Syndrome**：5-HT 過多 → 三聯征：**精神狀態改變 + 自律神經不穩（高燒、tachycardia、diaphoresis）+ 神經肌肉異常（clonus、hyperreflexia、tremor）**

    - vs. NMS：NMS 為 lead-pipe rigidity（肌肉僵硬），Serotonin syndrome 為 clonus/hyperreflexia

| **Morphine** | μ full agonist | 標準強效止痛藥；副作用：呼吸抑制、便秘（最常見，不產生耐受性）、噁心嘔吐、鎮靜、miosis、尿滯留、搔癢（histamine 釋放）、耐受與依賴 |
| **Fentanyl** | μ full agonist | 效力為 Morphine 100 倍；貼片/IV/lozenge；短效（IV） |
| **Methadone** | μ agonist + NMDA antagonist | 長效（長半衰期）→ **Opioid 戒癮替代治療**；延長 QT |
| **Meperidine（Pethidine）** | μ agonist | 活性代謝物 normeperidine → seizure；**與 MAOi 併用禁忌 → Serotonin syndrome** |
| **Codeine** | μ agonist（弱）；CYP2D6 → Morphine | 鎮咳、輕度止痛；ultra-rapid metabolizer → 毒性↑ |
| **Tramadol** | 弱 μ agonist + SNRI | 中等止痛；Serotonin syndrome 風險；seizure 風險↓ |
| **Buprenorphine** | **μ partial agonist + κ antagonist** | **Opioid 戒癮**（Suboxone = Buprenorphine + Naloxone）；ceiling effect for respiratory depression → 較安全 |
| **Nalbuphine** | κ agonist + μ antagonist | 止痛；ceiling effect |

- **Opioid 拮抗劑**：
    - **Naloxone**：短效 μ antagonist → **Opioid 過量解毒首選（IV/IM/IN）**
    - **Naltrexone**：長效口服 μ antagonist → **酒精/Opioid 依賴預防復發**
    - **Methylnaltrexone / Naloxegol**：周邊 μ antagonist → **Opioid-induced constipation（OIC）**（不穿越 BBB → 不影響止痛）

### 7.10 全身麻醉藥

#### 吸入性麻醉劑

| 藥物 | 特色 |
|------|------|
| **Halothane** | **肝毒性**（halothane hepatitis）；**惡性高熱**；心律不整（sensitize myocardium to catecholamine）；兒童面罩誘導 |
| **Isoflurane** | 冠竊現象（coronary steal）；較少肝毒性 |
| **Sevoflurane** | **兒童吸入誘導首選**（不刺激呼吸道）；compound A（腎毒性） |
| **Desflurane** | 起效/恢復最快；刺激呼吸道 → 不適合誘導 |
| **Nitrous Oxide（N₂O）** | 止痛效果好但麻醉效力弱（MAC >100%）→ 需合併其他藥物；**擴張封閉腔室**（禁忌：氣胸、腸阻塞、中耳手術）；長期使用 → Vit B12↓ → megaloblastic anemia |

- **MAC（Minimum Alveolar Concentration）**：50% 患者對手術刺激不動所需的肺泡濃度 → MAC 越低越強效
- N₂O MAC 最高（>100%）→ 最弱
- 所有吸入麻醉劑（除 N₂O）皆可引起 **Malignant Hyperthermia** → 治療：**Dantrolene**

#### 靜脈麻醉劑

| 藥物 | 特色 |
|------|------|
| **Propofol** | 起效快、恢復快；**降腦壓**；副作用：低血壓（最常見）、呼吸抑制、**propofol infusion syndrome**（長期高劑量 → 代謝性酸中毒、心衰、橫紋肌溶解）；注射痛 |
| **Etomidate** | 心血管穩定性最佳 → **血行動力學不穩患者誘導首選**；副作用：**adrenal suppression**（抑制 11β-hydroxylase）、myoclonus |
| **Ketamine** | NMDA antagonist；**唯一增加 BP/HR** 的 IV 麻醉劑 → 適合 hypovolemic shock 患者；解離性麻醉；止痛效果佳；副作用：emergence reaction（惡夢、幻覺）→ 合併 BZD 預防；**顱內壓↑** |

### 7.11 局部麻醉藥

- 機制：阻斷 **Na⁺ channel** → 阻斷動作電位傳導
- **Esters**：Procaine、Tetracaine、Cocaine、Benzocaine → 被 pseudocholinesterase 水解 → 過敏較常見（PABA 代謝物）
- **Amides**：**Lidocaine**、Bupivacaine、Ropivacaine、Mepivacaine、Prilocaine → 肝臟代謝 → 過敏罕見
- 記法：Amides 有兩個 "i"（Lidoca**i**ne, Bup**i**vacaine）
- **阻斷順序**：先阻斷小纖維（痛覺/溫覺 → C fiber, Aδ fiber）→ 後阻斷大纖維（觸覺/運動）
- **毒性**：CNS 先興奮後抑制（tinnitus → seizure → coma → respiratory arrest）；心臟毒性（**Bupivacaine 心臟毒性最強** → 解毒：**Intralipid（lipid emulsion）**）
- **Prilocaine** → **methemoglobinemia** → 治療：**Methylene blue**
- **Cocaine**：唯一具有血管收縮作用（抑制 NE 再回收）

## 八、抗感染藥理學（Antimicrobial Pharmacology）

### 8.1 細胞壁合成抑制劑

#### β-Lactams

| 類別 | 代表藥物 | 抗菌譜 | 備註 |
|------|---------|--------|------|
| **Penicillin G/V** | Penicillin G（IV）、Pen V（PO） | GPC（Strep）；梅毒 | 過敏反應（anaphylaxis） |
| **Aminopenicillins** | **Ampicillin、Amoxicillin** | GPC + 部分 GNR（E. coli, H. flu, Proteus）、Listeria、Enterococcus | Amoxicillin 口服吸收好；EBV 感染給 Ampicillin → **皮疹** |
| **Anti-staphylococcal** | **Nafcillin、Oxacillin、Dicloxacillin** | **MSSA**（penicillinase-resistant） | 不適用 MRSA |
| **Anti-pseudomonal** | **Piperacillin（+ Tazobactam）、Ticarcillin** | GNR 包括 Pseudomonas、Enterobacteriaceae、anaerobes | **Piperacillin/Tazobactam（Zosyn）**：廣效（院內感染） |
| **+ β-Lactamase inhibitor** | Clavulanate、Sulbactam、Tazobactam | 恢復被 β-lactamase 降解的 penicillin 活性 | Amoxicillin-Clavulanate（Augmentin）；Ampicillin-Sulbactam（Unasyn） |

#### Cephalosporins

| 世代 | 代表 | 特色 |
|------|------|------|
| **1st** | **Cefazolin（IV）、Cephalexin（PO）** | **MSSA、Strep**；**手術預防感染首選（Cefazolin）** |
| **2nd** | Cefoxitin、Cefuroxime | + H. flu；Cefoxitin 抗 anaerobe（用於腹腔感染） |
| **3rd** | **Ceftriaxone、Cefotaxime、Ceftazidime** | **廣效 GNR**；Ceftriaxone：穿越 BBB → **細菌性腦膜炎首選**（N. meningitidis, S. pneumoniae, H. flu）；Ceftazidime：anti-**Pseudomonas** |
| **4th** | **Cefepime** | 3rd + **Pseudomonas** + GPC | 院內感染 |
| **5th** | **Ceftaroline** | **MRSA**（唯一 Cephalosporin 有效對抗 MRSA） + community-acquired pneumonia pathogens |

- **Cephalosporin 過敏交叉反應**：Penicillin 過敏者約 1–2% 交叉反應（低風險可用；嚴重 PCN anaphylaxis → 避免或先做 skin test）

#### Carbapenems

- **Imipenem（+ Cilastatin）、Meropenem、Ertapenem、Doripenem**
- **最廣效 β-lactam**：幾乎所有 G(+)/G(−)/anaerobes（除 MRSA、Atypicals）
- Imipenem 需 Cilastatin（抑制腎臟 dehydropeptidase → 防止分解）；**Imipenem 降低 seizure threshold**（CNS 感染較不推薦 → 改用 Meropenem）
- Ertapenem：不涵蓋 Pseudomonas
- **Carbapenem-resistant organisms（CRE）** → 使用 Ceftazidime-avibactam、Meropenem-vaborbactam、Cefiderocol

#### Monobactam

- **Aztreonam**：僅對 **GNR**（包括 Pseudomonas）有效；對 GPC 和 anaerobes 無效
- **Penicillin 嚴重過敏者可安全使用**（無交叉反應）

#### Glycopeptides

- **Vancomycin**：抑制 cell wall 合成（結合 D-Ala-D-Ala）
    - 抗菌譜：**MRSA**（首選 IV）、C. difficile（**口服 Vancomycin** 用於 CDI）
    - 副作用：**Red man syndrome**（histamine 釋放 → 非過敏 → 減慢輸注速度 + Antihistamine 預防）；**腎毒性**（與 Aminoglycosides 協同腎毒性↑）；**耳毒性**
    - 需監測 trough level
- **Teicoplanin**：類似 Vancomycin
- **VRE（Vancomycin-Resistant Enterococcus）**→ 治療：**Linezolid** 或 **Daptomycin**

#### 其他細胞壁相關

- **Daptomycin**：脂肪肽 → 插入細菌細胞膜 → 去極化 → 死亡
    - 用途：MRSA 菌血症、VRE
    - 注意：**被 surfactant 不活化 → 不可用於肺炎**
    - 副作用：**CPK↑（myopathy）** → 需監測
- **Fosfomycin**：抑制 MurA → 口服用於 **uncomplicated UTI（單劑）**

### 8.2 蛋白質合成抑制劑

#### 30S subunit

| 藥物 | 機制 | 備註 |
|------|------|------|
| **Aminoglycosides**（Gentamicin、Tobramycin、Amikacin、Streptomycin） | 結合 30S → 殺菌（concentration-dependent） | 抗 GNR（aerobic）；與 β-lactam **協同**對抗 Enterococcus/Pseudomonas；副作用：**腎毒性 + 耳毒性**（不可逆前庭/耳蝸損傷）→ 需監測 peak/trough；不穿越 BBB；不口服吸收（除非用於 hepatic encephalopathy 腸道去污）；**禁忌與 Loop diuretics 併用（加重耳毒性）** |

| **Linezolid** | 結合 50S（23S rRNA）→ 靜菌 | **VRE、MRSA**（肺炎可用）；副作用：**骨髓抑制（thrombocytopenia）**；**Serotonin syndrome**（弱 MAOi）→ 與 SSRI 併用注意；**周邊/視神經病變**（長期使用） |

### 8.3 核酸合成抑制劑

| 藥物 | 機制 | 備註 |
|------|------|------|
| **Fluoroquinolones**（Ciprofloxacin、Levofloxacin、Moxifloxacin） | 抑制 **DNA gyrase（Topoisomerase II）** + **Topoisomerase IV** → 殺菌 | Ciprofloxacin：GNR（Pseudomonas）；Levofloxacin/Moxifloxacin：respiratory FQ（Strep pneumo, atypicals）；副作用：**Tendon rupture（Achilles）**、**QT 延長**、CNS（seizure、insomnia）、**C. diff**、光敏感、peripheral neuropathy、aortic aneurysm/dissection；**<18 歲避免**（軟骨損傷）；Moxifloxacin 不尿排 → UTI 無效；Cipro 為 CYP1A2 inhibitor（Theophylline 濃度↑） |

| **Sulfonamides / Trimethoprim** | 抑制 folate synthesis → 靜菌 | TMP-SMX（Bactrim）：UTI、PJP prophylaxis/treatment、MRSA 皮膚感染；副作用：**Megaloblastic anemia（folate↓）**、骨髓抑制、**SJS/TEN**、sulfa allergy、kernicterus（新生兒禁忌 → 置換 bilirubin）、高血鉀（TMP 抗 ENaC） |
| **Nitrofurantoin** | 多重機制 → 破壞 DNA | 下泌尿道感染（UTI prophylaxis/treatment）；不達有效血清濃度 → 僅限 UTI；副作用：**肺纖維化**（長期）；GI upset；**G6PD 缺乏禁忌** |

### 8.4 抗結核藥

| 藥物 | 機制 | 副作用 |
|------|------|--------|
| **Isoniazid（INH）** | 抑制 mycolic acid 合成（enoyl-ACP reductase） | **肝毒性**（最重要）；**周邊神經炎**（Vit B6↓ → 需補充 **Pyridoxine**）；SLE-like（anti-histone）；CYP inhibitor；慢乙醯化者毒性↑ |
| **Rifampin（RIF）** | RNA polymerase 抑制 | 見上方；體液變色；CYP inducer；肝毒性 |
| **Pyrazinamide（PZA）** | 殺菌（酸性環境，針對胞內菌）| **高尿酸（最常見副作用）** → 痛風；肝毒性 |
| **Ethambutol（EMB）** | 抑制 arabinosyl transferase → cell wall 合成↓ | **視神經炎（optic neuritis）**：紅綠色辨識障礙 → 定期視力檢查；兒童難以測試 → 有時改用 |

- **標準 TB 治療（RIPE）**：**INH + RIF + PZA + EMB × 2 個月 → INH + RIF × 4 個月**（總共 6 個月）
- **潛伏 TB（LTBI）**：INH × 9 個月 或 RIF × 4 個月 或 INH + Rifapentine × 3 個月（3HP）

### 8.6 抗病毒藥

| 藥物 | 機制 | 備註 |

#### 抗 HCV

- **DAAs（Direct-Acting Antivirals）**：
    - **Sofosbuvir**：NS5B polymerase inhibitor → 幾乎所有方案的 backbone
    - **Ledipasvir**：NS5A inhibitor → Harvoni = Sofosbuvir + Ledipasvir
    - **Velpatasvir**：NS5A inhibitor → Epclusa = Sofosbuvir + Velpatasvir（**pan-genotypic**）
    - **Glecaprevir + Pibrentasvir**：NS3/4A protease inhibitor + NS5A → Mavyret（pan-genotypic，8 週）
- 治癒率 >95%

#### 抗 HIV（HAART / ART）

| 類別 | 藥物 | 機制 | 副作用 |
|------|------|------|--------|
| **NRTIs** | **Tenofovir（TDF/TAF）、Emtricitabine（FTC）、Abacavir（ABC）、Zidovudine（AZT）、Lamivudine（3TC）** | Nucleos(t)ide reverse transcriptase inhibitor → chain terminator | TDF：**腎毒性、Fanconi syndrome、骨密度↓**；AZT：**骨髓抑制（macrocytic anemia）**；ABC：**HLA-B*5701** 過敏反應 → 使用前檢測；Didanosine/Stavudine：pancreatitis、peripheral neuropathy、lipoatrophy（已少用）；**所有 NRTI：乳酸酸中毒（mitochondrial toxicity）** |
| **NNRTIs** | **Efavirenz（EFV）、Nevirapine（NVP）、Rilpivirine、Doravirine** | Non-nucleoside RTI → 結合 RT allosteric site | EFV：**CNS 副作用**（vivid dreams, dizziness）、致畸；NVP：**SJS/TEN、肝毒性**；低耐藥屏障 |
| **PIs（-navir）** | **Atazanavir、Darunavir、Lopinavir/Ritonavir** | Protease inhibitor | **代謝症候群（lipodystrophy、高血糖、dyslipidemia）**；GI upset；Atazanavir：**indirect hyperbilirubinemia**（類似 Gilbert）、腎結石；皆需 **boosting**（Ritonavir 或 Cobicistat 作為 CYP3A4 inhibitor 增加濃度） |
| **INSTIs（-tegravir）** | **Dolutegravir（DTG）、Bictegravir（BIC）、Raltegravir（RAL）、Elvitegravir（EVG）** | Integrase strand transfer inhibitor | 高耐藥屏障（DTG, BIC）；副作用少（insomnia, headache）；DTG → 體重↑ |

| **CCR5 antagonist** | **Maraviroc** | 阻斷 CCR5 coreceptor → 抑制 HIV entry | 需先做 **tropism assay**（僅 R5-tropic 有效） |
| **Post-attachment inhibitor** | **Ibalizumab** | Anti-CD4 mAb | 多重抗藥 HIV |

- **一線 ART 方案**：2 NRTIs（TDF/TAF + FTC or ABC + 3TC）+ **INSTI（DTG 或 BIC）**
- **Biktarvy = BIC + TAF + FTC**（常用）

## 十一、NSAIDs 與止痛藥

### 11.1 NSAIDs

- 機制：抑制 **COX（Cyclooxygenase）** → Prostaglandin 合成↓
    - **COX-1**：constitutive → 胃黏膜保護、血小板 TXA₂、腎血流維持
    - **COX-2**：inducible → 發炎、疼痛、發燒

| 藥物 | 選擇性 | 特色 |
|------|--------|------|
| **Aspirin** | COX-1 = COX-2（**不可逆**） | 低劑量：抗血小板；中劑量：止痛解熱；高劑量：抗發炎；副作用：GI出血、Reye syndrome（兒童禁忌）、呼吸性鹼中毒 → 代謝性酸中毒（中毒）；過敏者可能有 aspirin-exacerbated respiratory disease（AERD / Samter's triad：asthma + nasal polyps + aspirin sensitivity） |
| **Ibuprofen** | 非選擇性 | OTC 止痛解熱；closure of PDA |
| **Naproxen** | 非選擇性 | 半衰期較長；心血管風險相對較低 |
| **Indomethacin** | 非選擇性（COX-1偏重） | **Gout 急性發作**；**PDA closure**；副作用較多（GI、CNS） |
| **Ketorolac** | 非選擇性 | **最強止痛 NSAID**（IV/IM）；僅短期使用（≤5 天）；GI 出血風險高 |
| **Diclofenac** | 非選擇性 | 外用/口服；肝毒性（需監測 LFT） |
| **Piroxicam** | 非選擇性 | 長效；GI 副作用多 |
| **Meloxicam** | **COX-2 偏重** | RA/OA |
| **Celecoxib** | **COX-2 選擇性** | 較少 GI 副作用（但非零風險）；**心血管風險↑（sulfa allergy 禁忌）** |

- **NSAIDs 共同副作用**：
    - **GI**：胃潰瘍/出血（COX-1 保護胃黏膜↓）→ 預防：PPI、Misoprostol
    - **腎臟**：急性腎損傷（腎血流依賴 PG 者：心衰、肝硬化、脫水）；間質性腎炎；Analgesic nephropathy
    - **心血管**：MI/stroke 風險↑（COX-2 選擇性更明顯 → rofecoxib 下架）；高血壓；鈉水滯留
    - **血小板**：出血風險↑（非選擇性）
    - **過敏/pseudoallergic**：aspirin-exacerbated respiratory disease
    - **孕婦**：第三孕期禁用（PDA 早閉）

### 11.2 Acetaminophen（Paracetamol）

- **不具抗發炎作用**（非 NSAID）→ 中樞 COX 抑制為主
- 用途：止痛、解熱（兒童/孕婦安全選擇）
- **過量 → 肝臟壞死**：
    - 機制：CYP2E1 產生 **NAPQI** → 消耗 Glutathione → 肝細胞壞死
    - 解毒：**N-Acetylcysteine（NAC）** → 補充 Glutathione
    - Rumack-Matthew nomogram 判斷治療需要

## 十四、重要藥物交互作用速查

| 組合 | 後果 | 機制 |
|------|------|------|
| **Warfarin + Rifampin** | INR↓ → 血栓 | Rifampin 為強 CYP inducer |
| **Warfarin + Amiodarone** | INR↑ → 出血 | Amiodarone 為 CYP inhibitor |
| **Statins + Fibrates（Gemfibrozil）** | Rhabdomyolysis | 競爭 glucuronidation |
| **Digoxin + Amiodarone/Verapamil/Quinidine** | Digoxin 濃度↑ → 中毒 | 抑制 P-glycoprotein |
| **Digoxin + Hypokalemia** | Digoxin toxicity↑ | K⁺ 與 Digoxin 競爭 Na⁺/K⁺-ATPase |
| **Lithium + Thiazide/NSAIDs** | Lithium 毒性↑ | 腎臟 Li⁺ 排泄↓ |
| **MAOi + Tyramine-rich food** | Hypertensive crisis | NE 大量釋放 |
| **MAOi + SSRI/Meperidine** | Serotonin syndrome | 5-HT↑↑↑ |
| **Methotrexate + TMP-SMX** | 骨髓抑制↑ | 均抑制 folate pathway |
| **Azathioprine + Allopurinol** | 骨髓抑制↑ | Allopurinol 抑制 XO → 6-MP 累積 |
| **Clopidogrel + Omeprazole** | Clopidogrel 效果↓ | Omeprazole 抑制 CYP2C19（活化 Clopidogrel 所需） |
| **Aminoglycoside + Loop diuretic** | 耳毒性↑ | 協同作用 |
| **NTG/Nitrate + Sildenafil** | 嚴重低血壓 | NO/cGMP pathway 疊加 |
| **Theophylline + Ciprofloxacin** | Theophylline 毒性↑ | CYP1A2 inhibition |
| **Cyclosporine + Aminoglycoside** | 腎毒性↑ | 協同腎毒性 |
