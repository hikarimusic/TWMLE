## 一、細胞損傷與適應（Cell Injury & Adaptation）

### 1.1 細胞適應（Cellular Adaptation）

| 適應類型 | 定義 | 舉例 |
|----------|------|------|
| **Hypertrophy（肥大）** | 細胞**體積增大**（非數目增加） | 左心室肥大（高血壓）、子宮平滑肌肥大（懷孕）、骨骼肌重訓 |
| **Hyperplasia（增生）** | 細胞**數目增加** | 子宮內膜增生（estrogen）、前列腺良性增生（BPH）、肝再生 |
| **Atrophy（萎縮）** | 細胞**體積縮小** | 去神經萎縮、廢用萎縮、壓迫萎縮、營養不良萎縮 |
| **Metaplasia（化生）** | 一種分化成熟細胞**轉變為另一種**分化成熟細胞 | Barrett esophagus（鱗狀→柱狀）、支氣管吸菸（柱狀→鱗狀）、膀胱結石（移行→鱗狀） |
| **Dysplasia（分化不良）** | 細胞增生伴形態異常，為**癌前病變** | 子宮頸上皮內贅瘤（CIN）、Barrett esophagus with dysplasia |

- **Hypertrophy vs Hyperplasia**：不能分裂的細胞（心肌、神經）只能 hypertrophy；可分裂的細胞可兩者並存
- **Metaplasia**：由幹細胞重新分化而來，非成熟細胞直接轉變；本身不是癌，但可作為癌前狀態（如 Barrett → adenocarcinoma）
- **Dysplasia**：若**未突破基底膜** → carcinoma in situ（原位癌），仍屬癌前；突破基底膜 → invasive carcinoma

### 1.2 可逆性細胞損傷（Reversible Cell Injury）

- **細胞腫脹（Cellular swelling）**：最早且最常見的變化；Na⁺/K⁺-ATPase 功能障礙 → 細胞內 Na⁺ 及水↑
- **脂肪變性（Fatty change / Steatosis）**：主要見於**肝臟**及心臟；肝細胞內脂質空泡
- **ER 腫脹、粒線體輕度腫脹**
- **核糖體脫離粗面 ER** → 蛋白質合成↓
- 細胞質嗜酸性增加（eosinophilia）

### 1.3 不可逆細胞損傷與細胞死亡

#### 壞死（Necrosis）

| 壞死類型 | 特徵 | 代表疾病 |
|----------|------|----------|
| **Coagulative necrosis（凝固性壞死）** | 細胞輪廓保留（「幽靈細胞」），蛋白質變性 | **大多數器官梗塞**（心、腎、脾）；**腦除外** |
| **Liquefactive necrosis（液化性壞死）** | 組織完全溶解成液態 | **腦梗塞**、**細菌性膿瘍**（neutrophil 釋放酵素） |
| **Caseous necrosis（乾酪性壞死）** | 無定形、顆粒狀壞死物質，像乾酪 | **結核病（TB）**、真菌感染 |
| **Fat necrosis（脂肪壞死）** | 脂肪酶釋放 → 脂肪酸 + 鈣結合 → **皂化反應（saponification）** | **急性胰臟炎** |
| **Fibrinoid necrosis（纖維素樣壞死）** | 血管壁 Ag-Ab 複合物沉積，呈亮粉紅色 | **惡性高血壓**、血管炎 |
| **Gangrenous necrosis** | 凝固性壞死（乾性壞疽）；若合併感染 → 濕性壞疽（液化性壞死）；氣性壞疽（Clostridium perfringens） | 糖尿病足、肢體缺血 |

#### 凋亡（Apoptosis）

| | **壞死（Necrosis）** | **凋亡（Apoptosis）** |
|--|---------------------|---------------------|
| 觸發 | 病理性（缺血、毒素） | 生理或病理性 |
| 影響範圍 | 一群細胞 | 單個細胞 |
| 細胞大小 | 腫脹 | **縮小** |
| 細胞膜 | 破裂 | 完整（形成凋亡小體） |
| 發炎反應 | **有**（內容物外洩） | **無**（被吞噬清除） |
| 能量需求 | 不需要 | 需要（ATP-dependent） |
| 核變化 | Karyolysis / Karyorrhexis / Pyknosis | DNA ladder pattern（核小體間斷裂） |

- **Apoptosis 路徑**：
    - **內在途徑（Intrinsic / Mitochondrial）**：細胞壓力 → Bcl-2 家族調控 → cytochrome c 從粒線體釋出 → 活化 **caspase-9** → caspase-3（effector）
        - **Bcl-2**：**抗凋亡**（抑制 cytochrome c 釋出）；Bcl-2 過度表現 → **濾泡性淋巴瘤**（t(14;18)）
        - **Bax / Bak**：促凋亡
    - **外在途徑（Extrinsic / Death Receptor）**：Fas-FasL 或 TNF receptor → 活化 **caspase-8** → caspase-3
    - **p53**：DNA 受損感應 → 促凋亡（活化 Bax）；**p53 突變 → 多種癌症**（Li-Fraumeni syndrome）

### 1.4 細胞內堆積（Intracellular Accumulations）

| 堆積物 | 舉例 |
|--------|------|
| **脂質** | 肝脂肪變性（酒精、代謝症候群）；動脈粥狀硬化（foam cells） |
| **蛋白質** | Mallory-Denk bodies（酒精性肝炎，受損角蛋白中間絲）；Russell bodies（漿細胞內 Ig 堆積） |
| **糖原** | 糖尿病（腎小管、肝細胞）；糖原儲積症 |
| **色素** | Lipofuscin（老化色素，不致病）；Hemosiderin（鐵，血鐵沉積症）；Carbon（anthracosis）；Bilirubin（黃疸） |
| **鈣化** | **Dystrophic**：沉積於壞死/受損組織（血鈣正常）；**Metastatic**：沉積於正常組織（血鈣升高，如 hyperPTH、sarcoidosis、骨轉移） |

### 1.5 自由基與氧化壓力

- **自由基來源**：粒線體氧化磷酸化、細胞色素 P450、NADPH oxidase（neutrophil respiratory burst）、輻射、化學物質（CCl₄）
- **重要 ROS**：Superoxide（O₂⁻）、Hydrogen peroxide（H₂O₂）、Hydroxyl radical（OH·，最具破壞力）
- **抗氧化防禦**：
    - **SOD（Superoxide dismutase）**：O₂⁻ → H₂O₂
    - **Catalase**：H₂O₂ → H₂O（在 peroxisome）
    - **Glutathione peroxidase**：H₂O₂ → H₂O（需 glutathione）
- **損傷機制**：脂質過氧化（膜損傷）、蛋白質氧化修飾、DNA 損傷
- **CCl₄ 中毒**：P450 代謝 → 自由基 → 肝細胞脂肪變性及壞死

## 二、發炎（Inflammation）

### 2.1 急性發炎（Acute Inflammation）

- **五大徵象（Cardinal Signs）**：紅（rubor）、腫（tumor）、熱（calor）、痛（dolor）、功能喪失（functio laesa）
- **三大事件**：
    1. **血管擴張**：Histamine、NO → arteriole 擴張 → 血流↑ → 紅、熱
    2. **血管通透性增加**：Histamine → venule 內皮收縮 → 血漿蛋白外滲 → **滲出液（exudate）** → 腫
    3. **白血球趨化與吞噬**

#### 白血球遷移步驟（Leukocyte Extravasation）

1. **Margination & Rolling**：selectins（E-selectin, P-selectin on endothelium; L-selectin on leukocyte）結合 sialyl-Lewis X → 慢速滾動
2. **Activation**：chemokines（IL-8/CXCL8）活化 integrin
3. **Firm adhesion**：**Integrins**（LFA-1, MAC-1/CD11b-CD18）結合 **ICAM-1**；VLA-4 結合 **VCAM-1**
4. **Transmigration（diapedesis）**：穿越內皮，PECAM-1（CD31）介導
5. **Chemotaxis**：沿化學梯度遷移（**C5a、LTB₄、IL-8、bacterial products** 為重要趨化因子）

- **Leukocyte Adhesion Deficiency（LAD）**：CD18（β2 integrin）缺陷 → WBC 無法 adhesion → 反覆感染、延遲臍帶脫落、**無膿形成**、WBC 極高

#### 吞噬作用與殺菌

- **Opsonins**：**C3b**（最重要）、IgG Fc、mannose-binding lectin
- **殺菌機制**：
    - **Oxygen-dependent**：
        - **Respiratory burst**：**NADPH oxidase** → O₂⁻ → H₂O₂ → **MPO + Cl⁻ → HOCl**（最強殺菌）
        - **CGD（Chronic Granulomatous Disease）**：NADPH oxidase 缺陷 → 無法產生 superoxide → 反覆 catalase(+) 菌感染
    - **Oxygen-independent**：lysozyme、lactoferrin、defensins、major basic protein（嗜酸性球）

#### 急性發炎的化學介質

| 介質 | 來源 | 功能 |
|------|------|------|
| **Histamine** | Mast cell、basophil、platelet | 血管擴張、通透性↑（最早釋放）；作用於 venule |
| **Serotonin** | Platelet | 血管擴張 |
| **Bradykinin** | Kinin system（factor XII → prekallikrein → kallikrein → kininogen → bradykinin） | 疼痛、血管擴張、通透性↑ |
| **PGE₂ / PGI₂** | COX pathway（Arachidonic acid → COX-1/2） | PGE₂：疼痛、發燒；PGI₂：血管擴張、抑制血小板 |
| **TXA₂** | COX pathway（platelets） | 血管收縮、促血小板凝集（與 PGI₂ 拮抗） |
| **LTB₄** | LOX pathway（5-lipoxygenase） | **趨化中性球**（最強趨化因子之一） |
| **LTC₄ / D₄ / E₄** | LOX pathway | **支氣管收縮**（slow-reacting substances of anaphylaxis）、血管通透性↑ |
| **PAF** | Leukocyte、endothelium | 血小板活化、支氣管收縮、血管通透性↑ |
| **NO** | Endothelial NOS（eNOS）、iNOS（macrophage） | **血管擴張**、殺菌 |
| **IL-8（CXCL8）** | Macrophage | **趨化中性球** |
| **C3a / C5a** | 補體活化 | Anaphylatoxin；**C5a 為最強趨化因子** |

- **Arachidonic acid 代謝**：
    - **Phospholipase A₂** 從細胞膜磷脂釋出 AA（被 **corticosteroid** 抑制）
    - **COX pathway** → Prostaglandins / Thromboxane（被 **NSAIDs** 抑制）
    - **5-LOX pathway** → Leukotrienes（被 **Zileuton** 抑制）；Leukotriene receptor antagonist：Montelukast

#### 急性發炎的結局

1. **Resolution（完全消退）**
2. **Abscess formation（膿瘍形成）**
3. **Scarring / Fibrosis（纖維化）**
4. **Chronic inflammation（轉為慢性發炎）**

#### 滲出液 vs 漏出液

| | **Exudate（滲出液）** | **Transudate（漏出液）** |
|--|---------------------|----------------------|
| 機制 | 血管通透性↑（發炎） | 靜水壓↑ 或膠體滲透壓↓ |
| 蛋白質 | **>3 g/dL** | <3 g/dL |
| 比重 | >1.020 | <1.020 |
| LDH | 高 | 低 |
| 細胞 | 多 | 少 |
| Light's criteria（肋膜液） | 符合 ≥1 項 → exudate | 都不符合 → transudate |

### 2.2 慢性發炎（Chronic Inflammation）

- **主角細胞**：**Macrophage**（最重要）、lymphocyte、plasma cell
- 特徵：組織破壞、修復（纖維化）與發炎同時進行
- **肉芽腫性發炎（Granulomatous Inflammation）**：
    - **肉芽腫組成**：中央為 activated macrophage（**epithelioid cells**）± 合併形成 **multinucleated giant cells**（Langhans type：核排列於周邊馬蹄形）；外圍 T lymphocyte、fibroblast
    - **Caseating granuloma**：中央乾酪性壞死 → **TB**、真菌
    - **Non-caseating granuloma**：無壞死 → **Sarcoidosis**、Crohn's disease、Berylliosis、Foreign body reaction
    - 其他原因：Cat-scratch disease（Bartonella henselae）、Leprosy、Schistosomiasis

### 2.3 發燒（Fever）

- **機制**：IL-1、IL-6、TNF-α → 下視丘 → PGE₂ → thermostat 上調
- **NSAIDs / Aspirin**：抑制 COX → 降低 PGE₂ → 退燒
- **Corticosteroid**：抑制 phospholipase A₂ → 減少 AA → 退燒及抗發炎

## 三、組織修復與傷口癒合（Tissue Repair & Wound Healing）

### 3.1 細胞再生能力分類

| 類型 | 特性 | 舉例 |
|------|------|------|
| **Labile cells** | 持續分裂 | 皮膚表皮、GI 黏膜上皮、骨髓造血細胞 |
| **Stable cells（quiescent）** | G₀ 期，受刺激可再進入細胞週期 | **肝臟（hepatocyte）**、腎小管上皮、纖維母細胞、平滑肌 |
| **Permanent cells** | 不再分裂 | **心肌細胞**、**神經元**、骨骼肌（有限再生能力由 satellite cell） |

### 3.2 傷口癒合

#### 一期癒合（Primary Intention / First Intention）
- 傷口邊緣整齊且靠近（如外科切口）
- 疤痕小、感染風險低

#### 二期癒合（Secondary Intention / Second Intention）
- 傷口大、邊緣不規則、組織缺損大（如潰瘍、膿瘍引流後）
- 需大量 **肉芽組織（granulation tissue）** 填充
- 傷口收縮（**myofibroblasts** 介導）
- 疤痕大

#### 癒合過程

1. **止血期**：血小板凝塊
2. **發炎期**（0–3 天）：**Neutrophils** 先到（清除壞死組織與細菌）→ **Macrophages**（48–96 hr 後主導，最重要的修復細胞）
3. **增生期**（3 天–3 週）：**Granulation tissue** 形成（新生血管 + fibroblast + ECM）
    - **Type III collagen** 先沉積
    - **Angiogenesis**：VEGF、FGF 驅動
4. **重塑期**（remodeling，3 週以上）：Type III → **Type I collagen** 取代；傷口強度逐漸增加但**永遠不回到原始強度**（最高約 80%）

### 3.3 影響傷口癒合的因素

- **不利因素**：感染（最常見原因）、糖尿病（微血管病變 + 白血球功能差）、異物、缺血/缺氧、營養不良（vitamin C 缺乏 → collagen 合成障礙）、corticosteroid（抑制發炎及 collagen 合成）、鋅缺乏
- **Vitamin C 缺乏（壞血病, Scurvy）**：proline/lysine 無法 hydroxylation → collagen 結構缺陷 → 傷口癒合不良、牙齦出血、瘀斑
- **銅缺乏**：lysyl oxidase 活性↓ → collagen/elastin cross-linking 障礙

### 3.4 異常傷口癒合

| 類型 | 特徵 |
|------|------|
| **Keloid（蟹足腫）** | 疤痕**超出原傷口範圍**；Type III collagen 過度堆積；好發深膚色人種；不會自發消退 |
| **Hypertrophic scar（肥厚性疤痕）** | 疤痕增厚但**不超出傷口範圍**；可能自發消退 |
| **Dehiscence（傷口裂開）** | 腹部手術常見；多因腹壓增加、感染、營養不良 |
| **Wound contracture（攣縮）** | Myofibroblast 過度收縮 → 功能障礙，好發燒傷 |

## 四、血液動力學障礙（Hemodynamic Disorders）

### 4.1 水腫（Edema）

- **機制**：
    - **靜水壓↑**：CHF、DVT、肝硬化（portal HTN）
    - **膠體滲透壓↓**（albumin↓）：Nephrotic syndrome、肝硬化、營養不良
    - **淋巴阻塞**：淋巴結切除後、絲蟲病（filariasis → elephantiasis）、腫瘤
    - **鈉滯留**：腎衰竭
    - **血管通透性↑**：發炎、過敏、燒傷
- **Dependent edema**：右心衰竭 → 下肢凹陷性水腫
- **Pulmonary edema**：左心衰竭
- **Ascites**：肝硬化（portal HTN + albumin↓ + Na retention）

### 4.2 止血與血栓（Hemostasis & Thrombosis）

#### 正常止血

1. **初級止血（Primary Hemostasis）**：血管收縮 + **血小板黏附與凝集** → 血小板栓
    - vWF 使血小板（**GP Ib**）黏附至暴露的 subendothelial collagen
    - ADP / TXA₂ → 血小板活化 → GP IIb/IIIa 暴露 → fibrinogen 橋接 → 凝集
2. **二級止血（Secondary Hemostasis）**：**凝血因子瀑布** → fibrin 形成
    - **Intrinsic pathway**：XII → XI → IX → VIII → X（監測：**aPTT**）
    - **Extrinsic pathway**：Tissue Factor（TF）→ VII → X（監測：**PT / INR**）
    - **Common pathway**：X → V → **Prothrombin（II）→ Thrombin** → **Fibrinogen（I）→ Fibrin**
    - **Thrombin** 功能：fibrinogen → fibrin、活化 factor V/VIII/XI/XIII、活化 protein C（透過 thrombomodulin）、血小板活化
3. **纖維蛋白穩定**：Factor XIII cross-links fibrin

#### 抗凝血機制

- **Antithrombin III（AT III）**：抑制 thrombin + IXa/Xa/XIa（**Heparin 增強其活性**）
- **Protein C / Protein S**：inactivate Va / VIIIa（Vitamin K-dependent）
    - **Factor V Leiden mutation**：Factor V 對 Protein C 抵抗 → **最常見遺傳性血栓傾向**
- **Tissue Factor Pathway Inhibitor（TFPI）**
- **Thrombomodulin**：內皮表面，與 thrombin 結合 → 活化 Protein C
- **Prostacyclin（PGI₂）**：內皮分泌 → 抑制血小板凝集 + 血管擴張
- **tPA（tissue Plasminogen Activator）**：fibrinolysis

#### Virchow's Triad（血栓三要素）

1. **血流停滯（Stasis）**：臥床、長途飛行、心房顫動
2. **內皮損傷（Endothelial Injury）**：動脈粥狀硬化、血管炎、外傷
3. **高凝血狀態（Hypercoagulability）**：Factor V Leiden、Prothrombin G20210A mutation、Antithrombin III deficiency、Protein C/S deficiency、APS、癌症、OCP/HRT

#### 血栓的命運

1. **Propagation（擴展）**
2. **Embolization（栓塞化）**
3. **Dissolution（溶解）**：纖溶系統
4. **Organization & Recanalization（機化與再通）**

### 4.3 栓塞（Embolism）

| 類型 | 來源 / 特徵 |
|------|------------|
| **Pulmonary thromboembolism（PE）** | >95% 來自**下肢深部靜脈血栓（DVT）**；大面積 PE → 急性右心衰竭 → 猝死；Saddle embolus 卡在肺動脈分叉處 |
| **Paradoxical embolism** | 靜脈栓子經由 **ASD / PFO（patent foramen ovale）** 進入體循環 → 動脈栓塞（如中風） |
| **Fat embolism** | **長骨骨折**後 1–3 天；三聯征：**呼吸困難 + 神經症狀 + 瘀斑（petechiae）** |
| **Air embolism** | 頸部/胸部手術、深海潛水減壓病（Caisson disease / decompression sickness → nitrogen 氣泡）；>100 mL 空氣可致命 |
| **Amniotic fluid embolism** | 產程中或產後；突發呼吸窘迫 + DIC + 休克；病理可見 **squamous cells / lanugo / mucin** 在肺血管 |

### 4.4 梗塞（Infarction）

| 類型 | 特徵 | 舉例 |
|------|------|------|
| **Red（hemorrhagic）infarct** | 組織鬆散、有雙重血供、靜脈阻塞、再灌注 | **肺**（雙重血供）、**肝**、**腸**、靜脈栓塞後腦梗塞 |
| **White（anemic / pale）infarct** | 實質器官、終端動脈（single blood supply） | **心**、**腎**、**脾**、**腦**（動脈阻塞） |

- **Watershed infarct（分水嶺梗塞）**：發生在兩條動脈供血交界處；低血壓/休克時最易受傷
    - 腦：ACA-MCA 交界 → 上肢近端無力（man-in-a-barrel syndrome）
    - 腸：Splenic flexure（SMA-IMA 交界）、rectosigmoid junction

### 4.5 休克（Shock）

| 類型 | 機制 | 舉例 | 特點 |
|------|------|------|------|
| **Hypovolemic** | 血量/體液不足 | 大量出血、嚴重脫水、燒傷 | CO↓、SVR↑、PCWP↓ |
| **Cardiogenic** | 心臟幫浦功能衰竭 | 大面積 MI、心肌炎、心包填塞 | CO↓、SVR↑、PCWP↑ |
| **Distributive** | 血管擴張 → 有效循環血量↓ | Septic、anaphylactic、neurogenic | CO↑（septic early）、**SVR↓** |
| **Obstructive** | 心臟充填受阻或流出道阻塞 | Tension pneumothorax、PE、cardiac tamponade | CO↓ |

- **Septic shock**：最常見的分佈型休克
    - **Warm shock（early）**：血管擴張 → 皮膚溫暖、CO↑、SVR↓
    - **Cold shock（late）**：心功能下降 → CO↓
    - 機制：Gram(-) LPS → TLR-4 → TNF-α / IL-1 / IL-6 → NO → vasodilation + endothelial damage → DIC
- **休克的器官病變**：
    - **腎**：Acute Tubular Necrosis（ATN）
    - **肺**：**ARDS（Diffuse Alveolar Damage, DAD）** → hyaline membrane
    - **肝**：Centrilobular necrosis（zone 3 最缺氧）
    - **腸**：Hemorrhagic enterocolitis
    - **腦**：Watershed infarcts
    - **多器官衰竭（MODS）**

### 4.6 彌散性血管內凝血（DIC, Disseminated Intravascular Coagulation）

- **病因**：Sepsis（最常見）、外傷、產科併發症（羊水栓塞、胎盤早剝）、惡性腫瘤（尤 acute promyelocytic leukemia APL）、胰臟炎
- **機制**：大量凝血因子活化 → 微血管內形成 microthrombi → 消耗凝血因子與血小板 → **出血**
- **實驗室**：
    - PT↑、aPTT↑
    - Fibrinogen↓（消耗）
    - **D-dimer↑**（fibrin 分解產物，最敏感）
    - **Platelet↓**
    - Schistocytes（fragmented RBC）on blood smear → microangiopathic hemolytic anemia（MAHA）
- **治療**：治療根本原因；補充凝血因子（FFP）、血小板、cryoprecipitate（fibrinogen）；Heparin（爭議，部分情況使用）

## 五、腫瘤學總論（Neoplasia - General Principles）

### 5.1 良性 vs 惡性腫瘤

| 特徵 | **良性（Benign）** | **惡性（Malignant）** |
|------|-------------------|---------------------|
| 分化 | 分化好（與正常相似） | 分化差 / 未分化（anaplasia） |
| 生長速度 | 慢 | 快 |
| 邊界 | 有**包膜**，界限清楚 | **浸潤性**，無包膜 |
| 轉移 | **不轉移** | **可轉移** |
| 壞死/出血 | 少 | 常見 |
| 核分裂象 | 少、正常 | 多、**異常（atypical mitoses）** |

### 5.2 腫瘤命名

| 細胞來源 | 良性 | 惡性 |
|----------|------|------|
| 上皮（腺體） | **Adenoma** | **Adenocarcinoma** |
| 上皮（鱗狀） | **Papilloma** | **Squamous cell carcinoma** |
| 上皮（移行） | **Urothelial papilloma** | **Urothelial carcinoma** |
| 間葉（纖維） | **Fibroma** | **Fibrosarcoma** |
| 間葉（脂肪） | **Lipoma** | **Liposarcoma** |
| 間葉（軟骨） | **Chondroma** | **Chondrosarcoma** |
| 間葉（骨） | **Osteoma** | **Osteosarcoma** |
| 間葉（血管） | **Hemangioma** | **Angiosarcoma** |
| 間葉（平滑肌） | **Leiomyoma** | **Leiomyosarcoma** |
| 間葉（橫紋肌） | **Rhabdomyoma** | **Rhabdomyosarcoma** |

- **命名例外**：以下名稱看似良性，實為**惡性**：
    - **Lymphoma**、**Melanoma**、**Mesothelioma**、**Seminoma**
    - **Hepatoblastoma**、**Retinoblastoma**、**Neuroblastoma**
- **Teratoma**：含三胚層組織；卵巢 mature cystic teratoma（dermoid cyst）通常良性；睪丸 teratoma 視為**惡性**
- **Hamartoma**：正常組織在正常位置但排列紊亂（非真正腫瘤）；如肺 hamartoma
- **Choristoma**：正常組織出現在不正常位置（如胰臟組織在胃壁）

### 5.3 腫瘤分級與分期

| | **Grading（分級）** | **Staging（分期）** |
|--|--------------------|--------------------|
| 依據 | **組織學分化程度** | **臨床 / 解剖 擴散範圍** |
| 系統 | Grade I（分化好）– IV（未分化） | **TNM**（T=原發腫瘤大小/深度，N=淋巴結，M=遠端轉移） |
| 預後預測 | 較弱 | **較強**（staging 比 grading 更能預測預後） |

### 5.4 癌症的分子生物學

#### 致癌基因（Oncogenes）— Gain of function（顯性）

| 基因 | 功能 | 相關腫瘤 |
|------|------|----------|
| **RAS**（KRAS, NRAS, HRAS） | GTPase → 持續活化 MAPK pathway | **最常見突變致癌基因**；KRAS：胰臟癌、大腸癌、肺腺癌 |
| **BRAF** | Serine/threonine kinase（RAS 下游） | Melanoma（V600E 突變）、Papillary thyroid carcinoma |
| **MYC** | 轉錄因子 → 細胞增殖 | **Burkitt lymphoma**（t(8;14)）；N-MYC：Neuroblastoma；L-MYC：Small cell lung ca |
| **BCR-ABL** | 融合基因 → tyrosine kinase 持續活化 | **CML**（t(9;22) = Philadelphia chromosome）；ALL |
| **HER2/NEU（ERBB2）** | Receptor tyrosine kinase | **Breast cancer**（約 20%）；Trastuzumab 靶向治療 |
| **RET** | Receptor tyrosine kinase | **MEN 2A/2B**（Medullary thyroid carcinoma）；Papillary thyroid ca |
| **KIT（c-KIT）** | Receptor tyrosine kinase | **GIST（胃腸基質瘤）**；Imatinib 治療 |
| **ALK** | Receptor tyrosine kinase | **非小細胞肺癌**（ALK rearrangement）；Crizotinib/Alectinib |
| **BCL-2** | 抗凋亡 | **Follicular lymphoma**（t(14;18)） |
| **Cyclin D1** | 細胞週期 G1→S | **Mantle cell lymphoma**（t(11;14)） |

#### 抑癌基因（Tumor Suppressor Genes）— Loss of function（隱性 / Two-hit hypothesis）

| 基因 | 功能 | 相關腫瘤 |
|------|------|----------|
| **Rb（Retinoblastoma gene）** | 抑制 E2F → 阻止 G1→S 進程 | **Retinoblastoma**（sporadic vs hereditary）；Osteosarcoma |
| **p53（TP53）** | 「基因組守護者」→ 細胞週期停止（G1 arrest）/ DNA修復 / 凋亡 | **Li-Fraumeni syndrome**（多種癌症）；**最常見被突變的抑癌基因**（>50% 人類癌症） |
| **APC** | Wnt pathway 負調控 → 抑制 β-catenin | **Familial Adenomatous Polyposis（FAP）** → 大腸癌（adenoma-carcinoma sequence） |
| **BRCA1 / BRCA2** | DNA 修復（homologous recombination） | **乳癌、卵巢癌**；BRCA1：basal-like / triple-negative 乳癌多見 |
| **VHL** | 抑制 HIF → 調控血管新生 | **Von Hippel-Lindau disease**（hemangioblastoma、Renal cell carcinoma、Pheochromocytoma） |
| **WT1** | 轉錄因子 | **Wilms tumor**（腎母細胞瘤） |
| **NF1** | RAS-GAP（RAS 的負調控） | **Neurofibromatosis type 1**（neurofibroma、optic glioma、café-au-lait spots） |
| **NF2** | Merlin（cytoskeletal protein） | **Neurofibromatosis type 2**（bilateral acoustic schwannoma） |
| **PTEN** | 抑制 PI3K/AKT pathway | **Cowden syndrome**（hamartoma、breast/thyroid/endometrial ca） |
| **DPC4 / SMAD4** | TGF-β signaling | 胰臟癌 |

#### DNA 修復基因缺陷

| 基因 / 疾病 | 修復機制 | 相關腫瘤 |
|------------|---------|---------|
| **BRCA1/2** | Homologous recombination | 乳癌、卵巢癌 |
| **MSH2 / MLH1（mismatch repair）** | Mismatch repair | **Lynch syndrome（HNPCC）** → 大腸癌（右側為主）、子宮內膜癌 |
| **XPA–XPG（Xeroderma Pigmentosum）** | Nucleotide excision repair（NER） | UV-induced 皮膚癌（SCC、BCC、Melanoma） |
| **ATM** | DNA damage sensing | Ataxia-Telangiectasia → lymphoma/leukemia |
| **FANC genes** | Interstrand crosslink repair | Fanconi anemia → AML、SCC |

### 5.5 癌症致癌因素

#### 化學致癌物

| 致癌物 | 相關癌症 |
|--------|---------|
| **Aflatoxin B₁**（Aspergillus flavus） | **肝細胞癌（HCC）**；p53 突變 |
| **Benzene** | **AML**、ALL |
| **Vinyl chloride** | **肝血管肉瘤（Angiosarcoma of liver）** |
| **Nitrosamines** | 胃癌、食道癌 |
| **Arsenic** | 皮膚癌（SCC）、肺癌、肝血管肉瘤 |

|------|---------|------|

| **HIV** | Kaposi sarcoma、primary CNS lymphoma、cervical cancer（間接，免疫抑制） | — |

- **UV 輻射**：Pyrimidine dimers → 皮膚癌（BCC > SCC > Melanoma）
- **游離輻射**：DNA double-strand break → 白血病（AML、CML、ALL）、甲狀腺癌（Papillary）、乳癌

### 5.8 轉移途徑

| 途徑 | 好發腫瘤 |
|------|---------|
| **血行轉移（Hematogenous）** | **Sarcoma**（最常→肺）；Renal cell ca（腎靜脈→IVC→肺）；HCC；Follicular thyroid ca |
| **淋巴轉移（Lymphatic）** | **Carcinoma**（多數）；乳癌→axillary LN；胃癌→Virchow node（left supraclavicular）；肺癌→mediastinal LN |
| **種植轉移（Seeding）** | Ovarian cancer（Krukenberg tumor 若轉移至卵巢 = signet ring cell from GI ca）；CNS tumor（drop metastasis via CSF） |

- **常見轉移目標器官**：肺、肝、骨、腦、腎上腺
- **骨轉移**：
    - **Osteolytic（溶骨性）**：多數（肺、腎、甲狀腺、多發性骨髓瘤）→ 高血鈣
    - **Osteoblastic（成骨性）**：**Prostate cancer**（最典型）、Breast cancer（也可溶骨）
- **常轉移至肝**：**GI tract cancers**（colon → portal vein → liver）

### 6.2 單基因遺傳疾病

#### 體染色體顯性（Autosomal Dominant）

| 疾病 | 缺陷基因/蛋白 | 重點特徵 |
|------|-------------|---------|
| **Marfan syndrome** | **Fibrillin-1（FBN1）** → 結締組織缺陷 | 高大、蜘蛛指（arachnodactyly）、**Lens subluxation（上外方脫位, upward and outward）**、**Aortic root dilation → dissection / aneurysm**（主要死因）、MVP、pectus excavatum/carinatum、dural ectasia |
| **Ehlers-Danlos syndrome（vascular type）** | **Type III collagen（COL3A1）** | 皮膚過度延展、關節過動、血管/腸壁/子宮壁易破裂（vascular type 最危險）；**動脈瘤/破裂** |
| **Osteogenesis Imperfecta（OI）** | **Type I collagen（COL1A1/COL1A2）** | 骨脆弱 → 反覆骨折（brittle bone disease）、**Blue sclera**（type I 最常見，最輕微）、聽力喪失、牙齒異常（dentinogenesis imperfecta）；Type II → 致命（宮內/出生即死亡） |
| **Huntington disease** | **HTT gene**（CAG trinucleotide repeat → polyglutamine） | 30–50 歲發病、**Chorea**（舞蹈症）、精神症狀、失智；**Caudate atrophy**；**Anticipation**（遺傳不穩定→下一代更早發病更嚴重） |
| **Familial hypercholesterolemia** | **LDL receptor 缺陷** | 總膽固醇極高、早發動脈粥狀硬化/MI、Tendon xanthomas、Corneal arcus |
| **Neurofibromatosis type 1（NF1）** | **NF1 gene（neurofibromin）** → RAS 負調控 | **Café-au-lait spots（≥6）**、Neurofibroma、**Lisch nodules（iris hamartoma）**、Optic glioma、Axillary/inguinal freckling、骨發育異常 |
| **Neurofibromatosis type 2（NF2）** | **NF2 gene（merlin/schwannomin）** | **Bilateral acoustic（vestibular）schwannomas**、Meningiomas |
| **Tuberous Sclerosis** | **TSC1（hamartin）/ TSC2（tuberin）** | **Cortical tubers → seizures/intellectual disability**、**Cardiac rhabdomyomas**（兒童最常見心臟腫瘤）、**Renal angiomyolipomas**、Facial angiofibromas（adenoma sebaceum）、Ash-leaf spots（hypopigmented macules）、Shagreen patches |
| **von Hippel-Lindau（VHL）** | **VHL gene** → HIF 調控 | **Hemangioblastomas**（cerebellum, retina）、**Renal cell carcinoma（clear cell）**、**Pheochromocytoma**、Pancreatic cysts/tumors |
| **ADPKD** | **PKD1（85%）/ PKD2** | 多囊腎 → 腎衰竭（成人型，30-40 歲後症狀）；肝囊腫；**Berry aneurysm → SAH**；MVP；腎結石 |

#### 體染色體隱性（Autosomal Recessive）

| 疾病 | 缺陷 | 重點 |
|------|------|------|
| **Cystic Fibrosis（CF）** | **CFTR（Cl⁻ channel）**；最常見突變 **ΔF508** | 白人最常見致死性 AR 遺傳病；**黏稠分泌物**→肺（反覆感染/支氣管擴張，Pseudomonas）、胰臟外分泌功能不全（脂肪瀉）、**Meconium ileus**（新生兒腸阻塞）、男性不孕（CBAVD）、汗液 Cl⁻↑ → **汗液氯離子測試（sweat chloride test >60 mmol/L）** |
| **Phenylketonuria（PKU）** | **Phenylalanine hydroxylase 缺陷** → Phe→Tyr 障礙 | Phe 堆積 → 智能障礙、seizures、eczema、musty odor；Tyrosine 不足→ 淡色皮膚/頭髮；新生兒篩檢；治療：低 Phe 飲食 |
| **Galactosemia（Classic）** | **Galactose-1-phosphate uridylyltransferase 缺乏** | 餵乳後嘔吐、黃疸、肝腫大、白內障（galactitol 堆積）、E. coli sepsis、智能障礙；治療：排除 galactose/lactose 飲食 |
| **Sickle Cell Disease** | **β-globin Glu→Val（HbS）** | 非裔；鐮刀化 RBC → 血管阻塞危象（vaso-occlusive crisis）、慢性溶血性貧血、脾自體梗塞（functional asplenia）→ encapsulated 菌感染、Dactylitis（hand-foot syndrome, 嬰幼兒）、Acute chest syndrome、Stroke、Aplastic crisis（Parvovirus B19）、Sequestration crisis（脾/肝）；**HbS 對 Plasmodium falciparum 有保護** |
| **Thalassemia** | α 或 β-globin 鏈合成不足 | **α-thal**：東南亞/華人；4 個 α-globin gene deletion → Hb Barts（γ4）→ hydrops fetalis；**β-thal major**：地中海/東南亞；β 鏈嚴重不足 → HbF↑、HbA₂↑、Cooley's anemia → 嚴重貧血、骨髓擴張（chipmunk facies, crew-cut X-ray）、iron overload → 需定期輸血 + chelation |
| **Wilson disease** | **ATP7B** → copper 排入膽汁/結合 ceruloplasmin 障礙 | 肝病（慢性肝炎→肝硬化）、**Kayser-Fleischer rings**（銅沉積角膜）、神經精神症狀（Basal ganglia）、溶血性貧血；Lab：Ceruloplasmin↓、尿 Cu↑、肝 Cu↑ |
| **Hemochromatosis** | **HFE gene（C282Y mutation）** → hepcidin↓ → iron 過度吸收 | 肝硬化 / HCC、Bronze diabetes、心肌病變、關節病變、hypogonadism；Lab：Transferrin saturation↑、Ferritin↑；治療：Phlebotomy |

#### X-linked Recessive

| 疾病 | 缺陷 | 重點 |

| **Hemophilia A** | **Factor VIII 缺乏** | 最常見遺傳性凝血障礙之一；深部組織/關節出血（hemarthrosis）；aPTT↑、PT 正常、BT 正常；治療：Factor VIII 補充 |

### 7.1 酒精相關病理

| 階段 / 表現 | 特徵 |
|------------|------|
| **脂肪肝（Steatosis）** | 最早、最常見、可逆 |
| **酒精性肝炎** | **Mallory-Denk bodies**（damaged cytokeratin intermediate filaments）、**Neutrophilic infiltrate**、Hepatocyte ballooning、肝腫大、發燒、黃疸 |

### 7.2 維生素缺乏

| 維生素 | 缺乏症 |
|--------|--------|
| **Vitamin A（Retinol）** | 夜盲症（night blindness）→ 乾眼症（xerophthalmia）→ **Bitot spots** → Keratomalacia → 角膜穿孔；Squamous metaplasia |

| **Vitamin D** | 兒童：**Rickets**（骨骼彎曲、craniotabes、rachitic rosary）；成人：**Osteomalacia** |
| **Vitamin E（Tocopherol）** | 溶血性貧血（新生兒）、周邊神經病變、後柱功能障礙（類似 B₁₂ but no megaloblastic anemia） |

### 7.3 鉛中毒（Lead Poisoning）

- 來源：老舊油漆、水管、陶瓷釉料
- **兒童**：學習障礙、行為問題、腦病變（encephalopathy）
- **成人**：腹痛（lead colic）、周邊神經病變（wrist drop / foot drop）、腎小管損傷
- 實驗室：
    - Blood smear：**Basophilic stippling**（粗顆粒 RNA 殘留）
    - **Ringed sideroblasts**（骨髓）
    - **Lead lines（Burton lines）**：牙齦藍黑線
    - **Protoporphyrin↑（FEP / ZPP↑）**
    - ALA 及 coproporphyrin 尿液↑
- 機制：抑制 **ALA dehydratase** 及 **ferrochelatase** → heme 合成障礙
- 治療：**EDTA（CaNa₂EDTA）**、Dimercaprol（BAL）、Succimer（DMSA，口服，兒童首選）

## 八、血管病理（Vascular Pathology）

### 8.1 動脈粥狀硬化（Atherosclerosis）

- **最常見的動脈硬化類型**
- 好發血管：**Abdominal aorta**（最常見位置）> Coronary arteries > Popliteal artery > Carotid arteries
- **危險因子**：高血壓（最重要）、高脂血症、糖尿病、吸菸、年齡、男性、家族史
- **病理進展**：
    1. **Fatty streak**：最早的病變，由 foam cells（lipid-laden macrophages）組成；兒童即可見
    2. **Fibrous plaque（Atheroma）**：fibrous cap + lipid core + inflammatory cells
    3. **Complicated plaque**：鈣化、潰瘍、出血、血栓
- **Response-to-injury hypothesis**：內皮損傷 → LDL 進入內皮下 → 氧化 LDL → 巨噬細胞吞噬成 foam cells → smooth muscle migration → fibrous cap 形成
- **併發症**：MI、中風（carotid atherosclerosis）、主動脈瘤（AAA）、周邊動脈疾病（claudication → critical limb ischemia）、腎動脈狹窄

### 8.2 動脈瘤（Aneurysm）

| 類型 | 機制 | 舉例 |
|------|------|------|
| **True aneurysm** | 血管壁三層皆擴張 | AAA、Berry aneurysm |
| **False aneurysm（pseudoaneurysm）** | 血管壁破損 → 血腫形成由結締組織包覆 | 心肌梗塞後心室游離壁破裂、動脈穿刺後 |

| 類型 | 特徵 |
|------|------|
| **Abdominal Aortic Aneurysm（AAA）** | 好發 **infrarenal aorta**；**動脈粥狀硬化** 為主因；>65 歲男性吸菸者最高風險；>5.5 cm → 手術；破裂 → 致命腹痛/低血壓 |
| **Thoracic Aortic Aneurysm** | 與 **Marfan syndrome**（cystic medial degeneration）、梅毒（vasa vasorum obliteration → aortic root dilation）、HTN 相關 |
| **Berry（Saccular）Aneurysm** | 先天性，位於 **Circle of Willis 分叉處**（AComm 最常見）；破裂 → **SAH**；與 **ADPKD** 相關 |
| **Mycotic Aneurysm** | 感染性（septic emboli、IE） |
| **Aortic Dissection** | **內膜撕裂**（intimal tear）→ 血液進入 media 層；劇烈撕裂性胸/背痛；與 **HTN**（最重要風險因子）、Marfan syndrome 相關；Stanford A（升主動脈）→ 手術；Stanford B（降主動脈）→ 藥物控制血壓 |

### 8.3 血管炎（已於免疫風濕章節詳述）

### 8.4 高血壓（Hypertension）

- **Essential HTN（原發性）**：~95%，原因不明
- **Secondary HTN**：腎動脈狹窄（fibromuscular dysplasia 年輕女性 / atherosclerosis 老年）、Pheochromocytoma、Conn's syndrome、Cushing's、Coarctation of aorta
- **惡性高血壓（Malignant HTN）**：BP >180/120 + 器官損傷
    - 血管病理：**Fibrinoid necrosis**（小動脈壁纖維素樣壞死）→ **Onion-skin hyperplasia**（concentric intimal thickening, hyperplastic arteriolosclerosis）
    - **Hyaline arteriolosclerosis**：良性高血壓/糖尿病 → 小動脈壁玻璃樣變性
- **高血壓終器官損傷**：左心室肥大、CHF、腎硬化（nephrosclerosis）、中風（出血性/缺血性）、視網膜病變、主動脈剝離

## 九、心臟病理（Cardiac Pathology）

### 9.1 缺血性心臟病（Ischemic Heart Disease）

#### 心肌梗塞（Myocardial Infarction）

- **病理時間軸**：

| 時間 | 大體 | 組織學 | 併發症 |
|------|------|--------|--------|
| **0–4 hr** | 無明顯變化 | **Wavy fibers** | 心律不整（最常見死因）→ VF |
| **4–24 hr** | 暗紅色 | **Coagulative necrosis** 開始；Neutrophil infiltration（4–12 hr 起） | 心律不整 |
| **1–3 天** | 黃色軟化 | **Neutrophils 最多** | 心律不整、心衰竭 |
| **3–7 天** | 黃色軟化、邊緣充血 | **Macrophages 開始清除壞死組織** | **壁破裂（free wall rupture → cardiac tamponade, 最危險）**、乳頭肌斷裂（MR）、室間隔穿孔 |
| **1–3 週** | 邊緣灰紅色肉芽組織 | **Granulation tissue（angiogenesis + fibroblasts）** | Mural thrombus → embolism |
| **數週–數月** | **白色疤痕** | Dense collagenous scar | Ventricular aneurysm（不會破裂，因為已纖維化）、Dressler syndrome（自體免疫心包膜炎，2–10 週後） |

- **MI 相關冠狀動脈**：
    - **LAD**（最常梗塞）→ 左心室前壁 + 前室間隔
    - **RCA** → 左心室後壁 + 後室間隔 + 右心室；RCA 供應 SA node / AV node → **心搏過緩/AV block**
    - **LCx** → 左心室側壁

- **Troponin I/T**：最敏感且最專一的心肌壞死標記（4-6 hr 升高，7-10 天持續）
- **CK-MB**：較早下降（~72 hr），可用來偵測 **re-infarction**

### 9.2 心衰竭

| | **Left-sided HF** | **Right-sided HF** |
|--|-------------------|-------------------|
| 最常見原因 | HTN、MI、Aortic/Mitral valve disease、DCM | **Left-sided HF（最常見原因）**、Pulmonary HTN、肺疾病（Cor pulmonale） |
| 症狀 | Dyspnea（exertional → orthopnea → PND）、Pulmonary edema | Peripheral edema（pitting）、JVD、Hepatomegaly（nutmeg liver）、Ascites |
| 病理 | 肺水腫（alveolar 內 heart failure cells = hemosiderin-laden macrophages） | 肝充血（centrilobular congestion → nutmeg liver → cardiac cirrhosis） |

### 9.3 瓣膜疾病

| 疾病 | 特徵 |
|------|------|
| **Rheumatic Heart Disease** | 風濕熱後（A 群 GAS，**molecular mimicry**）；急性：**Pancarditis**（所有三層心臟壁皆發炎）；**Aschoff bodies**（肉芽腫伴 Anitschkow cells）；慢性：**Mitral stenosis**（最常見慢性瓣膜病變）→ 左心房擴大 → AF → 栓塞；**Fish-mouth / button-hole** appearance |
| **Mitral Valve Prolapse（MVP）** | 瓣膜 **myxomatous degeneration** → 收縮中期 click + 晚期收縮期 murmur；好發年輕女性；與 Marfan、Ehlers-Danlos 相關；通常良性 |
| **Calcific Aortic Stenosis** | 老年人最常見需手術的瓣膜疾病；**Bicuspid aortic valve** → 早發（50-60 歲）鈣化狹窄 |
| **Infective Endocarditis（IE）** | **Acute**：S. aureus（毒力強、可侵犯正常瓣膜）；**Subacute**：S. viridans（原已受損瓣膜）；**Prosthetic valve early（<60 天）**：S. epidermidis；**IV drug user**：S. aureus → **Tricuspid valve**（右側）；**Culture-negative**：HACEK group；**SLE**：Libman-Sacks（非感染性）；病理：**Vegetations** on valve；併發症：栓塞（腦/脾/腎）、Roth spots（retina）、Osler nodes（指尖痛性結節，免疫複合體）、Janeway lesions（掌底無痛性出血斑，septic emboli）、Splinter hemorrhages |
| **Non-bacterial Thrombotic Endocarditis（NBTE, Marantic）** | 與癌症高凝血狀態相關；小的無菌 vegetations 於瓣膜關閉線上 |

### 9.4 心肌病變（Cardiomyopathy）

| 類型 | 特徵 | 原因 | 病理 |
|------|------|------|------|
| **Dilated（DCM）** | 最常見；四個腔室擴大、收縮力↓ | 酒精、Coxsackie B、Chagas disease、Doxorubicin、Peripartum、基因突變（titin, lamin） | Systolic dysfunction；有 Eccentric hypertrophy |
| **Hypertrophic（HCM）** | 不對稱 **中隔肥厚** → LVOT obstruction | **AD 遺傳**（β-myosin heavy chain / myosin-binding protein C）；**年輕運動員猝死最常見原因** | Myocyte disarray；Diastolic dysfunction；Murmur 增強：Valsalva、standing（前負荷↓） |
| **Restrictive** | 心室壁僵硬 → 舒張充填受限 | **Amyloidosis**（最常見 restrictive CM）、Sarcoidosis、Hemochromatosis、Endomyocardial fibrosis、Radiation | Diastolic dysfunction；Normal/decreased cavity size |

### 9.5 心包膜疾病

- **Pericarditis**：胸痛（leaning forward 減輕）、pericardial friction rub、diffuse ST elevation + PR depression
    - 原因：Viral（Coxsackie B, most common）、Uremia、MI（Dressler syndrome）、TB、SLE
- **Cardiac Tamponade**：心包積液壓迫心臟 → Beck's triad（低血壓 + JVD + 心音減弱）、Pulsus paradoxus
- **Constrictive Pericarditis**：心包纖維化/鈣化 → 舒張受限；Kussmaul sign（吸氣 JVP↑）；TB 為常見原因

### 9.6 心臟腫瘤

| 腫瘤 | 特徵 |
|------|------|
| **Myxoma** | 成人最常見原發性心臟腫瘤；好發 **左心房**；附著於 fossa ovalis；可造成瓣膜阻塞（ball-valve effect）→ syncopal episodes；散發或 Carney complex |
| **Rhabdomyoma** | **兒童**最常見原發性心臟腫瘤；與 **Tuberous Sclerosis** 相關 |
| **Metastatic tumors** | 比原發性心臟腫瘤常見得多 |

## 十、呼吸系統病理（Pulmonary Pathology）

### 10.1 阻塞性肺疾病

### 10.2 限制性肺疾病

- PFT：FEV₁↓、FVC↓、**FEV₁/FVC 正常或↑**、TLC↓、DLCO↓

| 類型 | 舉例 |
|------|------|
| **Idiopathic Pulmonary Fibrosis（IPF / UIP）** | 最常見 idiopathic ILD；**Usual interstitial pneumonia（UIP）** pattern → temporal heterogeneity（新舊病灶並存）；HRCT：**honeycombing（蜂窩肺）**、traction bronchiectasis（下葉為主）；**Pirfenidone / Nintedanib** 可延緩 |
| **Pneumoconioses** | **Asbestosis**（下葉纖維化 + pleural plaques；mesothelioma）；**Silicosis**（上葉纖維化 + eggshell calcification of hilar LN；↑ TB 風險）；**Coal worker's pneumoconiosis**（anthracosis；Caplan syndrome = CWP + RA）；**Berylliosis**（non-caseating granuloma，類似 sarcoidosis） |

### 10.3 肺癌（Lung Cancer）

| 類型 | 位置 | 特徵 | 備註 |
|------|------|------|------|
| **Adenocarcinoma** | **周邊** | 最常見肺癌類型（含非吸菸者）；腺體分化 / 黏液分泌；可見 **Lepidic pattern（formerly BAC）**；EGFR mutation、ALK rearrangement 較多 | Clubbing、Hypertrophic osteoarthropathy |
| **Squamous Cell Carcinoma（SCC）** | **中央** | 與吸菸最強關聯；角化 / intercellular bridges；**Cavitation** 常見；**PTHrP → Hypercalcemia**（副腫瘤） | Pancoast tumor（肺尖）→ 臂叢/交感神經壓迫 → Horner syndrome |
| **Small Cell Lung Carcinoma（SCLC）** | **中央** | Neuroendocrine 分化（chromogranin+, synaptophysin+）；**極高轉移率**；**副腫瘤**：SIADH、Cushing（ectopic ACTH）、Lambert-Eaton | **不手術**（確診時已轉移）；Chemo + RT |
| **Large Cell Carcinoma** | **周邊** | 未分化、排除其他類型後之診斷 | 預後差 |
| **Carcinoid Tumor** | 中央或周邊 | 低度惡性 neuroendocrine；可致 carcinoid syndrome（若轉移至肝） | — |

- **Pancoast tumor**：肺尖腫瘤（通常 SCC）→ 壓迫 **brachial plexus**（C8-T1 → 上肢疼痛/萎縮）+ **sympathetic chain**（**Horner syndrome**：miosis + ptosis + anhidrosis）+ SVC
- **SVC syndrome**：面部水腫、頸靜脈怒張、上肢水腫；常因肺癌或淋巴瘤壓迫 SVC

### 10.4 肋膜疾病

| 疾病 | 特徵 |
|------|------|
| **Mesothelioma** | **Asbestos** 暴露（潛伏期 25–45 年）；**Calretinin(+), Cytokeratin(+)**；預後極差 |
| **Pneumothorax** | **Primary spontaneous**：瘦高年輕男性；**Secondary**：COPD、CF；**Tension**：致命性，縱膈腔移位 → obstructive shock |

### 10.5 ARDS（Acute Respiratory Distress Syndrome）

- **原因**：Sepsis（最常見）、外傷、吸入、輸血反應（TRALI）、胰臟炎
- **病理**：Diffuse Alveolar Damage（DAD）
    - **Exudative phase**：**Hyaline membranes**（fibrin + necrotic debris 沿肺泡壁排列）
    - **Proliferative phase**：Type II pneumocyte 增生
    - **Fibrotic phase**：可致肺纖維化
- **臨床**：急性呼吸衰竭、bilateral diffuse infiltrates（非心因性肺水腫）、PaO₂/FiO₂ ≤300
- **Neonatal RDS**（Hyaline Membrane Disease）：**Surfactant 不足**（Type II pneumocyte 未成熟）→ 肺泡塌陷；好發早產兒；Risk↑：糖尿病母親、C-section；Risk↓：Maternal corticosteroid（促進 surfactant 成熟）；L/S ratio <2 → 高風險

### 11.3 小腸

| **Meckel diverticulum** | 最常見先天性 GI 異常；**Rule of 2's**：2 feet from ileocecal valve, 2 inches long, 2% population, presents by age 2；含 ectopic gastric mucosa → ulceration → painless bleeding（兒童下消化道出血最常見原因之一）；**Technetium-99m pertechnetate scan**（Meckel scan） |

### 11.4 大腸

| 疾病 | 特徵 |
|------|------|
| **IBD — Crohn's disease** | **Mouth to anus**（最常見 terminal ileum）；**Skip lesions**；**Transmural inflammation**（all layers）→ **Non-caseating granulomas**；**Cobblestone mucosa**、**Creeping fat**、**String sign**（on barium）；Complications：Fistulas、Strictures、Abscess、Calcium oxalate kidney stones（fat malabsorption → oxalate↑）；**不增加** colon cancer 風險（但有小增加，不如 UC 顯著） |
| **IBD — Ulcerative Colitis** | **Rectum → proximal continuous**（限於大腸）；**黏膜/黏膜下層**（不侵犯全層）；**Crypt abscess**、**Pseudopolyps**（再生黏膜）、**Loss of haustra（lead-pipe colon）**；Complications：**Toxic megacolon**、**高風險 colon cancer**（pancolitis >10 年）、**Primary Sclerosing Cholangitis（PSC）**、p-ANCA(+) |
| **Diverticular disease** | **左側（sigmoid）**最常見；**假性憩室**（黏膜/黏膜下層突出，不含全層肌肉壁）；好發低纖維飲食老年人；**Diverticulitis**（LLQ pain, "left-sided appendicitis"）；**Diverticular bleeding**（painless lower GI bleeding，老年人常見原因） |
| **Colorectal Cancer（CRC）** | 第三常見癌症死因；左側（rectosigmoid）最常見；**Adenoma-carcinoma sequence**（APC → KRAS → p53）；Screening：50 歲起 colonoscopy every 10 yr |
| **Familial Adenomatous Polyposis（FAP）** | **APC** gene mutation（AD）；**>100 adenomatous polyps** by teens；若不做 prophylactic colectomy → **100% → CRC**；**Gardner syndrome**（FAP + osteomas + desmoid tumors + soft tissue tumors）；**Turcot syndrome**（FAP + CNS tumors, medulloblastoma） |
| **Lynch syndrome（HNPCC）** | **Mismatch repair gene** mutation（MLH1, MSH2）；**Microsatellite instability**；右側大腸癌為主；↑ Risk：endometrial, ovarian, urinary tract cancer；**Amsterdam criteria**：≥3 affected members, ≥2 generations, ≥1 diagnosed <50 歲 |
| **Peutz-Jeghers syndrome** | **STK11/LKB1**（AD）；**Hamartomatous polyps**（小腸為主）+ **Mucocutaneous pigmentation**（嘴唇、口腔黏膜）；↑ Risk：GI cancer、breast、ovarian |
| **Juvenile polyps** | **Hamartomatous**；兒童最常見 polyp；通常單一且自限；Juvenile polyposis syndrome → ↑ CRC risk |
| **Hirschsprung disease** | Neural crest cells 未遷移 → **aganglionic segment**（缺乏 Meissner + Auerbach plexus）；**Rectum 必受累且向近端延伸**；新生兒不排胎便 → 功能性阻塞；確診：**Rectal suction biopsy**（absence of ganglion cells）；與 **Down syndrome** 相關 |
| **Appendicitis** | 最常見外科急症；McBurney point 壓痛（RLQ）；**Fecalith（糞石）** 最常見原因 |

| 疾病 | 特徵 |
|------|------|
| **Hepatitis B** | DNA virus（Hepadnavirus）；血液/體液傳染；**Ground-glass hepatocytes**（HBsAg 堆積 ER）；**可致肝硬化 + HCC**；Serology 詳見感染科 |

|------|------|

## 十二、腎臟病理（Renal Pathology）

### 12.1 腎絲球疾病

#### Nephrotic Syndrome vs Nephritic Syndrome

| | **Nephrotic** | **Nephritic** |
|--|--------------|--------------|
| 蛋白尿 | **>3.5 g/day（massive）** | Moderate（<3.5 g/day） |
| 血尿 | 不明顯 | **RBC casts, dysmorphic RBC** |
| 水腫 | 嚴重（眼周、全身） | 中等 |
| 血清 Albumin | ↓↓ | 正常或輕度↓ |
| Lipiduria | **有**（oval fat bodies, Maltese cross） | 無 |
| 高血壓 | 可有 | **常見** |
| 併發症 | 血栓（**Renal vein thrombosis**，尤其 membranous）、感染 | 腎功能急速惡化（RPGN） |

#### 主要腎絲球疾病

| 疾病 | 類型 | 特徵 |
|------|------|------|
| **Minimal Change Disease（MCD）** | **Nephrotic** | **兒童** nephrotic syndrome 最常見原因；LM 正常；EM：**Podocyte foot process effacement**；IF 陰性；**Corticosteroid 反應極佳** |
| **Focal Segmental Glomerulosclerosis（FSGS）** | **Nephrotic** | **成人/非裔美國人** nephrotic 最常見原因；HIV 相關（collapsing variant）；部分腎絲球部分硬化；Steroid 反應差；常進展至 ESRD |
| **Membranous Nephropathy** | **Nephrotic** | 成人白人 nephrotic 常見原因；**Diffuse GBM thickening**（spike-and-dome on EM）；**Subepithelial deposits（granular IF）**；**Anti-PLA2R Ab**（primary）；Secondary：SLE（Class V）、HBV、drugs（NSAIDs, gold, penicillamine）、malignancy；**Renal vein thrombosis** 風險最高 |
| **Membranoproliferative GN（MPGN）** | Nephrotic/Nephritic | **Tram-track（double contour）** appearance on LM（GBM splitting）；**Subendothelial deposits**（Type I, immune complex, HCV 相關）；**Dense deposit disease（C3GN）**（Type II, C3 nephritic factor 穩定 C3 convertase）；低補體 |
| **IgA Nephropathy（Berger disease）** | **Nephritic** | **全球最常見腎絲球腎炎**；上呼吸道感染後 **1-2 天** 出現肉眼血尿（vs PSGN 2-4 週後）；**Mesangial IgA deposits**；可能進展至 CKD |
| **Post-Streptococcal GN（PSGN）** | **Nephritic** | Group A Strep **pharyngitis（2-4 wk 後）** 或 skin infection（3-6 wk 後）；**Subepithelial humps**（electron dense deposits on EM）；**Granular IF（"starry sky"）**；低補體（C3↓）；兒童預後佳（通常自限） |
| **RPGN（Rapidly Progressive GN）** | **Nephritic** → 快速腎衰竭 | **Crescents**（Bowman's space 內增生）on biopsy |

#### RPGN 分型

| 類型 | 機制 | IF | 疾病 |
|------|------|-------|------|
| **Type I** | Anti-GBM Ab | **Linear** | **Goodpasture syndrome**（肺出血 + GN） |
| **Type II** | Immune complex | **Granular** | PSGN、SLE（Class III/IV）、IgA nephropathy |
| **Type III** | Pauci-immune（ANCA-associated） | **Negative** | **GPA、MPA、EGPA** |

### 12.2 腎小管與間質疾病

| 疾病 | 特徵 |
|------|------|
| **Acute Tubular Necrosis（ATN）** | 急性腎衰竭最常見原因；**Ischemic**（休克、sepsis）→ PCT + TAL（vulnerable segments）；**Nephrotoxic**（aminoglycosides、cisplatin、contrast dye、myoglobin）→ PCT；病程：Initiation → Maintenance（oliguria）→ Recovery（polyuria）；**Muddy brown granular casts** in urine |
| **Acute Interstitial Nephritis（AIN）** | 藥物過敏（NSAIDs、β-lactam、Rifampin、PPI、Sulfonamides）→ **Type IV hypersensitivity**；Triad：Fever + Rash + **Eosinophilia + Eosinophiluria**；尿液：**WBC casts, eosinophils** |
| **Renal Papillary Necrosis** | **Diabetes**、**Sickle cell disease**、**NSAIDs**（chronic analgesic use）、Pyelonephritis；Necrotic papillae slough → hematuria + flank pain |
| **Fanconi syndrome** | **Proximal tubule** 整體再吸收障礙 → glycosuria + aminoaciduria + phosphaturia + bicarbonaturia（Type II RTA）；原因：Cystinosis（兒童最常見）、Wilson disease、Lead、Multiple myeloma |

### 12.3 腎臟腫瘤

| 腫瘤 | 特徵 |
|------|------|
| **Renal Cell Carcinoma（RCC）** | 成人最常見腎臟惡性腫瘤；**Clear cell type**（最常見，VHL-associated）；Triad：Hematuria + Flank pain + Palpable mass（classic but uncommon）；副腫瘤：Polycythemia（EPO）、Hypercalcemia（PTHrP）、HTN（renin）；侵犯 **Renal vein → IVC**；與 VHL disease、smoking 相關 |
| **Wilms tumor（Nephroblastoma）** | **兒童**最常見腎臟腫瘤；**Triphasic**：blastemal + stromal + epithelial；**WT1 gene**；**WAGR syndrome**：Wilms + Aniridia + GU anomalies + mental Retardation（WT1 + PAX6 deletion, chr 11p13）；**Beckwith-Wiedemann syndrome**：chr 11p15 → Macrosomia + Macroglossia + Organomegaly + Wilms |
| **Angiomyolipoma** | 含血管 + 平滑肌 + 脂肪（hamartoma）；與 **Tuberous Sclerosis** 相關 |
| **Oncocytoma** | 良性；大量嗜酸性粒線體；well-circumscribed |
| **Transitional Cell Carcinoma（Urothelial）** | Renal pelvis → ureter → bladder（最常見）；與 **吸菸、Cyclophosphamide、Phenacetin、Aniline dyes** 相關 |

## 十三、內分泌病理（Endocrine Pathology）

### 13.1 甲狀腺

| 疾病 | 特徵 |
|------|------|
| **Graves' disease** | 最常見甲狀腺亢進原因；**TSI（Anti-TSH receptor stimulating Ab）**；**Diffuse goiter** + **Exophthalmos**（眼突）+ **Pretibial myxedema**；Path：**Scalloped colloid**（colloid 被吸收的痕跡）+ 濾泡上皮增生；Type II Hypersensitivity |
| **Hashimoto thyroiditis** | 最常見甲狀腺炎 & 最常見甲狀腺功能低下原因；**Anti-TPO Ab（anti-microsomal）** + **Anti-thyroglobulin Ab**；Path：**Hürthle cells**（oxyphilic metaplasia, 嗜酸性粒線體豐富細胞）+ **Lymphoid follicles with germinal centers**；↑ Risk **Thyroid lymphoma（MALT → DLBCL）** |
| **Subacute（de Quervain）thyroiditis** | 病毒感染後 → 甲狀腺疼痛 + granulomatous inflammation；自限；先 hyperthyroid → hypothyroid → euthyroid |
| **Riedel thyroiditis** | **IgG4-related**；甲狀腺纖維化硬如石頭（rock-hard, "woody"）；可壓迫氣管 |

#### 甲狀腺癌

| 類型 | 特徵 | 預後 |
|------|------|------|
| **Papillary** | **最常見**（~80%）；**Orphan Annie eye nuclei**（空亮核）、**Psammoma bodies**（鈣化同心圓層）、**Nuclear grooves / Intranuclear inclusions**；**淋巴轉移**為主；與**輻射暴露**、RET/PTC、BRAF 相關；預後極佳 | 極好 |
| **Follicular** | **血行轉移**（bone, lung）；**Hürthle cell variant**；需看整個包膜/血管侵犯（FNA 無法區分良惡性 → 需手術切片）；RAS mutation | 好 |
| **Medullary** | 來自 **parafollicular C cells** → **Calcitonin↑**；**Amyloid stroma**（calcitonin 衍生）；**Sporadic（80%）** 或 **Familial（MEN 2A/2B → RET proto-oncogene）** | 中等 |
| **Anaplastic** | **未分化**；老年人；極具侵犯性；**預後最差**（數月內死亡） | 極差 |

- **Psammoma bodies** 出現於：**P**apillary thyroid ca、**P**sammomatous meningioma、**P**apillary serous cystadenocarcinoma of ovary、**P**rolactinoma（偶見）

### 13.2 副甲狀腺

### 13.3 腎上腺

| 疾病 | 特徵 |
|------|------|
| **Cushing syndrome** | Cortisol↑；原因：Iatrogenic（最常見）、Cushing disease（pituitary adenoma → ACTH↑）、Ectopic ACTH（SCLC）、Adrenal adenoma/carcinoma；**Moon face、Buffalo hump、Central obesity、Striae、HTN、Hyperglycemia、Osteoporosis、Proximal muscle weakness** |

### 15.1 貧血分類

| RBC 大小 | 貧血類型 |

| **Microcytic（MCV <80）** | **Iron deficiency**（最常見貧血）、Thalassemia、Anemia of chronic disease（也可正球性）、Sideroblastic anemia、Lead poisoning |
| **Normocytic（MCV 80-100）** | Acute blood loss、Anemia of chronic disease、Aplastic anemia、Hemolytic anemias（SCD, Hereditary spherocytosis, G6PD） |
| **Macrocytic / Megaloblastic（MCV >100）** | **B₁₂ deficiency**（subacute combined degeneration）、**Folate deficiency**（no neuro symptoms）→ 共同特徵：**Hypersegmented neutrophils**、**Megaloblastic marrow**（nuclear-cytoplasmic dyssynchrony） |
| **Macrocytic / Non-megaloblastic** | Alcoholism、Liver disease、Reticulocytosis、Hypothyroidism |

| 指標 | **Iron Deficiency** | **Anemia of Chronic Disease** | **Sideroblastic** |

| Serum Iron | ↓ | ↓ | ↑ |
| TIBC | ↑ | ↓ | ↓ |
| Ferritin | ↓ | ↑ | ↑ |
| Transferrin Sat | ↓ | ↓ | ↑ |

### 15.2 溶血性貧血

#### 遺傳性

| 疾病 | 缺陷 | 特徵 |
|------|------|------|
| **Hereditary Spherocytosis** | **Spectrin / Ankyrin / Band 3** 缺陷 → RBC 膜骨架不穩 | **Spherocytes**；**Osmotic fragility↑**；Splenomegaly；Aplastic crisis（Parvovirus B19）；**MCHC↑**；Coombs test **NEGATIVE**；治療：Splenectomy |
| **Hereditary Elliptocytosis** | Spectrin 缺陷 → 橢圓形 RBC | 通常臨床輕微 |
| **Sickle Cell Disease** | HbS（已於遺傳性疾病章節詳述） | — |
| **G6PD Deficiency** | 已於遺傳性疾病章節詳述 | **Heinz bodies + Bite cells** |
| **Thalassemia** | 已於遺傳性疾病章節詳述 | **Target cells** |
| **Paroxysmal Nocturnal Hemoglobinuria（PNH）** | **GPI anchor** 缺乏（PIGA gene mutation）→ DAF（CD55）和 MIRL（CD59）缺失 → complement-mediated hemolysis | **Intravascular hemolysis**；Hemoglobinuria（dark morning urine）；↑ Risk：**Thrombosis**（hepatic vein = Budd-Chiari, most feared）、aplastic anemia；Dx：**Flow cytometry**（CD55/CD59↓）；Tx：**Eculizumab**（anti-C5） |

#### 後天性

| 疾病 | 特徵 |
|------|------|
| **Autoimmune Hemolytic Anemia（AIHA）** | **Warm AIHA**：IgG → **extravascular**（spleen）；Coombs test(+)；SLE、CLL、Methyldopa；**Cold AIHA**：IgM → **intravascular** + extravascular（liver）；Mycoplasma pneumoniae、EBV |
| **Microangiopathic Hemolytic Anemia（MAHA）** | **Schistocytes**（fragmented RBC）；Coombs test(−)；見於 **TTP、HUS、DIC、HELLP、Malignant HTN、Mechanical heart valves** |

### 15.3 血小板疾病

| 疾病 | 特徵 |
|------|------|
| **ITP（Immune Thrombocytopenic Purpura）** | **Anti-platelet Ab（IgG against GP IIb/IIIa）** → splenic destruction；兒童：急性（viral 後）→ 自限；成人：慢性；Lab：Platelet↓、PT/aPTT 正常、BT↑、Megakaryocytes↑ in marrow；Tx：Corticosteroid → IVIG → Splenectomy → Rituximab、Thrombopoietin receptor agonist（Eltrombopag、Romiplostim） |
| **TTP（Thrombotic Thrombocytopenic Purpura）** | **ADAMTS13 deficiency** → ultra-large vWF multimers → platelet microthrombi → MAHA；**Pentad**：Thrombocytopenia + MAHA + Fever + Renal dysfunction + Neurologic symptoms；Tx：**Plasma exchange（PLEX）**（emergent）+ Corticosteroid；**DO NOT give platelets**（worsens thrombosis） |
| **HUS（Hemolytic Uremic Syndrome）** | **Typical**：Shiga toxin（E. coli O157:H7、Shigella dysenteriae）→ endothelial damage → Triad：MAHA + Thrombocytopenia + **Acute renal failure**；兒童；**不用抗生素**（↑ toxin release）；**Atypical HUS**：Complement dysregulation → Eculizumab |
| **vWD（von Willebrand Disease）** | **最常見遺傳性出血疾病**；**AD**（most types）；vWF↓ → platelet adhesion↓ + Factor VIII↓（因 vWF 保護 VIII）；Lab：BT↑（or PFA-100↑）、aPTT↑（VIII↓）、PT 正常；**Ristocetin cofactor assay↓**；Tx：**Desmopressin（DDAVP）**（releases vWF from endothelial Weibel-Palade bodies）；**禁用於 Type 2B**（會 worsen thrombocytopenia） |
| **Bernard-Soulier syndrome** | **GP Ib** defect → 不能黏附到 vWF；**Large platelets**；Ristocetin assay **不可被 corrected by adding normal plasma**（因為 receptor 本身有缺陷） |
| **Glanzmann thrombasthenia** | **GP IIb/IIIa** defect → 血小板無法凝集；BT↑；Aggregation 對 **所有 agonists 異常**（除 ristocetin 正常） |
| **HIT（Heparin-Induced Thrombocytopenia）** | **Type II**（immune-mediated）：Ab vs **PF4-heparin complex** → platelet activation → **thrombosis**（paradoxical）；Platelet↓ + thrombosis（DVT/PE/stroke）；4-10 天 after heparin；Tx：**停 heparin** + 改用 **Direct thrombin inhibitor（Argatroban, Bivalirudin）** 或 **Fondaparinux** |

### 15.5 淋巴瘤

|------|------|

|------|------|
| **Ischemic stroke（最常見 85%）** | Thrombotic（大動脈粥狀硬化）或 Embolic（心臟來源：AF、IE、Paradoxical）；病理：**Liquefactive necrosis**（腦梗塞特殊為液化性壞死，非凝固性）；**Red neurons**（eosinophilic cytoplasm, pyknotic nuclei, 12-24 hr）→ Neutrophils（1-3 days）→ Macrophages / Gliosis（weeks-months）→ **Cystic cavity（glial scar）** |
| **Hemorrhagic stroke** | **Intracerebral hemorrhage**：高血壓（最常見原因）→ **Charcot-Bouchard microaneurysms** → basal ganglia（putamen 最常見位置）、thalamus、pons、cerebellum；**Subarachnoid hemorrhage（SAH）**：Berry aneurysm rupture（AComm 最常見位置）→ 劇烈突發頭痛（thunderclap headache）→ CT → LP（xanthochromia）→ CTA/DSA；Complication：Vasospasm（3-14 days, treated with Nimodipine） |
| **Epidural hematoma** | **Middle meningeal artery**（顳骨骨折）；CT：**Biconvex / Lens-shaped**；Lucid interval → rapid deterioration；Does not cross suture lines |
| **Subdural hematoma** | **Bridging veins**（tearing）；CT：**Crescent-shaped**；Risk：老年人（brain atrophy → veins stretched）、嬰兒（shaken baby syndrome）、Anticoagulant use；Crosses suture lines |

### 16.2 CNS 腫瘤

| 腫瘤 | 特徵 |
|------|------|
| **Glioblastoma（GBM, Grade IV）** | **最常見成人原發性惡性腦腫瘤**；好發大腦半球；**Butterfly glioma（crosses corpus callosum）**；Path：Pseudopalisading necrosis + Microvascular proliferation；**GFAP(+)**；Median survival ~15 months |
| **Meningioma** | **最常見成人 benign intracranial tumor**；來自 arachnoid cap cells；**Psammoma bodies**；Well-circumscribed, attached to dura；多數為良性；WHO Grade I |
| **Schwannoma** | **CN VIII（vestibular division）** 最常見；**S-100(+)**；**Antoni A（compact, spindle cells）+ Antoni B（loose, myxoid）**；**NF2** → bilateral；Unilateral → sporadic |
| **Pilocytic Astrocytoma** | **兒童**最常見腦腫瘤整體；**Cerebellum**；Cystic + mural nodule；**Rosenthal fibers + Eosinophilic granular bodies**；WHO Grade I；Excellent prognosis |
| **Medulloblastoma** | **兒童最常見惡性 posterior fossa tumor**；**Cerebellum**（vermis）；Highly malignant（Grade IV）；Can **seed via CSF（drop metastasis）**；Homer-Wright rosettes；與 **Turcot syndrome（APC-related）** 相關 |
| **Ependymoma** | **4th ventricle**（兒童）；Perivascular pseudorosettes；Can cause hydrocephalus |
| **Craniopharyngioma** | 兒童/青少年；**Suprasellar**（most common suprasellar mass in children）；來自 Rathke's pouch remnant；**Calcifications**；Motor oil-like fluid（cholesterol crystals）；Bitemporal hemianopsia（壓迫 optic chiasm） |
| **Oligodendroglioma** | "**Fried egg**" appearance（perinuclear halos）；**Chicken-wire vascularity**；**1p/19q co-deletion**（好預後標記）；前額葉常見 |
| **Hemangioblastoma** | **Cerebellum**（最常見位置）；Highly vascular；**VHL disease**；可分泌 EPO → Polycythemia |
| **CNS Lymphoma** | 通常 DLBCL；**AIDS-defining illness**；**EBV** 相關；常為 periventricular（ring-enhancing lesion, but solid, cf Toxoplasma which is also ring-enhancing） |

### 16.3 神經退化性疾病

| 疾病 | 病理特徵 | 臨床 |
|------|---------|------|
| **Alzheimer disease** | **Amyloid plaques（Aβ42, extracellular）** + **Neurofibrillary tangles（Tau protein, intracellular, 過度磷酸化）**；**Hirano bodies**；Cerebral amyloid angiopathy → lobar hemorrhage；APP gene on chr 21 → **Down syndrome → early Alzheimer's**；基因：**APOE ε4** = risk factor、**APOE ε2** = protective；Presenilin 1/2 → early-onset（AD） | 漸進性記憶喪失 → 失語、失用、失認 → 完全失能 |
| **Parkinson disease** | **Lewy bodies**（α-synuclein, intracytoplasmic, eosinophilic, round inclusion）in **Substantia nigra**（dopaminergic neuron loss）；**Substantia nigra depigmentation** | Resting tremor（pill-rolling）、Rigidity（cogwheel）、Bradykinesia、Postural instability |
| **Huntington disease** | **Caudate atrophy**（+ putamen）→ enlarged lateral ventricles（ex vacuo）；Loss of GABAergic neurons | Chorea → Dementia → Death（已於遺傳性疾病章節詳述）|
| **ALS（Amyotrophic Lateral Sclerosis）** | Upper motor neuron（lateral corticospinal tract）+ Lower motor neuron（anterior horn cells）degeneration → combined UMN + LMN signs；**No sensory loss**；Frontotemporal dementia in some | Fasciculations + Atrophy（LMN）+ Hyperreflexia + Spasticity（UMN）；Respiratory failure（主要死因） |
| **Frontotemporal Dementia（Pick disease）** | **Pick bodies**（Tau, round, intracytoplasmic）+ **Pick cells**（ballooned neurons）；Frontal/Temporal lobe atrophy | 早期人格/行為改變 + 語言障礙（vs Alzheimer：早期記憶障礙）|
| **Lewy Body Dementia** | 與 Parkinson 相似的 Lewy bodies 但 **widespread（cortex）** | 波動性認知障礙 + **Visual hallucinations** + Parkinsonism；**Avoid antipsychotics（neuroleptic sensitivity）** |
| **Creutzfeldt-Jakob Disease（CJD）** | **Prion disease**（PrPˢᶜ → misfolded protein → no immune response）；**Spongiform encephalopathy**（cortex vacuolation） | Rapidly progressive dementia + Myoclonus + 死亡（通常 <1 year）；**14-3-3 protein in CSF** |

### 16.4 脫髓鞘疾病

| 疾病 | 特徵 |
|------|------|
| **Multiple Sclerosis（MS）** | **CNS white matter demyelination**（plaques）at **different times** and **different locations**（dissemination in time and space）；好發年輕女性；**Periventricular plaques（Dawson fingers on MRI）**；**Oligoclonal bands in CSF**（IgG）；**Optic neuritis**（常為首發症狀）→ Internuclear ophthalmoplegia（MLF lesion）；Lhermitte sign（neck flexion → electric sensation）；Charcot triad（nystagmus + intention tremor + scanning speech）；Tx：Acute：IV methylprednisolone；Maintenance：Interferon-β、Natalizumab（anti-α4 integrin）、Fingolimod（S1P modulator） |
| **Guillain-Barré Syndrome（GBS）** | **PNS demyelination**（acute inflammatory demyelinating polyradiculoneuropathy, AIDP）；Post-infectious（Campylobacter jejuni 最常見）；**Ascending paralysis**（symmetrical, areflexia）；**Albuminocytologic dissociation**（↑protein, normal cell count in CSF）；Risk：Respiratory failure → intubation；Tx：**IVIG or Plasmapheresis**（NOT steroids） |
| **Central Pontine Myelinolysis（Osmotic Demyelination Syndrome）** | **太快糾正低血鈉** → Pons demyelination → Locked-in syndrome、quadriplegia、dysphagia |

## 十七、骨與軟組織病理（Bone & Soft Tissue Pathology）

### 17.1 代謝性骨病

| 疾病 | 特徵 |
|------|------|
| **Osteoporosis** | 骨量↓ but 正常礦化（質正常但量不足）；最常見代謝性骨病；停經後女性（Type I, estrogen↓）、老年（Type II, senile）；Pathologic fractures：vertebral compression（最常見）、Colles' fracture（distal radius）、femoral neck fracture；DEXA scan（T-score ≤−2.5） |
| **Osteomalacia / Rickets** | 骨基質正常但**礦化不足**（osteoid↑ unmineralized）；Vitamin D deficiency；兒童：Rickets（骨骼彎曲、rachitic rosary、craniotabes、widened growth plates）；成人：Osteomalacia（bone pain, proximal weakness, Looser zones / pseudofractures） |
| **Paget Disease of Bone** | 異常骨重塑：**Osteoclastic → Osteoblastic → Quiescent（sclerotic）**；好發 >40 歲；Skull enlargement（hat doesn't fit）、Long bone bowing、**Mosaic（jigsaw puzzle）pattern**（lamellar bone + woven bone）；Lab：**ALP↑↑↑**（最高）、Ca/PO₄ normal；Complications：**HF（high-output）**、Deafness（CN VIII 壓迫）、**Osteosarcoma（~1%）** |
| **Osteitis Fibrosa Cystica** | **Hyperparathyroidism** → excessive bone resorption；**Brown tumors**（hemorrhagic cystic lesions filled with hemosiderin-laden macrophages + osteoclasts） |

### 17.2 骨腫瘤

| 腫瘤 | 年齡 | 位置 | 特徵 |
|------|------|------|------|
| **Osteochondroma（外生性骨軟骨瘤）** | 青少年 | 長骨 metaphysis | **最常見良性骨腫瘤**；Bony outgrowth with cartilaginous cap；Hereditary multiple exostoses（EXT1/2）→ ↑ risk chondrosarcoma |
| **Giant Cell Tumor（GCT）** | 20-40 歲 | Long bone **epiphysis**（knee area） | **Locally aggressive**；"Soap-bubble" appearance on X-ray；Multinucleated giant cells（osteoclast-like）；RANKL 相關 → Denosumab |
| **Osteosarcoma** | **10-20 歲**（最常見原發性惡性骨腫瘤，不含 myeloma）；Second peak：>65 歲（Paget disease） | Long bone **metaphysis**（distal femur / proximal tibia） | **Codman triangle**（lifted periosteum）+ **Sunburst pattern**；Osteoid production by tumor cells；與 **Rb mutation、p53 mutation** 相關；Hematogenous metastasis → lung |
| **Ewing Sarcoma** | **<15 歲** | Long bone **diaphysis** | **t(11;22)**（EWS-FLI1）；**Onion-skin periosteal reaction**；Small round blue cells；**CD99（MIC2）(+)**；Aggressive |
| **Chondrosarcoma** | 40-60 歲 | Pelvis, proximal femur, shoulder | Malignant cartilage tumor；Does not respond to chemo/RT → **Surgical resection** |

## 十八、皮膚病理（Dermatopathology）

### 18.1 皮膚腫瘤

| 腫瘤 | 特徵 |
|------|------|
| **Basal Cell Carcinoma（BCC）** | **最常見皮膚癌**；日曬暴露部位（面部上半部 > 唇部以上）；**Pearly, rolled borders** + Telangiectasia + Central ulceration（rodent ulcer）；Path：**Palisading basaloid cells**；**Locally invasive but rarely metastasizes** |
| **Squamous Cell Carcinoma（SCC）** | 第二常見皮膚癌；日曬部位 / 嘴唇 / 疤痕（**Marjolin ulcer**）；可由 **Actinic keratosis**（癌前病變）進展；可轉移；Keratin pearls（分化好） |
| **Melanoma** | 最致命皮膚癌；與 UV 暴露（intermittent, sunburn）、Dysplastic nevi（atypical moles）、Family history 相關；**ABCDEs**：Asymmetry, Border irregularity, Color variation, Diameter >6mm, Evolving；**Breslow depth（最重要預後因子）**；Types：Superficial spreading（最常見）、Nodular（worst prognosis per size）、Lentigo maligna（sun-exposed, elderly face）、Acral lentiginous（palms/soles/nailbed, most common in dark-skinned）；S-100(+), HMB-45(+), Melan-A(+)；**BRAF V600E mutation** → Vemurafenib |
| **Actinic Keratosis** | **Precancer** of SCC；Rough, scaly patch on sun-exposed skin |
| **Seborrheic Keratosis** | **Benign**；**Stuck-on appearance**；Keratin pseudo-horn cysts；Common in elderly；**Leser-Trélat sign**：sudden appearance of many SK → suggests underlying GI malignancy |

### 18.2 水皰性皮膚病

| 疾病 | 抗體 / 機制 | 特徵 |
|------|------------|------|
| **Pemphigus Vulgaris** | **Anti-Desmoglein 3（Dsg3）IgG** → intraepidermal acantholysis | **Flaccid blisters** + oral erosions；**Nikolsky sign (+)**；**Intraepidermal split**（suprabasal）；IF：**Net-like（reticular）IgG** along cell surfaces；最嚴重，可致命（if untreated） |
| **Bullous Pemphigoid** | **Anti-BP180（BP230）IgG** → subepidermal | **Tense blisters**（不易破）；通常不侵犯口腔；**Subepidermal split**；IF：**Linear IgG/C3 at basement membrane**；Nikolsky sign (−)；老年人；預後較好 |
| **Dermatitis Herpetiformis** | **IgA** deposits at dermal papillae | 與 **Celiac disease** 相關；極癢的 vesicles on elbows, knees, buttocks；Granular IgA on IF；Tx：**Dapsone** + Gluten-free diet |

## 十九、類澱粉沉積症（Amyloidosis）— 重點整理

| 類型 | Precursor Protein | 相關疾病 |
|------|-------------------|---------|
