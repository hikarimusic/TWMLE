# 免疫學

## 一、免疫系統總論

### 1.1 先天免疫 vs 後天免疫

| 特徵 | **先天免疫（Innate Immunity）** | **後天免疫（Adaptive Immunity）** |
|------|-------------------------------|----------------------------------|
| 速度 | 即時（數分鐘~數小時） | 慢（數天~數週，初次接觸） |
| 專一性 | **非專一性**（辨認 PAMP/DAMP） | **高度專一性**（辨認特定 epitope） |
| 記憶性 | **無**（傳統觀點）；有「trained immunity」概念 | **有**（memory cells → 再次反應更快更強） |
| 受體 | **Pattern recognition receptors（PRR）**：TLR、NLR、RLR、CLR、cGAS-STING | **TCR、BCR（Ig）**：經基因重組產生多樣性 |
| 細胞 | Neutrophil、Macrophage、DC、NK cell、Mast cell、Eosinophil、Basophil、ILC | **T cell、B cell** |
| 體液因子 | Complement、Lysozyme、Defensin、Acute phase proteins、Interferons | **Antibodies（Immunoglobulins）**、Cytokines |
| 屏障 | 皮膚黏膜、胃酸、纖毛、正常菌叢 | — |

### 1.2 免疫系統的細胞

| 細胞 | 來源 | 主要功能 | 表面標記 |
|------|------|----------|----------|
| **Neutrophil** | 骨髓 myeloid | **最豐富的白血球**；吞噬殺菌（最早到達）；形成 NETs | CD66b |
| **Macrophage** | 血中 Monocyte 遷入組織分化 | 吞噬、APC、分泌細胞因子 | CD14、CD68；**MHC II** |
| **Dendritic cell（DC）** | Myeloid / Plasmacytoid | **最強的 APC**；活化 naïve T cell | MHC II、CD80/86、CD11c |
| **NK cell** | Lymphoid（innate） | 殺死病毒感染細胞 & 腫瘤細胞（不需 MHC）；ADCC | **CD16**（FcγRIII）、**CD56**；**無 CD3** |
| **Mast cell** | 骨髓→組織定居 | 過敏反應（IgE-FcεRI）、釋放 Histamine | FcεRI、c-Kit（CD117） |
| **Eosinophil** | 骨髓 | 抗寄生蟲（MBP、ECP）；過敏反應 | CD193（CCR3） |
| **Basophil** | 骨髓 | 類似 Mast cell（但在血中）；釋放 Histamine、IL-4 | FcεRI、CD123 |
| **T helper（CD4⁺）** | 胸腺 | 輔助免疫反應（活化 B cell、Macrophage） | **CD3、CD4** |
| **Cytotoxic T（CD8⁺）** | 胸腺 | 殺死病毒感染/腫瘤細胞（MHC I 限制） | **CD3、CD8** |
| **B cell** | 骨髓成熟 | 產生抗體；APC | **CD19、CD20、CD21**（CR2）；MHC II |
| **Plasma cell** | B cell 終末分化 | **大量分泌抗體** | CD38、CD138；**不表現 MHC II 和表面 Ig** |
| **Regulatory T（Treg）** | 胸腺（nTreg）/周邊（iTreg） | 免疫抑制、維持自我耐受 | **CD4⁺CD25⁺FoxP3⁺** |

## 二、先天免疫的分子機制

### 2.1 Pattern Recognition Receptors（PRR）

| PRR 類型 | 位置 | 辨認目標（PAMP） | 重要例子 |
|----------|------|-------------------|----------|
| **Toll-like receptors（TLR）** | 細胞膜 / 內體膜 | 微生物成分 | 見下表 |
| **NOD-like receptors（NLR）** | 細胞質 | 細菌胞壁成分、危險信號 | **NOD1**（meso-DAP）、**NOD2**（MDP）；**NLRP3 inflammasome** |
| **RIG-I-like receptors（RLR）** | 細胞質 | 病毒 dsRNA | **RIG-I**、**MDA5** → IFN-β 產生 |
| **C-type lectin receptors（CLR）** | 細胞膜 | 醣類結構 | **Mannose receptor**、**Dectin-1**（β-glucan → 真菌辨認） |
| **cGAS-STING** | 細胞質 | **胞質 dsDNA** | cGAS 偵測 DNA → cGAMP → STING → **Type I IFN** |
| **Scavenger receptors** | 細胞膜 | 修飾的 LDL、微生物 | SR-A、CD36 |

### 2.2 Toll-like Receptors（TLR）詳解

| TLR | 位置 | 配體（PAMP） | 來源 |
|-----|------|-------------|------|
| **TLR1/2** | 細胞膜 | Lipopeptides（triacyl） | 細菌 |
| **TLR2/6** | 細胞膜 | Lipopeptides（diacyl）、Zymosan | 細菌、真菌 |
| **TLR3** | **內體膜** | **dsRNA** | 病毒 |
| **TLR4** | 細胞膜 | **LPS（Lipopolysaccharide）** | **G(−) 細菌**；需 MD-2、CD14 協助 |
| **TLR5** | 細胞膜 | **Flagellin** | 有鞭毛細菌 |
| **TLR7** | **內體膜** | **ssRNA** | 病毒（如 HIV、Influenza） |
| **TLR8** | **內體膜** | ssRNA | 病毒 |
| **TLR9** | **內體膜** | **CpG DNA（unmethylated）** | 細菌、病毒 |

- **TLR 信號傳遞**：
    - 大多數 TLR → **MyD88** adaptor → NF-κB 活化 → 促發炎細胞因子（TNF-α、IL-1、IL-6、IL-12）
    - **TLR3**（及 TLR4 部分）→ **TRIF** adaptor → **IRF3** → **Type I IFN（IFN-α/β）**
    - **TLR4** 兼用 MyD88 和 TRIF
- 口訣記憶（內體 TLR）：**3、7、8、9 在內體膜**（偵測核酸）

### 2.3 Inflammasome

- **NLRP3 inflammasome** 是最重要的：
    - 組成：NLRP3 + ASC adaptor + **pro-Caspase-1**
    - 活化信號：ATP 外流、K⁺ 外流、尿酸結晶（MSU）、膽固醇結晶、β-amyloid、矽塵、石棉、ROS
    - **Caspase-1 活化後**：
        1. 切割 **pro-IL-1β → IL-1β**（促發炎）
        2. 切割 **pro-IL-18 → IL-18**（促 IFN-γ）
        3. 切割 **Gasdermin D** → **Pyroptosis**（發炎性細胞死亡，形成膜孔）
- **臨床相關**：
    - **Gout**：MSU 結晶活化 NLRP3 → IL-1β↑ → 急性關節炎
    - **Familial Mediterranean Fever（FMF）**：**Pyrin** 基因（MEFV）突變 → inflammasome 過度活化 → 反覆發燒 + 多漿膜炎；治療：**Colchicine**
    - **Cryopyrin-Associated Periodic Syndromes（CAPS）**：NLRP3 gain-of-function → IL-1β↑↑；治療：**Anakinra（IL-1 receptor antagonist）**

### 2.4 吞噬作用（Phagocytosis）與殺菌機制

- **吞噬步驟**：
    1. **趨化（Chemotaxis）**：IL-8（CXCL8）、C5a、LTB4、fMLP → 吸引嗜中性球
    2. **附著（Attachment）**：直接或經 opsonin 介導（IgG Fc、C3b、MBL）
    3. **吞入（Ingestion）**：形成 phagosome
    4. **殺菌（Killing）**：
        - **Oxygen-dependent（呼吸爆發）**：
            - **NADPH oxidase** → O₂⁻ → H₂O₂ → HOCl（**Myeloperoxidase, MPO**）
            - 需要 **NADPH**（G6PD → PPP 提供）
        - **Oxygen-independent**：
            - Lysozyme、Defensins、Lactoferrin、Cathepsins、酸性 pH

- **Chronic Granulomatous Disease（CGD）**：
    - 缺陷：**NADPH oxidase**（最常見為 **gp91^phox 突變，X-linked**）
    - 無法產生 superoxide → 無法殺死 **catalase(+) 菌**
    - **易感菌**（口訣 **"PLACESS"**）：**P**seudomonas, **L**isteria（部分）, **A**spergillus, **C**andida（部分）, **E**. coli, **S**. aureus, **S**erratia, Nocardia, Burkholderia cepacia
    - 診斷：**Dihydrorhodamine（DHR）flow cytometry test**（取代舊的 NBT test）→ CGD 患者嗜中性球不發螢光
    - 治療：**TMP-SMX** 預防 + **Itraconazole** 預防 + **IFN-γ**

- **Myeloperoxidase（MPO）deficiency**：
    - 無法生成 HOCl → 但臨床通常**無症狀或輕微**（其他殺菌機制代償）
    - DHR/NBT test **正常**（NADPH oxidase 正常）
    - 偶爾 *Candida* 感染增加

- **Leukocyte Adhesion Deficiency（LAD）**：

| 類型 | 缺陷 | 特色 |
|------|------|------|
| **LAD-1** | **CD18（β2 integrin）**→ LFA-1（CD11a/CD18）、Mac-1（CD11b/CD18）、CR3 缺陷 | 臍帶延遲脫落、反覆感染、**無膿瘍形成**（嗜中性球無法從血管移出）、WBC↑↑（neutrophilia） |
| **LAD-2** | **Selectin ligand（Sialyl-Lewis X）** 缺陷（fucose metabolism 異常） | 較輕；智力障礙、短肢、反覆感染 |

- **Chédiak-Higashi Syndrome**：
    - 缺陷：**LYST（CHS1）** 基因 → lysosomal trafficking 異常 → **巨大顆粒**（giant granules in WBC）
    - 表現：反覆化膿性感染、**oculocutaneous albinism（部分白化）**、周邊神經病變、進行性神經退化
    - 血液抹片：**Giant azurophilic granules in neutrophils/lymphocytes**
    - 可出現 **hemophagocytic lymphohistiocytosis（HLH）** 加速期
    - AR 遺傳

### 2.5 NK Cell（Natural Killer Cell）

- **辨認機制**：平衡 **activating receptors** 和 **inhibitory receptors** 的信號
    - **Inhibitory receptors**（**KIR** 家族、CD94/NKG2A）→ 辨認 **self MHC I** → 抑制殺傷（"missing self" hypothesis）
    - **Activating receptors**（NKG2D、NKp30/44/46、CD16）→ 辨認壓力配體（MICA/B、ULBPs）或 IgG Fc
- **"Missing self" 殺傷**：病毒感染或腫瘤細胞常 **下調 MHC I** → 失去抑制信號 → NK cell 殺傷
- **ADCC（Antibody-Dependent Cell-Mediated Cytotoxicity）**：
    - **CD16（FcγRIII）** 結合包覆在靶細胞上的 **IgG** Fc → 活化 NK cell → 釋放 perforin + granzymes → 殺死靶細胞
- **殺傷機制**：
    - **Perforin**：在靶細胞膜打孔
    - **Granzyme B**：進入靶細胞 → 活化 **caspase cascade → apoptosis**
- **NK cell 活化的細胞因子**：IL-2、**IL-12**、IL-15、**IL-18**、IFN-α/β

### 2.6 急性期反應（Acute Phase Response）

- 主要由 **IL-6**（最重要）、IL-1、TNF-α 刺激肝臟產生急性期蛋白

| 急性期蛋白（↑） | 功能 |
|-----------------|------|
| **CRP（C-reactive protein）** | Opsonization（結合 C-polysaccharide）；活化補體（經典途徑） |
| **Serum Amyloid A（SAA）** | 長期升高 → **AA Amyloidosis** |
| **Ferritin** | 鐵儲存（從血中隔離鐵） |
| **Hepcidin** | 降低血清鐵（阻斷 ferroportin） |
| **Fibrinogen** | 凝血；ESR 上升的主因 |
| **α1-antitrypsin、α2-macroglobulin** | Protease inhibitors |
| **Ceruloplasmin** | 銅運輸、鐵氧化 |
| **Haptoglobin** | 結合游離 Hb |
| **Mannose-binding lectin（MBL）** | 補體 Lectin pathway |

| 負急性期蛋白（↓） | 備註 |
|-------------------|------|
| **Albumin** | 滲透壓維持 |
| **Transferrin** | 鐵運輸 |
| **Transthyretin（prealbumin）** | 營養指標 |

## 三、補體系統（Complement System）

### 3.1 三條活化途徑

| 途徑 | 啟動因子 | 重要成分 | 共同終點 |
|------|----------|----------|----------|
| **經典途徑（Classical）** | **IgG 或 IgM** 與抗原結合（Ag-Ab complex）→ **C1q** 結合 | C1q → C1r → C1s → **C4 → C2** → **C3 convertase = C4b2a** | **C3 → C3a + C3b** |
| **替代途徑（Alternative）** | 微生物表面直接活化；**C3 自發水解（tick-over）** | **C3 → C3b + Factor B + Factor D** → **C3 convertase = C3bBb**（**Properdin** 穩定） | 同上 |
| **凝集素途徑（Lectin）** | **MBL（Mannose-Binding Lectin）** 或 Ficolins 結合微生物醣類 | MBL → **MASP-1/2** → **C4 → C2** → C3 convertase = C4b2a | 同上 |

- **C3 convertase**：
    - Classical / Lectin：**C4b2a**（別名 C4b2b 在某些書中）
    - Alternative：**C3bBb**
- **C5 convertase**：C3 convertase + C3b
    - Classical / Lectin：**C4b2a3b**
    - Alternative：**C3bBb3b**
- **C3** 是三條途徑的匯合點，**血清中含量最多的補體**

### 3.2 補體功能

| 功能 | 關鍵成分 | 說明 |
|------|----------|------|
| **Opsonization（調理作用）** | **C3b**（最重要的 opsonin）、iC3b | 包覆微生物 → 促進吞噬（CR1、CR3 辨認） |
| **Anaphylatoxin（過敏毒素）** | **C3a、C4a、C5a** | Mast cell degranulation → Histamine release → 血管擴張、通透性↑、平滑肌收縮；**C5a 最強**（也是最強趨化因子） |
| **Chemotaxis（趨化）** | **C5a** | 吸引嗜中性球（最強趨化因子之一） |
| **Membrane Attack Complex（MAC）** | **C5b-C6-C7-C8-C9** | 在靶細胞膜打孔 → 細胞溶解；**尤其重要於 Neisseria 感染** |
| **Immune complex clearance** | C3b、C4b | 紅血球上 CR1 結合免疫複合物 → 運至脾/肝清除 |

### 3.3 補體調控蛋白

| 調控蛋白 | 功能 | 臨床缺陷 |
|----------|------|----------|
| **C1 inhibitor（C1-INH）** | 抑制 C1r/C1s、Kallikrein | **缺乏 → Hereditary Angioedema（HAE）**：Bradykinin↑ → 無搔癢/蕁麻疹的皮下/黏膜下水腫；**C4↓**（chronic consumption） |
| **Decay-Accelerating Factor（DAF/CD55）** | 加速 C3/C5 convertase 解離 | 缺乏（合併 CD59 缺乏）→ **PNH** |
| **CD59（Protectin / MIRL）** | 阻止 C9 聚合成 MAC | 同上 |
| **Factor H** | Cofactor for Factor I（降解 C3b）；抑制替代途徑 | 缺陷 → **atypical HUS（aHUS）** |
| **Factor I** | 切割 C3b → iC3b | 類似 |
| **MCP（CD46）** | Cofactor for Factor I | 與 aHUS 相關 |

### 3.4 補體缺陷的臨床

| 缺陷 | 易感/疾病 |
|------|-----------|
| **C1q、C2、C4 缺陷**（經典途徑早期） | **SLE-like disease**（免疫複合物清除↓，尤其 **C2 deficiency** 最常見的補體缺陷） |
| **C3 缺陷** | **嚴重反覆化膿性感染**（opsonization↓↓） |
| **C5-C9 缺陷（MAC 缺陷）** | **反覆 Neisseria 感染**（N. meningitidis, N. gonorrhoeae） |
| **C1-INH 缺陷** | **Hereditary Angioedema（HAE）**；AD |
| **DAF/CD59 缺陷** | **Paroxysmal Nocturnal Hemoglobinuria（PNH）**（PIGA gene → GPI anchor↓ → DAF/CD59↓ → complement-mediated hemolysis）；治療：**Eculizumab**（anti-C5 Ab） |
| **Factor H/I 缺陷** | **Atypical HUS**（aHUS）；治療：**Eculizumab** |
| **MBL 缺陷** | 嬰幼兒期反覆感染（通常輕微，成人後代償） |

## 四、MHC 與抗原呈現

### 4.1 MHC 分子

| 特徵 | **MHC I** | **MHC II** |
|------|-----------|------------|
| 基因 | **HLA-A、HLA-B、HLA-C** | **HLA-DP、HLA-DQ、HLA-DR** |
| 結構 | **α chain + β2-microglobulin** | **α chain + β chain** |
| 表現細胞 | **幾乎所有有核細胞**（+血小板）；**RBC 無 MHC I** | **APC**：DC、Macrophage、B cell；活化的 T cell |
| 結合 peptide | **8–10 AA** 的短肽 | **13–25 AA** 的較長肽 |
| 呈現對象 | **CD8⁺ T cell** | **CD4⁺ T cell** |
| 來源 | **內源性抗原**（胞內蛋白、病毒蛋白） | **外源性抗原**（吞噬/內吞的蛋白） |
| 加工途徑 | **Proteasome** → TAP 運至 ER → 與 MHC I 結合 → 呈現 | **Endosome/Lysosome** → 酸性蛋白酶處理 → CLIP 被 **HLA-DM** 移除 → peptide 與 MHC II 結合 |

### 4.2 抗原加工與呈現途徑

- **MHC I pathway（內源性 / Endogenous）**：
    1. 胞內蛋白（自身 or 病毒）→ **Proteasome** 切割成 peptide
    2. Peptide 經 **TAP（Transporter Associated with Antigen Processing）** 運至 ER
    3. 與 MHC I α chain + β2-microglobulin 結合
    4. 經 Golgi → 細胞表面呈現給 **CD8⁺ T cell**

- **MHC II pathway（外源性 / Exogenous）**：
    1. 外來抗原經吞噬/內吞 → 形成 phagolysosome
    2. 酸性蛋白酶（cathepsins）切割抗原
    3. MHC II 在 ER 中與 **Invariant chain（Ii, CD74）** 結合 → 防止 MHC II 在 ER 中結合內源性 peptide
    4. MHC II-Ii 送至 endosome → Ii 被降解，留下 **CLIP** 片段佔據 peptide groove
    5. **HLA-DM** 催化 CLIP 與外源性 peptide 交換
    6. MHC II-peptide 送至細胞表面呈現給 **CD4⁺ T cell**

- **Cross-presentation（交叉呈現）**：
    - **DC** 可將**外源性抗原**經 MHC I 途徑呈現給 **CD8⁺ T cell**
    - 重要於抗腫瘤免疫和抗病毒免疫
    - 機制：外源性抗原從 endosome 逃逸至細胞質 → 進入 proteasome → TAP → MHC I

## 五、後天免疫 ── T 細胞

### 5.1 T 細胞發育（Thymus）

- **來源**：骨髓造血幹細胞 → 前驅 T 細胞遷至**胸腺**成熟
- **發育階段**：
    1. **Double Negative（DN）**：CD4⁻ CD8⁻ → TCR β chain rearrangement → β-selection
    2. **Double Positive（DP）**：**CD4⁺ CD8⁺** → TCR α chain rearrangement → 完整 αβ TCR
    3. **Positive selection**（**皮質，cortical epithelial cells**）：
        - DP T cell 的 TCR 必須能與 **self-MHC** 有適度結合 → 才能存活
        - 無法辨認 self-MHC → apoptosis（**death by neglect**，約 90% 在此淘汰）
        - 決定 MHC restriction：辨認 MHC I → CD8⁺；辨認 MHC II → CD4⁺
    4. **Negative selection**（**皮髓交界/髓質，medullary epithelial cells + DC**）：
        - TCR 與 self-antigen/self-MHC 結合力**太強** → apoptosis（淘汰自體反應性 T cell）
        - **AIRE（Autoimmune Regulator）**：在胸腺髓質上皮細胞中表現**外周組織自身抗原** → 使對這些抗原反應的 T cell 被淘汰
        - **AIRE 突變 → APS-1（Autoimmune Polyendocrinopathy Syndrome Type 1 / APECED）**：多發自體免疫（副甲狀腺低下、腎上腺功能不全、慢性黏膜念珠菌感染）
    5. 通過雙重篩選 → **Single Positive（SP）**：CD4⁺ 或 CD8⁺ → 進入周邊

### 5.2 T 細胞活化（Two-Signal Model）

- **Signal 1**：**TCR-MHC/peptide 結合**
    - CD4⁺ T cell：TCR + MHC II
    - CD8⁺ T cell：TCR + MHC I
    - **CD3 complex**（含 ζ chain）：信號傳遞 → **ITAM** 磷酸化 → ZAP-70（T cell）

- **Signal 2（Co-stimulation）**：
    - **B7（CD80/CD86）on APC** ↔ **CD28 on T cell** → **活化**
    - 沒有 Signal 2 → **Anergy（無反應性）** → 是周邊耐受機制之一
    - **CTLA-4（CD152）**：T cell 上的抑制受體 → 與 B7 結合（比 CD28 親和力更高）→ **抑制 T cell 活化**
    - **PD-1**：T cell 上的抑制受體 → 結合 **PD-L1/PD-L2**（腫瘤/APC）→ T cell exhaustion → **免疫逃逸**

- **Signal 3**：**Cytokines** → 決定 T helper 分化方向

- **免疫檢查點抑制劑**：

| 藥物 | 靶點 | 用途 |
|------|------|------|
| **Ipilimumab** | **Anti-CTLA-4** | Melanoma |
| **Nivolumab、Pembrolizumab** | **Anti-PD-1** | Melanoma、NSCLC、多種腫瘤 |
| **Atezolizumab、Durvalumab** | **Anti-PD-L1** | Urothelial ca、NSCLC |

### 5.3 T Helper Cell 分化

| Th subset | 分化細胞因子 | 主轉錄因子 | 分泌的細胞因子 | 主要功能 | 相關疾病 |
|-----------|-------------|------------|----------------|----------|----------|
| **Th1** | **IL-12、IFN-γ** | **T-bet** | **IFN-γ**、IL-2、TNF-β | 活化 Macrophage → **胞內菌**防禦；**DTH（Type IV）** | 過度 → 自體免疫（MS、RA、Type 1 DM） |
| **Th2** | **IL-4** | **GATA-3** | **IL-4**、**IL-5**、IL-10、**IL-13** | **B cell class switch → IgE**；**Eosinophil** 活化；抗寄生蟲 | 過度 → **過敏/氣喘** |
| **Th17** | **IL-6 + TGF-β**（人）；IL-23（維持） | **RORγt** | **IL-17A/F**、IL-22、IL-21 | 招募 Neutrophil → **抗胞外菌和真菌** | 過度 → **自體免疫**（Psoriasis、RA、MS、IBD）；**Hyper-IgE syndrome（Job syndrome）** Th17↓ |
| **Treg** | **TGF-β、IL-2** | **FoxP3** | **TGF-β、IL-10、IL-35** | **免疫抑制**；維持自我耐受 | 缺陷 → **IPEX syndrome** |
| **Tfh（Follicular helper）** | IL-6、IL-21 | **Bcl-6** | **IL-21**、IL-4 | 幫助 B cell **germinal center** 反應、class switch、affinity maturation | — |

- **重要對立關係**：
    - **Th1 ↔ Th2**：IFN-γ 抑制 Th2 分化；IL-4/IL-10 抑制 Th1 分化
    - **Th17 ↔ Treg**：共用 TGF-β，但 IL-6 的有無決定方向（+IL-6 → Th17；−IL-6 → Treg）

### 5.4 CD8⁺ Cytotoxic T Cell（CTL）殺傷機制

- **Perforin-Granzyme pathway**（主要）：
    - Perforin 打孔 → Granzyme B 進入靶細胞 → 活化 **Caspase cascade → Apoptosis**
- **Fas-FasL pathway**：
    - CTL 表面 **FasL（CD178）** → 靶細胞 **Fas（CD95）** → 活化 caspase-8 → apoptosis
    - Fas 突變 → **Autoimmune Lymphoproliferative Syndrome（ALPS）** → lymphocyte 無法凋亡 → 淋巴增殖、脾腫大、自體免疫
- CTL 只殺 **MHC I 呈現的**靶細胞（MHC I-restricted）

### 5.5 γδ T Cells

- 少數 T cell（血中 <5%）；但**皮膚和黏膜**中較多
- 不需 MHC 呈現 → 直接辨認 phosphoantigens 和脂質抗原
- 快速反應，具有先天免疫特性

### 5.6 NKT Cells

- 表現 TCR 但辨認 **CD1d** 呈現的**脂質抗原**（如 α-GalCer）
- 快速產生大量 cytokines（IFN-γ、IL-4）
- 在抗微生物免疫和腫瘤免疫中扮演橋樑角色

## 六、後天免疫 ── B 細胞與抗體

### 6.1 B 細胞發育

- **骨髓**：Pro-B → Pre-B → Immature B
    - **Heavy chain（VDJ）rearrangement** 先（Pro-B 階段）
    - **Light chain（VJ）rearrangement** 後（Pre-B 階段）
    - 表面表現 **IgM** → Immature B cell
    - **Central tolerance（骨髓中）**：
        - 對自身抗原強烈反應的 immature B cell →
            1. **Clonal deletion（apoptosis）**
            2. **Receptor editing**：重新 rearrange light chain
            3. **Anergy**
- **周邊**：
    - Immature B → **Mature naïve B cell**（共表現 **IgM + IgD**）
    - 遇到抗原 + T cell help → 活化 → **Germinal center reaction**

### 6.2 B 細胞活化

- **T-dependent（TD）activation**（需 T cell 幫助 → 對蛋白質抗原）：
    - BCR 結合抗原 → 內化、加工 → MHC II 呈現給 **Tfh cell**
    - **CD40（B cell）↔ CD40L/CD154（T cell）**：第二信號 → **必需 for class switching、germinal center 反應**
    - Tfh 分泌 cytokines → 決定 class switch 方向
    - 結果：**Class switching、Somatic hypermutation、Affinity maturation、Memory B cells**

- **T-independent（TI）activation**（不需 T cell help → 多醣、脂質抗原）：
    - **TI-1**：LPS 等（polyclonal B cell activator）
    - **TI-2**：重複多醣結構（pneumococcal capsular polysaccharide）→ crosslinking BCR
    - 結果：主要產生 **IgM**（少 class switch）；**無 memory cells**；嬰幼兒及脾切除後對此類反應差
    - 脾切除 → 對**encapsulated bacteria** 易感（因為 TI-2 反應主要發生在脾臟）

### 6.3 Germinal Center Reaction

- 位置：次級淋巴器官的 **B cell follicle**
- 過程：
    1. **Somatic Hypermutation（SHM）**：V region 高頻突變（**AID / Activation-Induced Cytidine Deaminase**）
    2. **Affinity maturation**：高親和力 B cell 被 **Follicular Dendritic Cell（FDC）** 選擇存活；低親和力 → apoptosis
    3. **Class Switch Recombination（CSR）**：也需 **AID** → 改變 Heavy chain constant region（IgM → IgG/IgA/IgE）
    4. 產生 **Memory B cells** 和 **Plasma cells（漿細胞）**

- **AID（Activation-Induced Cytidine Deaminase）**：
    - 負責 SHM 和 CSR
    - AID 缺陷 → **Hyper-IgM syndrome Type 2**（AR）

### 6.4 免疫球蛋白（Immunoglobulins）

| Ig | 結構 | 特色 |
|----|------|------|
| **IgG** | Monomer | **血清中含量最多**；**唯一能通過胎盤**（經 FcRn）→ 提供新生兒被動免疫；Opsonization；活化補體（經典途徑）；**ADCC**（經 CD16/FcγRIII）；**Secondary response 的主要抗體** |
| **IgA** | Dimer（分泌型，含 J chain + Secretory component） | **黏膜免疫的主要抗體**；母乳、唾液、淚液、腸道；**不活化補體**（經典途徑）；防止微生物黏附 |
| **IgM** | **Pentamer**（含 J chain） | **Primary response 的主要抗體**；**最早產生的 Ig**（也是 B cell 表面最先表現的）；**活化補體最強**（C1q 結合）；**不能通過胎盤** |
| **IgD** | Monomer | 成熟 naïve B cell 表面與 IgM 共表現；功能不完全清楚 |
| **IgE** | Monomer | **血清中含量最少**；結合 **FcεRI**（Mast cell、Basophil）→ **Type I Hypersensitivity（過敏）**；**抗寄生蟲**（helminth） |

### 6.5 抗體結構

- **基本結構**：2 Heavy chains + 2 Light chains（κ or λ）；Y 字型
- **Fab（Fragment antigen-binding）**：包含 **VH + VL**（antigen-binding site）+ CH1 + CL
- **Fc（Fragment crystallizable）**：**CH2 + CH3**；與 Fc receptors 結合、活化補體、決定 Ig class、通過胎盤
- **Hinge region**：IgG、IgA 有（賦予 flexibility）；IgE、IgM 無 hinge
- **CDR（Complementarity-Determining Region）**：V 區中的超變區（CDR1、CDR2、**CDR3 最具多樣性**）→ 決定抗原專一性

### 6.6 抗體多樣性機制

| 機制 | 說明 |
|------|------|
| **V(D)J Recombination** | V、D（僅 Heavy chain）、J gene segment 隨機組合；酵素：**RAG-1/RAG-2** |
| **Combinatorial diversity** | 不同 V、D、J 的組合 |
| **Junctional diversity** | N-nucleotide addition（**TdT** 加隨機核苷酸）和 P-nucleotide addition → CDR3 區多樣性最高 |
| **Somatic Hypermutation** | Germinal center 中 V region 高頻點突變（需 **AID**）→ affinity maturation |
| **Heavy + Light chain pairing** | 不同 H chain 和 L chain 組合 |

- **RAG-1/RAG-2 缺陷** → **Omenn syndrome**（嚴重 SCID 變型：erythroderma、hepatosplenomegaly、elevated IgE）

### 6.7 Class Switch 與 Cytokine 關係

| 目標 Ig class | 驅動 Cytokine | 功能意義 |
|---------------|---------------|----------|
| **IgE** | **IL-4、IL-13** | 過敏、抗寄生蟲（Th2 驅動） |
| **IgG** | **IFN-γ**（IgG1, IgG3 in human） | Opsonization、ADCC、補體活化（Th1 驅動） |
| **IgA** | **TGF-β、IL-5、APRIL、BAFF** | 黏膜免疫 |

- **Hyper-IgM Syndromes**：class switch 缺陷 → IgM↑↑，IgG/IgA/IgE↓↓

| Type | 缺陷 | 遺傳 | 特色 |
|------|------|------|------|
| **Type 1（最常見）** | **CD40L（CD154）缺陷** | **X-linked** | 反覆感染；**Pneumocystis jirovecii** 和 **Cryptosporidium** 易感 |
| **Type 2** | **AID 缺陷** | AR | 無 SHM 和 CSR |
| **Type 3** | CD40 缺陷 | AR | 類似 Type 1 |

### 6.8 Fc Receptors

| Receptor | 結合 Ig | 表現細胞 | 功能 |
|----------|---------|----------|------|
| **FcγRI（CD64）** | IgG（高親和力） | Macrophage、Neutrophil、DC | Phagocytosis、ADCC |
| **FcγRIIA（CD32）** | IgG（低親和力） | Macrophage、Neutrophil | Phagocytosis |
| **FcγRIIB（CD32B）** | IgG | B cell | **抑制 B cell 活化**（ITIM） |
| **FcγRIII（CD16）** | IgG | **NK cell**、Macrophage | **ADCC** |
| **FcεRI** | **IgE**（高親和力） | **Mast cell、Basophil** | **Type I Hypersensitivity**；crosslinking → degranulation |
| **FcαR（CD89）** | IgA | Neutrophil、Macrophage | 黏膜防禦 |
| **FcRn（neonatal Fc receptor）** | IgG | Placental cells、Intestinal epithelium | **IgG 通過胎盤**；延長 IgG 半衰期 |

### 6.9 Monoclonal Antibody 命名法

| 後綴 | 來源 | 例子 |
|------|------|------|
| **-omab** | Mouse | Muromonab（OKT3，anti-CD3） |
| **-ximab** | Chimeric（人/鼠嵌合） | In**fliximab**、Ri**tuximab** |
| **-zumab** | Humanized | Trast**uzumab**、Omali**zumab** |
| **-umab** | Fully human | Adalimu**mab**、Nivolumab |

## 七、淋巴器官

### 7.1 初級（中央）淋巴器官

| 器官 | 功能 |
|------|------|
| **骨髓（Bone Marrow）** | B cell 成熟；所有血球前驅細胞來源；B cell central tolerance |
| **胸腺（Thymus）** | T cell 成熟（positive + negative selection）；T cell central tolerance |

- **胸腺**：
    - **皮質（Cortex）**：DP T cell + cortical epithelial cell → **Positive selection**
    - **髓質（Medulla）**：SP T cell + medullary epithelial cell + DC → **Negative selection**
    - **Hassall's corpuscles**：胸腺髓質中特有結構
    - **DiGeorge syndrome**：22q11.2 deletion → 胸腺發育不全/缺失 → T cell↓↓ → **combined immunodeficiency**（+副甲狀腺低下 → 低血鈣 + 心臟缺損 + facial dysmorphism）

### 7.2 次級（周邊）淋巴器官

| 器官 | T cell 區 | B cell 區 | 特殊功能 |
|------|-----------|-----------|----------|
| **淋巴結（Lymph Node）** | **Paracortex（副皮質區）** | **Follicle（濾泡）**（皮質） | 過濾淋巴液；Medullary cords 含 Plasma cells |
| **脾臟（Spleen）** | **PALS（Periarteriolar Lymphoid Sheath）**= White pulp 中的 T cell 區 | **Follicle（White pulp 中）** | 過濾血液；Red pulp：巨噬細胞清除老化/受損 RBC；**脾切除 → 對 encapsulated bacteria 易感** |
| **MALT / Peyer's patches** | Interfollicular area | Follicle | 腸道黏膜免疫；M cell 取樣抗原 |

- **脾臟功能與脾切除**：
    - **脾切除後易感菌**（**SHiN**）：**S**. pneumoniae（最重要）、**H**. influenzae（Type b）、**N**. meningitidis
    - 原因：①脾臟是 T-independent B cell response 的主要場所 ②脾臟巨噬細胞清除 encapsulated bacteria
    - 預防：脾切除前/後**接種疫苗**（Pneumococcal、Meningococcal、Hib）+ 預防性 **Penicillin**（尤其兒童）
    - 血液表現：**Howell-Jolly bodies**（RBC 中殘留核碎片）→ 脾功能缺失的標記
    - **Target cells** 增加

- **淋巴結結構**：
    - **Primary follicle**：naïve B cells（無 germinal center）
    - **Secondary follicle**：含 **Germinal center**（活化後）→ B cell 增殖、SHM、CSR
    - **Paracortex**：T cell zone；在 **viral infection** 時擴大（T cell 增殖）
    - **Medullary cords**：Plasma cells → 產生抗體
    - **Medullary sinuses**：Macrophages
    - **右淋巴管** 引流右上半身；**胸管（Thoracic duct）** 引流其餘全身

## 八、細胞因子（Cytokines）

### 8.1 重要細胞因子總覽

| Cytokine | 主要來源 | 主要功能 | 臨床重點 |
|----------|----------|----------|----------|
| **IL-1** | Macrophage（主要） | **發燒**（作用於下視丘 → PGE2）；急性期蛋白；內皮活化 | **Anakinra**（IL-1R antagonist）→ RA、CAPS、gout |

### 8.2 細胞因子的臨床聯想口訣

- **發燒三兄弟**：**IL-1、IL-6、TNF-α** → 內源性致熱原 → 作用下視丘 → PGE2↑ → 體溫↑
- **急性期蛋白誘導者**：**IL-6**（最重要）、IL-1、TNF-α
- **Th1 軸**：IL-12 → Th1 → IFN-γ → Macrophage 活化
- **Th2 軸**：IL-4 → Th2 → IL-4/IL-5/IL-13 → IgE↑、Eosinophil↑
- **Th17 軸**：IL-6 + TGF-β → Th17 → IL-17 → Neutrophil↑
- **抗發炎**：IL-10、TGF-β

### 8.3 Cytokine Storm / Sepsis

- **Sepsis**：感染引起全身性發炎反應 → 多器官衰竭
    - G(−) 菌：**LPS → TLR4 → TNF-α↑↑、IL-1↑↑、IL-6↑↑** → 血管擴張、通透性↑ → **Septic shock**
    - Superantigens（SEB、TSST-1）：不經 APC 加工，直接 crosslink TCR Vβ 與 MHC II → **非專一性大量 T cell 活化** → 大量 cytokine → **Toxic shock syndrome**
- **Cytokine Release Syndrome（CRS）**：CAR-T 治療的嚴重副作用；治療：**Tocilizumab（anti-IL-6R）** + 必要時 corticosteroids

## 九、過敏反應（Hypersensitivity）

### 9.1 四型過敏反應

| Type | 名稱 | 機制 | 時間 | 代表疾病 |
|------|------|------|------|----------|
| **I** | **Immediate / Anaphylactic** | **IgE + Mast cell degranulation** | 數分鐘 | 過敏性休克、Asthma、Allergic rhinitis、Urticaria、Food allergy、Drug allergy（Penicillin anaphylaxis） |
| **II** | **Cytotoxic / Antibody-mediated** | **IgG / IgM** 結合細胞表面抗原 → complement/ADCC/phagocytosis 或 receptor 功能異常 | 數小時 | AIHA、Transfusion reaction、HDN（Rh disease）、Goodpasture、Graves'、MG、Rheumatic fever |
| **III** | **Immune complex** | **Ag-Ab complex** 沉積 → 補體活化 → 組織損傷 | 數小時~數天 | SLE、Serum sickness、PSGN、Arthus reaction、Polyarteritis nodosa（PAN with HBV）、Hypersensitivity pneumonitis |
| **IV** | **Delayed-type (DTH) / Cell-mediated** | **T cell**（Th1/CD8⁺/Th17） | **24–72 小時** | TB skin test（PPD/Mantoux）、Contact dermatitis、Granuloma（TB、Sarcoidosis）、Transplant rejection（acute cellular）、Stevens-Johnson Syndrome（SJS）、Drug rash |

### 9.2 Type I Hypersensitivity 詳解

- **機制**：
    1. **Sensitization**：首次接觸 allergen → APC 呈現 → Th2 → IL-4 → B cell class switch → **IgE**
    2. IgE 結合 Mast cell 的 **FcεRI** → **sensitized Mast cell**
    3. **再次接觸**：allergen crosslinks IgE → Mast cell degranulation

- **Mast cell 釋放介質**：

| 介質類型 | 成分 | 效果 |
|----------|------|------|
| **Preformed（granules 內）** | **Histamine**、Tryptase、Heparin、TNF-α、Proteases | 血管擴張、通透性↑、支氣管收縮、搔癢 |
| **Newly synthesized（lipid mediators）** | **Leukotrienes（LTC4/D4/E4）**、**Prostaglandins（PGD2）**、**PAF** | **LT = 持續性支氣管收縮（比 histamine 更強更持久）**；PAF = 血小板活化 |
| **Cytokines** | IL-4、IL-5、IL-13、TNF-α | 晚期反應（late-phase，4–12 hr 後）：eosinophil 浸潤、持續發炎 |

- **Anaphylaxis 治療**：
    - **Epinephrine（IM）**：**首選**（α1 → 血管收縮；β2 → 支氣管擴張；β1 → 心輸出量↑）
    - 支持：O₂、IV fluids、H1 blocker（Diphenhydramine）、H2 blocker（Ranitidine）、Corticosteroids（預防 late-phase）、Nebulized β-agonist

- **Atopy**：遺傳易感的 Type I 體質 → allergic rhinitis、asthma、atopic dermatitis、food allergy
    - 與 Th2 dominant、IgE↑ 相關

- **Allergic asthma 治療相關 monoclonal Ab**：
    - **Omalizumab**：anti-IgE → 防止 IgE 結合 FcεRI
    - **Mepolizumab/Reslizumab**：anti-IL-5 → 減少 eosinophil
    - **Dupilumab**：anti-IL-4Rα → 阻斷 IL-4 和 IL-13 信號
    - **Benralizumab**：anti-IL-5Rα → deplete eosinophil

### 9.3 Type II Hypersensitivity 詳解

- **機制**：抗體結合**細胞表面抗原或組織基底膜抗原**

| 亞型 | 機制 | 例子 |
|------|------|------|
| **Cytotoxic（細胞破壞）** | Ab 結合 → Complement 活化 / ADCC / Phagocytosis → 細胞破壞 | **AIHA**（warm: IgG; cold: IgM + complement）、**HDN（Rh disease）**、**Transfusion reaction**、**ITP**（anti-platelet Ab）、**Drug-induced hemolytic anemia** |
| **Anti-receptor（功能異常）** | Ab 結合受體 → **刺激**或**阻斷**受體功能 | **Graves' disease**（anti-TSH receptor Ab → **刺激**）；**MG**（anti-AChR Ab → **阻斷**）；**Pernicious anemia**（anti-IF Ab → **阻斷**） |
| **Anti-tissue** | Ab 結合 ECM/基底膜 | **Goodpasture syndrome**（anti-GBM Ab → Type IV collagen α3 chain → 腎 + 肺）；**Rheumatic fever**（anti-M protein Ab → 分子模擬 → 心臟、關節） |

### 9.4 Type III Hypersensitivity 詳解

- **機制**：Ag-Ab immune complex 沉積在血管壁/組織 → 補體活化（C3a、C5a）→ 嗜中性球浸潤 → 組織損傷
- **Arthus reaction**：**局部** Type III；注射抗原於已有大量 Ab 的個體 → 局部免疫複合物沉積 → 局部壞死
- **Serum sickness**：**全身** Type III；7–14 天後出現（等 Ab 產生）；發燒、皮疹、關節痛、蛋白尿、淋巴結腫大；**C3↓**
    - 常見誘因：異種血清（anti-thymocyte globulin）、某些藥物（Penicillin、Sulfonamides、Cephalosporins）

| 疾病 | 沉積位置 |
|------|----------|
| **SLE** | 多處：腎絲球、皮膚、關節等 |
| **Poststreptococcal GN（PSGN）** | 腎絲球（subepithelial "humps"） |
| **Serum sickness** | 全身性（小血管壁） |
| **Polyarteritis nodosa（PAN）** | 中型動脈壁（常與 HBV 相關） |
| **Hypersensitivity pneumonitis** | 肺泡（農夫肺、鳥飼者肺）→ 也有 Type IV 成分 |
| **Reactive arthritis** | 關節、眼、泌尿道 |

### 9.5 Type IV Hypersensitivity 詳解

- **機制**：**T cell-mediated**（不涉及抗體）

| 亞型 | 效應細胞 | 例子 |
|------|----------|------|
| **IVa（DTH, Th1）** | **Th1 → IFN-γ → Macrophage 活化** | **PPD/Mantoux test**；**Granuloma**（TB、Leprosy、Sarcoidosis、Crohn's、Foreign body reaction）；Contact dermatitis（Th1+Th17） |
| **IVb（Th2-mediated）** | Th2 → Eosinophil 浸潤 | Chronic asthma（部分）、Chronic allergic responses |
| **IVc（CTL-mediated）** | **CD8⁺ CTL** | **Graft rejection（acute cellular）**；**SJS/TEN**（嚴重藥物不良反應）；**Type 1 DM**（CTL 破壞 β cells） |
| **IVd（Th17-mediated）** | Th17 → Neutrophil 浸潤 | **AGEP（Acute Generalized Exanthematous Pustulosis）** |

- **Granuloma 形成**：
    - 慢性 Type IV 反應 → Macrophage 持續活化 → **Epithelioid cells** → 融合成 **Giant cells（Langhans type or Foreign body type）**
    - Th1 → IFN-γ → Macrophage 活化 → TNF-α → Granuloma 維持
    - **Caseating granuloma**：TB、真菌感染
    - **Non-caseating granuloma**：Sarcoidosis、Crohn's disease、Berylliosis、Foreign body

### 9.6 Hypersensitivity 總結比較

| | Type I | Type II | Type III | Type IV |
|--|--------|---------|----------|---------|
| **介質** | IgE | IgG/IgM | Immune complex（IgG/IgM） | T cells |
| **時間** | 分鐘 | 小時 | 小時~天 | **24–72 小時** |
| **補體** | 不涉及 | 常涉及 | 涉及 | 不涉及 |
| **Transfer** | 可經血清（被動轉移 IgE/血清） | 可經血清 | 可經血清 | **僅能經 T cells 轉移** |

## 十一、免疫缺陷（Immunodeficiency）

### 11.1 B Cell（Humoral）Deficiencies

| 疾病 | 缺陷 | 遺傳 | 特色 |
|------|------|------|------|
| **X-linked Agammaglobulinemia（Bruton's）** | **BTK（Bruton tyrosine kinase）** → Pre-B → B cell 成熟障礙 | **X-linked** | **所有 Ig↓↓**；B cell **absent/very low**；T cell 正常；**6 個月後**發病（母體 IgG 消耗後）；反覆 **sinopulmonary infection**（encapsulated bacteria）；**無淋巴結/扁桃腺**；susceptible to **Enterovirus**（encephalitis） |
| **Common Variable Immunodeficiency（CVID）** | 多基因；B cell 分化成 plasma cell 障礙 | 通常散發 | **最常見的有症狀的 primary Ab deficiency**；IgG↓、IgA↓（+/-IgM↓）；B cell 數量**正常**但功能差；20–30 歲發病；反覆 sinopulmonary infection；**↑risk for autoimmune disease、lymphoma、gastric cancer** |
| **Selective IgA Deficiency** | IgA 產生缺陷 | — | **最常見的 primary immunodeficiency 整體**；多數**無症狀**；部分有反覆 sinopulmonary/GI infection；**Anaphylaxis risk** if receiving blood products containing IgA（因有 anti-IgA Ab）；與 **celiac disease、autoimmune disease** 相關 |

### 11.2 T Cell（Cell-Mediated）Deficiencies

| 疾病 | 缺陷 | 特色 |
|------|------|------|
| **DiGeorge Syndrome（22q11.2 deletion）** | 胸腺發育不全 → T cell↓ | **CATCH-22**：**C**ardiac defects、**A**bnormal facies、**T**hymic aplasia、**C**left palate、**H**ypocalcemia/Hypoparathyroidism；**22**q11.2 deletion |
| **Chronic Mucocutaneous Candidiasis** | T cell 對 *Candida* 特異性反應缺陷 | 皮膚、黏膜反覆 *Candida* 感染；部分與 AIRE 突變相關 |
| **IL-12 receptor deficiency** | IL-12 → IFN-γ axis 障礙 | **Disseminated mycobacterial（BCG/NTM）/ Salmonella** 感染；Th1 反應↓ |

### 11.3 Combined（T + B Cell）Deficiencies

| 疾病 | 缺陷 | 特色 |
|------|------|------|
| **Severe Combined Immunodeficiency（SCID）** | 多種基因缺陷（見下） | **最嚴重的免疫缺陷**；T cell **absent/very low** ± B cell ± NK cell；出生早期即嚴重感染（*PCP, CMV, Candida*）；chronic diarrhea、FTT；**absent thymic shadow on CXR**；致命若不治療 → **bone marrow transplant（HSCT）** |

| — RAG1/RAG2 deficiency | V(D)J recombination 障礙 | **T(−) B(−) NK(+)** |
| — IL-7R deficiency | T cell 發育缺陷 | **T(−) B(+) NK(+)** |
| — JAK3 deficiency | 同 γc chain downstream signaling | **T(−) B(+) NK(−)**（phenocopy of X-linked SCID） |

| **Ataxia-Telangiectasia** | **ATM** gene（DNA DSB repair） | **AR**；Cerebellar ataxia + Spider angiomata（telangiectasia）+ IgA↓ + ↑AFP + **↑sensitivity to ionizing radiation**；↑risk for lymphoma/leukemia |
| **Hyper-IgE Syndrome（Job Syndrome）** | **STAT3 deficiency**（AD）或 DOCK8 deficiency（AR） | **FATED**：coarse **F**acies、cold Staphylococcal **A**bscesses（"cold" = 不紅不痛，因為缺 neutrophil chemotaxis）、retained primary **T**eeth、**E**czema（severe）、↑IgE、**D**ermatologic（pathologic fractures from osteoporosis）；**Th17↓** → fungal/bacterial infection；Eosinophilia |

## 十二、移植免疫學（Transplantation Immunology）

### 12.1 移植排斥反應

| 類型 | 時間 | 機制 | 病理 |
|------|------|------|------|
| **Hyperacute rejection** | **分鐘~小時** | **Preformed Ab**（anti-donor ABO 或 anti-HLA Ab）→ complement → 血管內血栓 | 移植物立即壞死；**Type II hypersensitivity** |
| **Acute rejection** | **天~月** | ① **Cellular**（Type IV）：Host T cells 攻擊 donor MHC → 最常見；② **Humoral**（Type II）：Ab 介導 → C4d 沉積 | Cellular：淋巴球浸潤；Humoral：血管炎 |
| **Chronic rejection** | **月~年** | 慢性 Ab + T cell → 血管內膜增厚（intimal fibrosis）、管腔狹窄 → 器官纖維化、功能漸失 | 不可逆；治療效果差 |

### 12.2 移植物抗宿主病（Graft-versus-Host Disease, GvHD）

- 見於 **骨髓移植（HSCT）** 和輸注含大量淋巴球的血品
- **機制**：**Donor T cells** 攻擊 **Host tissues**
- **受影響器官（三聯徵）**：
    1. **皮膚**（皮疹 → 全身）
    2. **肝臟**（黃疸）
    3. **腸胃道**（腹瀉、腹痛、黏膜破損）
- **Acute GvHD**：移植後 100 天內；主要 donor T cell 活化
- **Chronic GvHD**：移植後 >100 天；類似自體免疫（似 scleroderma、Sjögren）
- **預防**：T cell depletion、免疫抑制劑
- **注意**：GvHD 的程度與 **Graft-versus-Leukemia（GvL）effect** 有部分正相關 → 適度 GvHD 可能有利於白血病復發控制

### 12.3 免疫抑制藥物

| 藥物 | 機制 | 用途/備註 |
|------|------|-----------|
| **Cyclosporine** | 結合 **Cyclophilin** → 抑制 **Calcineurin** → 阻斷 **NFAT** → **IL-2 轉錄↓** → T cell 活化↓ | 移植排斥預防；副作用：腎毒性、HTN、牙齦增生、多毛 |
| **Tacrolimus（FK506）** | 結合 **FKBP** → 抑制 **Calcineurin** → 同 Cyclosporine | 比 Cyclosporine 效力更強；副作用類似+糖尿病 |
| **Sirolimus（Rapamycin）** | 結合 FKBP → 抑制 **mTOR** → T cell 增殖↓（阻斷 IL-2 downstream） | **不抑制 Calcineurin → 腎毒性較低**；副作用：高脂血症、骨髓抑制；抑制傷口癒合 |
| **Mycophenolate Mofetil（MMF）** | 抑制 **IMP dehydrogenase** → **Guanine synthesis↓** → **lymphocyte 增殖↓**（淋巴球依賴 de novo pathway） | 移植；副作用：GI distress、bone marrow suppression；**致畸** |
| **Azathioprine** | Prodrug → **6-MP** → 抑制 purine synthesis → 細胞增殖↓ | 移植、AI disease；代謝由 **TPMT**（缺陷者毒性↑）；注意與 **Allopurinol 交互**（抑制 xanthine oxidase → 6-MP↑ → 骨髓抑制） |
| **Corticosteroids** | 抑制 **NF-κB** → 多種 cytokine↓；lymphocyte apoptosis | 廣泛抗發炎/免疫抑制 |
| **Anti-thymocyte globulin（ATG）** | Polyclonal Ab against T cells → T cell depletion | Induction therapy in transplant；可致 serum sickness |
| **Basiliximab** | Anti-**CD25（IL-2Rα）** monoclonal Ab → 阻斷 IL-2 信號 | Transplant induction |
| **Muromonab（OKT3）** | Anti-**CD3** → T cell depletion/blocking | 歷史上用於 transplant rejection（現少用） |
| **Alemtuzumab** | Anti-**CD52** → lymphocyte depletion（T + B） | MS、transplant、CLL |
| **Rituximab** | Anti-**CD20** → B cell depletion | NHL、RA、AIHA、ITP、GPA、Transplant（Ab-mediated rejection） |
| **Belatacept** | **CTLA-4-Ig fusion protein** → 阻斷 B7-CD28 co-stimulation | Kidney transplant |

## 十三、腫瘤免疫學

### 13.1 免疫監視（Immune Surveillance）

- **Tumor-associated antigens（TAA）**：正常細胞也有但腫瘤過度表現（如 HER2、CEA）
- **Tumor-specific antigens（TSA）**：僅腫瘤表現（如 BCR-ABL fusion protein、mutant p53）
- **免疫監視細胞**：
    - **NK cells**：辨認 MHC I↓ 的腫瘤細胞（missing self）
    - **CTL（CD8⁺）**：MHC I 呈現腫瘤抗原 → 殺傷
    - **Macrophage、DC**：抗原呈現 + 直接殺腫瘤
    - **γδ T cells、NKT cells**

### 13.2 腫瘤免疫逃逸機制

| 機制 | 說明 |
|------|------|
| **MHC I 下調** | 逃避 CTL 辨認 |
| **PD-L1 表現** | 結合 T cell 上 PD-1 → T cell exhaustion |
| **Treg 招募** | 分泌 TGF-β、IL-10 → 抑制抗腫瘤免疫 |
| **MDSC（Myeloid-Derived Suppressor Cells）** | 抑制 T cell |
| **腫瘤微環境** | 低氧、酸性、缺營養 → T cell 功能↓ |
| **抗原丟失（Antigen loss）** | 突變/選擇壓力 → 失去腫瘤抗原 |
| **分泌免疫抑制因子** | TGF-β、IL-10、VEGF、IDO |

### 13.3 癌症免疫治療

| 治療 | 機制 |
|------|------|
| **Immune checkpoint inhibitors** | Anti-CTLA-4（Ipilimumab）；Anti-PD-1（Nivolumab、Pembrolizumab）；Anti-PD-L1 → 解除 T cell 抑制 |
| **CAR-T cell therapy** | 患者 T cell 基因工程加裝 chimeric antigen receptor（如 anti-CD19）→ 直接辨認腫瘤 B cell → 殺傷；用於 B-ALL、DLBCL |
| **Bispecific Ab** | 同時結合 T cell（CD3）和腫瘤抗原 → 橋接殺傷；Blinatumomab（anti-CD19 × anti-CD3）→ B-ALL |
| **Tumor vaccines** | Sipuleucel-T（DC-based vaccine）→ Prostate cancer |
| **Oncolytic viruses** | Talimogene laherparepvec（T-VEC）→ Melanoma |
| **Cytokine therapy** | IL-2（Aldesleukin）→ RCC、Melanoma；IFN-α → Melanoma |

## 十四、感染免疫學

### 14.1 不同病原體的免疫反應

| 病原體類型 | 主要免疫防禦 | 關鍵效應 |
|------------|-------------|----------|
| **胞外細菌** | **Ab（opsonization, complement）+ Neutrophil + Th17** | IgG opsonization → phagocytosis；Complement MAC → 溶菌；IL-17 → Neutrophil 招募 |
| **胞內細菌**（TB, Listeria, Brucella, Legionella） | **Th1 → IFN-γ → Macrophage 活化**；CTL（CD8⁺） | Granuloma 形成；IFN-γ 為關鍵 |
| **病毒** | **CTL（CD8⁺）**（殺死感染細胞）+ NK cell + **Type I IFN**；Ab 中和游離病毒 | MHC I 呈現 viral peptide → CTL 辨認 |
| **真菌** | **Th17 → Neutrophil**；Th1 → Macrophage | IL-17 → 招募 Neutrophil 殺真菌 |
| **寄生蟲（Helminth）** | **Th2 → IgE + Eosinophil + Mast cell** | IL-5 → Eosinophil 活化；IgE-FcεRI → ADCC against helminths |
| **Protozoa**（Malaria, Leishmania, Trypanosoma） | Th1 → Macrophage（intracellular）；Ab（extracellular stages） | IFN-γ → macrophage killing of intracellular parasites |

### 14.2 病原體免疫逃逸策略

| 策略 | 病原體例子 |
|------|-----------|
| **抗原變異（Antigenic variation）** | **Influenza**（antigenic drift/shift）、**Trypanosoma**（VSG switching）、HIV、N. gonorrhoeae（pili variation） |
| **莢膜（Capsule）** | S. pneumoniae、H. influenzae、N. meningitidis → 抗吞噬 |
| **抑制 phagolysosome 融合** | **Mycobacterium tuberculosis** |
| **逃出 phagosome** | **Listeria**（Listeriolysin O） |
| **抑制 MHC I 表現** | **CMV**（多種機制）、**EBV**、**Adenovirus** → 逃避 CTL |
| **分泌 cytokine homologs** | **EBV**（viral IL-10 → 抑制 Th1） |
| **抑制補體** | S. aureus（Protein A 結合 IgG Fc → 阻止 opsonization） |
| **Superantigen** | S. aureus（TSST-1、SEB）、S. pyogenes（SpeA）→ 非專一性 T cell 活化 → cytokine storm |
| **IgA protease** | N. meningitidis、N. gonorrhoeae、H. influenzae、S. pneumoniae → 切斷黏膜 IgA |

### 14.3 Superantigens

- **機制**：不需 APC 加工 → 直接結合 **MHC II outside（α chain 外側）** + **TCR Vβ region** → 同時活化大量 T cell（可達 20–30% 全部 T cell）
- 結果：**大量 IL-2、TNF-α、IFN-γ 釋放** → Toxic Shock Syndrome
- 例子：
    - **S. aureus**：TSST-1（Toxic Shock Syndrome Toxin-1）、Staphylococcal Enterotoxins（SEB 等）
    - **S. pyogenes**：Streptococcal Pyrogenic Exotoxins（SpeA 等）

## 十五、疫苗學（Vaccinology）

### 15.1 疫苗類型

| 類型 | 例子 | 特色 |
|------|------|------|
| **Live attenuated** | **MMR、Varicella、OPV（Sabin）、BCG、Yellow fever、Rotavirus（oral）、Smallpox（vaccinia）、Intranasal influenza（LAIV）** | **最強免疫反應**（humoral + cellular + mucosal）；**禁忌**：免疫低下者、孕婦 |
| **Inactivated / Killed** | **IPV（Salk）、Rabies、Hepatitis A、Influenza（IM injection）** | 較安全但免疫力較弱；通常需多劑 |
| **Subunit / Recombinant** | **HBV（HBsAg）、HPV、Pertussis（acellular）、Influenza（recombinant HA）** | 安全；可能需 adjuvant |
| **Toxoid** | **Tetanus toxoid、Diphtheria toxoid** | 針對外毒素；刺激 antitoxin Ab |
| **Conjugate** | **PCV（Pneumococcal conjugate）、HiB、Meningococcal conjugate** | **多醣抗原 + 蛋白質 carrier → 將 T-independent → T-dependent** → 嬰幼兒也能產生良好反應 + **memory** |
| **Polysaccharide** | **PPSV23（Pneumococcal polysaccharide）** | T-independent；**不產生 memory**；嬰幼兒反應差；用於 ≥2 歲 |
| **mRNA vaccine** | **COVID-19（Pfizer-BioNTech、Moderna）** | mRNA 編碼 spike protein → host cell 翻譯 → 呈現 → 免疫反應 |
| **Viral vector** | **COVID-19（AstraZeneca、J&J）** | Adenovirus vector 攜帶 antigen gene |

### 15.2 疫苗免疫學原理

- **Primary response**：首次接觸 → 7–10 天後 → 以 **IgM** 為主 → 逐漸 class switch → IgG
- **Secondary response（Anamnestic response）**：再次接觸 → **更快（1–3 天）、更強、更持久** → 以 **IgG 為主**（更高親和力）→ **Memory B/T cells** 的功能
- **Conjugate vaccine 的重要性**：
    - 嬰幼兒（<2 歲）的 B cell 對 **T-independent polysaccharide** 反應差
    - Conjugate vaccine 將 polysaccharide 共價結合 protein carrier → 變成 **T-dependent** → 可產生 class switch、affinity maturation、memory
    - 用於 *S. pneumoniae*、*H. influenzae type b*、*N. meningitidis*

### 15.3 Adjuvants（佐劑）

- **功能**：增強免疫反應、延緩抗原釋放、活化 APC
- **常見佐劑**：
    - **Alum（aluminum salts）**：最常用；促進 Th2 反應
    - **MF59、AS03**：油-水乳劑
    - **AS01B**：含 MPL + QS-21（用於 Shingrix）
    - **CpG ODN**：TLR9 agonist
    - **Incomplete Freund's adjuvant**：油-水乳劑（動物實驗用）
    - **Complete Freund's adjuvant**：含 killed mycobacteria（動物實驗用，人類不用）

### 15.4 被動免疫 vs 主動免疫

| | **Active Immunization** | **Passive Immunization** |
|--|-------------------------|--------------------------|
| 方式 | 疫苗接種 / 自然感染 | 注射預成抗體（IVIG、antiserum） |
| 產生時間 | 慢（需數天~週） | 即時 |
| 持續時間 | **長期**（memory cells） | **短暫**（抗體半衰期） |
| 記憶性 | **有** | **無** |
| 例子 | 各種疫苗 | **Anti-Rh(D) IgG（RhoGAM）**、Rabies Ig、HBV Ig、Tetanus Ig、IVIG |

## 十六、黏膜免疫（Mucosal Immunity）

### 16.1 重點概念

- **MALT（Mucosa-Associated Lymphoid Tissue）**：GALT（腸）、BALT（支氣管）、NALT（鼻咽）
- **Peyer's patches**：小腸中的 GALT → **M cell** 取樣腸腔抗原 → 傳遞給下方 DC/Macrophage
- **IgA** 是黏膜免疫的主角：
    - B cell 在 GALT 經 class switch → IgA（需 TGF-β）
    - **Dimeric IgA** + J chain → 結合 **polymeric Ig receptor（pIgR）** on 腸上皮細胞 basolateral → transcytosis → **Secretory IgA（sIgA）** 釋放到腸腔
    - sIgA 含 **Secretory component**（來自 pIgR 切割）→ 保護 IgA 不被蛋白酶降解
    - sIgA 功能：**immune exclusion** → 阻止微生物和毒素黏附上皮
- **Oral tolerance**：腸道大量接觸食物抗原 → 產生 **Treg** → 對食物抗原不反應 → 這是正常的
    - Oral tolerance 失敗 → 食物過敏、Celiac disease

## 十七、常見免疫學實驗技術

| 技術 | 用途 |
|------|------|
| **ELISA（Enzyme-Linked Immunosorbent Assay）** | 偵測 Ab 或 Ag（定量）；**HIV 篩檢**（最常用）；Sandwich / Indirect / Competitive |
