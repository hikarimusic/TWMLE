## 一、細菌學總論

### 1.1 細菌基本結構

| 結構 | 功能 | 考試重點 |
|------|------|----------|
| **細胞壁** | 維持形狀、抵抗滲透壓 | G(+)：厚 peptidoglycan + teichoic acid；G(−)：薄 peptidoglycan + 外膜（含 **LPS**） |
| **LPS（脂多醣）** | G(−) 外膜成分 | **Lipid A**：內毒素活性（endotoxin）→ 發燒、休克、DIC；**O-antigen**：血清分型 |
| **莢膜（Capsule）** | 抗吞噬（anti-phagocytic） | 最重要毒力因子之一；quellung reaction 可偵測；多醣莢膜 → T-independent antigen |
| **鞭毛（Flagella）** | 運動 | H-antigen（Salmonella 分型）；蛋白質組成 |
| **線毛/菌毛（Pili/Fimbriae）** | 黏附宿主細胞、接合（conjugation） | **Sex pilus**：F plasmid 轉移；**Type IV pili**：Neisseria、Pseudomonas（twitching motility） |
| **孢子（Spore）** | 極端環境生存 | 只有 G(+)：**Bacillus**、**Clostridium**；含 **dipicolinic acid + calcium**；高壓滅菌（autoclave 121°C, 15 min）才能殺死 |
| **Plasmid** | 攜帶抗藥性/毒力基因 | R-plasmid（抗藥性）、F-plasmid（fertility） |

### 1.2 革蘭氏染色與分類

| 分類 | 代表菌屬 |
|------|----------|
| **G(+) cocci** | Staphylococcus、Streptococcus、Enterococcus |
| **G(+) bacilli** | Bacillus、Clostridium、Corynebacterium、Listeria、Actinomyces、Nocardia |
| **G(−) cocci** | Neisseria、Moraxella |
| **G(−) bacilli** | Enterobacteriaceae（E. coli, Klebsiella, Salmonella, Shigella 等）、Pseudomonas、Haemophilus、Vibrio、Campylobacter、Helicobacter、Legionella、Bordetella、Brucella、Bartonella |
| **不染色/特殊** | Mycobacterium（acid-fast）、Mycoplasma（無細胞壁）、Spirochetes、Chlamydia（專性胞內）、Rickettsia（專性胞內） |

### 1.3 細菌遺傳學

| 機制 | 說明 | 代表 |
|------|------|------|
| **Transformation** | 游離 DNA 被細菌攝入 | **Streptococcus pneumoniae**（Griffith 實驗） |
| **Transduction** | 噬菌體（phage）攜帶 DNA | **Generalized**：隨機 DNA；**Specialized**：特定基因（如 λ phage） |
| **Conjugation** | 經由 sex pilus 轉移 plasmid | F plasmid、Hfr、R plasmid |
| **Transposon** | 跳躍基因（可攜帶抗藥性） | VanA gene（VRE）；可在 chromosome 與 plasmid 間跳躍 |

- **Lysogenic conversion（溶原轉換）**：噬菌體基因整合後改變細菌毒力
    - **Corynebacterium diphtheriae**：β-phage → **diphtheria toxin**
    - **Clostridium botulinum**：phage → **botulinum toxin**
    - **Vibrio cholerae**：CTXφ phage → **cholera toxin**
    - **Streptococcus pyogenes**：phage → **erythrogenic toxin**（scarlet fever）
    - **E. coli O157:H7**：phage → **Shiga-like toxin**
    - **S. aureus**：phage → enterotoxin（部分）

### 1.4 細菌毒素

| 特性 | **外毒素（Exotoxin）** | **內毒素（Endotoxin）** |
|------|----------------------|----------------------|
| 來源 | G(+) 或 G(−) 分泌 | **G(−) 細胞壁 LPS 之 Lipid A** |
| 化學成分 | 蛋白質 | 脂多醣 |
| 熱穩定性 | 不耐熱（60°C 即破壞） | **耐熱** |
| 毒性 | 極強，作用專一 | 較弱，作用廣泛 |
| Toxoid | 可製成 toxoid（甲醛處理）→ 疫苗 | 無法製成 toxoid |
| 免疫原性 | 強（可產生 antitoxin） | 弱 |
| 偵測 | 各種生物分析法 | **Limulus lysate assay（鱟試驗）** |
| 代表 | Diphtheria toxin、Tetanus toxin、Botulinum toxin、Cholera toxin | 所有 G(−) 菌 |

#### 重要外毒素機制

| 毒素 | 機制 | 疾病 |
|------|------|------|
| **Diphtheria toxin** | **ADP-ribosylation of EF-2** → 抑制蛋白質合成 | 白喉 |
| **Pseudomonas exotoxin A** | **ADP-ribosylation of EF-2**（同 diphtheria） | Pseudomonas 感染 |
| **Cholera toxin** | **ADP-ribosylation of Gs protein** → 持續活化 adenylate cyclase → cAMP↑ → Cl⁻ 及水分泌↑ | 霍亂（rice-water diarrhea） |
| **E. coli heat-labile toxin（LT）** | 同 cholera toxin 機制（**Gs → cAMP↑**） | ETEC 旅行者腹瀉 |
| **E. coli heat-stable toxin（ST）** | 活化 guanylate cyclase → **cGMP↑** | ETEC 旅行者腹瀉 |
| **Pertussis toxin** | **ADP-ribosylation of Gi protein** → 無法抑制 adenylate cyclase → cAMP↑ | 百日咳 |
| **Tetanus toxin（Tetanospasmin）** | **阻斷抑制性神經傳導物質（glycine, GABA）釋放**（脊髓 Renshaw cell） | 破傷風（痙攣性麻痺） |
| **Botulinum toxin** | **阻斷 ACh 釋放**（NMJ presynaptic） | 肉毒桿菌中毒（弛緩性麻痺） |
| **C. perfringens α-toxin** | **Lecithinase（phospholipase C）** → 破壞細胞膜 | 氣壞疽 |
| **S. aureus TSST-1** | **Superantigen** → 大量 T cell 活化 → cytokine storm | 中毒性休克症候群 |
| **S. pyogenes SpeA/C** | **Superantigen** | 猩紅熱、Streptococcal TSS |
| **Shiga toxin / Shiga-like toxin** | **抑制 60S ribosomal subunit**（切斷 28S rRNA）→ 抑制蛋白質合成 | Shigella 痢疾、EHEC O157:H7 HUS |
| **C. difficile toxin A & B** | **Glucosylation of Rho GTPase** → 破壞 actin 細胞骨架 | 偽膜性腸炎 |
| **Anthrax toxin** | **Edema factor**（adenylate cyclase → cAMP↑）+ **Lethal factor**（metalloprotease → MAPK↓）均需 **Protective antigen** 導入 | 炭疽 |

### 1.5 培養與鑑別重要媒介

| 培養基 / 檢查 | 用途 |
|---------------|------|
| **Blood agar** | 溶血反應：α（綠色，部分溶血）、β（清澈，完全溶血）、γ（不溶血） |
| **MacConkey agar** | 選擇性培養 G(−)；**乳糖發酵(+)**（pink）：E. coli, Klebsiella, Enterobacter；**乳糖(−)**（colorless）：Salmonella, Shigella, Proteus, Pseudomonas |
| **Chocolate agar** | Haemophilus、Neisseria（需 CO₂） |
| **Thayer-Martin（VCN）agar** | 選擇性培養 **Neisseria**（含 Vancomycin, Colistin, Nystatin 抑制其他菌） |
| **Löwenstein-Jensen（LJ）** | **Mycobacterium tuberculosis** |
| **Bordet-Gengou agar** | **Bordetella pertussis** |
| **Charcoal yeast extract（CYE / BCYE）** | **Legionella** |
| **Eaton's agar** | **Mycoplasma pneumoniae**（fried-egg colonies） |
| **Sabouraud agar** | 真菌培養 |
| **Tellurite agar** | **Corynebacterium diphtheriae** |
| **TCBS agar** | **Vibrio cholerae** |

## 二、革蘭氏陽性球菌（Gram-Positive Cocci）

### 2.1 Staphylococcus

#### 共同特徵
- G(+) cocci in **clusters（葡萄串狀）**
- **Catalase(+)**（與 Streptococcus 區分）
- 兼性厭氧

#### S. aureus

| 項目 | 內容 |
|------|------|
| **鑑別** | **Coagulase(+)**（唯一）、**Mannitol fermentation(+)**、Protein A（結合 IgG Fc → 抗調理） |
| **毒力因子** | Protein A、Coagulase、Catalase、β-lactamase、**PVL（Panton-Valentine Leukocidin）** |
| **毒素相關疾病** | ① **食物中毒**：preformed **enterotoxin**（耐熱）→ 1–6 hr 嘔吐為主 → 自限；② **TSST-1** → Toxic Shock Syndrome（高燒、低血壓、瀰漫性紅斑 → 脫皮）；③ **Exfoliative toxin** → Scalded Skin Syndrome（SSSS，好發嬰幼兒，Nikolsky sign(+)，表皮分離在 granular layer） |
| **直接感染** | 皮膚軟組織（癤、癰、蜂窩性組織炎、膿瘍）、骨髓炎（**最常見致病菌**）、敗血性關節炎（**最常見**）、急性細菌性心內膜炎、肺炎（post-influenza, 壞死性）、菌血症 |
| **MRSA** | mecA gene → **PBP2a** → 對所有 β-lactam 抗藥；治療：**Vancomycin**、Linezolid、Daptomycin、TMP-SMX（CA-MRSA 較輕症） |
| **VISA / VRSA** | vanA gene（VRSA）→ Vancomycin 抗藥；治療：Linezolid、Daptomycin |

#### Coagulase-negative Staphylococci（CoNS）

| 菌種 | 特色 |
|------|------|
| **S. epidermidis** | **Coagulase(−)**、Novobiocin **sensitive**；正常皮膚菌叢；**人工植入物 / catheter 感染最常見**（biofilm 形成）；prosthetic valve endocarditis（<1 年） |
| **S. saprophyticus** | **Coagulase(−)**、Novobiocin **resistant**；**年輕性活躍女性 UTI 第二常見菌**（僅次於 E. coli） |

### 2.2 Streptococcus

#### 共同特徵
- G(+) cocci in **chains（鏈狀）**
- **Catalase(−)**

#### Lancefield 分群與重要菌種

| 菌種 | 分群 | 溶血 | 重點 |
|------|------|------|------|
| **S. pyogenes（GAS）** | Group A | **β-hemolytic** | 下述詳細 |
| **S. agalactiae（GBS）** | Group B | **β-hemolytic** | 新生兒敗血症/腦膜炎最常見菌；產前 35-37 週陰道篩檢；CAMP test(+)、Hippurate hydrolysis(+) |
| **S. pneumoniae** | 無 Lancefield group | **α-hemolytic** | 下述詳細 |
| **Viridans group Streptococci** | 多種 | **α-hemolytic** | Optochin **resistant**、bile **insoluble**（與 S. pneumoniae 區分）；**S. mutans**：齲齒主因；**S. sanguinis / S. mitis**：**亞急性心內膜炎**最常見致病菌（自然瓣膜） |
| **Enterococcus（E. faecalis, E. faecium）** | Group D | **γ-hemolytic**（多數） | 生長於 **6.5% NaCl + bile esculin(+)**；UTI、膽道感染、心內膜炎；天然對 cephalosporin 抗藥；**VRE**：vanA 或 vanB → 治療 Linezolid、Daptomycin |

#### S. pyogenes（Group A Streptococcus, GAS）

- **Bacitracin sensitive**、**PYR(+)**
- **毒力因子**：
    - **M protein**：最重要毒力因子（抗吞噬）；分型基礎；rheumatic fever 之 molecular mimicry 對象
    - **Streptolysin O（SLO）**：oxygen-labile → **ASO titer** 可偵測（風濕熱/PSGN 後評估）
    - **Streptolysin S**：oxygen-stable → 在 blood agar 上造成 β-hemolysis
    - **Erythrogenic toxin（SpeA/B/C）**：superantigen → **猩紅熱**
    - **Streptokinase**：溶解血栓
    - **Hyaluronidase**：促進擴散
    - **DNase（Streptodornase）**：**Anti-DNase B titer** → 皮膚感染後 PSGN 的最佳指標
- **化膿性疾病**：
    - 咽炎（pharyngitis）→ 最常見細菌性咽炎病因
    - 猩紅熱（scarlet fever）：咽炎 + sandpaper-like rash + strawberry tongue + Pastia's lines（腋窩/鼠蹊暗紅線）
    - 蜂窩性組織炎（cellulitis）、丹毒（erysipelas，邊界清楚的紅腫）
    - 壞死性筋膜炎（necrotizing fasciitis）
    - 膿疱瘡（impetigo）：honey-crusted lesions
- **毒素相關**：
    - Streptococcal Toxic Shock Syndrome（STSS）
- **非化膿性併發症（Post-streptococcal）**：
    - **急性風濕熱（Acute Rheumatic Fever, ARF）**：
        - 僅 **咽炎** 後（皮膚感染不會引起）
        - **Jones criteria**：2 major 或 1 major + 2 minor
        - **Major**：**J**oint（migratory polyarthritis，最常見）、♥ **Carditis**（最嚴重，pancarditis，Aschoff bodies）、**N**odules（subcutaneous）、**E**rythema marginatum、**S**ydenham chorea
        - **Minor**：fever、arthralgia、elevated ESR/CRP、prolonged PR interval
        - 治療：Penicillin（清除 GAS）+ Aspirin（關節炎）+ Corticosteroid（嚴重 carditis）
        - 預防：長期 Penicillin G IM（benzathine penicillin）
    - **Post-streptococcal Glomerulonephritis（PSGN）**：
        - 咽炎或**皮膚感染**後均可
        - 機制：Type III hypersensitivity（免疫複合體沉積）
        - 表現：水腫、高血壓、血尿（cola-colored urine）、蛋白尿
        - 實驗室：**C3↓**、ASO↑（咽炎後）、Anti-DNase B↑（皮膚感染後）
        - IF：**starry sky pattern**（granular subepithelial deposits）；EM：subepithelial **humps**
        - 多數自限，支持治療

#### S. pneumoniae（肺炎鏈球菌）

- **α-hemolytic**、**Optochin sensitive**、**Bile soluble**、**Quellung reaction(+)**（莢膜膨脹）
- **莢膜**：最重要毒力因子（>90 serotypes）
- **IgA protease**：破壞黏膜 IgA → 促進黏附
- **重要感染**：
    - **成人社區型肺炎（CAP）最常見菌** → 典型肺炎（rust-colored sputum）
    - **成人細菌性腦膜炎最常見菌**
    - **中耳炎（otitis media）最常見菌**（兒童）
    - **鼻竇炎最常見菌**
- **高風險族群**：脾臟切除（**asplenia**）、鎌狀細胞病、HIV、老人、COPD
- **疫苗**：
    - **PCV13 / PCV15 / PCV20**（conjugate vaccine）：兒童常規接種
    - **PPSV23**（polysaccharide vaccine）：成人高風險族群追加
- **治療**：Penicillin（首選）；抗藥時 → Vancomycin + Ceftriaxone（腦膜炎經驗治療）

### 2.3 Enterococcus

- **耐受性強**：生長於 6.5% NaCl、bile esculin hydrolysis(+)、PYR(+)
- **天然抗藥**：Cephalosporins、Aminoglycosides（低濃度）、TMP-SMX（in vivo 無效）
- **VRE（Vancomycin-Resistant Enterococcus）**：
    - **vanA**：高度抗藥（對 Vancomycin 和 Teicoplanin 均抗藥）
    - **vanB**：僅對 Vancomycin 抗藥
    - 治療：Linezolid、Daptomycin、Tigecycline

## 三、革蘭氏陽性桿菌（Gram-Positive Bacilli）

### 3.1 Bacillus

#### B. anthracis（炭疽桿菌）

- **不運動**（唯一不運動的 Bacillus）、產芽孢、莢膜（**poly-D-glutamic acid**，唯一多肽莢膜）
- **毒素**：Protective antigen + Edema factor（EF，adenylate cyclase）+ Lethal factor（LF，metalloprotease）
- **三型臨床表現**：
    - **皮膚型**（最常見，95%）：**Painless black eschar**（Malignant pustule）
    - **肺部型（吸入型）**：最致命；wool-sorter's disease；CXR → **widened mediastinum**（hemorrhagic mediastinitis）
    - **腸胃型**：食入污染肉類
- 治療：**Ciprofloxacin** 或 Doxycycline（PEP 及治療）

#### B. cereus

- **兩型食物中毒**：
    - **嘔吐型**：preformed **heat-stable toxin**（cereulide）→ 1–6 hr → 嘔吐為主；常見於**再加熱的米飯**
    - **腹瀉型**：heat-labile toxin → 8–16 hr → 水瀉

### 3.2 Clostridium（厭氧、產芽孢）

| 菌種 | 毒素/機制 | 疾病 | 治療 |
|------|----------|------|------|
| **C. tetani** | **Tetanospasmin** → 阻斷 Renshaw cell 釋放 glycine/GABA（抑制性神經傳導物質） | **破傷風**：trismus（lockjaw）→ risus sardonicus → opisthotonus → 呼吸肌痙攣 | **TIG（tetanus immune globulin）** + Metronidazole + 傷口清創 + 疫苗 |
| **C. botulinum** | **Botulinum toxin** → 阻斷 NMJ presynaptic ACh 釋放 | **肉毒桿菌中毒**：**descending** flaccid paralysis → 先顱神經（複視、吞嚥困難）→ 呼吸衰竭；嬰兒型：**floppy baby**（蜂蜜為風險因子）；成人：食物型（preformed toxin）或傷口型 | **Antitoxin**（成人）、**BIG-IV（BabyBIG）**（嬰兒）；支持呼吸 |
| **C. perfringens** | **α-toxin（lecithinase / phospholipase C）** | **氣壞疽（Gas gangrene）**：外傷後肌肉壞死、crepitus（皮下氣腫）、X-ray 見氣體；**食物中毒**（type A enterotoxin → 8–16 hr 水瀉、cramping） | 清創 + 高劑量 Penicillin（± 高壓氧） |
| **C. difficile** | **Toxin A**（enterotoxin）、**Toxin B**（cytotoxin，**臨床檢驗主要標靶**） | **偽膜性腸炎（Pseudomembranous colitis）**：抗生素使用後（clindamycin, fluoroquinolone, cephalosporin 高風險）→ 水瀉、腹痛、發燒 | 初發 non-severe：**Fidaxomicin** 或 **oral Vancomycin**；Severe：**oral Vancomycin**；Fulminant：oral Vancomycin + **IV Metronidazole**；復發：Fidaxomicin / 糞便微生物移植（FMT） |

- **C. difficile 診斷**：
    - **首選**：NAAT（PCR for toxin B gene）或 GDH + toxin EIA 兩步驟
    - **大腸鏡**：pseudomembrane（黃白色偽膜）
    - **預防**：antimicrobial stewardship、接觸隔離、手洗（酒精無法殺芽孢，需用**肥皂水洗手**）

### 3.3 Corynebacterium diphtheriae（白喉桿菌）

- G(+) bacilli，**club-shaped**、排列如 **Chinese letters / V-shaped / L-shaped**
- **染色**：Albert stain / Loeffler's methylene blue → **metachromatic granules（異染顆粒）**
- **毒素**：**Diphtheria toxin**（由 **β-phage** 賦予）→ **ADP-ribosylation of EF-2** → 抑制蛋白質合成
- **臨床**：
    - **咽喉白喉**：咽喉灰白色**偽膜**（tough, adherent pseudomembrane）→ 強行撕除易出血 → 可致呼吸道阻塞
    - **Bull neck**：頸部淋巴結腫大 + 組織水腫
    - **心肌炎**（toxin 最嚴重的全身併發症）
    - **周邊神經病變**
- **診斷**：Elek test（毒素偵測）、Tellurite agar（黑色菌落）、Loeffler's medium
- **治療**：**Diphtheria antitoxin**（首要）+ **Penicillin 或 Erythromycin**
- **疫苗**：**Toxoid（DPT/Td/Tdap 中的 D/d 成分）**

### 3.4 Listeria monocytogenes

- G(+) bacilli、**兼性厭氧**、**兼性胞內寄生菌**
- **4°C 可生長**（cold enrichment）→ 冷藏食品（乳製品、冷盤肉品、軟質起司）
- **Tumbling motility**：actin rocket（利用宿主 actin 在細胞間移動）
- **溶血**：β-hemolysis（listeriolysin O → 穿透 phagosome 逃入細胞質）
- **高風險族群**：**孕婦**、新生兒、老人、免疫低下
- **臨床**：
    - 孕婦：菌血症 → 流產/死胎/早產
    - 新生兒：敗血症、腦膜炎（**新生兒腦膜炎第三常見菌**，僅次於 GBS、E. coli）
    - 免疫低下：**腦膜炎**（CSF 可見 G(+) bacilli；**單核球為主**）
    - 免疫正常成人：通常只有自限性腸胃炎
- **治療**：**Ampicillin**（首選）± Gentamicin
- **注意**：對 Cephalosporin **天然抗藥**

### 3.5 Actinomyces vs. Nocardia

| 特徵 | **Actinomyces israelii** | **Nocardia** |
|------|-------------------------|--------------|
| G(+)/G(−) | G(+) | G(+)（weakly acid-fast） |
| 氧氣需求 | **厭氧** | **好氧** |
| 形態 | filamentous, branching | filamentous, branching |
| 硫磺顆粒 | **Sulfur granules(+)** | (−) |
| 常見感染 | **Cervicofacial**（最常見）→ draining sinus tracts、下顎腫塊（IUD 相關 → 骨盆腔） | **肺部**（immunocompromised, 如 HIV/移植）→ 可擴散至 **CNS**（腦膿瘍） |
| 治療 | **Penicillin G**（長期，6-12 月） | **TMP-SMX**（長期） |

## 四、革蘭氏陰性球菌（Gram-Negative Cocci）

### 4.1 Neisseria

#### 共同特徵
- G(−) **diplococci**（腎形成對）
- **Oxidase(+)**
- 需 **chocolate agar + CO₂**
- **選擇性培養**：Thayer-Martin（VCN）agar
- 有 **IgA protease**
- 有 **Type IV pili**（黏附 + antigenic variation）
- 利用 **LOS（lipooligosaccharide）**

#### N. gonorrhoeae（淋病雙球菌）

| 項目 | 內容 |
|------|------|
| **鑑別** | 發酵 **glucose only** |
| **臨床** | ① **Urethritis**：男性膿性尿道分泌物、排尿痛；② **子宮頸炎**；③ **PID（骨盆腔發炎）** → 輸卵管疤痕 → 不孕、子宮外孕；④ **Disseminated Gonococcal Infection（DGI）**：purulent monoarthritis + tenosynovitis + dermatitis；⑤ **新生兒眼炎（ophthalmia neonatorum）**：產道感染 → **2-5 天**發作 → 嚴重可致失明 → 預防：**Erythromycin 眼藥膏** |
| **診斷** | **NAAT（PCR）首選**；Gram stain of urethral discharge → intracellular G(−) diplococci in PMN；培養（chocolate agar / Thayer-Martin） |
| **治療** | **Ceftriaxone IM single dose**；經驗上常合併治療 **Chlamydia**（Doxycycline 或 Azithromycin） |

#### N. meningitidis（腦膜炎雙球菌）

| 項目 | 內容 |
|------|------|
| **鑑別** | 發酵 **glucose AND maltose** |
| **莢膜** | 有（**最重要毒力因子**） |
| **臨床** | ① **細菌性腦膜炎**：青少年/年輕成人最常見菌 → 高燒、頸部僵硬、意識改變；② **Meningococcemia** → **Waterhouse-Friderichsen syndrome**：暴發性敗血症 → **雙側腎上腺出血性壞死** → 急性腎上腺衰竭 + DIC + purpura fulminans（瀰漫性紫斑）；極高死亡率 |
| **風險因子** | **Terminal complement deficiency（C5-C9/MAC 缺乏）**；asplenia；宿舍群居 |
| **預防** | 密切接觸者需 **化學性預防**（**Rifampin**、Ciprofloxacin 或 Ceftriaxone）；**疫苗** |
| **治療** | **Ceftriaxone** 或 Penicillin G |

### 4.2 Moraxella catarrhalis

- G(−) diplococci、oxidase(+)
- **產 β-lactamase**
- 常見於 COPD 急性惡化、兒童中耳炎、鼻竇炎
- 治療：Amoxicillin-clavulanate、2nd/3rd gen cephalosporin、macrolides

## 五、革蘭氏陰性桿菌——腸內菌（Enterobacteriaceae）

### 5.1 共同特徵

- G(−) bacilli、**Oxidase(−)**（與 Pseudomonas 等 oxidase(+) 區分）
- 兼性厭氧
- 可發酵 glucose
- 還原 nitrate
- 分為 **乳糖發酵(+)**（E. coli, Klebsiella, Enterobacter, Citrobacter, Serratia）與 **乳糖發酵(−)**（Salmonella, Shigella, Proteus, Yersinia）

### 5.2 Escherichia coli

- **最常見 UTI 致病菌**（所有年齡層）
- **最常見 G(−) 菌血症致病菌**
- **新生兒腦膜炎第二常見菌**（K1 capsule）
- **致病型腹瀉 E. coli**：

| 型別 | 機制 | 特色 |
|------|------|------|
| **ETEC（Enterotoxigenic）** | **LT（heat-labile → cAMP↑，同 cholera）** + **ST（heat-stable → cGMP↑）** | **旅行者腹瀉最常見菌**；水瀉 |
| **EHEC（Enterohemorrhagic）** | **Shiga-like toxin（Stx）** → 抑制 60S ribosome | **O157:H7**；不發酵 sorbitol；**出血性結腸炎**（bloody diarrhea, no fever）→ **HUS（溶血性尿毒症候群）**：MAHA + 血小板↓ + 急性腎衰竭（兒童最常見）；**不可使用抗生素**（可促進毒素釋放） |
| **EIEC（Enteroinvasive）** | 侵入結腸上皮（類似 Shigella） | 血便、發燒（類似痢疾） |
| **EPEC（Enteropathogenic）** | A/E lesion（attaching and effacing） | 嬰幼兒水瀉（開發中國家） |
| **EAEC（Enteroaggregative）** | 黏附形成 biofilm | 持續性水瀉（>14 天） |

### 5.3 Klebsiella pneumoniae

- **厚莢膜**（mucoid colonies）→ 高毒力
- **常見感染**：
    - **CAP**（特別在酗酒者、糖尿病）→ **current jelly sputum（紅磚色痰）**；好發**右上葉**；易形成膿瘍及空洞
    - **UTI**、院內肺炎、肝膿瘍
- **台灣特殊**：**Klebsiella pneumoniae liver abscess（KPLA）**
    - **高毒力莢膜型（K1/K2 hypervirulent）**
    - 好發**糖尿病患者**
    - 可合併轉移性感染：**眼內炎（endophthalmitis）** → 失明風險；腦膿瘍、肺膿瘍
- 抗藥性：產 ESBL → 治療首選 **Carbapenem**
- **CRE / CRKP**：carbapenemase-producing（KPC、NDM） → 治療選擇有限（Ceftazidime-avibactam、Polymyxins）

### 5.4 Salmonella

- **乳糖(−)**、**H₂S(+)**、**Motile**
- 特色：**intracellular pathogen**（在巨噬細胞內存活）
- 分型：

| 型別 | 代表 | 臨床 |
|------|------|------|
| **Typhoidal** | **S. Typhi、S. Paratyphi** | **傷寒（Typhoid fever）**：持續高燒（stepwise fever）、相對性心搏過緩（relative bradycardia）、**rose spots**（腹部）、肝脾腫大、**腸穿孔**（回腸末端 Peyer's patches 壞死）；骨髓培養最敏感 |
| **Non-typhoidal** | S. Enteritidis、S. Typhimurium | 自限性腸胃炎（8–48 hr，嘔吐+腹瀉+腹痛+發燒）；通常不需抗生素；免疫不全/極端年齡可致菌血症 |

- **Salmonella 特別關聯**：
    - **鐮狀細胞病（Sickle cell disease）**：**Salmonella 骨髓炎**
    - **Salmonella 帶菌者**：膽囊為 reservoir → **膽結石患者** → 慢性帶菌
- **傷寒治療**：**Ciprofloxacin** 或 **Ceftriaxone** 或 **Azithromycin**
- **疫苗**：Vi polysaccharide（IM）或 Ty21a live attenuated（oral）

### 5.5 Shigella

- **乳糖(−)**、**H₂S(−)**、**Non-motile**
- **不侵入血流**（局限於腸道黏膜）
- 極低感染劑量（**10–200 菌體**）→ 人傳人
- **毒素**：**Shiga toxin**（S. dysenteriae type 1 產生）→ 抑制 60S ribosome → HUS
- **臨床**：**Bacillary dysentery** → 高燒、腹痛、黏液膿血便、tenesmus（裡急後重）
- **治療**：**Ciprofloxacin** 或 **Azithromycin**

### 5.6 Proteus

- **乳糖(−)**、**Urease(+)**（強陽性）
- **Swarming motility**（在 blood agar 上呈放射狀擴散）
- **臨床**：UTI → urease 分解尿素 → pH↑ → **鹿角結石（Struvite/Staghorn stones, MgNH₄PO₄）**
- 治療：Ampicillin、TMP-SMX（P. mirabilis）；P. vulgaris 多重抗藥

### 5.7 Yersinia

#### Y. pestis（鼠疫桿菌）

- 透過**跳蚤（flea）**叮咬傳播
- **三型臨床**：
    - **Bubonic plague**（最常見）：急性淋巴結腫痛（bubo，常在腹股溝）
    - **Septicemic plague**：DIC、gangrene → **Black Death**
    - **Pneumonic plague**：最嚴重，人傳人（飛沫）
- 治療：**Streptomycin** 或 **Gentamicin** 或 Doxycycline

#### Y. enterocolitica

- 低溫（4°C）可生長
- 急性腸炎（**右下腹痛**，mimics appendicitis，尤其兒童）
- 可引起反應性關節炎
- 經由污染食物（尤其豬肉）或輸血（血袋中增殖）

### 5.8 Serratia marcescens

- 產生**紅色色素（prodigiosin）**（低溫培養時）
- 院內感染：UTI、肺炎、菌血症
- **靜脈藥癮者（IVDU）心內膜炎**

## 六、革蘭氏陰性桿菌——非腸內菌及其他

### 6.1 Pseudomonas aeruginosa

- **Oxidase(+)**、**好氧**、non-lactose fermenter
- **藍綠色色素**（pyocyanin + pyoverdin）、fruit-like odor（grape-like）
- **Biofilm 形成** → 器械/植入物感染
- **臨床**：
    - **院內感染大宗**：院內肺炎（VAP）、UTI（catheter-associated）、burn wound infection、菌血症
    - **Ecthyma gangrenosum**：皮膚壞死性潰瘍（neutropenic patient）
    - **Hot tub folliculitis**
    - **Malignant（necrotizing）external otitis**：**糖尿病老年患者**外耳道劇痛 → 侵犯骨頭（skull base osteomyelitis）
    - **Contact lens keratitis**
    - **心內膜炎**（IVDU 使用者）
    - **慢性肺部感染**（CF 患者）
- **天然抗藥性多**（efflux pump、AmpC β-lactamase 等）
- **Anti-Pseudomonal 抗生素**：Piperacillin-tazobactam、Ceftazidime、Cefepime、Meropenem、Ciprofloxacin、Aminoglycosides、Colistin（最後線）

### 6.2 Haemophilus influenzae

- G(−) coccobacilli
- 生長需要 **Factor X（hemin）** + **Factor V（NAD）** → chocolate agar 或 XV supplement
- **Type b（Hib）** 有莢膜 → 侵襲性感染；**Non-typeable（NTHi）** 無莢膜 → 黏膜感染
- **臨床**：
    - **急性會厭炎（epiglottitis）**：2–7 歲兒童；drooling、stridor、tripod position、thumb sign → 呼吸道急症（疫苗接種後已大幅減少）
    - 腦膜炎（Type b，Hib 疫苗前兒童常見）
    - 中耳炎、鼻竇炎（non-typeable）
    - 肺炎（COPD 急性惡化常見菌）
- **疫苗**：**Hib conjugate vaccine** → 兒童常規接種
- **治療**：Ceftriaxone（腦膜炎）、Amoxicillin-clavulanate（中耳炎、鼻竇炎）

### 6.3 Bordetella pertussis

- G(−) coccobacilli、**Bordet-Gengou（potato agar）** 培養
- **毒素**：
    - **Pertussis toxin**：**ADP-ribosylation of Gi → cAMP↑**
    - **Tracheal cytotoxin**：破壞纖毛上皮
    - **Filamentous hemagglutinin（FHA）**：黏附
- **臨床三期**：
    1. **Catarrhal stage**（1–2 週）：最具傳染力，類似上呼吸道感染
    2. **Paroxysmal stage**（2–6 週）：陣發性咳嗽 + **inspiratory whoop** + post-tussive vomiting（**百日咳**）；嬰兒可無 whoop 而以 **apnea** 表現
    3. **Convalescent stage**（數週至數月）：緩慢恢復
- **實驗室**：**WBC↑↑（lymphocytosis 為主）**；PCR（nasopharyngeal swab 首選檢查）
- **治療**：**Azithromycin**（首選）或 Erythromycin
- **疫苗**：DTaP（兒童）/ Tdap（青少年成人 booster）

### 6.4 Legionella pneumophila

- G(−) bacilli、**兼性胞內菌**
- 生長於 **Buffered Charcoal Yeast Extract（BCYE）agar**（需 iron + cysteine）
- 普通 Gram stain 不易見 → 用 **silver stain** 可見
- **傳播**：吸入受污染的**空調冷卻水塔、蓮蓬頭、噴泉**之氣霧（aerosol）→ **非人傳人**
- **臨床**：
    - **Legionnaires' disease**：**非典型肺炎**（高燒、乾咳、relative bradycardia、GI symptoms、hyponatremia、CNS 症狀）
    - **Pontiac fever**：自限性流感樣疾病
- **診斷**：**Urine Legionella antigen**（serogroup 1）；培養（BCYE）
- **治療**：**Azithromycin** 或 **Fluoroquinolone**

### 6.5 Vibrio

| 菌種 | 特色 |
|------|------|
| **V. cholerae** | comma-shaped、oxidase(+)、**TCBS agar**（yellow colonies）；O1/O139 產 **cholera toxin（CT）**（ADP-ribosylation Gs → cAMP↑ → Cl⁻/水分泌）→ **rice-water diarrhea**（大量水瀉無血便，非發炎性）→ 嚴重脫水 → 治療首要：**ORS 補液** + Doxycycline（縮短病程） |
| **V. parahaemolyticus** | **生食海鮮**（台灣最常見細菌性食物中毒致病菌之一）；**Kanagawa phenomenon(+)**（β-hemolysis on Wagatsuma agar）；水瀉±血便 |
| **V. vulnificus** | **生食牡蠣/海鮮** 或傷口接觸海水；好發**肝硬化、免疫低下**；嚴重 **necrotizing fasciitis** + sepsis → 高死亡率 |

### 6.6 Campylobacter jejuni

- G(−) **comma/S-shaped/gull-wing**
- **Microaerophilic**（42°C 最適溫度）
- **最常見細菌性腸炎致病菌**（已開發國家）
- 傳播：**未煮熟家禽**
- 臨床：發燒、水瀉→血便（inflammatory diarrhea）
- **併發症**：**Guillain-Barré Syndrome（GBS）**（分子模擬 → anti-ganglioside Ab）；反應性關節炎
- 診斷：42°C 培養
- 治療：通常自限；嚴重 → **Azithromycin**（Fluoroquinolone 抗藥率升高）

### 6.7 Helicobacter pylori

- G(−) curved/spiral rod
- **Urease(+)**（強陽性）→ 產生 NH₃ 中和胃酸
- **CagA / VacA** virulence factors → 增加胃癌風險
- **臨床**：
    - **慢性胃炎**（最常見結果）
    - **消化性潰瘍**：十二指腸潰瘍（最常見）、胃潰瘍
    - **胃腺癌（gastric adenocarcinoma）**
    - **胃 MALT lymphoma** → H. pylori 根除治療可能使淋巴瘤消退
- **診斷**：
    - **非侵入性**：**Urea breath test（UBT，¹³C/¹⁴C）**（最佳追蹤檢查）、stool antigen test、serology（無法區分現在/過去感染）
    - **侵入性**：胃鏡切片 → rapid urease test（CLO test）、組織學、培養
- **治療（Triple therapy）**：**PPI + Clarithromycin + Amoxicillin**（或 Metronidazole）× 14 天；台灣 clarithromycin 抗藥率高 → 可考慮 **Bismuth-based quadruple therapy**

### 6.8 Brucella

- G(−) coccobacilli、**兼性胞內菌**
- 傳播：攝入未消毒乳製品、接觸受感染動物（牛/羊/豬）
- 臨床：**Undulant fever**（波浪狀發燒）、關節痛、肝脾腫大、骨髓肉芽腫
- 治療：**Doxycycline + Streptomycin/Gentamicin** 或 Rifampin

### 6.9 Bartonella

| 菌種 | 疾病 | 特色 |
|------|------|------|
| **B. henselae** | **Cat-scratch disease** | 被貓抓/咬後 → 局部紅色丘疹 → **區域性淋巴結腫大**（自限）；免疫低下 → **bacillary angiomatosis**（血管增生性病灶，似 Kaposi sarcoma）、**peliosis hepatis** |
| **B. quintana** | Trench fever、bacillary angiomatosis | 經體蝨（body louse）傳播；homeless |

### 6.10 Francisella tularensis

- 傳播：tick bite、接觸兔子/小型動物
- **臨床**：**Tularemia** → ulceroglandular form 最常見（潰瘍 + 局部淋巴結腫大）
- 治療：**Streptomycin** 或 Gentamicin

### 6.11 Pasteurella multocida

- **動物咬傷**（尤其**貓咬**）→ 快速進展的**蜂窩性組織炎**（<24 小時）
- 治療：**Amoxicillin-clavulanate**

### 6.12 Gardnerella vaginalis

- G(−)（variable staining）
- **Bacterial vaginosis（BV）**：非發炎性；grey-white thin discharge、**fishy odor**（whiff test with KOH(+)）、pH >4.5、**clue cells**（上皮細胞表面覆蓋 bacteria）
- 治療：**Metronidazole**（口服或陰道內）或 Clindamycin

## 七、厭氧菌（Anaerobes）

### 7.1 重要厭氧菌

| 菌種 | G(+/-) | 特色 |
|------|--------|------|
| **Bacteroides fragilis** | G(−) bacilli | **最常見的臨床厭氧菌**；腸道正常菌叢；腹腔膿瘍最常見厭氧菌；**有莢膜**（polysaccharide capsule → abscess formation）；**β-lactamase(+)** → 對 Penicillin 抗藥 |
| **Fusobacterium** | G(−) bacilli | **Lemierre syndrome**：pharyngitis → internal jugular vein thrombophlebitis → septic emboli |
| **Clostridium** | G(+) bacilli | 前述 |
| **Actinomyces** | G(+) filamentous | 前述 |
| **Peptostreptococcus** | G(+) cocci | 混合感染 |

### 7.2 厭氧感染特徵
- Foul-smelling discharge（惡臭分泌物）
- Gas production in tissue
- Infection near mucosal surfaces（常為正常菌叢汙染）
- Abscess formation
- Gram stain 見多型菌但培養陰性（一般培養未做厭氧培養）

### 7.3 治療
- **Metronidazole**（最常用抗厭氧菌藥物）
- **β-lactam + β-lactamase inhibitor**（Ampicillin-sulbactam、Piperacillin-tazobactam）
- Carbapenems（Meropenem）
- Clindamycin（但 B. fragilis 抗藥率升高）

## 八、分枝桿菌（Mycobacteria）

### 8.1 共同特徵

- **Acid-fast bacilli（AFB）**：Ziehl-Neelsen stain 或 Auramine-rhodamine fluorescent stain
- 細胞壁含 **mycolic acid**（蠟質成分）→ 抗酸染色、不易被 Gram stain 染色
- **生長緩慢**（M. tuberculosis 世代時間 ~15–20 hrs）

### 8.2 Mycobacterium tuberculosis

#### 傳播與致病
- **飛沫核（droplet nuclei）** 傳播
- **兼性胞內菌**（在巨噬細胞內存活）
- **Cord factor（trehalose dimycolate）**：抑制 phagosome-lysosome fusion、促進肉芽腫
- **Type IV hypersensitivity**：T cell（CD4⁺ Th1）→ IFN-γ → 活化巨噬細胞 → **乾酪性肉芽腫（caseating granuloma）**（中央壞死、Langhans giant cells、epithelioid cells）

#### 臨床

- **初次感染（Primary TB）**：
    - 多無症狀 → **Ghon focus**（中下肺野的肉芽腫）+ hilar lymphadenopathy = **Ghon complex** → 多自行鈣化癒合 → **Ranke complex**
    - 兒童可致**進展性原發性 TB** 或**粟粒性 TB**
- **再活化 TB（Reactivation/Secondary TB）**：
    - 好發**肺尖**（高氧分壓）
    - 症狀：慢性咳嗽（>3 週）、咳血、夜間盜汗、體重下降、發燒
    - CXR：**upper lobe cavitary lesion**
- **肺外 TB**：
    - 淋巴結（scrofula，頸部淋巴結腫大 → 最常見肺外 TB）
    - **脊椎（Pott's disease）**：椎體破壞 + 冷膿瘍（cold abscess）
    - 腦膜炎：CSF → lymphocytic pleocytosis、protein↑↑、glucose↓↓
    - 泌尿生殖系統：sterile pyuria
    - **Miliary TB**：血行散播 → CXR 呈 millet seed 樣分布

#### 診斷

| 檢查 | 說明 |
|------|------|
| **AFB smear** | Ziehl-Neelsen / Auramine；快速但敏感度有限 |
| **Culture** | **Gold standard**；LJ medium 或 BACTEC liquid media（4–8 週，BACTEC 約 1–3 週） |
| **NAAT / PCR（如 GeneXpert）** | 快速（2 hr）偵測 TB + rifampin resistance（rpoB gene 突變） |
| **TST（PPD/Tuberculin skin test）** | 注射 PPD → 48–72 hr 讀取**硬結（induration）**大小；測 Type IV hypersensitivity |
| **IGRA（QFT-GIT / T-SPOT）** | 血液檢查，測 T cell 對 TB 特異抗原（ESAT-6, CFP-10）釋放之 IFN-γ；不受 BCG 影響 |

- **TST 判讀**：
    - ≥5 mm：HIV、close contact、CXR 異常、免疫抑制（immunosuppression）
    - ≥10 mm：高風險族群（移民、醫護、IVDU、糖尿病、慢性腎病）
    - ≥15 mm：低風險族群

#### 治療

- **LTBI（潛伏感染）**：
    - **INH × 9 months**（首選）；或 Rifampin × 4 months；或 INH + Rifapentine × 3 months（3HP regimen）
- **Active TB**：
    - **初始 2 個月（Intensive phase）**：**RIPE** = **Rifampin + INH（Isoniazid）+ Pyrazinamide + Ethambutol**
    - **後續 4 個月（Continuation phase）**：**Rifampin + INH**
    - 總療程：**至少 6 個月**（TB meningitis/bone → 9–12 個月）

#### 抗 TB 藥物副作用

| 藥物 | 副作用 | 備註 |
|------|--------|------|
| **INH** | **Peripheral neuropathy**（vitamin B6/pyridoxine 缺乏 → 需補充）、**Hepatotoxicity**、SLE-like syndrome、Sideroblastic anemia | CYP450 inhibitor；slow acetylator 副作用風險↑ |
| **Rifampin** | **Hepatotoxicity**、體液橘紅色（淚液/尿液/汗液）、**CYP450 inducer**（降低 OCP、warfarin、protease inhibitor 等藥效）、flu-like syndrome | **CYP450 最強 inducer** |
| **Pyrazinamide** | **Hepatotoxicity（最嚴重者）**、**Hyperuricemia / Gout** | — |
| **Ethambutol** | **Optic neuritis（視力模糊、色覺異常 → red-green color blindness）** | 需定期視力檢查 |
| **Streptomycin** | Ototoxicity、nephrotoxicity | Aminoglycoside；孕婦禁用 |

### 8.3 非結核分枝桿菌（NTM / Atypical Mycobacteria）

| 菌種 | 特色 |
|------|------|
| **M. avium complex（MAC）** | HIV（**CD4 <50**）最常見的 NTM 感染 → 散播性感染：高燒、體重下降、pancytopenia、肝脾腫大；**Azithromycin prophylaxis**（CD4 <50）；治療：**Clarithromycin + Ethambutol ± Rifabutin** |
| **M. kansasii** | 類似肺 TB（upper lobe cavitary lesion）；photochromogen |
| **M. marinum** | **Swimming pool granuloma / fish tank granuloma**；水中/魚缸接觸 → 皮膚結節 |
| **M. leprae** | 下述 |
| **M. scrofulaceum** | 兒童頸部淋巴結炎（scrofula） |
| **Rapid growers（M. fortuitum, M. abscessus, M. chelonae）** | 皮膚軟組織感染、術後傷口感染、catheter 感染 |

### 8.4 M. leprae（痲瘋分枝桿菌）

- **不能人工培養**（在 armadillo 或 mouse footpad 培養）
- 嗜低溫（侵犯皮膚、周邊神經）
- **兩型光譜**：

| | **Tuberculoid leprosy（TT）** | **Lepromatous leprosy（LL）** |
|--|------------------------------|------------------------------|
| 免疫反應 | **Th1 為主**（強細胞免疫） | **Th2 為主**（弱細胞免疫、高體液免疫但無效） |
| 皮膚病灶 | **少量**、界線清楚、hypopigmented、乾燥、感覺喪失 | **大量**、界線不清、結節/丘疹/斑塊、**leonine facies（獅面）** |
| 神經 | **早期即有大而粗的周邊神經**腫大 → 感覺喪失 | 晚期對稱性「手套襪子」感覺喪失 |
| AFB smear | **(−)** 或極少 | **(++++)**（大量 bacilli） |
| Lepromin test | **(+)** | **(−)** |
| 治療 | **Dapsone + Rifampin**（6–12 月） | **Dapsone + Rifampin + Clofazimine**（12–24 月） |

- **Dapsone 副作用**：hemolytic anemia（G6PD deficiency 風險↑）、methemoglobinemia、DRESS
- **Erythema nodosum leprosum（ENL）**：LL 患者治療中的 Type 2 反應 → 治療：**Thalidomide**（孕婦禁用 → teratogenic）

## 九、螺旋體（Spirochetes）

### 9.1 共同特徵
- 螺旋形、運動活潑（axial filament/endoflagella）
- **暗視野顯微鏡（Darkfield microscopy）** 或 **Silver stain** 可見
- Gram stain 不佳

### 9.2 Treponema pallidum（梅毒螺旋體）

- **不能人工培養**
- **傳播**：性接觸、垂直傳播（先天性梅毒）、輸血（罕見）

#### 分期

| 期別 | 時間 | 臨床 | 傳染性 |
|------|------|------|--------|
| **Primary** | 感染後 ~3 週 | **Painless chancre**（硬性下疳）：單一、邊緣隆起、硬底、不痛、**高度傳染力** | +++ |
| **Secondary** | 6–8 週後 | **全身性**：diffuse maculopapular rash（**包含手掌和腳底**）、**Condylomata lata**（生殖器周圍濕扁平疣）、mucosal patches、淋巴結腫大、全身症狀 | +++ |
| **Latent** | — | 無症狀；Early latent（<1 yr）vs Late latent（>1 yr） | Early ± |
| **Tertiary** | 數年後 | ① **Gumma**（慢性肉芽腫，可侵犯任何器官）；② **Cardiovascular**：**ascending aortic aneurysm**（vasa vasorum 發炎 → 主動脈瓣閉鎖不全）；③ **Neurosyphilis**：**General paresis**（dementia）、**Tabes dorsalis**（後柱退化 → 感覺性共濟失調、Argyll Robertson pupils「近光分離」、lightning pains、Charcot joints）| − |

#### 先天性梅毒

- **早期**（<2 歲）：rhinitis（snuffles）、maculopapular rash、hepatosplenomegaly、osteochondritis
- **晚期**（>2 歲）：**Hutchinson's triad**（interstitial keratitis + Hutchinson's teeth（notched incisors）+ CN VIII deafness）；saddle nose、saber shins、Clutton's joints

#### 診斷

| 檢查 | 說明 |
|------|------|
| **Darkfield microscopy** | 初期/二期皮膚病灶直接觀察（最快速） |
| **Non-treponemal tests（VDRL/RPR）** | **篩檢用**；活性/療效追蹤（titer 與疾病活性相關）；可能**偽陽性**（SLE、APS、pregnancy、other infections） |
| **Treponemal tests（FTA-ABS/TP-PA）** | **確認用**；終身陽性（不用於追蹤療效） |

#### 治療

| 期別 | 治療 |
|------|------|
| Primary / Secondary / Early latent | **Benzathine Penicillin G 2.4 MU IM × 1 dose** |
| Late latent / Tertiary（non-neuro） | **Benzathine Penicillin G 2.4 MU IM × 3 doses（每週一次）** |
| **Neurosyphilis** | **IV Aqueous Penicillin G × 10–14 days** |
| Penicillin 過敏 | Doxycycline（非 neurosyphilis）；neurosyphilis → desensitization to Penicillin |

- **Jarisch-Herxheimer reaction**：治療後數小時因大量螺旋體死亡 → 發燒、寒顫、頭痛、皮疹惡化 → 自限（支持治療）

### 9.3 Borrelia burgdorferi（萊姆病）

- **傳播**：**Ixodes tick（硬蜱）** 叮咬
- **分期**：

| 期別 | 時間 | 臨床 |
|------|------|------|
| **Early localized** | 3–30 天 | **Erythema migrans（EM）**：牛眼樣（target/bull's-eye）紅斑，自蜱咬處擴散；可伴 flu-like symptoms |
| **Early disseminated** | 數週–數月 | **神經**：CN VII palsy（facial nerve palsy，可雙側）、meningitis、radiculopathy；**心臟**：**AV block（各級，尤其三度）**、myocarditis；多發 EM |
| **Late** | 數月–數年 | **關節炎**（大關節，尤其**膝關節**；反覆發作或慢性） |

- **診斷**：**Two-tier testing** → ELISA/EIA（篩檢）→ Western blot（確認）；EM 為臨床診斷（不需等血清學）
- **治療**：
    - Early / facial palsy / mild carditis：**Doxycycline**（首選；兒童 <8 歲或孕婦 → Amoxicillin）
    - Neuro（meningitis）、severe carditis、late arthritis 失敗：**IV Ceftriaxone**

### 9.4 Borrelia recurrentis

- **Relapsing fever**：**體蝨（louse-borne）** 或 **tick-borne**
- 反覆發燒 → antigenic variation（Variable Major Proteins, VMPs）
- 血液抹片見螺旋體
- 治療：Doxycycline

### 9.5 Leptospira interrogans（鉤端螺旋體）

- 傳播：接觸受感染動物**尿液**污染的水（稻田、洪水）
- **臨床**：
    - **輕型（Anicteric）**：自限性發燒、頭痛、**結膜充血（conjunctival suffusion，最具特色的早期 sign）**、肌痛
    - **重型（Weil's disease）**：**黃疸 + 急性腎衰竭 + 出血** → 高死亡率
- 治療：**Penicillin G 或 Doxycycline**

## 十、非典型細菌（Atypical Bacteria）

### 10.1 Mycoplasma pneumoniae

- **沒有細胞壁** → **Gram stain 不可見**、**β-lactam 無效**
- 細胞膜含 **cholesterol**（唯一含 cholesterol 的細菌）
- 培養：Eaton's agar → **fried-egg colonies**（非常緩慢）
- **臨床**：
    - **Walking pneumonia**（非典型肺炎）：好發**年輕人/學齡兒童**
    - 漸進式乾咳、低度發燒、頭痛；CXR（間質性浸潤）比臨床症狀嚴重
    - **併發症**：**Cold agglutinins（IgM anti-I）**（可致 autoimmune hemolytic anemia）、erythema multiforme（Stevens-Johnson syndrome）、bullous myringitis（鼓膜水泡）
- **診斷**：PCR（首選）、serology（IgM）；cold agglutinin test
- **治療**：**Macrolide（Azithromycin）** 或 Doxycycline 或 Fluoroquinolone

### 10.2 Chlamydia

- **專性胞內寄生菌**（obligate intracellular）
- **無法合成 ATP**（energy parasite）
- **二型生活史**：
    - **Elementary body（EB）**：**感染型**（胞外、代謝不活躍、resistant）→ 類似孢子
    - **Reticulate body（RB）**：**繁殖型**（胞內、代謝活躍）

| 菌種 | 疾病 |
|------|------|
| **C. trachomatis** serotype A–C | **Trachoma**（眼睛慢性感染 → **follicular conjunctivitis** → **全球最常見的可預防失明原因**） |
| **C. trachomatis** serotype D–K | **Urethritis / Cervicitis**（最常見 STD 致病菌）；**PID** → 不孕；**新生兒眼炎**（產後 **5–14 天**，較 gonococcal 晚）；新生兒肺炎（staccato cough、afebrile、eosinophilia）；**Reiter's syndrome（反應性關節炎）** |
| **C. trachomatis** serotype **L1–L3** | **Lymphogranuloma venereum（LGV）**：painless genital ulcer → **painful inguinal lymphadenopathy（buboes）** → **groove sign** |
| **C. pneumoniae** | **非典型肺炎**（成人常見；single spear-shaped EB） |
| **C. psittaci** | **Psittacosis（鸚鵡熱）**：接觸**鳥類**→ 非典型肺炎（高燒、頭痛、hepatosplenomegaly） |

- **治療**：**Azithromycin 1g single dose** 或 **Doxycycline 100 mg BID × 7 days**（LGV 需 21 天 Doxycycline）

### 10.3 Rickettsia、Coxiella、Ehrlichia/Anaplasma

#### 共同特徵
- **專性胞內寄生菌**（除 Coxiella 可在胞外短暫存活）
- 經節肢動物（tick、louse、flea、mite）傳播（除 Coxiella）
- 治療：**Doxycycline**（幾乎所有首選）

| 疾病 | 病原體 | 媒介 | 特色 |
|------|--------|------|------|
| **Rocky Mountain Spotted Fever（RMSF）** | **R. rickettsii** | **Tick**（Dermacentor） | 最嚴重的 rickettsial disease（美國）；triad：**fever + headache + rash**（**centripetal** → 從四肢向軀幹擴展，**包含手掌腳底**，petechial）；血管炎 → vasculitis |
| **Epidemic typhus** | **R. prowazekii** | **Body louse** | 高燒、嚴重頭痛、rash（**centrifugal**：軀幹→四肢，**不含手掌腳底**）；戰爭/難民營 |
| **Endemic（murine）typhus** | R. typhi | **Flea** | 較溫和 |
| **Scrub typhus** | **Orientia tsutsugamushi** | **Chigger（恙蟎）** | 亞太地區常見；**eschar（焦痂）** 在蟎叮咬處 → 最具特色 |
| **Q fever** | **Coxiella burnetii** | **無需節肢動物**（吸入受感染動物產物之氣霧） | **不需 tick bite**；急性：非典型肺炎、hepatitis；慢性：**culture-negative endocarditis**（最常見慢性表現）；can form **spore-like** structures |
| **Ehrlichiosis** | Ehrlichia chaffeensis | **Tick** | 侵犯 **monocytes** → **morulae**（胞內包涵體）；leukopenia、thrombocytopenia、elevated transaminases |
| **Anaplasmosis** | Anaplasma phagocytophilum | **Tick**（Ixodes，同 Lyme） | 侵犯 **granulocytes（neutrophils）** → morulae |

## 十一、真菌學

### 11.1 基本概念

| 特徵 | 說明 |
|------|------|
| 細胞壁 | **Ergosterol**（細胞膜成分，抗真菌藥靶點）+ **β-glucan** + **chitin** |
| 分類 | **Yeasts**（酵母菌，圓形出芽）：Candida、Cryptococcus；**Molds**（黴菌，菌絲 hyphae）：Aspergillus、Mucor；**Dimorphic**（溫度依賴型態轉換） |
| 溫度二型性 | **Mold in cold（25°C 環境）**、**Yeast in heat（37°C 體內）** → Histoplasma, Blastomyces, Coccidioides, Paracoccidioides, Talaromyces(Penicillium) marneffei, Sporothrix |
| 染色 | **PAS**、**GMS**、India ink（Cryptococcus）、KOH（溶解角質看菌絲） |

### 11.2 機會性真菌感染（Opportunistic Fungal Infection）

#### Candida

- **最常見的真菌感染**（免疫正常及免疫低下均可）
- **Yeast with pseudohyphae**（C. albicans 可形成 **true hyphae** + **germ tube**）
- **臨床**：
    - **Oral thrush**：白色可刮除的假膜；HIV（CD4 <200）、新生兒、假牙使用者、steroid 吸入劑
    - **Esophageal candidiasis**：吞嚥疼痛（AIDS-defining illness）
    - **Vulvovaginal candidiasis**：白色 cottage cheese-like discharge、搔癢
    - **Invasive candidiasis**：catheter-related、ICU、TPN、broad-spectrum antibiotics
    - **Chronic mucocutaneous candidiasis**：T cell 功能缺陷
    - **Diaper dermatitis**：satellite lesions
- **治療**：
    - 黏膜感染：**Fluconazole**（或 Nystatin topical）
    - 全身感染：**Echinocandin**（首選）→ step-down to Fluconazole
    - **C. krusei**：intrinsically resistant to Fluconazole → Echinocandin
    - **C. auris**：多重抗藥 → 院內感控挑戰

#### Cryptococcus neoformans

- **Encapsulated yeast**（莢膜，不形成 hyphae）
- 棲息於**鴿糞**
- **臨床**：
    - **Cryptococcal meningitis**：HIV（**CD4 <100**）最重要的機會性 CNS 感染
    - 亞急性至慢性病程：頭痛、發燒、頸部僵硬、顱內壓升高
- **診斷**：
    - CSF：**India ink** → capsule 陰影（敏感度有限）
    - **Cryptococcal antigen**：血清及 CSF（最敏感且專一）
    - CSF：opening pressure↑、WBC↑、protein↑、glucose↓
- **治療**：
    - **Induction**（2 週）：**Amphotericin B + Flucytosine**
    - **Consolidation**（8 週）：**Fluconazole**

#### Aspergillus

- **Septate hyphae** with **acute-angle (45°) branching**
- **臨床光譜**：

| 型別 | 族群 | 特色 |
|------|------|------|
| **Allergic Bronchopulmonary Aspergillosis（ABPA）** | **Asthma / CF** 患者 | Type I + III hypersensitivity → 氣喘惡化、proximal bronchiectasis、IgE↑、eosinophilia；治療：**Corticosteroid + Itraconazole** |
| **Aspergilloma（fungus ball）** | 有肺部空洞者（TB 後空洞） | 空洞內真菌球；CXR → **crescent sign**；通常不需治療；嚴重咳血 → 手術/血管栓塞 |
| **Invasive Aspergillosis** | **Neutropenia**（AML 化療、移植）| 最嚴重；快速肺部浸潤、halo sign → air crescent sign；可散播至 CNS；**Galactomannan antigen** 偵測；治療首選：**Voriconazole** |

#### Mucor / Rhizopus

- **Non-septate hyphae** with **wide-angle（90°）branching**
- **臨床**：
    - **Rhinocerebral mucormycosis**：好發 **diabetic ketoacidosis**、neutropenia
    - 黑色焦痂（black eschar）由鼻甲或硬顎開始 → 侵犯眼眶 → 腦
    - **血管侵犯（angioinvasive）** → 組織壞死
- **治療**：**Amphotericin B**（首選）+ 外科清創；控制 DKA

#### Pneumocystis jirovecii

- 分類為真菌但外觀不典型（不能人工培養）
- **臨床**：**Pneumocystis pneumonia（PJP）**
    - HIV（**CD4 <200**）最常見的 **AIDS-defining opportunistic infection**
    - 漸進性呼吸困難、乾咳、低度發燒
    - CXR：**bilateral diffuse ground-glass / interstitial infiltrates**
    - LDH↑、A-a gradient↑
- **診段**：**Induced sputum or BAL** → stain 或 PCR
- **治療**：**TMP-SMX**（首選）；PaO₂ <70 或 A-a gradient >35 → 加 **Corticosteroid**
- **預防**：CD4 <200 → **TMP-SMX prophylaxis**

### 11.3 雙態性真菌（Dimorphic Fungi）

| 菌種 | 地理分布 | 特色 |
|------|----------|------|
| **Histoplasma capsulatum** | **美洲**（Ohio/Mississippi river valleys） | 鳥糞/蝙蝠洞穴 → 吸入感染；肺部肉芽腫（可鈣化類似 TB）；immunocompromised → disseminated；**intracellular small yeast（巨噬細胞內）** |
| **Blastomyces dermatitidis** | **美洲**（Great Lakes, Ohio-Mississippi area） | 肺部感染；皮膚擴散（verrucous lesions）；**broad-based budding yeast** |
| **Coccidioides immitis** | **美洲**（Arizona, California, Mexico） | 肺部感染；erythema nodosum/multiforme；腦膜炎；**spherules with endospores** |
| **Talaromyces（Penicillium）marneffei** | **東南亞**（台灣有報告） | HIV（CD4 <100）→ disseminated → 高燒、皮膚丘疹（**central umbilicated**）、hepatosplenomegaly |

### 11.4 其他真菌感染

#### Sporothrix schenckii

- 好發：園藝工人、花農
- **Rose gardener's disease**：皮膚接種 → **沿淋巴管分佈的結節/潰瘍**
- 診斷：Culture（dimorphic）
- 治療：**Itraconazole**（皮膚型）、Amphotericin B（全身型）

#### 皮膚真菌（Dermatophytes）

- **Trichophyton、Microsporum、Epidermophyton**
- 感染**角化組織**（皮膚、毛髮、指甲）→ **Tinea（癬）**
- 診斷：KOH preparation → **septate hyphae**
- **Wood's lamp**：Microsporum → **fluorescence(+)**
- 治療：局部 azole/terbinafine；全身 **Terbinafine/Griseofulvin**（指甲/頭皮/廣泛）

## 十二、病毒學總論

### 12.1 基本概念

| 特徵 | 說明 |
|------|------|
| 結構 | Nucleic acid（DNA 或 RNA）+ capsid（protein coat）± **envelope**（脂質雙層膜） |
| **有套膜（Enveloped）** | 來自宿主細胞膜；以**出芽（budding）**釋放；對乾燥/清潔劑/乙醇**敏感** |
| **無套膜（Naked）** | 較穩定；以**細胞溶解（lysis）**釋放；抵抗乾燥/清潔劑/酸 |
| 複製位置 | **DNA virus**：多在**核內**；**RNA virus**：多在**細胞質** |

### 12.2 DNA 病毒總覽

- **HHAPPPy**：Herpes, Hepadna, Adeno, Pox, Papilloma, Parvo, Polyoma
- 大部分 **dsDNA**，除了 **Parvovirus（ssDNA）**
- 大部分**核內複製**，除了 **Poxvirus（細胞質）**

### 12.3 RNA 病毒總覽

- 大部分 **ssRNA**，除了 **Reovirus（dsRNA）**
- **Positive-sense（+）ssRNA**（可直接作為 mRNA）：Picorna, Calici, Flavi, Toga, Corona, Hepe, Retro
- **Negative-sense（−）ssRNA**（需 RNA polymerase 先轉錄）：Orthomyxo, Paramyxo, Rhabdo, Filo, Bunya, Arena

## 十三、DNA 病毒（DNA Viruses）

### 13.1 Herpesviridae

- dsDNA、**enveloped**、**latency（潛伏感染）**

| 病毒 | 別名 | 潛伏位置 | 重要疾病 |
|------|------|----------|----------|
| **HHV-1（HSV-1）** | Herpes simplex 1 | **三叉神經節（trigeminal ganglion）** | **Oral herpes**（gingivostomatitis、cold sore/fever blister）；**Herpes keratitis**（dendritic ulcer）；**Herpes encephalitis**（temporal lobe 出血性壞死）；**Herpetic whitlow**（指端疱疹） |
| **HHV-2（HSV-2）** | Herpes simplex 2 | **薦神經節（sacral ganglion）** | **Genital herpes**（painful vesicles on erythematous base）；**neonatal herpes**（產道感染 → 高死亡率）；viral meningitis|
| **HHV-3（VZV）** | Varicella-Zoster | **背根神經節（dorsal root ganglion）** | **Chickenpox（水痘）**：全身性 vesicular rash（各期共存，dew drop on rose petal）；**Herpes zoster（帶狀疱疹）**：沿**單側皮節**分布之 painful vesicles；**Ramsay Hunt syndrome**（侵犯 CN VII → facial palsy + ear vesicles + hearing loss）；**Hutchinson sign**（侵犯 CN V1 → 鼻尖 vesicle → 眼部併發症風險） |
| **HHV-4（EBV）** | Epstein-Barr virus | **B cells** | **Infectious mononucleosis**：fever + pharyngitis + lymphadenopathy、**hepatosplenomegaly**（脾破裂風險）、**maculopapular rash**（若給 Ampicillin/Amoxicillin）、**atypical lymphocytes**（reactive CD8⁺ T cells）、**Heterophile Ab**（Monospot test）；**相關腫瘤**：**Burkitt lymphoma**、**Nasopharyngeal carcinoma**、Hodgkin lymphoma、PTLD |
| **HHV-5（CMV）** | Cytomegalovirus | **Mononuclear cells** | **Mononucleosis**（無 Heterophile Ab）；**先天性 CMV**：sensorineural hearing loss、periventricular calcifications、chorioretinitis；**HIV（CD4 <50）**：**retinitis**、colitis、esophagitis、pneumonitis；**owl-eye intranuclear inclusions** |
| **HHV-6** | — | T cells | **Roseola infantum（Exanthem subitum）**：嬰幼兒 **高燒 3–5 天**（可 febrile seizure）→ **退燒後出疹**（macular rash）；**DRESS**（HHV-6 reactivation） |
| **HHV-7** | — | T cells | 與 HHV-6 類似（roseola） |
| **HHV-8（KSHV）** | Kaposi sarcoma-associated herpesvirus | B cells | **Kaposi sarcoma**（AIDS-defining illness）：紫紅色皮膚/黏膜血管增生性病灶；Primary effusion lymphoma；Multicentric Castleman disease |

- **HSV/VZV 治療**：**Acyclovir** → 由 **viral thymidine kinase** 磷酸化活化 → 抑制 viral DNA polymerase；抗藥：**Foscarnet**
- **CMV 治療**：**Ganciclovir** → 由 **UL97 kinase** 磷酸化 → 抑制 DNA polymerase；副作用：**骨髓抑制**（neutropenia）；替代：Foscarnet、Cidofovir

### 13.2 Papillomaviridae（HPV）

- dsDNA、non-enveloped
- 感染**鱗狀上皮**
- **Oncoproteins**：
    - **E6** → 抑制 **p53**（抗凋亡）
    - **E7** → 抑制 **Rb**（促進細胞週期進入 S phase）
- **低風險型（HPV 6, 11）**：**condylomata acuminata（尖銳濕疣/菜花）**、laryngeal papillomatosis（兒童呼吸道乳突瘤）
- **高風險型（HPV 16, 18, 31, 33, 45 等）**：**子宮頸癌**（squamous cell carcinoma）、**口咽癌**、肛門癌、外陰/陰莖癌
- **組織學**：**Koilocytes**（perinuclear clearing + nuclear irregularity）
- **疫苗**：**9-valent HPV vaccine**（HPV 6, 11, 16, 18, 31, 33, 45, 52, 58）
- **篩檢**：Pap smear + HPV DNA testing

### 13.3 Adenovirus

- dsDNA、non-enveloped
- **臨床**：
    - **Pharyngoconjunctival fever**（咽結膜熱）
    - **Epidemic keratoconjunctivitis**（高傳染性）
    - **Acute hemorrhagic cystitis**（兒童）
    - **Pneumonia**（軍營）

### 13.4 Parvovirus B19

- **ssDNA**、non-enveloped、**最小 DNA virus**
- 感染 **erythroid progenitor cells**（經 P antigen）
- **臨床**：
    - **Erythema infectiosum**：兒童常見（Fifth disease）、 **slapped cheek rash**、軀幹網狀紅斑
    - **Aplastic crisis**：**慢性溶血性貧血**患者（sickle cell disease、hereditary spherocytosis）→ 暫時性紅血球生成停止 → 急性貧血加重
    - **Hydrops fetalis**：孕婦感染 → 胎兒嚴重貧血 → 非免疫性胎兒水腫
    - **Pure red cell aplasia**：免疫低下者持續感染
    - 關節炎/關節痛

## 十四、RNA 病毒（RNA Viruses）

### 14.1 Orthomyxoviridae（Influenza）

- **(−) ssRNA**、**enveloped**、**segmented（8 段）**
- **表面蛋白**：
    - **Hemagglutinin（HA）**：病毒吸附宿主細胞
    - **Neuraminidase（NA）**：幫助子代病毒釋放
- **抗原變異**：
    - **Antigenic drift**：**點突變** → 小幅變化 → **季節性流行（epidemic）**
    - **Antigenic shift**：**基因重組（reassortment）** → 新亞型（HA/NA 改變）→ **大流行（pandemic）**；只有 **Influenza A** 可發生（動物宿主 reservoir）
- **分型**：
    - **Influenza A**：最重要，感染人類及動物；依 HA/NA 分亞型（如 H1N1, H3N2, H5N1）
    - **Influenza B**：僅感染人類；不分亞型
    - **Influenza C**：輕微上呼吸道感染
- **臨床**：急性高燒、肌痛、頭痛、乾咳 → 通常自限
- **併發症**：
    - **繼發性細菌性肺炎**：最常見嚴重併發症 → **S. aureus**、S. pneumoniae、H. influenzae
    - **Reye syndrome**：兒童使用 **Aspirin** → 肝脂肪變性 + 腦病變
    - Myocarditis
- **診新**：Rapid antigen test、RT-PCR
- **治療/預防**：
    - **Oseltamivir/Zanamivir**：Neuraminidase inhibitors（48 小時內使用）
    - **Baloxavir**：Cap-dependent endonuclease inhibitor（單劑即可）
    - **年度流感疫苗**：inactivated or live attenuated

### 14.2 Paramyxoviridae

| 病毒 | 疾病 | 特色 |
|------|------|------|
| **Parainfluenza** | **Croup（哮吼）**：6 月–3 歲兒童 → **barking cough**（seal-like）、inspiratory stridor、X-ray **steeple sign**；治療：nebulized epinephrine + Dexamethasone | 最常見 croup 致病原 |
| **Respiratory Syncytial Virus (RSV)** | **Bronchiolitis**：<2 歲嬰幼兒最常見下呼吸道感染 → wheezing、tachypnea、retractions；治療：supportive；預防：Palivizumab/Nirsevimab | Syncytia（多核巨細胞） |
| **Measles** | **Measles**：prodrome（**Cough, Coryza, Conjunctivitis**）→ **Koplik spots**（頰黏膜白點） → **maculopapular rash**（向下擴散）；併發症：肺炎（最常見死因）、中耳炎、腦炎、**SSPE**（遲發性致命性腦病變） | Warthin-Finkeldey giant cells、MMR vaccine |
| **Mumps** | **Parotitis**（腮腺腫大）；**Orchitis**（不孕風險）；meningitis / encephalitis；pancreatitis | MMR vaccine |

### 14.3 Rhabdoviridae（Rabies virus）

- **Enveloped、(−) ssRNA**、**bullet-shaped**
- **傳播**：被感染動物咬傷（蝙蝠最重要 reservoir in US；台灣 → 鼬獾）
- **病程**：沿**周邊神經 retrograde transport** → CNS
    - 潛伏期長（weeks to months）
    - **Prodrome**：咬傷部位感覺異常
    - **Encephalitic（furious）form**：hydrophobia（恐水）、aerophobia、agitation、autonomic instability
    - **Paralytic（dumb）form**：ascending paralysis
    - 發病後**幾乎 100% 致死**
- **病理**：**Negri bodies**（intracytoplasmic eosinophilic inclusions in hippocampal / Purkinje neurons）
- **PEP（暴露後預防）**：
    - **傷口清潔**（最重要第一步）
    - 未接種過疫苗者：**HRIG（Human Rabies Immune Globulin）** 注射於傷口周圍 + **Rabies vaccine × 4 doses**（Days 0, 3, 7, 14）
    - 已接種過疫苗者：**Vaccine × 2 doses**（Days 0, 3），不需 HRIG

### 14.4 Picornaviridae

#### Rhinovirus
- **最常見的普通感冒（common cold）致病原**
- **>100 serotypes** → 反覆感染

| **Coxsackie A** | **Hand-foot-mouth disease**（手足口病）：兒童 → 口腔潰瘍 + 手掌足底水泡；**Herpangina**：後咽部水泡/潰瘍 |

### 14.5 Caliciviridae（Norovirus）

- **Non-enveloped、(+) ssRNA**
- **最常見的病毒性腸胃炎**（所有年齡層）
- 極低感染劑量（~10 viral particles）
- 常見於冬季、群聚事件（cruise ships、學校、安養機構）
- 臨床：嘔吐為主 + 水瀉、腹痛（24–72 hr 自限）
- 治療：支持療法（補液）

### 14.6 Reoviridae（Rotavirus）

- **dsRNA（唯一 dsRNA 病毒）**、**non-enveloped**、**segmented（11 段）**
- **嬰幼兒（6 月–2 歲）最常見嚴重脫水性腹瀉**（before vaccine era）
- 冬季好發
- **疫苗**：**Oral live attenuated**（RV1/RV5）→ 嬰兒常規接種
- **注意**：intussusception（腸套疊）之輕微風險

### 14.7 Togaviridae（Rubella virus）

- **Enveloped、(+) ssRNA**
- **臨床**：
    - **Rubella（German measles / 德國麻疹）**：輕度發燒 + **maculopapular rash**（臉→軀幹→四肢，較麻疹輕且短暫）+ **posterior cervical/postauricular lymphadenopathy**（最具特色）+ 關節痛（成年女性常見）
    - **Congenital Rubella Syndrome（CRS）**：孕婦第一孕期感染風險最高
        - **Classic triad**：**Sensorineural deafness（最常見）** + **Cataracts（白內障）** + **Cardiac defects（PDA 最常見、pulmonary artery stenosis）**
        - 其他：blueberry muffin rash、hepatosplenomegaly、thrombocytopenia、microcephaly、intellectual disability
- **疫苗**：**MMR**（live attenuated）→ **孕婦禁用**

### 14.8 Flaviviridae

|------|------|------|

### 14.10 Retroviridae（HIV）

- **Enveloped、(+) ssRNA × 2 copies**
- **Reverse transcriptase（RT）**：RNA → DNA → 整合入宿主基因組（proviral DNA）
- **Structural proteins**：gp120（結合 **CD4** + coreceptor CCR5/CXCR4）、gp41（membrane fusion）、p24（capsid antigen → 急性感染早期偵測）
- **病程**：
    1. **Acute retroviral syndrome**（2–4 weeks post-infection）：mononucleosis-like（fever, rash, lymphadenopathy）；p24↑、viral load↑、CD4 急降後部分恢復
    2. **Clinical latency**：數年；漸進性 CD4 下降
    3. **AIDS**：**CD4 <200** 或出現 **AIDS-defining illness**

#### AIDS-defining illnesses（重要考點）

| CD4 門檻 | 疾病 |
|-----------|------|
| **<500** | Kaposi sarcoma、Lymphoma |
| **<200** | **Pneumocystis jirovecii pneumonia（PJP）**（最常見 AIDS-defining OI）、Toxoplasma encephalitis、Histoplasmosis |
| **<100** | **Cryptococcal meningitis**、**Talaromyces marneffei** |
| **<50** | **CMV retinitis**、**MAC（disseminated）**、CNS lymphoma |

#### 診斷
- **Screening**：HIV-1/2 **Ag/Ab combination assay（4th gen）**
- **Confirmatory**：HIV-1/2 differentiation immunoassay
- **Viral load（RT-PCR）**：追蹤療效
- **CD4 count**：決定 OI prophylaxis、評估免疫狀態

#### 治療（ART, Antiretroviral Therapy）
- **診斷即治療（treat all）**
- **常用組合**：2 NRTIs + 1 INSTI（或 NNRTI 或 boosted PI）

| 藥物類別 | 機制 | 代表藥物 | 副作用 |
|----------|------|----------|--------|
| **NRTIs** | 核苷類似物 → 抑制 RT（chain terminator） | Tenofovir（TDF/TAF）、Emtricitabine（FTC）、Lamivudine（3TC）、Zidovudine（AZT）、Abacavir（ABC） | TDF：**nephrotoxicity、Fanconi syndrome、osteoporosis**；AZT：**bone marrow suppression（macrocytic anemia）**；ABC：hypersensitivity（**HLA-B*5701 screening**）；Didanosine（ddI）：pancreatitis |
| **NNRTIs** | 非核苷類 → 直接結合 RT allosteric site | Efavirenz（EFV）、Nevirapine、Rilpivirine、Doravirine | EFV：**CNS effects（vivid dreams, dizziness）**、teratogenic；Nevirapine：hepatotoxicity、SJS/TEN |
| **Protease Inhibitors（PIs）** | 抑制 viral protease → 未成熟病毒粒子 | Atazanavir（ATV）、Darunavir（DRV）、Lopinavir | **Lipodystrophy**、**hyperlipidemia**、**insulin resistance**、GI side effects；ATV：**indirect hyperbilirubinemia（jaundice）** |
| **INSTIs（Integrase Strand Transfer Inhibitors）** | 抑制 integrase → 阻止 proviral DNA 整合 | **Dolutegravir（DTG）**、Bictegravir（BIC）、Raltegravir、Cabotegravir（long-acting） | 相對安全；weight gain；Dolutegravir → neural tube defect concern（early data，後修正為 low risk） |
| **Entry inhibitors** | Maraviroc：CCR5 antagonist；Enfuvirtide：fusion inhibitor（gp41） | — | — |

#### OI 預防

| CD4 門檻 | 預防 |
|-----------|------|
| **<200** | **TMP-SMX**（PJP + Toxoplasma） |
| **<100** | **TMP-SMX**（Toxoplasma，if seropositive） |
| **<50** | **Azithromycin**（MAC） |

### 14.11 Filoviridae（Ebola & Marburg）

- **Enveloped、(−) ssRNA**、**filamentous（絲狀）**
- **Ebola**：Viral hemorrhagic fever → 高死亡率（up to 90%）；fruit bat reservoir；human-to-human via body fluids
- 治療：支持療法 + monoclonal Ab（Inmazeb）
- 疫苗：rVSV-ZEBOV（Ervebo）

### 14.12 Bunyavirales（Hantavirus）

- **Enveloped、(−) ssRNA、segmented（3 段）**
- 傳播：吸入受感染**鼠類排泄物**之氣霧
- **Hantavirus Pulmonary Syndrome（HPS）**：美洲 → 急速肺水腫 → 呼吸衰竭 → 高死亡率
- **Hemorrhagic Fever with Renal Syndrome（HFRS）**：亞洲/歐洲 → 出血 + 腎衰竭

| 特徵 | **HAV** | **HBV** | **HCV** | **HDV** | **HEV** |

| **Anti-HBc IgG** | 曾經感染（past or current） |

### HBV 治療
- **Tenofovir（TDF/TAF）** 或 **Entecavir**（nucleos(t)ide analogue → 抑制 HBV DNA polymerase/RT）
- **PEG-Interferon α**（有限療程 48 週；e-antigen seroconversion 機會較高）
- **Lamivudine**：抗藥率高，不再首選

### HCV 治療
