# 寄生蟲學

---

## 一、總論

### 1.1 寄生蟲分類

| 大類 | 亞分類 | 代表蟲種 |
|------|--------|----------|
| **原蟲（Protozoa）** | 變形蟲、鞭毛蟲、孢子蟲、纖毛蟲 | Entamoeba、Giardia、Plasmodium、Balantidium |
| **蠕蟲（Helminths）** | 線蟲（Nematoda）、吸蟲（Trematoda）、條蟲（Cestoda） | Ascaris、Clonorchis、Taenia |
| **節肢動物（Arthropoda）** | 昆蟲、蜱蟎 | 蚊、蠅、蝨、疥蟎 |

### 1.2 重要名詞

- **終宿主（Definitive host）**：寄生蟲行**有性生殖**之宿主
- **中間宿主（Intermediate host）**：寄生蟲行**無性生殖或幼蟲發育**之宿主
- **保蟲宿主（Reservoir host）**：維持寄生蟲生命週期之動物宿主
- **媒介（Vector）**：傳播病原之節肢動物
- **感染型（Infective stage）**：能感染人體的蟲體階段

### 1.3 診斷通則

- **糞便檢查**：直接塗片法、濃縮法（浮游法/沉澱法）、Kato-Katz 厚塗片法（定量）
- **血液檢查**：厚薄血片（瘧疾）、Giemsa 染色
- **血清學**：ELISA、IFA、Western blot
- **分子生物學**：PCR
- **影像學**：超音波、CT、MRI（組織寄生蟲）

## 二、原蟲——腸道原蟲

### 2.1 痢疾阿米巴（*Entamoeba histolytica*）

- **形態**：
    - 營養體（trophozoite）：可吞噬紅血球（**erythrophagocytosis**，為致病種鑑別要點）
    - 囊體（cyst）：成熟囊體含 **4 個核**（與 *E. coli* 的 8 核鑑別）
- **傳染**：糞口途徑，經由攝入成熟**囊體**（infective stage）
- **致病機轉**：營養體侵入大腸壁 → **flask-shaped ulcer**（燒瓶狀潰瘍）→ 經血行至肝臟
- **臨床表現**：
    - **阿米巴痢疾**：血便（raspberry jelly stool）、腹痛、裡急後重（tenesmus）
    - **阿米巴肝膿瘍**：右上腹痛、發燒、肝腫大；**膿液呈巧克力色（anchovy paste/chocolate color）**，無臭味；多為**右葉單一膿瘍**
- **診斷**：
    - 糞便：找營養體或囊體；抗原檢測（ELISA）
    - 肝膿瘍：超音波/CT + **血清抗體**（敏感度高）
    - 需與非致病種 *E. dispar* 鑑別（形態幾乎相同，但 *E. dispar* 不吞噬紅血球、不致病）
- **治療**：
    - 侵襲性疾病（痢疾/肝膿瘍）：**Metronidazole**（或 Tinidazole）
    - 腸腔內囊體清除：接續使用 **Paromomycin** 或 **Diloxanide furoate**（luminal agent）
    - 無症狀帶囊者亦需治療（以 luminal agent）

### 2.2 梨形鞭毛蟲（*Giardia lamblia / G. intestinalis / G. duodenalis*）

- **形態**：
    - 營養體：**梨形，具雙核（owl-face/monkey face）**、4 對鞭毛、腹吸盤
    - 囊體：橢圓形，成熟含 **4 核**
- **傳染**：糞口途徑（飲水污染最重要）；感染型為**囊體**
- **致病**：寄生於**十二指腸及上段空腸**，以腹吸盤吸附黏膜 → 吸收不良（malabsorption）
- **臨床表現**：
    - 水樣腹瀉（非血便）、脂肪便（steatorrhea）、腹脹、噁心
    - **不侵入組織、不進入血流**
    - 好發：旅遊者（背包客）、daycare 中心兒童、**IgA 缺乏者**、CVID 患者
- **診斷**：糞便找囊體或營養體；**糞便抗原檢測**（ELISA）；「string test」（Entero-test）
- **治療**：**Metronidazole**（首選）或 Tinidazole、Nitazoxanide

### 2.3 隱孢子蟲（*Cryptosporidium parvum / C. hominis*）

- **傳染**：糞口途徑；感染型為含 sporozoite 之**卵囊（oocyst）**；耐氯消毒
- **寄生部位**：小腸上皮細胞刷狀緣（**intracellular but extracytoplasmic**）
- **臨床表現**：
    - 免疫正常者：自限性水樣腹瀉（1–2 週）
    - **AIDS（CD4 <100）**：嚴重慢性水樣腹瀉、脫水、營養不良、可侵犯膽道
- **診斷**：糞便 **modified acid-fast stain**（卵囊呈紅色）；抗原檢測；PCR
- **治療**：
    - 免疫正常：多數自癒；Nitazoxanide 可加速恢復
    - AIDS：**HAART（抗反轉錄病毒治療）恢復免疫**最重要；Nitazoxanide 效果有限

### 2.4 環孢子蟲（*Cyclospora cayetanensis*）

- **傳染**：糞口途徑，經污染蔬果/水源；卵囊排出時**未芽孢化（non-sporulated）**，需在環境中成熟才有感染力
- **臨床**：持續性水樣腹瀉、疲倦，可持續數週；AIDS 患者更嚴重
- **診斷**：糞便 **modified acid-fast stain**（卵囊較 Cryptosporidium 大，約 8–10 μm vs 4–5 μm）；卵囊在 UV 下呈**藍色自體螢光**
- **治療**：**TMP-SMX**（首選）

### 2.5 大腸乃鞭毛蟲（*Balantidium coli*）

- **唯一致病的人體纖毛蟲**，也是**人體感染最大的原蟲**
- **保蟲宿主**：**豬**
- **傳染**：糞口途徑（與豬接觸相關）
- **臨床**：大腸潰瘍、痢疾（類似阿米巴痢疾）
- **治療**：**Tetracycline** 或 Metronidazole

### 2.6 其他腸道原蟲鑑別

| 蟲種 | 致病性 | 備註 |
|------|--------|------|
| *Entamoeba dispar* | 非致病 | 與 *E. histolytica* 形態相同 |
| *Entamoeba coli* | 非致病 | 囊體 **8 核**（鑑別重點） |
| *Endolimax nana* | 非致病 | 囊體 4 核 |
| *Iodamoeba bütschlii* | 非致病 | 囊體有大型碘染肝醣體（glycogen mass） |
| *Blastocystis hominis* | 爭議 | 可能引起腹瀉，免疫不全者較有症狀 |

## 三、原蟲——泌尿生殖道原蟲

### 3.1 陰道滴蟲（*Trichomonas vaginalis*）

- **形態**：梨形營養體、4 條前鞭毛 + 1 條波動膜邊緣鞭毛、**無囊體期**
- **傳染**：**性行為傳染**（STI）
- **臨床表現**：
    - 女性：**黃綠色泡沫狀惡臭白帶（frothy discharge）**、外陰搔癢、陰道 pH >4.5、**草莓狀子宮頸（strawberry cervix）**
    - 男性：多數無症狀，偶有尿道炎
- **診斷**：陰道分泌物**濕片鏡檢**（見活動營養體）、NAAT（更敏感）
- **治療**：**Metronidazole**（口服，單劑 2g 或 7 天療程）；**性伴侶需同時治療**

## 四、原蟲——血液及組織原蟲

### 4.1 瘧原蟲（*Plasmodium* spp.）

#### 4.1.1 蟲種比較

| 特徵 | *P. falciparum* | *P. vivax* | *P. ovale* | *P. malariae* |
|------|-----------------|------------|------------|---------------|
| **嚴重度** | **最嚴重/致命** | 中等 | 輕 | 輕 |
| **發作週期** | 48 hr（惡性三日瘧）但常不規則 | **48 hr（間日瘧）** | 48 hr | **72 hr（四日瘧）** |
| **侵犯紅血球** | **所有年齡紅血球** → 高寄生蟲血症 | **網狀紅血球（reticulocyte）** | 網狀紅血球 | **老紅血球** |
| **休眠體** | 無 | **有 hypnozoite**（肝臟） | **有 hypnozoite** | 無 |
| **血片特徵** | 環形體（ring form）為主、**banana-shaped gametocyte**、多重感染的 RBC、Maurer's dot；紅血球不脹大 | RBC 脹大、Schüffner's dots | RBC 脹大呈橢圓（fimbriated）、Schüffner's dots | Band form trophozoite；RBC 不脹大 |
| **嚴重併發症** | **腦瘧疾、嚴重貧血、ARDS、低血糖、腎衰竭、DIC** | 脾腫大破裂 | 少 | **腎病症候群** |

#### 4.1.2 生活史

- **蚊（Anopheles 瘧蚊）**為終宿主（有性生殖）；**人為中間宿主**（無性生殖）
- 感染型：蚊唾液腺中的 **sporozoite**
- 蚊叮咬 → sporozoite → **肝細胞**（exoerythrocytic schizogony）→ merozoite → **紅血球**（erythrocytic schizogony）→ ring → trophozoite → schizont → 破裂 → 發燒（與 RBC 破裂同步）
- *P. vivax* / *P. ovale* 在肝臟可形成 **hypnozoite** → 數月至數年後復發（relapse）
- *P. malariae* 無 hypnozoite，但紅血球期可低度持續存在多年 → **recrudescence**

#### 4.1.3 診斷

- **厚薄血片 Giemsa 染色**（gold standard）：厚片偵測、薄片鑑種
- **快速診斷試劑（RDT）**：偵測 HRP-2（*P. falciparum*）或 pLDH/aldolase
- PCR：敏感度最高但非常規

#### 4.1.4 治療

| 情境 | 治療 |
|------|------|
| **非嚴重 *P. falciparum***（氯奎寧敏感區） | Chloroquine |
| **非嚴重 *P. falciparum***（抗藥區/多數地區） | **ACT（Artemisinin-based Combination Therapy）**：Artemether-Lumefantrine 或 Artesunate-Mefloquine |
| **嚴重瘧疾（腦瘧疾等）** | **IV Artesunate**（首選）→ 穩定後接 ACT 口服 |
| ***P. vivax / P. ovale*** | **Chloroquine** + **Primaquine（14 天）**（殺 hypnozoite，防 relapse） |
| ***P. malariae*** | Chloroquine |

- **Primaquine 注意事項**：可引起 **G6PD 缺乏者溶血** → 使用前需檢驗 G6PD
- **預防**：依旅遊地區選擇 Atovaquone-Proguanil / Doxycycline / Mefloquine

#### 4.1.5 先天抗瘧疾因素

- **鐮刀型紅血球特質（Sickle cell trait, HbAS）**：對 *P. falciparum* 有保護力
- **Duffy antigen 陰性**：對 *P. vivax* 有保護力（非洲人群，*P. vivax* 需 Duffy antigen 進入 RBC）
- **G6PD deficiency**、**Thalassemia**：部分保護力

### 4.2 弓形蟲（*Toxoplasma gondii*）

- **終宿主**：**貓科動物**（在貓腸道行有性生殖，排出 oocyst）
- **中間宿主**：人、其他哺乳動物、鳥類
- **傳染途徑**：
    1. 食入含**組織囊體（tissue cyst）**的生肉/未熟肉（尤其豬肉、羊肉）
    2. 食入被貓糞污染之 **oocyst**
    3. **經胎盤垂直感染**（先天性弓形蟲症）
    4. 器官移植/輸血（罕見）
- **臨床表現**：
    - **免疫正常者**：80–90% 無症狀或輕微淋巴腺腫大（尤其頸部）；自限性
    - **AIDS（CD4 <100）**：**腦弓形蟲症**（最常見 AIDS 的腦部佔位性病變）→ 多發性 **ring-enhancing lesions**（CT/MRI）→ 頭痛、意識改變、局部神經缺損、癲癇
    - **先天性弓形蟲症**：母親初次感染（尤其妊娠第三期感染率最高，但第一期感染嚴重度最高）→ 經典三聯征：**腦積水（hydrocephalus）+ 腦內鈣化（intracranial calcification，散在分布）+ 脈絡膜視網膜炎（chorioretinitis）**
    - **眼弓形蟲症**：脈絡膜視網膜炎（免疫正常者也可發生）
- **診斷**：
    - 血清學：IgG/IgM 抗體（篩檢；IgM 陽性提示急性或近期感染）
    - AIDS 腦病變：臨床 + 影像 + **經驗性治療後反應**（2 週內改善）；必要時腦部切片
    - PCR（羊水 → 先天性感染）
- **治療**：
    - AIDS 腦弓形蟲症：**Pyrimethamine + Sulfadiazine + Leucovorin（folinic acid）**
    - AIDS 預防（CD4 <100 + Toxoplasma IgG+）：**TMP-SMX**
    - 先天性：Pyrimethamine + Sulfadiazine + Leucovorin
    - 免疫正常者通常不需治療（自限）

### 4.3 利什曼原蟲（*Leishmania* spp.）

- **媒介**：**沙蠅（sandfly, *Phlebotomus* / *Lutzomyia*）**
- **形態**：沙蠅體內為 promastigote（前鞭毛體）；人體巨噬細胞內為 **amastigote（無鞭毛體）**
- **臨床分型**：

| 分型 | 蟲種 | 表現 |
|------|------|------|
| **內臟型（Visceral, Kala-azar）** | *L. donovani* | 發燒、**巨大肝脾腫大**、全血球減少（pancytopenia）、低白蛋白血症、高球蛋白血症（polyclonal hypergammaglobulinemia）、皮膚黑化（kala-azar = 黑熱病） |
| **皮膚型（Cutaneous）** | *L. tropica* / *L. major* / *L. mexicana* | 皮膚無痛性潰瘍（ulcer with raised border），可自癒 |
| **黏膜皮膚型（Mucocutaneous）** | *L. braziliensis* | 鼻中膈/口咽黏膜破壞（espundia），嚴重可毀損面容 |

- **診斷**：組織切片或骨髓/脾臟抹片見**巨噬細胞內 amastigote（Leishman-Donovan body）**；PCR；rK39 抗原快篩（內臟型）
- **治療**：
    - 內臟型：**Amphotericin B（liposomal）**（首選）或 Miltefosine
    - 皮膚型：局部治療或 Sodium stibogluconate（五價銻化合物）

### 4.4 錐蟲（*Trypanosoma* spp.）

#### 4.4.1 非洲錐蟲病（African Trypanosomiasis, 睡眠病）

| 特徵 | *T. brucei gambiense*（西非型） | *T. brucei rhodesiense*（東非型） |
|------|---|----|
| 病程 | **慢性**（數月至數年） | **急性**（數週至數月） |
| 媒介 | **乙蠅（Tsetse fly, *Glossina*）** | 同左 |

- **臨床**：叮咬處硬性下疳（chancre）→ **血液淋巴期**（發燒、淋巴結腫大【Winterbottom's sign：後頸淋巴結腫大】）→ **CNS 期**（嗜睡、人格改變、白天嗜睡/夜間失眠 → 昏迷死亡）
- **診斷**：血液厚薄片見錐鞭毛體（trypomastigote）；腦脊髓液檢查（判斷是否進入 CNS 期）
- **免疫逃避**：**抗原變異（antigenic variation）** → 不斷更換 VSG（variable surface glycoprotein）→ 無法產生有效免疫

#### 4.4.2 美洲錐蟲病（American Trypanosomiasis, Chagas disease）

- **蟲種**：*T. cruzi*
- **媒介**：**錐鼻蟲（Reduviid bug / Kissing bug / Triatomine bug）**；蟲糞中含感染型（metacyclic trypomastigote），經叮咬傷口或黏膜進入人體
- **臨床**：
    - **急性期**：叮咬處皮膚腫脹（**Romaña's sign**：眼周單側無痛性水腫）或 chagoma；發燒、淋巴結腫大、肝脾腫大
    - **慢性期**（多年後）：**心肌病變（Chagas cardiomyopathy）** → 擴大型心肌病、心律不整（RBBB 最常見）、心衰竭；**巨食道症（megaesophagus）**、**巨結腸症（megacolon）** → 自主神經叢被破壞
- **診斷**：急性期血片見 trypomastigote；慢性期靠**血清學**（ELISA、IFA）
- **治療**：**Benznidazole** 或 Nifurtimox（急性期及早期慢性期效果較好）

### 4.5 自由乃阿米巴（Free-living Amoeba）

| 蟲種 | 疾病 | 特色 |
|------|------|------|
| ***Naegleria fowleri*** | **原發性阿米巴腦膜腦炎（PAM）** | 經**鼻腔**進入（游泳/跳水於溫暖淡水）→ 沿嗅神經→腦 → **急性**猛爆性腦膜腦炎，致死率 >95%；CSF 見營養體；治療：Amphotericin B |
| ***Acanthamoeba* spp.** | **肉芽腫性阿米巴腦炎（GAE）**、**角膜炎** | GAE：慢性、免疫不全者；**角膜炎**：與**隱形眼鏡使用**高度相關，劇痛、ring-shaped corneal infiltrate |
| ***Balamuthia mandrillaris*** | **肉芽腫性阿米巴腦炎（GAE）** | 慢性，免疫正常或不全者皆可 |

### 4.6 肺囊蟲（*Pneumocystis jirovecii*）

- 分類上歸屬**真菌**（但傳統於寄生蟲學討論）
- **臨床意義**：**AIDS（CD4 <200）最重要的伺機性感染**
- **臨床表現**：進行性呼吸困難、乾咳、發燒；**無痰或很少痰**
- **影像**：CXR → **bilateral diffuse interstitial/ground-glass infiltrates**；**不會產生肋膜積液或空洞（除非上葉，見於使用 aerosolized pentamidine 預防者）**
- **診斷**：誘導痰或 BAL 液 → **GMS（Gomori methenamine silver）染色**或 **DFA**（直接螢光抗體）；血清 **β-D-glucan↑**（敏感但非專一）；**LDH↑**（與嚴重度相關）
- **治療**：
    - 首選：**TMP-SMX**（高劑量，21 天）
    - 中重度（PaO₂ <70 mmHg 或 A-a gradient >35）：加 **adjunctive corticosteroid**
    - 替代：Pentamidine、Atovaquone、Dapsone + TMP
- **預防**（CD4 <200 或有口腔念珠菌感染）：**TMP-SMX**（首選預防藥）

## 五、線蟲（Nematoda）——腸道線蟲

### 5.1 蛔蟲（*Ascaris lumbricoides*）

- **最大的腸道線蟲**；全球感染人數最多的蠕蟲
- **傳染**：糞口途徑；感染型為**含幼蟲之胚胎化蟲卵（embryonated egg）**
- **生活史**：口入卵 → 小腸孵化 → 幼蟲穿腸壁入血 → **肝 → 心 → 肺**（穿破肺泡）→ 氣管 → 咽 → 吞入小腸 → 成蟲（**體內移行：Lung migration pathway**）
- **臨床表現**：
    - **肺期**：**Löffler syndrome** → 暫時性肺浸潤 + **嗜酸性球增多** + 咳嗽、喘鳴
    - **腸期**：多數無症狀；大量感染 → 營養不良、腹痛
    - **併發症**：**膽道蛔蟲症**（蟲體鑽入膽管 → 膽道阻塞、膽管炎、胰臟炎）、**腸阻塞**（大量蟲體糾結）
- **診斷**：糞便找蟲卵（受精卵為橢圓形，外殼有蛋白質粗糙外層 mammillated coat）
- **治療**：**Albendazole**（單劑 400mg）或 Mebendazole；膽道阻塞/腸阻塞可能需內視鏡或手術

### 5.2 鉤蟲（*Ancylostoma duodenale* / *Necator americanus*）

| 特徵 | *Ancylostoma duodenale*（十二指腸鉤蟲） | *Necator americanus*（美洲鉤蟲） |
|------|-----|-----|
| 口器 | **齒（teeth）** | **切板（cutting plates）** |
| 感染途徑 | 經皮（主要）+ 經口 | **經皮**（絲狀幼蟲穿皮膚） |

- **生活史**：土壤中蟲卵 → 桿狀幼蟲（rhabditiform）→ **絲狀幼蟲（filariform, L3）**（infective stage）→ **穿足底皮膚** → 血行 → 肺 → 氣管 → 吞入小腸 → 成蟲以口器吸附腸壁吸血
- **臨床表現**：
    - 皮膚期：**ground itch**（穿皮處搔癢紅疹）
    - 肺期：輕微 Löffler syndrome（較蛔蟲輕）
    - 腸期：**缺鐵性貧血（IDA）**（最重要臨床問題，因慢性失血）、嗜酸性球增多、蛋白流失腸病變
- **診斷**：糞便找蟲卵（薄殼、內含分裂球 morula）
- **治療**：**Albendazole** 或 Mebendazole + **補鐵**

### 5.3 蟯蟲（*Enterobius vermicularis*）

- **最常見於溫帶/已開發國家兒童的腸道線蟲**
- **傳染**：糞口途徑；感染型為**含幼蟲之蟲卵**；**肛門-手-口自體感染（autoinfection）**常見
- **生活史**：成蟲寄生於盲腸/闌尾區；**雌蟲夜間爬至肛門周圍產卵** → 搔癢
- **臨床表現**：**肛門周圍搔癢（perianal pruritus）**（尤其夜間）、失眠、躁動
    - 女童：蟲體可能爬入陰道 → 外陰陰道炎
    - 偶引起闌尾炎
- **診斷**：**透明膠帶法（Scotch tape / cellophane tape test）**（晨起如廁前，黏取肛周蟲卵），**非糞便檢查**（蟲卵不在糞便中）
- **治療**：**Mebendazole** 或 Albendazole 或 Pyrantel pamoate；**2 週後重複一次**（殺成蟲不殺卵）；**全家同時治療**

### 5.4 鞭蟲（*Trichuris trichiura*）

- **形態**：前端細長如鞭柄，插入大腸黏膜；蟲卵呈**檸檬形/橄欖球形（barrel-shaped/lemon-shaped）**，兩端有透明栓（bipolar plugs）
- **傳染**：糞口途徑；感染型為含幼蟲之蟲卵
- **寄生部位**：**盲腸/大腸**
- **臨床表現**：輕度感染多無症狀；重度感染 → 血性腹瀉、腹痛、**直腸脫垂（rectal prolapse）**（兒童）、缺鐵性貧血
- **診斷**：糞便找蟲卵（barrel-shaped with bipolar plugs）
- **治療**：**Albendazole**（3 天療程，較單劑效果好）或 Mebendazole

### 5.5 糞小桿線蟲（*Strongyloides stercoralis*）

- **重要特性**：可行**體內自體感染（autoinfection）** → 免疫不全者可致 **hyperinfection syndrome**
- **傳染**：絲狀幼蟲（filariform, L3）**經皮穿入**（類似鉤蟲）
- **生活史**：穿皮 → 肺 → 氣管 → 小腸 → 成蟲（雌蟲可孤雌生殖 parthenogenesis）→ 幼蟲可在腸道或肛周即轉變為感染型 → **autoinfection**（不需離開人體即可再感染 → 感染可持續數十年）
- **臨床表現**：
    - 皮膚：**larva currens**（快速移行的蕁麻疹樣線狀疹，速度比鉤蟲皮膚幼蟲移行症快）
    - 肺：Löffler syndrome
    - 腸：腹痛、腹瀉、吸收不良
    - **Hyperinfection syndrome**：**免疫抑制（尤其使用 corticosteroid、HTLV-1 感染）**→ 大量幼蟲全身散布 → 嚴重肺炎、腸道大量出血、敗血症（幼蟲攜帶腸內細菌進入血液 → **革蘭氏陰性菌菌血症/腦膜炎**）→ 高死亡率
- **診斷**：糞便找**桿狀幼蟲（rhabditiform larva）**（非蟲卵！與鉤蟲不同：鉤蟲糞便見蟲卵，Strongyloides 糞便見幼蟲）；血清學（ELISA）；嗜酸性球增多（hyperinfection 時反而可能正常或下降）
- **治療**：**Ivermectin**（首選）；替代：Albendazole
- **重要**：使用 corticosteroid 或免疫抑制劑前，**流行區來的病人需先篩檢並治療 Strongyloides**

### 5.6 旋毛蟲（*Trichinella spiralis*）

- **傳染**：食入含**包囊幼蟲（encysted larvae）**的生肉/未熟肉（**豬肉**最常見）
- **生活史**：幼蟲在小腸脫囊 → 發育為成蟲 → 交配後雌蟲產出幼蟲 → 經血流/淋巴擴散至**橫紋肌**形成包囊（nurse cell）
- **臨床表現**：
    - 腸期：噁心、嘔吐、腹瀉
    - **肌肉期**：肌肉痛、水腫（尤其**眼周水腫 periorbital edema**）、發燒
    - 嚴重：心肌炎、腦炎
    - **嗜酸性球顯著增多**
- **診斷**：臨床（生肉食用史 + 肌肉痛 + 眼周水腫 + 嗜酸性球增多）；血清學；**肌肉切片見包囊幼蟲**
- **治療**：**Albendazole** 或 Mebendazole + **Corticosteroid**（嚴重症狀時抑制發炎）

## 六、線蟲——組織/血液線蟲

### 6.1 絲蟲（Filariasis）

| 特徵 | *Wuchereria bancrofti*（班氏絲蟲） | *Brugia malayi*（馬來絲蟲） |
|------|-----|-----|
| 分布 | 熱帶/亞熱帶（全球最多） | 東南亞 |
| 媒介 | **蚊（Culex、Aedes、Anopheles）** | 蚊（Mansonia） |
| 寄生部位 | 淋巴系統 | 淋巴系統 |

- **生活史**：蚊叮咬注入 L3 幼蟲 → 淋巴管發育為成蟲 → 產出 **microfilaria（微絲蚴）**至血液 → 蚊吸血攝入
- **夜間週期性（nocturnal periodicity）**：微絲蚴於**夜間**出現在週邊血液（配合蚊叮咬時間）→ 採血須在**夜間（22:00–02:00）**
- **臨床表現**：
    - 急性：反覆淋巴管炎/淋巴腺炎、發燒
    - 慢性：**淋巴水腫（lymphedema）→ 象皮病（elephantiasis）**（下肢、陰囊水腫）
    - **乳糜尿（chyluria）**：淋巴液流入泌尿道
    - **Tropical Pulmonary Eosinophilia（TPE）**：肺部微絲蚴引起過敏反應 → 夜間咳嗽、喘鳴、嗜酸性球極高、IgE↑
- **診斷**：**夜間週邊血液厚片**見微絲蚴（Giemsa 染色）；抗原檢測（ICT card, *W. bancrofti*）；超音波見淋巴管內成蟲活動（filaria dance sign）
- **治療**：**DEC（Diethylcarbamazine）**；合併 Albendazole（mass drug administration, MDA）
- ***Onchocerca volvulus***（蟠尾絲蟲，河盲症）：
    - 媒介：**黑蠅（Simulium, black fly）**
    - 成蟲在皮下結節（onchocercoma）；微絲蚴在皮膚及眼睛
    - **臨床**：**失明（river blindness）**（微絲蚴死亡引發角膜/視網膜發炎）、嚴重搔癢性皮膚炎
    - 診斷：**皮膚切片（skin snip）**見微絲蚴（非血液！）
    - 治療：**Ivermectin**（殺微絲蚴）；**禁用 DEC**（可引起嚴重 Mazzotti reaction → 低血壓、休克）
- ***Loa loa*（羅阿絲蟲，眼絲蟲）**：
    - 媒介：**鹿蠅（Chrysops, deer fly/mango fly）**
    - 成蟲可在結膜下移行（眼睛可見蟲體橫過）
    - **Calabar swelling**：遊走性皮下腫脹
    - 白天週期性（diurnal periodicity）
    - 治療：**DEC**

### 6.2 犬蛔蟲/貓蛔蟲（*Toxocara canis / T. cati*）

- 人為**非正常宿主（paratenic host）**，幼蟲無法發育為成蟲
- **傳染**：食入土壤中含幼蟲之犬/貓蛔蟲蟲卵（兒童玩泥土/沙坑）
- **臨床**：
    - **內臟幼蟲移行症（Visceral Larva Migrans, VLM）**：幼兒，發燒、肝腫大、嗜酸性球極高、肺浸潤
    - **眼幼蟲移行症（Ocular Larva Migrans, OLM）**：較大兒童，單側視力下降、白瞳（leukocoria），需與 retinoblastoma 鑑別
- **診斷**：血清學（ELISA）；糞便檢查陰性（人體內無成蟲，不排卵）
- **治療**：Albendazole + Corticosteroid（抗發炎）

### 6.3 廣東住血線蟲（*Angiostrongylus cantonensis*）

- **台灣重要寄生蟲**
- **終宿主**：鼠
- **中間宿主**：蝸牛、蛞蝓（slug）
- **人為意外宿主**
- **傳染**：食入生的或未煮熟的蝸牛/蛞蝓（如非洲大蝸牛）；或被其黏液污染之生菜
- **臨床表現**：**嗜酸性球性腦膜炎（eosinophilic meningitis）**最重要的病因
    - 頭痛、頸部僵硬、感覺異常（paresthesia）
    - CSF：**嗜酸性球增多**、蛋白質升高、糖正常或略低
- **診斷**：臨床（食用蝸牛史 + 嗜酸性球性腦膜炎）；血清學；CSF 偶見幼蟲
- **治療**：**支持療法為主**（止痛、反覆腰椎穿刺降壓）；Corticosteroid 減輕發炎；驅蟲藥效果有爭議（幼蟲死亡可加重發炎）

### 6.4 美洲鉤蟲幼蟲（犬鉤蟲 *Ancylostoma braziliense*）

- **皮膚幼蟲移行症（Cutaneous Larva Migrans, CLM）**
- 人為非正常宿主，幼蟲只能在皮膚表層移行，無法穿透基底膜
- **傳染**：赤腳行走於被犬/貓糞便污染的沙灘
- **臨床**：足底/臀部出現**蛇行狀紅色搔癢性皮疹（creeping eruption/serpiginous track）**
- **治療**：**Ivermectin**（口服）或 Albendazole

## 七、吸蟲（Trematoda）

### 7.1 通則

- 除血吸蟲外，吸蟲皆為**雌雄同體（hermaphroditic）**
- **血吸蟲（Schistosoma）為雌雄異體**
- 多數吸蟲之第一中間宿主為**螺（snail）**
- 感染型多為 **metacercaria（囊狀幼蟲）**（食入含 metacercaria 之中間宿主/水生植物）；血吸蟲例外：感染型為 **cercaria（尾蚴）**，直接穿皮

### 7.2 血吸蟲（*Schistosoma* spp.）

| 蟲種 | 分布 | 寄生靜脈叢 | 蟲卵特徵 | 主要病變 |
|------|------|-----------|----------|----------|
| ***S. mansoni*** | 非洲、南美 | 下腸繫膜靜脈（大腸） | **側棘（lateral spine）** | **肝纖維化（pipe-stem fibrosis）**、門脈高壓 |
| ***S. japonicum*** | 東亞（中國、菲律賓） | 上下腸繫膜靜脈 | **側面小棘或無棘（small lateral spine/knob）**、蟲卵最小 | 肝纖維化最嚴重、**與大腸癌相關** |
| ***S. haematobium*** | 非洲、中東 | **膀胱靜脈叢** | **末端棘（terminal spine）** | **血尿**、膀胱壁鈣化、**膀胱鱗狀細胞癌（SCC）** |

- **生活史**：人為終宿主；**螺為中間宿主**
    - 蟲卵入水 → 孵化為 miracidium → 進入螺 → 發育為 cercaria → **cercaria（尾蚴）穿皮感染人體** → schistosomula → 經血行至肝（發育為成蟲）→ 配對後移行至靜脈叢產卵
    - 蟲卵沉積於組織引起**肉芽腫反應（granuloma）**→ 纖維化
- **臨床表現**：
    - **尾蚴皮膚炎（cercarial dermatitis / swimmer's itch）**：接觸水後搔癢性皮疹
    - **急性血吸蟲症（Katayama fever）**：初次感染 4–8 週後，發燒、蕁麻疹、嗜酸性球↑、肝脾腫大；免疫複合體反應
    - **慢性**：蟲卵肉芽腫 → 門脈高壓、肝脾腫大（肝硬化但肝功能常保留較久）
    - *S. haematobium*：**終末血尿（terminal hematuria）**、膀胱壁鈣化 → **膀胱 SCC**
- **診斷**：糞便或尿液找蟲卵（依蟲種不同蟲卵特徵）；血清學；嗜酸性球增多
    - *S. haematobium* → 尿液（尤其正午排尿）找蟲卵
- **治療**：**Praziquantel**（所有血吸蟲的首選）
- **Oxamniquine**：僅對 *S. mansoni* 有效（替代藥）

### 7.3 中華肝吸蟲（*Clonorchis sinensis*）

- **台灣重要寄生蟲**
- **傳染**：食入含 **metacercaria** 之**淡水魚生魚片（raw freshwater fish）**
- **中間宿主**：第一中間宿主 = 螺；第二中間宿主 = **淡水魚**
- **寄生部位**：**膽管（bile duct）**
- **臨床表現**：
    - 輕度：多無症狀
    - 慢性重度感染：**膽管炎**、膽管阻塞、膽結石、肝腫大、嗜酸性球增多
    - **最嚴重併發症**：**膽管癌（cholangiocarcinoma）** → IARC 歸類為第一類致癌物
- **蟲卵特徵**：小型、燈泡形/壺形，有**蓋（operculum）** + 底端有小突起（knob）
- **診斷**：糞便找蟲卵
- **治療**：**Praziquantel**

### 7.4 肝片吸蟲（*Fasciola hepatica*）

- 傳染：食入含 metacercaria 之**水生植物**（如水芹菜 watercress）
- 中間宿主：螺
- 寄生部位：肝臟 → 膽管
- 臨床：幼蟲穿肝實質期 → 右上腹痛、發燒、嗜酸性球增多；成蟲期 → 膽管阻塞、膽管炎
- 蟲卵：大型、有蓋
- 治療：**Triclabendazole**（首選）；Praziquantel 對肝片吸蟲效果不佳

### 7.5 肺吸蟲（*Paragonimus westermani*）

- **傳染**：食入含 metacercaria 之**生淡水蟹或蝲蛄（crayfish）**
- 中間宿主：第一 = 螺；第二 = **淡水蟹/蝲蛄**
- 寄生部位：**肺臟**
- **臨床表現**：
    - 慢性咳嗽、**鐵鏽色/血痰（rusty/bloody sputum）**
    - 可誤診為**肺結核**（慢性咳嗽+咳血+影像可見空洞/結節/肋膜積液）
    - 異位寄生：腦（癲癇、腦內鈣化）、腹部、皮下
- **影像**：胸部 X-ray 可見結節、空洞、肋膜積液
- **診斷**：**痰液或糞便**找蟲卵（蟲卵大型、有蓋、金棕色）；血清學
- **治療**：**Praziquantel**

### 7.6 薑片蟲（*Fasciolopsis buski*）

- **最大的人體吸蟲**
- 傳染：食入含 metacercaria 之**水生植物**（菱角、荸薺、蓮藕等）→ 用牙齒剝皮時感染
- 寄生部位：小腸
- 臨床：腹痛、腹瀉、腸壁潰瘍、吸收不良；重度 → 腸阻塞、水腫（低蛋白血症）
- 蟲卵：最大的吸蟲蟲卵，有蓋
- 治療：**Praziquantel**

## 八、條蟲（Cestoda）

### 8.1 通則

- **頭節（scolex）+ 頸部 + 節片（proglottid）**
- **無消化道**，經體表吸收營養
- 雌雄同體
- 人吃到**幼蟲（larvae）**→ 成為腸道條蟲（人為終宿主）
- 人吃到**蟲卵** → 幼蟲在人體組織發育（人為中間宿主）→ 組織病變（如囊蟲症）

### 8.2 豬肉條蟲（*Taenia solium*）

- **雙重角色**：
    - 人吃**含囊尾幼蟲（cysticercus）的生豬肉** → 小腸成蟲（腸道條蟲病 taeniasis）
    - 人吃到**蟲卵**（糞口、自體感染 autoinfection）→ **囊蟲症（Cysticercosis）**
- **頭節**：4 個吸盤 + **頂突（rostellum）有雙排鉤**（armed scolex）
- **囊蟲症（Cysticercosis）**：
    - 幼蟲可寄生於**腦（Neurocysticercosis, NCC）**、肌肉、眼睛、皮下
    - **NCC 是全球可預防癲癇最重要的原因**
    - 臨床：**癲癇（seizures）** → 最常見表現；頭痛、腦積水（obstructive hydrocephalus）
    - 影像：CT/MRI → **囊狀病灶內含 scolex（"dot in hole" sign）**；鈣化；水腫
    - 診斷：影像 + 血清學（EITB, ELISA）
    - 治療：**Albendazole**（首選）± Praziquantel + **Corticosteroid（Dexamethasone）**（減少幼蟲死亡引起的水腫及發炎）+ **抗癲癇藥**；單顆鈣化病灶可能僅需抗癲癇藥
    - 眼內囊蟲不可直接驅蟲（蟲死亡引發嚴重眼內發炎 → 先手術）

### 8.3 牛肉條蟲（*Taenia saginata*）

- 人吃含囊尾幼蟲之**生牛肉** → 小腸成蟲
- **頭節**：4 個吸盤，**無頂突無鉤（unarmed scolex）**
- **不會引起囊蟲症**（人吃到 *T. saginata* 蟲卵不發育為囊尾幼蟲）
- 臨床：多無症狀，偶腹部不適；病人可能注意到**節片自肛門排出**（孕節片會主動蠕動爬出）
- 診斷：糞便找蟲卵（*T. solium* 和 *T. saginata* 蟲卵形態相同，無法鑑別）→ 鑑別靠**孕節片（gravid proglottid）子宮分支數**：*T. saginata* **15–30 分支**；*T. solium* **7–13 分支**
- 治療：**Praziquantel**（單劑）或 Niclosamide

### 8.4 短小條蟲（*Hymenolepis nana*）

- **最小的人體條蟲**
- **唯一不需中間宿主**即可完成生活史之條蟲（蟲卵直接感染人 → **直接發育型**）
- **可行體內自體感染（internal autoinfection）**
- 好發兒童、機構群居
- 治療：**Praziquantel**

### 8.5 裂頭絛蟲（*Diphyllobothrium latum*，闊節裂頭條蟲）

- **最長的人體條蟲**（可達 10 公尺以上）
- 傳染：食入含 **plerocercoid 幼蟲**之**生淡水魚**
- 中間宿主：第一 = 劍水蚤（Cyclops）；第二 = 淡水魚
- **頭節**：具 2 條吸溝（bothria），無吸盤無鉤
- **臨床**：多無症狀；特色為 **巨芽球性貧血（megaloblastic anemia）** → 蟲體大量吸收 **維生素 B12** → B12 缺乏
- **蟲卵**：有蓋（operculated），類似吸蟲蟲卵
- **治療**：**Praziquantel** + 補充 B12

### 8.6 犬條蟲 / 包蟲（*Echinococcus granulosus / E. multilocularis*）

| 特徵 | *E. granulosus*（囊型包蟲） | *E. multilocularis*（泡型包蟲） |
|------|-----|-----|
| 終宿主 | 犬 | 狐狸 |
| 中間宿主 | 羊 | 鼠類 |
| 人的角色 | **意外中間宿主** | 同左 |
| 感染方式 | 食入犬糞中蟲卵 | 食入狐糞中蟲卵 |
| 病灶型態 | **肝臟囊狀病灶（hydatid cyst）**，有明確界線 | **浸潤性、多泡狀**，類似惡性腫瘤 |
| 好發器官 | **肝（最常見）> 肺** | 肝 |

- ***E. granulosus*（最常考）**：
    - **囊腫（Hydatid cyst）結構**：外囊（宿主纖維組織）→ 板層膜（laminated layer）→ 生發層（germinal layer）→ 原頭蚴（protoscolex，"hydatid sand"）+ 子囊（daughter cyst）
    - **臨床**：肝臟巨大囊腫 → 上腹腫塊、壓迫症狀；肺囊腫 → 咳嗽
    - **破裂風險**：囊腫破裂 → 內容物漏出 → **嚴重過敏反應（anaphylaxis）** + 蟲體播散（secondary echinococcosis）
    - **診斷**：超音波/CT → 囊腫（可見子囊、鈣化、膜分離）；血清學；**嗜酸性球可能正常**（囊腫未破裂時）
    - **注意**：**不可貿然穿刺**（破裂風險 → anaphylaxis + 播散）
    - **治療**：
        - 手術切除（最根本）+ **術前/術後 Albendazole**（降低復發、預防播散）
        - **PAIR（Puncture-Aspiration-Injection-Reaspiration）**：經皮穿刺 → 抽吸 → 注入殺蟲劑（高濃度食鹽水或 ethanol）→ 再抽吸；需在 Albendazole 保護下進行
        - 小型/鈣化囊腫 → 觀察或單用 Albendazole

### 9.6 蟎（Mite）

| 蟎種 | 疾病 |
|------|------|

## 十一、抗寄生蟲藥物總整理

### 11.1 抗原蟲藥物

| 藥物 | 適應症 | 重要副作用/注意事項 |
|------|--------|---------------------|
| **Metronidazole** | *E. histolytica*（侵襲性）、*Giardia*、*Trichomonas*、*Balantidium* | **Disulfiram-like reaction**（禁酒）；金屬味、周邊神經病變（長期）|
| **Chloroquine** | *P. vivax/ovale/malariae*；敏感區 *P. falciparum* | 視網膜病變（長期使用）|
| **Primaquine** | 殺 *P. vivax/ovale* 的 hypnozoite | **G6PD 缺乏 → 溶血**；禁用於孕婦 |
| **Artesunate / ACT** | *P. falciparum*（嚴重或抗藥性） | 延遲性溶血（post-artemisinin delayed hemolysis） |
| **Pyrimethamine + Sulfadiazine** | *Toxoplasma gondii* | 葉酸拮抗 → 骨髓抑制 → 需補 **Leucovorin** |
| **TMP-SMX** | *Pneumocystis jirovecii*、*Cyclospora*、弓形蟲預防 | 過敏、骨髓抑制（AIDS 患者常見過敏）|
| **Amphotericin B（liposomal）** | *Leishmania*（內臟型）、*Naegleria* | 腎毒性、低血鉀 |
| **Nitazoxanide** | *Cryptosporidium*、*Giardia* | 腸胃不適 |
| **Benznidazole** | *T. cruzi*（Chagas） | 皮膚過敏、周邊神經病變 |

### 11.2 抗蠕蟲藥物

| 藥物 | 適應症 | 機轉/注意事項 |
|------|--------|---------------|
| **Albendazole** | 多數腸道線蟲（蛔蟲、鉤蟲、鞭蟲、蟯蟲）、*Strongyloides*（替代）、囊蟲症、包蟲症 | 抑制微管蛋白（β-tubulin）→ 抑制葡萄糖吸收；**禁用孕婦（teratogenic）**；長期使用需監測肝功能和血球 |
| **Mebendazole** | 同 Albendazole（吸收差，較限於腸道線蟲） | 同上機轉 |
| **Ivermectin** | **Strongyloides**（首選）、**Onchocerca**（首選）、皮膚幼蟲移行症、疥瘡 | 增強 GABA/glutamate-gated Cl⁻ channel → 蟲體麻痺；*Onchocerca* → 不用 DEC |
| **Praziquantel** | 所有吸蟲（除 *Fasciola*）、所有條蟲 | 增加蟲體 Ca²⁺ 通透性 → 痙攣性麻痺；對 *Fasciola* 無效 |
| **DEC（Diethylcarbamazine）** | 淋巴絲蟲（*Wuchereria*、*Brugia*）、*Loa loa* | **禁用於 *Onchocerca*（Mazzotti reaction）** |
| **Triclabendazole** | ***Fasciola hepatica***（首選） | 唯一對肝片吸蟲有效 |
| **Niclosamide** | 腸道條蟲（替代藥） | 不被腸道吸收，對組織幼蟲無效 |
| **Pyrantel pamoate** | 蛔蟲、鉤蟲、蟯蟲 | 神經肌肉阻斷 → 蟲體麻痺排出 |

### 12.2 感染型態速查

| 感染方式 | 寄生蟲 |
|----------|--------|
| **經口（蟲卵）** | 蛔蟲、鞭蟲、蟯蟲、*Toxocara*、*Echinococcus*、*T. solium*（囊蟲症） |
| **經口（囊體/卵囊）** | *E. histolytica*、*Giardia*、*Cryptosporidium*、*Cyclospora*、*Toxoplasma* |
| **經口（生肉/魚/蟹中幼蟲）** | *Taenia*（豬/牛肉）、*Trichinella*（豬肉）、*Clonorchis*/*Diphyllobothrium*（生魚）、*Paragonimus*（蟹/蝲蛄）、蝸牛（*Angiostrongylus*） |
| **經口（水生植物上 metacercaria）** | *Fasciola*、*Fasciolopsis* |
| **經皮膚穿入** | 鉤蟲、*Strongyloides*、血吸蟲（cercaria） |
| **蚊叮咬** | 瘧原蟲、絲蟲 |
| **其他節肢動物叮咬** | Leishmania（沙蠅）、Trypanosoma（乙蠅/錐鼻蟲）、Onchocerca（黑蠅）、Loa loa（鹿蠅） |

### 12.3 Praziquantel vs Albendazole vs Ivermectin 使用時機

| 藥物 | 核心適應症 | 不適用 |
|------|-----------|--------|
| **Praziquantel** | 所有吸蟲（血吸蟲、肝吸蟲、肺吸蟲、薑片蟲）+ 所有條蟲 | ***Fasciola hepatica***（需用 Triclabendazole） |
| **Albendazole** | 腸道線蟲（蛔蟲、鉤蟲、鞭蟲、蟯蟲）、囊蟲症、包蟲症 | — |
| **Ivermectin** | *Strongyloides*（首選）、*Onchocerca*（首選）、皮膚幼蟲移行症、疥瘡 | — |
