# 婦科補充

## 第一部分：產前照護

### 1. 公費產檢與重要時程

| 週數 | 重點 |
|---|---|
| ≤8 週 | 確認懷孕、預產期；初次抽血（HIV、梅毒、B 肝、德國麻疹抗體、地中海貧血等） |
| 11–13⁺⁶ 週 | 第一孕期唐氏症篩檢 |
| 20–24 週 | 高層次超音波（多為自費） |
| 24–28 週 | 妊娠糖尿病篩檢 |
| 28 週後 | 注意胎動、貧血與梅毒複檢 |
| 35–37 週 | GBS 篩檢 |
| 38 週後 | 每週產檢 |

- **核心**：「產檢是為了早期發現、早期處理。很多問題沒有症狀，覺得正常也要按時來。」

### 2. 唐氏症篩檢與產前診斷

- **「我才 28 歲需要做嗎？」**→「唐氏症是第 21 號染色體多一條。任何年齡都可能發生，只是年齡越大機率越高（25 歲約 1/1300、35 歲約 1/270、40 歲約 1/85）。」

| 項目 | 時間 | 性質 | 重點 |
|---|---|---|---|
| 第一孕期篩檢 | 11–13⁺⁶ 週 | 篩檢 | 偵測率約 85–90%，有偽陽性 |
| 第二孕期篩檢 | 15–20 週 | 篩檢 | 約 80% |
| NIPT | 10 週後 | 篩檢 | 約 99%，自費；高風險仍需確診 |
| 絨毛膜採樣 | 10–13 週 | 確診 | 流產風險略高 |
| 羊膜穿刺 | 16–18 週 | 確診 | 流產風險約 0.1–0.5%；34 歲以上等有補助 |

- **重要觀念**：篩檢 ≠ 確診；後續是否確診、是否繼續妊娠都是父母的決定。
- **高風險時**：「我們會安排確診檢查，您不需要立刻做決定，我會陪您討論。」
- **羊穿後**：休息 20–30 分鐘、24 小時內避免提重物與性行為；腹痛、出血、破水、發燒 → 回診；結果約 2–3 週。
- **高層次超音波**：20–24 週詳細看器官構造；可發現大部分構造異常，但看不到智力、聽力，正常也不能保證 100%。
- **高齡產婦（≥34 歲）**：染色體異常、妊娠糖尿病、子癇前症、早產風險較高，建議積極產前診斷，但「不代表一定有問題」。

### 3. 孕期用藥

- **核心**：「沒有藥 100% 安全，也沒有藥 100% 不能用。自行停藥（氣喘、癲癇、糖尿病）可能傷害更大。」
- **禁用**：isotretinoin、warfarin（換 heparin）、ACEI/ARB、methotrexate、valproate、tetracycline。
- **感冒**：休息喝水優先；必要時 acetaminophen；孕後期避免 NSAIDs。

## 第二部分：妊娠合併症

### 4. 妊娠糖尿病

- **篩檢**：24–28 週，一階段 75 g OGTT 或兩階段（50 g → 100 g）。
- **核心**：「懷孕時胎盤荷爾蒙讓胰島素效果變差。不是您吃太多糖造成的。不控制會讓寶寶過大、新生兒低血糖、難產與剖腹率增加。」
- **治療**：飲食定時定量 → 飯後散步 → 必要時胰島素（首選）。
- **家屬常問**：
    - 「胰島素會影響寶寶嗎？」→「胰島素是大分子不會通過胎盤，是孕期最安全的選擇。」
    - 「要打一輩子嗎？」→「多數產後恢復，產後 6–12 週再驗一次。」
- **長期**：媽媽未來第二型糖尿病風險顯著增加、下一胎易再發 → 產後定期追蹤血糖。

### 5. 子癇前症

- **定義**：≥20 週，血壓 ≥140/90 + 蛋白尿或器官受損。
- **核心**：「懷孕特有的高血壓疾病，跟胎盤有關，會影響肝、腎、腦、凝血。最根本的治療是把寶寶生下來，要平衡媽媽和寶寶的安全。」
- **嚴重特徵**：血壓 ≥160/110、血小板 <10 萬、肝指數 2 倍、肌酸酐上升、肺水腫、頭痛視力模糊上腹痛。
- **警訊**：劇烈頭痛、視力模糊看到亮點、右上腹痛、臉手突然水腫、喘、胎動減少 → 立刻急診。
- **子癇（抽搐）**：MgSO₄ + 終止妊娠。**HELLP**：溶血、肝酵素升高、血小板低，預後差。
- **家屬常問**：「下一胎會再發嗎？」→「風險增加，下一胎可早期開始低劑量阿斯匹靈預防。」「以後呢？」→「未來高血壓、心血管、腎臟病風險增加，產後要持續追蹤血壓。」

### 6. 早產

- **核心**：「37 週前生產，台灣約 8–10%。越早產併發症越多，目標是『拖過去』讓寶寶肺部成熟。」
- **<34 週處置**：安胎藥（爭取 48 小時）、**產前類固醇**（最重要的單一介入，降低呼吸窘迫、腦出血、壞死性腸炎）、<32 週 MgSO₄ 神經保護、破水或 GBS 陽性給抗生素。
- **「安胎要躺多久？」**→「現在不建議完全臥床，依宮縮狀況適度活動。」
- **警訊**：規律宮縮（10 分鐘 ≥1 次）、持續腰痠、出血、分泌物增加、下墜感、破水。

### 7. 產前出血：前置胎盤 vs 胎盤早期剝離

| | 前置胎盤 | 胎盤早期剝離 |
|---|---|---|
| 出血 | 鮮紅、**無痛** | 暗紅或內出血、**劇痛** |
| 子宮 | 軟 | 硬如木板 |
| 胎心 | 通常正常 | 常異常 |
| 危險因子 | 剖腹史、多胎、前次前置 | 高血壓、外傷、抽菸 |
| 處置 | 減少活動、避免性行為與內診，36–37 週計畫剖腹 | 多需緊急剖腹 |

- **前置胎盤**：早期診斷不一定要擔心，子宮變大後胎盤可能「往上移」；合併剖腹史要警覺植入性胎盤。
- **任何孕期出血都要就醫**，記錄出血量顏色、有無腹痛，不要自行塞東西。

### 8. 胎兒生長遲滯與羊水異常

- **生長遲滯**：體重 < 第 10 百分位，可能是體質性，也可能是胎盤功能差、抽菸、感染、染色體異常 → 每 2–3 週超音波 + 都卜勒，必要時提早生產。
- **羊水過多**：糖尿病、多胎、胎兒吞嚥或消化道異常；風險早產、產後出血。
- **羊水過少**：破水、胎盤功能差、胎兒泌尿異常；風險肺發育不全、臍帶受壓。

## 第三部分：早期妊娠問題

### 9. 流產

- **先處理情緒，不要急著講醫學**。
- **絕對不要說**：「再生一個就好」「妳還年輕」「應該是寶寶不健康」。
- **核心**：「流產很常見，約 10–20% 的懷孕會流產。八成以上是胚胎染色體異常，是自然淘汰。**真的不是您的錯**，跟工作、運動、性生活、情緒都無關。」
- **分類**：先兆性（子宮頸閉、胎兒存活 → 觀察）、不可避免、不完全、完全、過期流產。
- **處置選項**：期待自然排出 / 藥物（misoprostol）/ 子宮搔刮術。
- **家屬常問**：
    - 「下次還會嗎？」→「一次流產後，下次成功率仍很高（約八成以上）。」
    - 「多久能再懷孕？」→「身體上等一次月經，但情緒恢復同樣重要，不用急。」
- **反覆流產（連續 ≥2 次）檢查**：夫妻染色體、子宮構造、抗磷脂抗體、甲狀腺/糖尿病。抗磷脂症候群 → 低劑量阿斯匹靈 + LMWH。
- 提供心理諮商、支持團體；提醒家人媽媽需要時間。

### 10. 子宮外孕

- **核心**：「胚胎著床在子宮外，最常見輸卵管。這個胚胎無法繼續發育，還會造成內出血，可能危及生命。越早處理對未來生育越好。」
- **危險因子**：前次子宮外孕、輸卵管手術或骨盆腔感染、試管嬰兒、抽菸。
- **治療**：methotrexate（穩定、β-hCG <5000、無胎心）；手術（輸卵管切開或切除）。
- **「以後能懷孕嗎？」**→「對側輸卵管正常的話仍有機會；再發約 10–15%，下次懷孕要早期確認位置。」
- **警訊**：突發劇烈下腹痛、頭暈、肩膀痛 → 急診。

### 11. 葡萄胎

- **核心**：「胎盤組織異常增生成水泡狀，這次懷孕無法成功，且少數會變成絨毛膜癌，所以處理後的追蹤非常重要。」
- **表現**：出血、子宮比週數大、β-hCG 異常高、嚴重孕吐、超音波暴風雪樣。
- **處置**：子宮搔刮術。
- **追蹤**：每週 β-hCG 至連續 3 次陰性，之後每月追蹤；**追蹤期間嚴格避孕**（懷孕會干擾判讀）；不降反升 → 需化療。

## 第四部分：生產與產後

### 12. 生產方式選擇

| | 自然產 | 剖腹產 |
|---|---|---|
| 恢復 | 快 | 慢 |
| 出血/感染 | 較少 | 較多 |
| 寶寶呼吸 | 較好 | 暫時性呼吸急促較常見 |
| 下一胎 | 影響少 | 子宮疤痕、植入性胎盤風險 |
| 適應症 | 大多數 | 胎位不正、前置胎盤、胎兒窘迫等 |

- **VBAC**：一次低位橫切剖腹史可考慮；子宮破裂約 0.5–1%，需嚴密監測。

### 13. 產後出血

- **定義**：自然產 >500 mL、剖腹 >1000 mL 或造成血行不穩。
- **4T**：Tone（收縮不良，約 70%）、Trauma（裂傷）、Tissue（胎盤殘留）、Thrombin（凝血）。
- **處置**：子宮按摩、子宮收縮劑、修補裂傷、移除殘留、輸血；嚴重時氣球填塞、栓塞、子宮切除。

### 14. 產後憂鬱

| | Baby blues | 產後憂鬱 | 產後精神病 |
|---|---|---|---|
| 發生率 | 50–80% | 10–15% | 0.1–0.2% |
| 時間 | 產後 3–10 天 | 多在數週內 | 多在 2 週內 |
| 持續 | <2 週 | >2 週 | 急症 |
| 處理 | 支持、自限 | 需治療 | 緊急精神科 |

- **核心**：「產後憂鬱是真正的疾病，不是您不夠堅強或不愛寶寶。跟荷爾蒙、睡眠不足、角色轉換有關，可以治療。」
- **處理**：EPDS 篩檢、心理治療、SSRI（sertraline 哺乳相對安全）、家人支持。
- **衛教家人**：不要說「生小孩本來就辛苦」；分擔家務、讓媽媽睡覺。
- **危險訊號**：談論死亡、想傷害寶寶、妄想 → 立刻就醫。

### 15. GBS 陽性

- 「這是陰道常見的細菌，陽性不代表您生病，但生產時可能傳給寶寶造成敗血症。」
- 「生產時打抗生素（penicillin）可大幅降低風險，**破水或產兆出現要盡早到院**。」

### 16. 哺乳

- **好處**：寶寶免疫、過敏少；媽媽子宮復原、降低乳癌卵巢癌風險。
- **奶量不夠**：「需求決定供應，多吸就多。不夠可以加配方奶，不要勉強。」
- **塞奶/乳腺炎**：含乳姿勢、熱敷、頻繁餵；乳腺炎（紅腫熱痛發燒）→ 抗生素，**可繼續哺乳**。
- 上班可擠奶，法規保障哺乳時間。

## 第五部分：月經與內分泌

### 17. 異常子宮出血

- **PALM-COEIN**：結構性（息肉、腺肌症、肌瘤、惡性）／非結構性（凝血、排卵異常、內膜、醫源性）。
- **「量多怎麼算？」**→「衛生棉每小時濕透、血塊 >2.5 cm、超過 7 天、有貧血症狀。」
- **依年齡**：青少女多為排卵異常；育齡先排除懷孕；**停經後出血一定要排除子宮內膜癌**。

### 18. 經痛與子宮內膜異位症

- **原發性**：青春期開始、無器質病因；NSAIDs 經期前 1–2 天開始吃、口服避孕藥、熱敷運動。
- **子宮內膜異位症**：「內膜長到子宮外，跟著月經出血腫脹。」三大症狀：**漸進性經痛、性交深部痛、不孕**；巧克力囊腫可在超音波看到，確診靠腹腔鏡。
- **治療**：疼痛優先 → NSAIDs、連續避孕藥、dienogest、GnRH 類藥物、手術；生育優先 → 手術或試管。
- **家屬常問**：「會變癌嗎？」→「機率很低，但巧克力囊腫要追蹤。」「停經會好嗎？」→「多數會改善。」

### 19. 多囊性卵巢症候群

- **Rotterdam 3 取 2**：排卵異常、高雄性素（多毛、痘痘）、超音波多囊卵巢。
- **核心**：「是內分泌失調，和胰島素阻抗有關，影響月經、生育、外觀，長期增加糖尿病、心血管、子宮內膜癌風險。」
- **治療**：減重（降 5–10% 可恢復排卵）、運動；不想懷孕 → 口服避孕藥規則經期、metformin；想懷孕 → letrozole 誘導排卵。

## 第六部分：婦科腫瘤

### 20. 子宮肌瘤

- **核心**：「子宮肌肉層的良性瘤，30–50% 女性都有，惡性 <1%。」依位置：黏膜下、肌肉內、漿膜下。
- **處置**：無症狀不大 → 追蹤；有症狀 → 藥物、子宮鏡（黏膜下）、肌瘤切除（保留子宮）、子宮切除、栓塞或聚焦超音波。
- **家屬常問**：「影響懷孕嗎？」→「黏膜下影響最大，建議處理；漿膜下多不影響。」「停經會縮小嗎？」→「通常會。停經後還長大要警覺。」

### 21. 卵巢囊腫

- **功能性**（濾泡/黃體囊腫）：<5 cm 多自行消退，觀察 2–3 個月。
- **需注意**：持續 >5 cm、實心成分、雙側、CA-125 升高、停經後新發。
- **急症**：**卵巢扭轉**（突發單側劇痛 + 嘔吐 → 急診手術）、囊腫破裂。

### 22. 子宮頸抹片異常 / HPV

- **核心**：「HPV 主要經性接觸傳染，八成有性行為的人一生會感染。大多數會自行清除，少數高危型（16、18）持續感染才可能癌變，通常要 5–20 年，所以規律抹片能早期發現。」
- **公費**：國健署提供定期抹片與部分年齡 HPV 檢測（以最新公告為準）。

| 結果 | 處置 |
|---|---|
| ASC-US | HPV 檢測或重複抹片 |
| LSIL | 陰道鏡 |
| HSIL | 陰道鏡 + 切片 |
| CIN 1 | 多自行消退，追蹤 |
| CIN 2/3 | 圓錐切除（LEEP） |

- **HPV 疫苗**：性行為前最佳；男生也建議；**打了仍要抹片**。
- **家屬常問**：
    - 「是另一半的問題嗎？」→「HPV 可潛伏多年，無法判斷誰先有，追究來源沒有意義。」
    - 「圓錐切除影響懷孕嗎？」→「可能略增早產與子宮頸閉鎖不全，懷孕時監測子宮頸長度。」

### 23. 子宮內膜癌

- **最重要警訊**：停經後出血。
- **危險因子**：肥胖、糖尿病、高血壓、PCOS、未生育、單獨雌激素、tamoxifen、Lynch 症候群。
- **診斷**：子宮內膜切片。**治療**：早期手術分期，再決定放化療；早期 5 年存活 >90%。

### 24. 卵巢癌

- **核心**：「被稱為沉默的殺手，早期幾乎沒症狀，也沒有像抹片一樣好的篩檢。」
- **症狀**：腹脹、腹圍變大、早飽、頻尿、體重減輕。
- **治療**：手術 + 化療。**遺傳諮詢**：家族史強或年輕發病 → BRCA 檢測；帶因者可考慮預防性卵巢輸卵管切除。

## 第七部分：更年期、避孕與生育

### 25. 更年期與荷爾蒙治療

- **核心**：「停經是卵巢自然退休，不是疾病。平均約 50 歲，症狀因人而異。」
- **症狀**：熱潮紅盜汗、陰道乾澀、頻尿、失眠焦慮；長期骨鬆、心血管風險上升（骨鬆處理見〈內科篇〉）。
- **HRT**：適合症狀嚴重、<60 歲或停經 <10 年；有子宮要雌激素 + 黃體素；風險血栓、中風、長期使用乳癌風險上升。
- **非荷爾蒙**：SSRI/SNRI、局部陰道雌激素、生活型態。
- **「HRT 會得乳癌嗎？」**→「長期合併使用會略增加；短期用於治療嚴重症狀，益處常大於風險，要定期乳房檢查。」

### 26. 避孕方式

| 方法 | 典型失敗率 | 特點 |
|---|---|---|
| 保險套 | ~13% | **唯一同時預防性病** |
| 口服避孕藥 | ~7% | 規則經期；每天吃；血栓風險 |
| 子宮內避孕器 | <1% | 長效 5–10 年、可逆 |
| 皮下植入 | ~0.05% | 3 年；不規則出血 |
| 結紮 | <0.5% | 永久 |
| 安全期 | ~24% | 失敗率高 |

- **口服避孕藥禁忌（要問）**：≥35 歲且抽菸、未控制高血壓、有先兆偏頭痛、血栓史、乳癌、嚴重肝病。
- **緊急避孕**：levonorgestrel 72 小時內（越早越好）、ulipristal 120 小時內、銅 IUD 120 小時內最有效；不能取代常規避孕。

### 27. 人工流產諮詢

- 優生保健法：24 週內依法定事由可施行；已婚需配偶同意（特殊情況除外）；未婚未成年需法定代理人同意。
- 中性不批判、**確認是自主決定沒有被脅迫**、說明藥物 vs 手術、提供心理支持資源。

### 28. 不孕症

- **定義**：規律性行為 1 年未孕（≥35 歲 6 個月）。
- **核心**：「不孕不是哪一方的錯，男女都要檢查，成因女方、男方、雙方大約各占三分之一。」
- **檢查**：男方先做精液分析（簡單便宜）；女方排卵、輸卵管攝影、AMH、子宮、甲狀腺泌乳素。
- **治療階梯**：生活調整 → 排卵誘導 → 人工授精 → 試管嬰兒（政府有試管補助，依條件申請）。
- **成功率**：<35 歲約 40–50%，>40 歲明顯下降；現多單胚胎植入降低多胞胎。

## 第八部分：感染與骨盆底

### 29. 骨盆腔發炎與性傳染病

- **PID**：「多由披衣菌、淋病上行感染，不治療會造成不孕、慢性骨盆痛、子宮外孕。」
- **常見 STI**：披衣菌（女性約 70% 無症狀）、淋病、梅毒、生殖器疱疹（可抑制不可根治）、菜花、HIV。
- **衛教**：**伴侶一起治療**、治療期間禁性行為、完成療程、保險套、重複篩檢。

### 30. 陰道炎

| 類型 | 分泌物 | 氣味 | 治療 |
|---|---|---|---|
| 念珠菌 | 白色乾酪狀 | 無 | 抗黴菌 |
| 細菌性 | 灰白稀薄 | 魚腥味 | metronidazole |
| 滴蟲 | 黃綠泡沫 | 臭 | metronidazole + **伴侶治療** |

- 不要過度灌洗、穿棉質寬鬆內褲。

### 31. 尿失禁與骨盆器官脫垂

- **應力性**（咳嗽運動漏尿，產後常見）→ 凱格爾運動、減重、吊帶手術；**急迫性**（來不及）→ 膀胱訓練、藥物。
- **脫垂**：「骨盆底支撐鬆弛，子宮、膀胱、直腸往下掉。」輕度凱格爾或子宮托，嚴重手術。

## 第九部分：特殊情境

### 32. 胎兒異常告知

1. 確認家屬到齊、預警：「今天的超音波發現了一些狀況⋯」
2. 畫圖客觀說明異常與預後（可治療？可存活？）
3. 給時間：「不需要馬上決定。」
4. 進一步檢查（羊穿、胎兒心臟超音波、MRI）
5. 後續選擇：繼續或終止妊娠（依法規時限）
6. 轉介遺傳諮詢、支持團體；**不批判任何選擇**

### 33. 流產告知

「很遺憾，今天的超音波看不到寶寶的心跳了⋯」→ 沉默 → 「這真的不是您的錯。」→ 處置選項 → 不急著講「下次」→ 心理支持。

### 34. 疑似家暴 / 被脅迫

- **警訊**：病人沉默迴避、配偶代答、不明傷痕。
- **處理**：找機會單獨會談（「為了檢查，請先生先在外面等」）；直接問人身安全；提供 113 保護專線、社工；尊重步調，有生命危險時立即處理。

### 35. 未成年懷孕

- 中性不批判、了解家庭支持、說明法定代理人規定、避孕與性教育、轉介社工。
- **未滿 16 歲性行為依法須通報**，並注意性侵害可能。
