# 外科補充

## 第一部分：一般外科

### 1. 急性闌尾炎

- **核心**：「右下腹的闌尾，像大腸開頭的小尾巴，發炎了。不處理可能破掉造成腹膜炎。治療是手術切除，目前以腹腔鏡為主。」
- **典型病程**：肚臍周圍悶痛、噁心 → 6–12 小時後轉移右下腹、越動越痛。
- **術式比較**

| | 開腹 | 腹腔鏡 |
|---|---|---|
| 傷口 | 5–7 cm | 3 個 0.5–1 cm 小洞 |
| 疼痛 | 較痛 | 較輕 |
| 住院 | 3–5 天 | 1–3 天 |
| 恢復活動 | 2–3 週 | 約 1 週 |
| 適用 | 嚴重發炎、破裂、沾黏 | 大多數 |

- **特定風險**：傷口感染（穿孔型 5–10%）、腹腔膿瘍、沾黏性腸阻塞、中轉開腹 5–10%。
- **不開刀後果**：穿孔 → 腹膜炎、敗血症；越晚穿孔率越高。
- **抗生素保守治療**：部分單純性可嘗試，但復發率約 30–40%，手術仍為標準。
- **術後**：早下床、排氣後由清流漸進飲食、1 個月內避免劇烈運動提重物；發燒、傷口流膿、腹痛加劇 → 回診。

### 2. 膽結石 / 急性膽囊炎

- **核心**：「膽囊是肝臟下方存膽汁的小袋子。結石塞住出口造成發炎，治療是把整個膽囊拿掉。」
- **「不能只拿石頭嗎？」**→「膽囊本身已病變，留著會再長石頭。沒有膽囊不影響生活，只是吃太油可能拉肚子，多數幾個月內適應。」
- **術式**：腹腔鏡膽囊切除（標準）；嚴重發炎或疑癌時開腹。
- **特定風險**：**膽道損傷（0.3–0.5%，最重要，可能需再手術）**、膽汁滲漏、中轉開腹、殘餘總膽管結石。
- **時機**：急性發作 72 小時內手術較好；錯過則抗生素後 6–8 週再開。
- **無症狀膽結石**：通常不需預防性手術（例外：瓷化膽囊、息肉 >1 cm 等）。
- **警訊**：黃疸、白色大便、茶色尿、發燒、劇烈腹痛。

### 3. 腹股溝疝氣

- **核心**：「肚子肌肉有個弱點，腸子或脂肪從那裡鑽出來。站著、咳嗽時明顯，躺下會消。不會自己好，藥物無效，只能手術修補。」
- **為什麼要開**：「最怕腸子卡住（崁頓），血流被掐斷就會壞死，變成急診切腸。」
- **術式**：傳統 Lichtenstein（放網片）；腹腔鏡 TAPP/TEP（雙側或復發首選）。
- **特定風險**：復發 5–10%、慢性鼠蹊痛 5–10%、血腫/血清腫、網片感染 <1%、男性睪丸相關併發症（罕見）。
- **術後**：1 個月不提 >5 kg、3 個月避免劇烈運動；處理便秘與慢性咳嗽、戒菸控制體重。
- **嬰幼兒疝氣**：不會自己好、卡住風險高，建議盡早手術（兒外）。

### 4. 痔瘡

- **核心**：「肛門周圍的血管叢膨脹，像肛門的靜脈曲張。和久坐、便秘、懷孕有關。不是癌症，但要先排除別的問題。」
- **內痔分級**：I 只出血；II 脫出自己縮回；III 要用手推回；IV 推不回。
- **治療階梯**：生活調整（高纖、多水、不久蹲、溫水坐浴）→ 藥物 → 橡皮筋結紮/硬化劑 → 手術（III–IV）。
- **術式**：傳統切除（較痛）、PPH（自費、較不痛）、雷射/LigaSure。
- **風險**：術後 1–2 週掉痂出血、疼痛、肛門狹窄、暫時性失禁（罕見）、復發。
- **術後**：溫水坐浴每天 3–4 次、軟便劑、不憋便；大量出血要回診。

### 5. 甲狀腺癌

- **核心**：「細針檢查偏向甲狀腺癌。先讓您安心：大部分是乳突癌，是預後最好的癌症之一，10 年存活率超過 95%。治療以手術為主，部分需放射碘。」
- **術式**：半側切除（單側低風險）vs 全切除（雙側、較大、淋巴轉移或需放射碘）± 頸部淋巴廓清。
- **特定風險**：
    - 喉返神經 → 聲音沙啞（暫時 5–10%、永久約 1%）
    - 副甲狀腺 → 低血鈣：嘴麻、手抖、抽筋（暫時 20–30%、永久 1–3%）
    - **術後血腫壓迫氣管 → 急救**
- **術後**：全切除者終身吃甲狀腺素；追蹤 thyroglobulin、血鈣、頸部超音波。
- **警訊**：傷口快速腫脹、呼吸困難、手腳麻抽筋。

### 6. 乳癌

- **告知**：SPIKES。「切片結果出來了，是乳癌。」（暫停）「我知道這對您是很大的衝擊⋯」**第一次以處理情緒為主**，不急著講細節，可提供書面資料。
- **核心**：「乳癌不等於絕症，0–II 期 5 年存活率超過 90%。治療要看『期別 + 分子型態』決定。」
- **治療組合**：手術、放療、化療、荷爾蒙（ER/PR+，5–10 年）、標靶（HER2+）、免疫（部分三陰性）。
- **術式選擇**

| | 乳房保留 | 全乳房切除 |
|---|---|---|
| 範圍 | 腫瘤 + 周圍 | 整個乳房 |
| 後續放療 | 必要 | 視情況 |
| 存活率 | 相當 | 相當 |
| 局部復發 | 略高 | 較低 |
| 重建 | 通常不需 | 可同時或延後 |

- **特定風險**：淋巴水腫（腋下廓清 20–30%、哨兵淋巴結約 5%）、上肢感覺異常、重建併發症。
- **家屬常問**：
    - 「會遺傳嗎？」→「約 5–10% 與 BRCA 等基因有關；年輕、雙側、家族史強者可做基因檢測。」
    - 「我才 35 歲？」→「年輕乳癌治療要更完整，也會考慮生育保留。」
- **支持**：乳癌個管師全程陪伴；身體形象、性、生育都可討論。
- **篩檢**：國健署公費乳房攝影（年齡範圍以最新公告為準）；警訊：無痛硬塊、乳頭凹陷或異常分泌、橘皮樣皮膚、腋下腫塊。

### 7. 大腸直腸癌

- **告知**：「報告確認是大腸癌。會再做胸腹 CT、腫瘤指數（CEA）確定期別。」
- **期別（病人版）**：I 侷限淺層 → 手術即可；II 穿透腸壁 → 手術 ± 化療；III 淋巴轉移 → 手術 + 化療；IV 遠端轉移 → 化療為主，部分仍可手術。
- **術式與造口**

| 部位 | 手術 | 造口 |
|---|---|---|
| 右側結腸 | 右半結腸切除 | 通常不需 |
| 左側/乙狀結腸 | 左半/乙狀結腸切除 | 通常不需 |
| 中下段直腸 | (超)低位前位切除 | 常有暫時性 |
| 極低位侵犯括約肌 | 腹會陰切除（APR） | 永久性 |

- **造口告知**：「我們會盡量保留肛門。如果腫瘤太靠近肛門，可能需要人工肛門——把腸子接到肚皮上，糞便排到袋子裡。現代造口照護很進步，大部分人能正常上班、運動，造口護理師會教您。」
- **特定風險**：吻合處滲漏（3–10%，直腸較高，可能需再手術）、腸阻塞、排尿與性功能障礙（直腸手術）、造口問題。
- **追蹤**：前 3 年每 3 個月 CEA 與影像；大腸鏡 1、3、5 年。
- **家屬常問**：「會遺傳嗎？」→「多數散發性，少數家族性（如林奇症候群）。一等親建議 40 歲或比診斷年齡早 10 年開始大腸鏡篩檢。」

### 8. 胃癌

- **核心**：「與幽門桿菌、飲食、家族史有關。早期 5 年存活 >90%，但早期常沒症狀。」
- **術式**：極早期內視鏡切除（ESD）、次全胃切除、全胃切除；重建（B-I、B-II、Roux-en-Y）用畫圖簡單說明。
- **術後生活**：少量多餐（每天 5–6 餐）；傾食症候群（吃完心悸冒汗 → 慢慢吃）；B12 缺乏需終身補充、缺鐵、骨鬆、體重下降。
- **風險**：吻合處滲漏、胰瘺、出血感染；全胃切除死亡率約 1–3%。

### 9. 肝癌

- **核心**：「多與 B/C 肝、肝硬化、酒精有關。治療要評估腫瘤、肝功能、體能三件事。」
- **依 BCLC**：早期 → 切除、電燒、移植；中期 → 栓塞（TACE）；晚期 → 標靶/免疫；末期 → 安寧。
- **手術風險**：出血輸血、膽汁滲漏、**術後肝衰竭**（肝硬化者尤其）。
- **TACE**：「從鼠蹊部打導管到肝動脈，打藥並堵住腫瘤血流。」栓塞後症候群：發燒、噁心、腹痛 1–3 天。
- **衛教**：戒酒、抗病毒治療、每 3–6 個月超音波 + AFP、一等親 B 肝篩檢。

### 10. 腸阻塞

- **核心**：「腸子的通道塞住，東西過不去。最常見是以前手術造成的沾黏、疝氣、腫瘤。」
- **症狀**：陣發性絞痛、嘔吐、腹脹、不排氣不排便。
- **處置**：禁食 + 鼻胃管減壓 + 點滴，多數沾黏型可緩解；**持續疼痛、發燒、腹膜炎徵象（懷疑絞窄）→ 手術**。
- **風險**：再沾黏、切除過多造成短腸症、絞窄性死亡率較高。

## 第二部分：泌尿外科

### 11. 攝護腺肥大

- **核心**：「攝護腺像甜甜圈包住尿道，年紀大變大壓迫尿道。不是癌症，但要先排除攝護腺癌。」
- **症狀**：尿流細、解不乾淨、等很久；頻尿、夜尿、急尿。
- **治療階梯**：生活調整 → α-blocker、5α-reductase 抑制劑 → 手術（TURP、雷射等）。
- **TURP 風險**：**逆行性射精（常見，可能影響自然生育，術前一定要說）**、暫時尿失禁、尿道狹窄、術後數週血尿。

### 12. 攝護腺癌

- **核心**：「大部分進展慢。治療不是越積極越好，要平衡效果與副作用。」
- **依風險**：極低/低 → 主動監測；中 → 根除手術、放療；高 → 手術 + 放療 ± 荷爾蒙；轉移 → 荷爾蒙、化療、新型藥物。
- **根除手術風險**：尿失禁（1 年後約 90% 恢復）、勃起功能障礙（30–80%，視神經保留）、不孕（一定發生）。

### 13. 尿路結石

- **核心**：「結石卡在輸尿管造成阻塞，痛到腰、下腹、鼠蹊。」
- **依大小**

| 大小/位置 | 處置 |
|---|---|
| <5 mm 輸尿管 | 多喝水、止痛、α-blocker 助排 |
| 5–10 mm | 體外震波（ESWL） |
| >10 mm 或 ESWL 失敗 | 輸尿管鏡（URS） |
| >2 cm 腎結石 | 經皮腎造廔取石（PCNL） |

- **預防**：每日喝水 2.5–3 L；鈣結石**不需限鈣**，要限鈉、限動物蛋白、限草酸（菠菜、堅果、茶）；尿酸結石鹼化尿液；10 年復發率約 50%。
- **警訊**：發燒（合併感染 → 急診）、無尿、劇痛嘔吐。

### 14. 膀胱癌

- **核心**：「典型是無痛血尿，與抽菸、染料、馬兜鈴酸有關。」
- **治療**：非肌肉侵犯 → 經尿道刮除（TURBT）+ 膀胱內灌注；肌肉侵犯 → 根除性膀胱切除 + 尿路重建（造口或新膀胱）。
- **根除術衛教**：住院約 2 週、性功能影響、終身追蹤。

## 第三部分：骨科

### 15. 老年髖部骨折

- **核心**：「不開刀的話長期臥床，肺炎、褥瘡、血栓會讓死亡率更高。48 小時內手術恢復較好。」
- **術式**：股骨頸移位 → 半髖/全髖置換；無移位或年輕 → 內固定；轉子間 → 髓內釘或 DHS。
- **風險**：一年死亡率 20–30%、麻醉心肺風險、輸血、感染（人工關節可能需重做）、脫位、血栓、**術後譫妄**。
- **術後**：盡早下床復健、治療骨鬆、預防再跌倒。

### 16. 全人工膝關節置換

- **核心**：「膝蓋軟骨磨損已影響生活，人工關節可大幅改善疼痛，壽命約 15–20 年。」先試過減重、復健、止痛、注射。
- **風險**：深部感染 1–2%（可能需取出重做）、血栓、鬆動、持續疼痛 10–20%。
- **術後**：第一天就開始復健；拔牙等侵入性處置前告知醫師；避免跑跳等高衝擊運動。

### 17. 椎間盤突出

- **核心**：「脊椎之間的軟墊破裂壓到神經，會痛、麻、無力。多數保守治療 6–12 週可改善。」
- **手術適應**：**馬尾症候群（大小便失禁、會陰麻）→ 急診**、進行性無力、保守治療無效。
- **術式**：微創椎間盤切除、融合（不穩定時）、人工椎間盤（自費）。
- **風險**：神經損傷、硬膜破裂腦脊髓液漏、感染、復發、鄰近節退化。

## 第四部分：神經外科

### 18. 出血性中風 / 顱內出血 / 蛛網膜下腔出血

- **核心（家屬版）**：「這是出血性中風，腦血管破掉，血壓迫腦組織。常見原因：高血壓、動脈瘤、血管畸形。」
- **SAH**：「最常見是腦動脈瘤破裂，再出血風險高，要儘快夾閉或栓塞。」
- **處置**：小量 → 保守、嚴格控壓；腦室出血/腦壓高 → 引流（EVD）；大量有壓迫 → 開顱清血塊。
- **預後要誠實**：ICH 30 天死亡率 35–50%，倖存者常有後遺症；「前 24–72 小時是關鍵期。」
- **「會醒來嗎？會變植物人嗎？」**→「我們會觀察接下來幾天的意識變化，恢復程度需要時間評估。」不過度承諾，也不剝奪希望。

### 19. 腦腫瘤

- **核心**：「影像看到腦部腫瘤，分良性、惡性、轉移，要切片才能確定。」
- **治療**：手術（在不傷功能下盡量切除）、放療（含加馬刀）、化療。
- **風險**：依位置的神經功能缺損、癲癇、感染出血。
- **惡性（如 GBM）**：「即使積極治療，平均存活約 14–18 個月，但每個人不同。」同理 + 適時安寧諮詢。

## 第五部分：胸腔 / 心臟外科

### 20. 肺癌手術

（診斷告知與標靶/免疫治療見〈內科篇〉）

- **適應**：I–II 期手術為主；IIIA 手術合併化放療。
- **術式**：楔形切除、肺葉切除（標準）、全肺切除；多採微創 VATS/RATS。
- **風險**：持續漏氣 5–10%、肺炎、心房顫動；死亡率肺葉 1–2%、全肺 5–10%。
- **術前戒菸 ≥4 週**可降低併發症。

### 21. 自發性氣胸

- **核心**：「肺表面小氣泡破裂，空氣跑到肋膜腔把肺壓扁。常見於高瘦年輕男性。」
- **處置**：小量無症狀 → 觀察給氧；大量或有症狀 → 胸管；復發或持續漏氣 → VATS 切除氣泡 + 肋膜沾黏。
- **衛教**：同側復發率 30–50%；**戒菸**；避免潛水、高空等氣壓劇變；突發胸痛喘 → 急診。

### 22. 冠狀動脈繞道

- **核心**：「心臟血管多處嚴重狹窄，支架無法處理，要取腿部或胸部的血管繞過塞住的地方。」
- **vs 支架**：多條病變、糖尿病、左主幹 → CABG；單條、急性 → PCI。
- **風險**：死亡 1–3%（緊急、高齡更高）、中風 1–2%、心律不整、縱膈腔感染、腎衰竭、認知變化。
- **術後**：心肺復健、控制三高、戒菸、aspirin + statin 終身。

## 第六部分：困難情境

### 23. 拒絕手術

1. 不急著反駁：「謝謝您告訴我您的決定。」
2. 探詢原因：怕痛、怕死、經濟、宗教、過去經驗
3. 針對性釋疑：「您擔心的風險機率大約是⋯，我們會這樣預防⋯」
4. 誠實說明不開刀的後果
5. 尊重決定、持續照顧；簽署拒絕治療同意書並記錄

### 24. 告知手術併發症（SAFER）

- **S**orry：誠懇道歉（表達遺憾不等於認錯）
- **A**cknowledge：承認發生什麼事
- **F**actual：客觀說明事實
- **E**xplain：說明後續處置
- **R**emedy：補救方案
- **範例**：「這次手術中膽道有受傷。我們已請更有經驗的醫師會診修補完成，您可能需要多放幾天引流管。我對這個情況感到非常抱歉，我們會盡全力幫您恢復。您有什麼想問的嗎？」
- **禁忌**：推卸責任、攻擊同仁、隱瞞、過度承諾「不會再發生」、跟家屬辯論。

### 25. 醫療糾紛苗頭

- 聆聽不打斷、同理情緒
- 不當下做無法兌現的承諾
- 邀請正式溝通：「我們安排時間，請主治醫師、護理長一起跟您詳細說明。」
- 通報醫院關懷小組

## 第七部分：常見解釋模板

- **腹腔鏡 vs 開腹**：「腹腔鏡用幾個小洞伸入鏡頭和器械，傷口小、恢復快。但如果術中發現嚴重沾黏或出血，會改成開腹——這不是失敗，是為了您的安全。」
- **達文西**：「更精細的機械手臂腹腔鏡，健保不給付需自費（依術式數萬到數十萬）。不是每個人都需要。」
- **全身麻醉**：「現代麻醉很安全，嚴重併發症約十萬分之一以下；常見是喉嚨痛、噁心。麻醉醫師會另外評估說明。」
- **引流管**：「讓手術部位的血水流出，避免積在裡面感染。通常 2–5 天，看量決定何時拔。」
- **術前禁食**：「為了避免麻醉時嘔吐物吸進肺裡造成嚴重肺炎。一般固體食物禁 6–8 小時，清水依麻醉科指示（常為術前 2 小時）。」
- **沾黏**：「開過刀後組織之間像疤痕一樣黏在一起，是正常癒合反應。多數沒症狀，少數會造成腸阻塞或慢性痛。」
