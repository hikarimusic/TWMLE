# 急診補充

## 第一部分：成人急症告知與同意

### 1. STEMI + 緊急心導管同意

- **核心**：「心臟的血管塞住了，心肌會在幾小時內壞死。時間就是心肌，越早打通救回越多。」
- **處置**：緊急 PCI（door-to-balloon 90 分鐘內）；無法及時則血栓溶解劑；同時抗血小板、抗凝。
- **風險（同意書必講）**：穿刺處出血瘀青、血管損傷、心律不整、顯影劑過敏、腎功能影響、極少數需緊急開刀；**術中術後仍可能有生命危險**。
- **不做的後果**：死亡率高、存活者常留下嚴重心衰竭。
- **「會不會走？」**→「這是有生命危險的疾病，但越早打通預後越好，我們會盡全力。」

### 2. 急性缺血性中風 + rt-PA / 取栓同意

- **核心**：「腦血管被血塊塞住，腦細胞正在缺氧死亡，每分鐘約有 190 萬個神經細胞死亡——Time is brain。」
- **依時間窗**：<4.5 小時 → 靜脈 rt-PA；大血管阻塞 → 動脈取栓（部分可延至 24 小時）；超過 → 保守治療。
- **rt-PA 風險**：症狀性腦出血約 6%、致死性出血約 2–3%。
- **關鍵說法**：「不打的話，現在的症狀很可能變成永久；打了有改善的機會，但少數人會因出血變得更糟。我會給您建議，但時間有限。」
- **「不能再觀察一下嗎？」**→「越觀察腦細胞死越多，現在每一分鐘都重要。」
- **FAST**：臉歪、手無力、說話不清 → 立刻 119。

### 3. 主動脈剝離

- **核心**：「主動脈是身體最粗的血管，現在血管內層撕裂，血流進血管壁裡，隨時可能破裂。」
- **分型**：**A 型**（升主動脈）→ 緊急手術，未治療早期每小時死亡率持續上升；**B 型** → 以嚴格控制血壓心跳為主，部分需介入。
- **溝通**：「我必須老實說，這是死亡率非常高的疾病。開刀仍有機會，不開刀幾乎沒有希望。」手術後仍可能中風、腎衰竭、下肢癱瘓。
- **出院衛教**：嚴格控制血壓（約 <120/80）、避免舉重與劇烈運動、終身影像追蹤、戒菸。

### 4. 急性肺栓塞

- **核心**：「腳上的血塊跑到肺部血管塞住，嚴重時心臟撐不住會休克。」
- **處置**：heparin 抗凝；大範圍合併休克 → 血栓溶解或介入取栓；之後口服抗凝 3–6 個月以上（衛教見〈內科篇〉）。
- **風險**：抗凝出血、溶栓腦出血、復發。

### 5. 過敏性休克

- **核心**：「嚴重過敏反應，全身血管擴張、氣管收縮，不立刻處理會休克死亡。」
- **處置**：**IM epinephrine 第一線**、氧氣、輸液；抗組織胺、類固醇為輔；氣道阻塞 → 插管。
- **衛教**：找出並避免過敏原、隨身攜帶腎上腺素自動注射筆、醫療警示手環；**雙相反應可在 4–24 小時後再發**，需留觀。

### 6. 上消化道出血 + 緊急胃鏡同意

- **核心**：「腸胃道在出血，可能是潰瘍或食道靜脈曲張，需要胃鏡找出血點並止血。」
- **處置**：輸液輸血、IV PPI、24 小時內胃鏡（靜脈曲張更急）；止血失敗 → 栓塞或手術。
- **胃鏡風險**：出血、穿孔（罕見）、麻醉風險、止血失敗。
- **肝硬化靜脈曲張破裂**：死亡率約 15–20%，可能需 ICU，要說明預後較差的原因。

### 7. 急性腹症

- 鑑別：闌尾炎、膽囊炎、腸阻塞、潰瘍穿孔、胰臟炎、卵巢扭轉、子宮外孕。
- 急診溝通重點：「目前在找原因，可能需要抽血、影像，也可能要會診外科。」**育齡女性先排除懷孕**。
- **消化性潰瘍穿孔**：「胃或十二指腸破洞，胃液流到肚子裡，需要緊急手術。高齡、延遲就醫者死亡率較高。」
- 個別手術同意書內容見〈外科篇〉。

### 8. 敗血症 / 敗血性休克

- **核心**：「嚴重感染引起全身過度反應，血壓掉、器官功能變差，是要分秒必爭的急症。」
- **Bundle（1 小時內）**：抽血培養、廣效抗生素、大量輸液、乳酸；必要時升壓藥、插管、透析。
- **家屬告知**：「需要加護病房治療。敗血性休克死亡率可達三到五成，即使存活也可能留下器官損傷。我們會盡全力，但也要有心理準備。」誠實但不絕望。

## 第二部分：兒科急診特殊場景

### 9. 兒童頭部外傷

- **評估**：GCS、嘔吐、受傷機制、意識喪失、行為改變。
- **PECARN 高風險**：
  - **<2 歲**：意識改變、可摸到顱骨骨折、高風險機制（跌落 >0.9 m、嚴重車禍）、非額部頭皮血腫、意識喪失 ≥5 秒、行為異常
  - **≥2 歲**：意識改變、顱底骨折徵象、高風險機制、嘔吐、嚴重頭痛、意識喪失
- **說明**：「電腦斷層有輻射，兒童影響較大，所以我們會評估必要性。目前風險不高，但 24–48 小時要密切觀察。」
- **居家警訊**：持續嘔吐、嗜睡叫不醒、抽搐、行為或言語異常、走路不穩、瞳孔不等大、頭痛加劇。

### 10. 疑似兒虐

- **警訊**：傷勢與描述機制不符、新舊傷並存、特殊形狀傷（菸燙、皮帶痕）、延遲就醫、說法改變、多次外傷史。
- **法定通報**：**24 小時內**通報（113 保護專線），不需家屬同意。
- **溝通**：不當面指控；客觀記錄拍照；「這個傷勢的原因，我需要請社工跟您一起釐清。」必要時收住院保護。

### 11. 嬰兒猝死告知

- 私密空間、家屬到齊；直接但溫柔：「我必須告訴您一個非常難過的消息⋯經過急救，○○ 已經離開了。」
- **不要說**「我了解您的感受」→ 改說「我無法想像您現在的痛。」
- **自責**：「都是我的錯⋯」→「請不要這樣想，這不是您的錯。」
- 讓家屬陪伴寶寶、社工與宗教師、說明檢察官相驗程序、哀傷輔導資源。

## 第三部分：創傷、急救與死亡告知

### 12. 多重外傷

- 先講當下（生命徵象穩不穩）→ 已做的處置（影像、止血、輸血）→ 接下來要做什麼 → 預後保留彈性：「未來 24–72 小時是關鍵期。」
- ❌「會沒事的」 ✅「我們會盡全力」

### 13. CPR 進行中告知

1. 帶到諮詢室、確認身分
2. 「○○ 現在心跳停止，我們正在急救。」簡述多久、做了什麼
3. 詢問有無 DNR 或預立醫療決定、過去病史
4. **詢問家屬是否想在場陪伴急救**（family-witnessed resuscitation，研究顯示有助哀悼），讓家屬選擇

### 14. 急診 DNR 討論

- 先評估：「您覺得他現在最重要的是什麼？他以前有沒有提過萬一的時候希望怎麼做？」
- 說明選擇：「我們可以繼續積極治療（壓胸、插管、升壓藥），目標是延長生命；或轉為舒適照顧，目標是不痛苦地走完最後一段。」
- 「即使選擇 DNR，我們不會停止照顧，止痛和關懷都會繼續。」
- **避免**：❌「我們無能為力了」❌「要不要急救？」❌「不簽是浪費醫療資源」
- 最近親屬順序與病主法細節見〈內科篇〉。

### 15. 死亡告知

- **準備**：家屬到齊（避免重複講）、私密空間、衛生紙、確認病人姓名與死亡時間。
- **腳本**：
  > 「○太太，您先請坐⋯您先生今天下午 3 點送到急診時，已經沒有呼吸心跳。（停頓）我們立刻急救，給氧氣、心臟按摩、電擊，做了所有能做的努力。（停頓）但是非常遺憾，他的心跳沒有恢復，我們在 3 點 45 分宣告他過世了。（停頓，不要急著填補沉默）」
- **用明確的詞**：「過世」「死亡」「離開了」；避免「沒救回來」「失敗了」等模糊說法。
- **禁忌語**：❌「他走得很安詳」❌「至少他不痛了」❌「我了解您的感受」❌「節哀順變」❌「您要堅強」
- **可以說**：「我無法想像這對您有多難。」「您不需要堅強。」「您現在需要什麼？我們可以怎麼幫您？」
- **後續**（情緒稍緩再談）：看遺體、相驗/解剖、殯葬（社工協助）、器官捐贈（符合條件時）。

## 第四部分：困難家屬

### 16. 憤怒家屬（NURSE）

- **N**aming：「您現在看起來非常生氣、擔心⋯」
- **U**nderstanding：「換作是我也會很急。」
- **R**especting：「您這麼關心家人，很重要。」
- **S**upporting：「我會跟您一起面對。」
- **E**xploring：「可以多告訴我您的擔心嗎？」
- **技巧**：坐下平視、放慢語速、不打斷、不辯解；必要時請主管或保全支援。
- **範例**：「等了三小時！」→ ❌「我們真的很忙」 ✅「三小時對擔心家人的您一定非常難熬，等待中沒人即時告訴您狀況，是我們要改進的。我現在來詳細說明⋯」

### 17. 拒絕治療 / 自動出院

1. 評估**決定能力**；家屬與病人意見是否一致
2. 探索原因（怕痛、宗教、經濟、誤解）：「我尊重您不想插管的決定，可以告訴我您的考量嗎？」
3. 完整告知不治療的風險（包括死亡）
4. 找折衷：如「限時嘗試」插管
5. 書面記錄、簽署拒絕同意書；告知隨時可回來

### 18. 質疑醫療處置

- 「您這個問題很重要，我能理解您想多一份保險的心情。我先說明目前診斷的依據，若仍有疑慮可以安排會診。」
- 絕不說「我是醫師我說了算」。

### 19. 醫療糾紛苗頭

- 承接痛苦：「我了解您現在非常痛苦、憤怒。」
- 不當下認錯也不否認到底；詳實記錄；通知主管、社工、關懷小組
- 可說明醫療爭議調解等正式管道

## 第五部分：急診知情同意

### 同意四要素

1. **處置內容**：白話說明與必要性
2. **風險**：常見 + 嚴重（含死亡風險）
3. **好處**：預期效果，不保證
4. **替代方案**：其他選項 + 不做的自然病程

### 簽署

- 病人本人（成年、有意識）優先；無法表達時由法定代理人、配偶、親屬或關係人簽署（醫療法第 63 條）。
- **情況緊急**：為搶救生命可先行處置，事後詳實記錄理由。
- **未成年**：原則需法定代理人；緊急時可逕行處置。
