# 神經解剖學

---

## 一、神經系統總論

### 1.1 神經系統組成

- **中樞神經系統（CNS）**：腦（Brain）+ 脊髓（Spinal cord）
- **周邊神經系統（PNS）**：腦神經（12 對）+ 脊神經（31 對）+ 自主神經（ANS）

### 1.2 神經膠質細胞（Neuroglia）

| 細胞 | 位置 | 功能 | 病理 |
|------|------|------|------|
| **Astrocyte** | CNS | 血腦障壁（BBB）組成、K⁺ 緩衝、代謝支持、疤痕形成（gliosis） | 反應性星狀膠質增生（reactive gliosis）；Glioblastoma（GBM） |
| **Oligodendrocyte** | CNS | **CNS 髓鞘形成**（一個細胞可包覆多段軸突） | 多發性硬化症（MS）→ 脫髓鞘；Progressive multifocal leukoencephalopathy（PML, JC virus） |
| **Microglia** | CNS | 吞噬、免疫防禦（CNS 的巨噬細胞）→ 來自 **骨髓單核球系** | HIV encephalitis → multinucleated giant cells |
| **Ependymal cells** | CNS（腦室/中央管內襯） | CSF 循環、纖毛推動 | Ependymoma（兒童第4腦室） |
| **Schwann cell** | **PNS** | **PNS 髓鞘形成**（一個細胞只包覆一段軸突） | Schwannoma（如 Vestibular schwannoma = Acoustic neuroma，CN VIII）；Guillain-Barré syndrome（GBS）→ PNS 脫髓鞘 |
| **Satellite cell** | PNS（背根神經節） | 支持感覺神經元 | — |

### 1.3 血腦障壁（Blood-Brain Barrier, BBB）

- 由 **腦毛細血管內皮 tight junctions** + Astrocyte foot processes + Pericytes 構成
- BBB 不完整的區域（**Circumventricular organs**）：可直接感受血液中的化學物質
    - **Area postrema**（嘔吐中樞 chemoreceptor trigger zone）
    - Median eminence（下視丘分泌 releasing hormones 處）
    - Neurohypophysis（後腦垂體）
    - Pineal gland
    - OVLT（Organum vasculosum of lamina terminalis）→ 發燒的 prostaglandin 感測
    - Subfornical organ → 渴覺
- **BBB 通透性增加**：發炎（腦膜炎）、腫瘤、缺血

## 二、脊髓（Spinal Cord）

### 2.1 脊髓橫切面結構

- **灰質（Gray matter）**：H 型，位於中央
    - **前角（Anterior/Ventral horn）**：**α-motor neurons（LMN）** → 支配骨骼肌
    - **側角（Lateral horn）**：T1-L2 → **交感神經** preganglionic neurons；S2-S4 → **副交感神經**
    - **後角（Posterior/Dorsal horn）**：感覺神經接受 → **Substantia gelatinosa（Rexed lamina II）** 處理痛溫覺
- **白質（White matter）**：外圍，含上行/下行傳導路徑
    - **後柱（Dorsal/Posterior column）**：精細觸覺、振動覺、本體感覺
    - **側柱（Lateral column）**：皮質脊髓束（Lateral corticospinal tract）、脊髓丘腦束（Lateral spinothalamic tract）
    - **前柱（Anterior column）**：Anterior corticospinal tract、Anterior spinothalamic tract（粗觸覺）

### 2.2 上行傳導路徑（Ascending Tracts）

#### 後柱-內側蹄系路徑（Dorsal Column-Medial Lemniscus Pathway, DCML）

- **傳遞**：精細觸覺（fine touch）、振動覺（vibration）、本體感覺（proprioception）、兩點辨別（two-point discrimination）
- **路徑**：
    1. **一級神經元**：周邊感覺受器 → 脊髓後角 → 進入 **同側後柱（Dorsal column）** 上行
        - T6 以下 → **Fasciculus gracilis（薄束）**（內側）
        - T6 以上（含上肢）→ **Fasciculus cuneatus（楔束）**（外側）
    2. **二級神經元**：在 **延腦（Medulla）** 的 **Nucleus gracilis / Nucleus cuneatus** 換神經元 → **交叉至對側（internal arcuate fibers → sensory decussation）** → 形成 **Medial lemniscus** 上行
    3. **三級神經元**：在 **Thalamus（VPL nucleus）** 換神經元 → 經 posterior limb of internal capsule → **Primary somatosensory cortex（S1, Brodmann 3,1,2）**
- **損傷特徵**：**同側精細觸覺/振動覺/本體感覺消失**（在延腦交叉之前的損傷 → 同側；交叉之後 → 對側）

#### 脊髓丘腦路徑（Spinothalamic Tract）

- **傳遞**：痛覺（pain）、溫度覺（temperature）（Lateral spinothalamic tract）；粗觸覺（crude touch）、壓覺（Anterior spinothalamic tract）
- **路徑**：
    1. **一級神經元**：周邊感覺受器 → 脊髓後角 → 在 **脊髓同一節段或上下1-2節段** 的後角換神經元
    2. **二級神經元**：在後角換元後 → **立即在脊髓前連合（anterior white commissure）交叉至對側** → 進入 **對側側柱** 上行
    3. **三級神經元**：在 **Thalamus（VPL nucleus）** 換神經元 → 到 S1
- **損傷特徵**：**對側（損傷平面以下 1-2 節段）痛溫覺消失**
- **對比 DCML**：Spinothalamic tract 在脊髓即交叉 → 損傷對側；DCML 在延腦才交叉 → 損傷同側

#### 脊髓小腦路徑（Spinocerebellar Tracts）

- **傳遞**：**無意識本體感覺** → 到小腦（不到大腦皮質，不產生意識感覺）
- **Posterior spinocerebellar tract**：同側，下肢本體感覺 → 經 inferior cerebellar peduncle 入小腦
- **Anterior spinocerebellar tract**：交叉 × 2（一次在脊髓、一次入小腦時）→ 最終同側
- 臨床：小腦性共濟失調（cerebellar ataxia）

### 2.3 下行傳導路徑（Descending Tracts）

#### 皮質脊髓路徑（Corticospinal Tract）

- **功能**：控制隨意運動（voluntary movement），尤其精細肢體動作
- **路徑**：
    1. **Upper Motor Neuron（UMN）**：Primary motor cortex（M1, Brodmann 4）→ Corona radiata → **Posterior limb of internal capsule** → Cerebral peduncle（中腦）→ Basis pontis → 延腦 **Pyramid**
    2. **在延腦-脊髓交界處（Pyramidal decussation）**：**約 85% 交叉至對側** → 形成 **Lateral corticospinal tract**
        - 未交叉 15% → Anterior corticospinal tract → 在脊髓各段再交叉至對側
    3. **Lower Motor Neuron（LMN）**：脊髓前角 → 前根 → 脊神經 → 骨骼肌
- **損傷特徵**：

| | **UMN Lesion** | **LMN Lesion** |
|--|----------------|----------------|
| 肌張力 | **↑（Hypertonia/Spasticity）** | **↓（Hypotonia/Flaccidity）** |
| 反射 | **↑（Hyperreflexia）** | **↓（Hyporeflexia/Areflexia）** |
| 病理反射 | **Babinski sign(+)**（大拇趾上翹 + 其他腳趾外展） | **Babinski(−)** |
| 肌肉萎縮 | 輕度（disuse atrophy） | **明顯（denervation atrophy）** |
| 肌束顫動 | 無 | **Fasciculation（+）** |
| 分佈 | 通常影響肢體整組肌群 | 特定肌肉/肌群（依受損之 nerve root/nerve） |
| Clonus | 可有 | 無 |

### 2.4 脊髓症候群（Spinal Cord Syndromes）

| 症候群 | 損傷範圍 | 臨床表現 | 常見原因 |
|--------|----------|----------|----------|
| **Brown-Séquard syndrome（脊髓半切）** | 一側脊髓 | **同側**：UMN signs（損傷平面以下）+ DCML 喪失（精細觸覺、振動覺、本體感覺）；**對側**：痛溫覺喪失（Spinothalamic，損傷平面以下1-2節段開始） | 刺傷、腫瘤 |
| **Anterior cord syndrome（前脊髓症候群）** | 脊髓前 2/3（前脊髓動脈阻塞） | 雙側：UMN signs + 痛溫覺喪失（Spinothalamic）；**保留**：DCML（精細觸覺、振動覺、本體感覺）→ 後柱由後脊髓動脈供應 | 前脊髓動脈栓塞、主動脈手術併發症 |
| **Central cord syndrome（中央脊髓症候群）** | 脊髓中央（頸髓） | **上肢比下肢更嚴重**（因脊髓丘腦束和皮質脊髓束的 somatotopic organization：上肢纖維在內側/中央）；可有 cape-like 痛溫覺喪失 | 頸椎過伸傷（老人 + 頸椎退化性狹窄）；**Syringomyelia** |
| **Posterior cord syndrome** | 後柱 | 精細觸覺、振動覺、本體感覺喪失 → 感覺性共濟失調（sensory ataxia）；Romberg sign(+) | 維生素 B12 缺乏（subacute combined degeneration）、Tabes dorsalis（梅毒 → 背根/後柱） |
| **Cauda equina syndrome（馬尾症候群）** | L2 以下神經根 | **LMN signs**：下肢弛緩性無力、反射消失、**鞍狀感覺喪失（saddle anesthesia）**、膀胱/腸道功能障礙（urinary retention、fecal incontinence） | 大型腰椎椎間盤突出、腫瘤 |
| **Conus medullaris syndrome** | 脊髓圓錐（S3-S5/Coccygeal segments） | 早期膀胱/腸道/性功能障礙、鞍狀感覺喪失；**下肢運動功能相對保留** | 腫瘤、椎間盤突出 |

### 2.5 Syringomyelia（脊髓空洞症）

- **病理**：脊髓中央管擴大形成空洞（syrinx），最常見於**頸髓**
- **最常合併**：**Arnold-Chiari malformation Type I**（小腦扁桃體下疝）
- **臨床表現**（因空洞最先損傷 **anterior white commissure** → spinothalamic 交叉纖維）：
    - **Cape-like（披肩式）bilateral 痛溫覺喪失**（上肢/肩/上背），但精細觸覺/本體感覺保留（後柱未受損）→ **Dissociated sensory loss**
    - 進展 → 擴展至前角 → **LMN signs（手部肌肉萎縮、肌束顫動）**
    - 再進展 → 側柱 → UMN signs（下肢）
- **Chiari malformations**：
    - **Type I**：小腦扁桃體下疝超過枕骨大孔 > 5mm → 成人；頭痛、syringomyelia
    - **Type II（Arnold-Chiari）**：小腦扁桃體 + 延腦 + 第4腦室下疝 → 兒童；合併 **myelomeningocele**（脊柱裂）+ **hydrocephalus**

### 2.6 Subacute Combined Degeneration（亞急性聯合退化）

- 原因：**Vitamin B12 缺乏**
- 受損結構：**後柱（Dorsal column）** + **側柱的皮質脊髓束（Lateral corticospinal tract）** + 周邊神經
- 臨床：
    - 後柱：振動覺/本體感覺喪失 → **感覺性共濟失調**、Romberg sign(+)
    - 皮質脊髓束：UMN signs → 反射亢進、Babinski(+)
    - 周邊神經：LMN signs → 可能反射消失（LMN 與 UMN 混合表現）
    - 合併巨幼芽球性貧血（megaloblastic anemia）

## 三、腦幹（Brainstem）

### 3.1 腦幹概論

- 由上到下：**中腦（Midbrain）→ 橋腦（Pons）→ 延腦（Medulla oblongata）**
- 每個腦幹段的背側面向 **第4腦室**（橋腦與延腦段）或 **中腦水管（Cerebral aqueduct）**（中腦段）

### 3.2 中腦（Midbrain）

- **背側（Tectum）**：**Superior colliculus**（視覺反射）+ **Inferior colliculus**（聽覺中繼）
- **Cerebral peduncle**：含 corticospinal tract、corticobulbar tract、corticopontine fibers
- **Red nucleus**：接受小腦 input → Rubrospinal tract → 上肢屈肌運動（flexor tone）
- **Substantia nigra**：
    - **Pars compacta**：含多巴胺神經元 → 投射至 Striatum → 損傷 → **Parkinson's disease**
    - **Pars reticulata**：GABAergic → 抑制 thalamus
- **腦神經核**：
    - **CN III（Oculomotor）核**：包括 Edinger-Westphal nucleus（副交感 → 瞳孔收縮、睫狀肌調節）
    - **CN IV（Trochlear）核**：在 inferior colliculus 平面；纖維從背側出腦（唯一）並交叉

#### Weber Syndrome（中腦腹側症候群）

- 損傷部位：中腦 cerebral peduncle（basilar portion）
- 臨床：**同側 CN III palsy**（眼球外下偏 + 瞳孔散大 + 上眼瞼下垂）+ **對側偏癱（UMN signs）**（Corticospinal tract 損傷，尚未交叉）
- 最常見原因：PCA 分支梗塞

#### Benedikt Syndrome

- 損傷部位：中腦 tegmentum（含 Red nucleus + CN III + Medial lemniscus）
- 臨床：同側 CN III palsy + 對側不自主運動（紅核損傷 → tremor/chorea/athetosis）+ 對側深感覺喪失

#### Parinaud Syndrome（背側中腦症候群）

- 損傷部位：Superior colliculus / Pretectal area
- 臨床：**向上凝視麻痺（Upgaze palsy）** + 瞳孔光反射消失（但調節反射保留 → light-near dissociation）+ Convergence-retraction nystagmus
- 常見原因：**松果體腫瘤（Pinealoma）** 壓迫、腦水腫

### 3.3 橋腦（Pons）

- **基底部（Basis pontis）**：Pontine nuclei（皮質橋腦小腦系統的中繼站）、Corticospinal tract 通過
- **被蓋部（Tegmentum）**：腦神經核、網狀結構、Medial lemniscus、上行/下行束
- **腦神經核**：
    - **CN V（Trigeminal）**：Motor nucleus（咀嚼肌）+ Principal sensory nucleus（精細觸覺）+ Mesencephalic nucleus（本體感覺 = 下巴反射傳入）
    - **CN VI（Abducens）核**：在 **facial colliculus** 下方（CN VII 的纖維繞過 CN VI 核 → 形成面丘）
    - **CN VII（Facial）核**：在橋腦下部
    - **CN VIII（Vestibulocochlear）**：Cochlear nuclei + Vestibular nuclei

#### Medial Pontine Syndrome（Foville syndrome 變異）

- 損傷：基底動脈（paramedian branches）→ 橋腦基底部
- 臨床：**同側 CN VI palsy**（lateral rectus palsy → 無法外展）+ **對側偏癱**（corticospinal tract）
- 可合併同側 CN VII palsy（若損傷較廣）

#### Lateral Pontine Syndrome

- 損傷：AICA（前下小腦動脈）阻塞
- 臨床：**同側**：CN V（面部感覺喪失）、CN VII（面癱）、CN VIII（耳聾/眩暈）、Horner syndrome、小腦 ataxia；**對側**：痛溫覺喪失（spinothalamic tract）

#### Facial Nerve Palsy 鑑別

| | **UMN lesion（Central）** | **LMN lesion（Peripheral/Bell's palsy）** |
|--|---------------------------|------------------------------------------|
| 額肌 | **保留**（雙側皮質支配） | **受影響** → 無法皺眉 |
| 下半臉 | 對側下半臉無力 | 同側整側臉無力 |
| 其他 | 通常合併偏癱 | 可合併 hyperacusis（stapedius）、味覺喪失（chorda tympani）、淚液減少（greater petrosal n.）|

- **Bell's palsy**：最常見的急性面癱 → LMN 型 → 同側整臉無力（含額肌）；可能與 HSV-1 reactivation 相關
- **Ramsay Hunt syndrome**：VZV reactivation → CN VII palsy + 耳痛 + 外耳道/耳廓帶狀疱疹

### 3.4 延腦（Medulla Oblongata）

- **重要結構**：
    - **Pyramid**：Corticospinal tract → Pyramidal decussation（85% 交叉至對側）
    - **Inferior olivary nucleus**：接受大腦皮質、紅核 input → 輸出至小腦 → 運動學習
    - **Nucleus gracilis & Nucleus cuneatus**：DCML 二級神經元
    - **Nucleus ambiguus**：CN IX、X、XI 的運動核 → 咽喉肌
    - **Nucleus solitarius（Solitary nucleus/tract）**：味覺（CN VII, IX, X）+ 內臟感覺（baroreceptor, chemoreceptor）
    - **Dorsal motor nucleus of vagus**：CN X 副交感→心肺腸
    - **Hypoglossal nucleus**：CN XII
    - **Vestibular nuclei**（延腦 + 橋腦交界）
    - **Area postrema**：嘔吐化學感受觸發區（無 BBB）
- **生命中樞**：呼吸中樞、心血管中樞位於延腦 → 延腦損傷可致命

#### Lateral Medullary Syndrome（Wallenberg Syndrome）— 最高頻考題之一

- **血管**：**Posterior inferior cerebellar artery（PICA）** 或 **Vertebral artery** 阻塞
- **損傷結構與症狀**：

| 損傷結構 | 症狀 |
|----------|------|
| **Inferior cerebellar peduncle** | **同側小腦性共濟失調**（ataxia, dysmetria） |
| **Vestibular nuclei** | 眩暈（vertigo）、嘔吐、眼震（nystagmus） |
| **Nucleus ambiguus（CN IX, X）** | **同側軟顎/咽喉肌癱瘓** → 吞嚥困難（dysphagia）、聲音嘶啞（hoarseness）、懸雍垂偏向健側 |
| **Spinal trigeminal nucleus（CN V）** | **同側面部痛溫覺喪失** |
| **Spinothalamic tract** | **對側身體痛溫覺喪失** |
| **Descending sympathetic fibers** | **同側 Horner syndrome**（Miosis + Ptosis + Anhidrosis） |

- **特徵**：痛溫覺「交叉性」喪失 → 同側臉 + 對側身體
- **不影響**：Corticospinal tract（位於前方/基底部 → medial medullary syndrome 才影響）→ **不造成偏癱**

#### Medial Medullary Syndrome（Dejerine Syndrome）

- **血管**：Anterior spinal artery 或 Vertebral artery 的 paramedian branches
- **損傷結構與症狀**：

| 損傷結構 | 症狀 |
|----------|------|
| **Pyramid（Corticospinal tract）** | **對側偏癱**（UMN signs） |
| **Medial lemniscus** | **對側精細觸覺/振動覺/本體感覺喪失** |
| **CN XII（Hypoglossal nucleus/nerve）** | **同側舌癱** → 舌頭偏向患側 |

### 3.5 腦幹血管供應總整理

| 區域 | 血管 | 損傷 → 症候群 |
|------|------|---------------|
| **中腦 ventral** | PCA（paramedian branches） | Weber syndrome |
| **中腦 tegmentum** | PCA branches | Benedikt syndrome |
| **中腦 dorsal** | PCA / SCA | Parinaud syndrome |
| **橋腦 medial** | Basilar artery（paramedian） | Medial pontine syndrome |
| **橋腦 lateral** | **AICA** | Lateral pontine syndrome |
| **延腦 lateral** | **PICA / Vertebral a.** | **Wallenberg syndrome** |
| **延腦 medial** | ASA / Vertebral a. paramedian | Dejerine syndrome |

## 四、小腦（Cerebellum）

### 4.1 小腦解剖

- **三個腳（Peduncles）**：
    - **Superior cerebellar peduncle（SCP）**：主要為 **輸出**（efferent）→ 到 Red nucleus、Thalamus（VL nucleus）→ 大腦皮質
    - **Middle cerebellar peduncle（MCP）**：最大 → 接收 **Pontine nuclei 的輸入**（corticopontocerebellar pathway）
    - **Inferior cerebellar peduncle（ICP）**：接收 脊髓小腦束、橄欖小腦束 等輸入
- **三個功能區**：

| 區域 | 結構 | 輸入 | 功能 | 損傷表現 |
|------|------|------|------|----------|
| **Vestibulocerebellum** | **Flocculonodular lobe** | Vestibular nuclei | 平衡、眼球運動 | **軀幹性共濟失調（truncal ataxia）** → 走路搖晃、寬基步態；兒童 → **Medulloblastoma** |
| **Spinocerebellum** | **Vermis + Paravermal zone** | Spinocerebellar tracts | 姿勢、步態（Vermis → 軀幹）；四肢近端協調（Paravermal） | **Vermis**：軀幹 ataxia、步態不穩；**Paravermal**：四肢近端 |
| **Cerebrocerebellum** | **Lateral hemispheres** | Cerebral cortex（via Pontine nuclei → MCP） | **精細動作規劃、協調** | **同側肢體遠端**共濟失調、**意向性震顫（intention tremor）**、辨距困難（dysmetria）、輪替運動困難（dysdiadochokinesia） |

### 4.2 小腦損傷表現

- 小腦損傷 → **同側（Ipsilateral）** 症狀（因 SCP 在中腦上部交叉 → 最終影響同側肢體的上行和下行路徑雙重交叉抵消）
- **DANISH** 口訣：
    - **D**ysdiadochokinesia、Dysmetria
    - **A**taxia（小腦性）
    - **N**ystagmus
    - **I**ntention tremor
    - **S**canning speech（斷續言語）
    - **H**ypotonia

### 4.3 小腦重要腫瘤

| 腫瘤 | 年齡 | 位置 | 特徵 |
|------|------|------|------|
| **Medulloblastoma** | **兒童**（最常見的惡性小兒腦瘤） | **小腦 Vermis / 4th ventricle roof** | 可經 CSF drop metastasis；PNET 類型；Homer-Wright rosettes |
| **Pilocytic astrocytoma** | **兒童** | **小腦半球** | 最常見良性小兒腦瘤；Rosenthal fibers；BRAF fusion；cystic + enhancing nodule（on MRI） |
| **Hemangioblastoma** | 成人 | **小腦半球** | 與 **von Hippel-Lindau disease** 相關；highly vascular；可製造 EPO → polycythemia |

## 五、間腦（Diencephalon）

### 5.1 丘腦（Thalamus）

- **功能**：幾乎所有感覺的中繼站（除嗅覺外）→ 投射至大腦皮質
- **重要核團**：

| 核團 | 輸入 | 輸出/功能 | 臨床 |
|------|------|-----------|------|
| **VPL（Ventral posterolateral）** | 身體感覺（DCML + Spinothalamic） | → S1（Somatosensory cortex） | 丘腦中風 → 對側感覺喪失 |
| **VPM（Ventral posteromedial）** | 面部感覺（Trigeminal lemniscus）+ 味覺（Solitary nucleus） | → S1（臉部區域） | — |
| **VL（Ventral lateral）** | 小腦（via SCP）、基底核 | → M1（Motor cortex） | 損傷 → 運動失調；**DBS 靶點**（tremor） |
| **VA（Ventral anterior）** | 基底核（GPi, SNr） | → Prefrontal cortex、Premotor area | 運動規劃 |
| **LGN（Lateral geniculate nucleus）** | **CN II（Optic tract）** | → **V1（Primary visual cortex）** via **Optic radiation** | 損傷 → 對側同側偏盲（contralateral homonymous hemianopia） |
| **MGN（Medial geniculate nucleus）** | **Inferior colliculus（聽覺路徑）** | → **A1（Primary auditory cortex）** | — |
| **Anterior nucleus** | Mammillary body（via Mammillothalamic tract） | → Cingulate gyrus | **Papez circuit（情緒/記憶）** |
| **Pulvinar** | 多種 | 注意力、語言整合 | — |
| **Mediodorsal（MD）nucleus** | Amygdala、Prefrontal cortex | → Prefrontal cortex | 損傷 → 人格改變 |

#### Thalamic Syndrome（Dejerine-Roussy Syndrome）

- **損傷**：丘腦 VPL/VPM（通常 PCA 梗塞）
- **臨床**：初期 → 對側全感覺喪失 → 之後恢復期 → **對側嚴重、持續性、燒灼性疼痛**（thalamic pain），對輕觸極度敏感

### 5.2 下視丘（Hypothalamus）

- **功能**：自主神經、內分泌、體溫調節、食慾、渴覺、晝夜節律、情緒
- **重要核團與功能**：

| 核團 | 功能 | 損傷 |
|------|------|------|
| **Suprachiasmatic nucleus** | 晝夜節律（Circadian rhythm）→ 接收視網膜 input | 睡眠-覺醒週期異常 |
| **Supraoptic & Paraventricular nuclei** | 製造 **ADH** 和 **Oxytocin** → 沿軸突運輸至後腦垂體分泌 | **尿崩症（Diabetes insipidus）** |
| **Arcuate nucleus** | 分泌 **Releasing/Inhibiting hormones**（GnRH, GHRH, CRH, TRH, Dopamine, Somatostatin）→ 到前腦垂體 | 影響各軸線 |
| **Ventromedial nucleus** | **飽食中樞（Satiety center）** | 損傷 → **肥胖（obesity）**、暴食 |
| **Lateral hypothalamus** | **飢餓中樞（Hunger center）** → 也與 Orexin 相關 | 損傷 → **厭食（anorexia）**、消瘦 |
| **Anterior hypothalamus** | **散熱中樞** → 副交感功能 | 損傷 → **高熱（hyperthermia）** |
| **Posterior hypothalamus** | **產熱中樞** → 交感功能 | 損傷 → **低溫（hypothermia）**、嗜睡 |
| **Mammillary body** | 記憶迴路（Papez circuit）；接受 fornix 輸入 | **Wernicke encephalopathy**（Thiamine/B1 缺乏）→ 出血性壞死 → confusion, ataxia, ophthalmoplegia |

- 口訣記憶：**Lateral = hunger（Lateral → 少了就 Lean）；Ventromedial = satiety（VM → 少了就 Very Massive）**
- **Anterior = cool（parasympathetic → A/C = Air Conditioning）；Posterior = heat（sympathetic）**

### 5.3 上丘腦（Epithalamus）

- 含 **Pineal gland**（分泌 **Melatonin** → 由 Serotonin 轉化 → 調節晝夜節律）
    - Pinealoma → 壓迫 Superior colliculus → **Parinaud syndrome**
    - Pineal gland 鈣化在影像學上是正常現象（成人）→ 可作為正中線標誌

### 5.4 底丘腦（Subthalamus）

- **Subthalamic nucleus（STN）**：基底核迴路的一部分
    - 功能：Excitatory（glutamate）→ 興奮 GPi → 抑制 thalamus → 抑制不需要的運動
    - **損傷 → 對側 Hemiballismus**（劇烈甩擲樣不自主運動，尤其近端肢體）

## 六、大腦（Cerebrum）

### 6.1 大腦皮質功能區

| 區域 | Brodmann Area | 功能 | 損傷表現 |
|------|---------------|------|----------|
| **Primary motor cortex（M1）** | **4** | 隨意運動 → 對側肢體 | 對側 UMN 偏癱 |
| **Premotor cortex** | **6** | 運動規劃 | 運動起始困難 |
| **Frontal eye field（FEF）** | **8** | 控制對側水平 saccade → 眼球向對側看 | 損傷 → 眼球偏向**患側**（"Eyes look toward the lesion"）；刺激（如癲癇）→ 眼球偏向對側 |
| **Broca's area** | **44, 45** | **表達性語言（Motor speech）** | **Broca's aphasia**：非流暢、理解力保留、知道自己有問題 → frustration |
| **Prefrontal cortex** | 9-12, 46 | 計畫、判斷、人格、社會行為 | 人格改變、判斷力差、社會行為退化 → **Frontal lobe syndrome** |
| **Primary somatosensory cortex（S1）** | **3, 1, 2** | 體感覺 | 對側感覺喪失 |
| **Somatosensory association area** | **5, 7** | 感覺整合 | 無法辨識物體形狀/質地 |
| **Wernicke's area** | **22** | **接受性語言理解（Receptive speech）** | **Wernicke's aphasia**：流暢但無意義（word salad）、理解力差、不自覺有問題 |
| **Angular gyrus** | **39** | 跨感覺整合（視覺→語言） | **Alexia（閱讀障礙）**、Agraphia、Gerstmann syndrome |
| **Primary visual cortex（V1）** | **17** | 視覺 | 對側同側偏盲（homonymous hemianopia）with macular sparing |
| **Visual association cortex** | **18, 19** | 高階視覺處理 | 視覺失認（Visual agnosia） |
| **Primary auditory cortex（A1）** | **41, 42** | 聽覺 | 單側損傷不致全聾（雙側聽覺路徑） |

#### Gerstmann Syndrome

- 損傷：**Dominant（通常左側）Angular gyrus（Brodmann 39）**
- 四大症狀：**Agraphia（書寫障礙）+ Acalculia（計算障礙）+ Finger agnosia（手指辨認障礙）+ Left-right confusion（左右混淆）**

### 6.2 失語症（Aphasia）總整理

| 類型 | 流暢性 | 理解力 | 重述能力 | 損傷位置 |
|------|--------|--------|----------|----------|
| **Broca's（表達性）** | **非流暢** | 保留 | 受損 | **Broca's area（左 inferior frontal gyrus）** |
| **Wernicke's（接受性）** | 流暢（但無意義） | **受損** | 受損 | **Wernicke's area（左 superior temporal gyrus）** |
| **Conduction** | 流暢 | 保留 | **嚴重受損** | **Arcuate fasciculus**（連接 Broca 與 Wernicke） |
| **Global** | 非流暢 | 受損 | 受損 | 大範圍 MCA territory（Broca + Wernicke） |
| **Transcortical motor** | 非流暢 | 保留 | **保留** | Broca 周圍（watershed） |
| **Transcortical sensory** | 流暢 | 受損 | **保留** | Wernicke 周圍（watershed） |

- **重述能力（Repetition）**：**Arcuate fasciculus** 完整 → repetition 保留（Transcortical types）；損傷 → repetition 受損（Broca, Wernicke, Conduction, Global）

### 6.3 大腦半球側化（Lateralization）

- **優勢半球（Dominant hemisphere）**：通常為 **左側**（>95% 右利手、~70% 左利手）
    - 語言（Broca, Wernicke）
    - 計算
    - 分析性思維
- **非優勢半球（Non-dominant，通常右側）**：
    - 空間感知、視覺空間處理
    - 音樂感知
    - 情緒理解（語調、表情）
    - **Hemispatial neglect（半側忽略）**：通常右 parietal lobe 損傷 → **忽視左側空間**

### 6.4 大腦血管供應

#### Willis 環（Circle of Willis）

- **組成**：ACA → ACoA → ACA（前方）；ICA → PCoA → PCA（後方）；連接前後循環
    - **ACoA（前交通動脈）**：最常見的腦動脈瘤位置 → 破裂 → SAH
    - **PCoA（後交通動脈）**：動脈瘤壓迫 → **CN III palsy**（瞳孔散大為首先表現，parasympathetic 在外側先受壓）

#### 大腦動脈供應區域

| 動脈 | 供應區域 | 梗塞表現 |
|------|----------|----------|
| **ACA** | 額葉內側面、頂葉內側面 → 下肢 motor/sensory cortex | **對側下肢** UMN 偏癱 + 感覺喪失；上肢和面部保留 |
| **MCA** | 額葉外側、頂葉外側、顳葉外側 → 上肢 + 面部 motor/sensory cortex；Broca；Wernicke | **對側上肢 + 面部** UMN 偏癱 + 感覺喪失（下肢相對保留）；**優勢半球 → Aphasia**；非優勢半球 → Neglect |
| **PCA** | 枕葉（Visual cortex）、顳葉下內側、丘腦（部分） | **對側同側偏盲（Contralateral homonymous hemianopia）** with **macular sparing**；Thalamic syndrome |
| **Lenticulostriate arteries（MCA 穿通支）** | 基底核（Putamen、Caudate）、Internal capsule | **高血壓性腦出血最常見部位** → 對側偏癱 + 感覺喪失 |
| **Anterior choroidal artery** | Internal capsule（posterior limb）、Optic tract、LGN | 對側偏癱 + 偏身感覺喪失 + 同側偏盲（上象限） |

#### Watershed（分水嶺）區域梗塞

- **ACA/MCA watershed**：額頂葉外上方 → **上肢近端** 無力（"man in a barrel"）
- **MCA/PCA watershed**：頂枕葉交界 → 高階視覺功能障礙
- 原因：全身性低血壓 → 分水嶺區灌流不足

### 6.5 內囊（Internal Capsule）

- **位置**：Thalamus（內側）與 Lentiform nucleus（Putamen + Globus pallidus，外側）之間
- **重要段落**：

| 段 | 通過的纖維 |
|----|------------|
| **Anterior limb** | Frontopontine fibers、Thalamocortical fibers（to prefrontal） |
| **Genu** | **Corticobulbar tract**（面部/咽喉運動） |
| **Posterior limb** | **Corticospinal tract**（肢體運動）、Somatosensory radiations（VPL → S1）、Optic radiation（部分）、Auditory radiation |

- **Lacunar infarct** of internal capsule → **Pure motor hemiparesis**（最常見 lacunar syndrome）

## 七、基底核（Basal Ganglia）

### 7.1 基底核組成

| 結構 | 組成/別名 |
|------|-----------|
| **Caudate nucleus** | 與 Putamen 合稱 **Striatum**（紋狀體）→ 基底核的主要「輸入」站 |
| **Putamen** | 與 Globus pallidus 合稱 **Lentiform nucleus**（豆狀核） |
| **Globus pallidus** | 分為 **GPe（外段）** 和 **GPi（內段）** → GPi 為基底核的主要「輸出」站 |
| **Subthalamic nucleus（STN）** | 位於間腦；興奮性（Glutamate）|
| **Substantia nigra** | 位於中腦；**Pars compacta（SNc）** → Dopamine；**Pars reticulata（SNr）** → GABA（功能類似 GPi） |

### 7.2 基底核迴路（Direct & Indirect Pathway）

#### Direct Pathway（促進運動）

- Cortex → **Striatum**（excited）→ **GPi/SNr**（inhibited, GABA）→ **Thalamus**（disinhibited = activated）→ **Cortex** → Movement **↑**
- Dopamine（from SNc）via **D1 receptor** → **Excites** direct pathway → 促進運動

#### Indirect Pathway（抑制運動）

- Cortex → **Striatum** → **GPe**（inhibited）→ **STN**（disinhibited = activated）→ **GPi/SNr**（excited, Glutamate）→ **Thalamus**（inhibited）→ **Cortex** → Movement **↓**
- Dopamine（from SNc）via **D2 receptor** → **Inhibits** indirect pathway → 減少抑制 → 促進運動

#### 綜合效果

- **Dopamine 整體促進運動** → Dopamine 不足 → 運動減少 → **Parkinson's disease**
- 圖示概念：D1 excites direct（Go pathway），D2 inhibits indirect（removes the brake）→ 雙重促進

### 7.3 基底核疾病

| 疾病 | 病理 | 臨床表現 |
|------|------|----------|
| **Parkinson's disease** | **SNc dopaminergic neurons 退化** → Striatum dopamine↓ → Lewy bodies（α-synuclein） | **TRAP**：**T**remor（resting tremor, pill-rolling）、**R**igidity（cogwheel rigidity）、**A**kinesia/Bradykinesia、**P**ostural instability；Shuffling gait；Masked facies |
| **Huntington's disease** | **Caudate nucleus 萎縮**（GABAergic + cholinergic neurons 退化）→ AD 遺傳、**Chromosome 4** CAG repeat（Huntingtin gene） | **Chorea**（舞蹈症 = 不自主、不規則、快速動作）；**精神症狀/認知退化（dementia）**；**好發 30-50 歲**；MRI → Caudate atrophy → "box-car" ventricles（側腦室前角擴大） |
| **Hemiballismus** | **Contralateral STN 損傷**（通常小血管梗塞） | **對側肢體劇烈甩擲動作**（proximal > distal） |
| **Wilson's disease** | 銅沉積於 **Putamen** + Liver → AR、ATP7B gene（Chromosome 13） | **Parkinsonism/Dystonia** + Wing-beating tremor + 肝硬化 + **Kayser-Fleischer rings**（角膜銅沉積）；↓Ceruloplasmin、↑Urine copper |
| **Chorea（舞蹈症）其他原因** | Sydenham's（Group A Strep/Rheumatic fever 後）；藥物（levodopa 過量）；SLE | 不規則、無目的舞動 |

## 八、邊緣系統（Limbic System）

### 8.1 組成

- **Hippocampus**：記憶（短期 → 長期的鞏固）
- **Amygdala**：情緒（尤其恐懼、攻擊性）、情緒記憶
- **Cingulate gyrus**：情緒表達、動機
- **Mammillary body**：記憶迴路
- **Fornix**：Hippocampus → Mammillary body 的投射纖維
- **Septal nuclei**：獎勵/愉悅

### 8.2 Papez Circuit（情緒-記憶迴路）

- Hippocampus → **Fornix** → **Mammillary body** → **Mammillothalamic tract** → **Anterior nucleus of thalamus** → **Cingulate gyrus** → **Parahippocampal gyrus** → 回到 Hippocampus
- **Mammillary body 損傷** → **Wernicke-Korsakoff syndrome**（Thiamine/B1 缺乏）

### 8.3 Hippocampus 與記憶

- **損傷 → Anterograde amnesia**（無法形成新的長期記憶）
    - **雙側海馬損傷**：最嚴重 → HM patient
    - **Alzheimer's disease**：Entorhinal cortex 和 Hippocampus 最早受影響 → **記憶喪失為首發症狀**
- 海馬的血液供應：**PCA 分支** → 缺血易致記憶障礙
- **Transient Global Amnesia（TGA）**：短暫性雙側海馬缺血 → 突發 anterograde amnesia，通常 < 24 小時完全恢復

### 8.4 Kluver-Bucy Syndrome

- 損傷：**雙側 Amygdala**（bilateral anterior temporal lobectomy）
- 臨床表現：
    - **Hyperorality**（把所有東西放入口中）
    - **Hypersexuality**
    - **Visual agnosia**（Psychic blindness → 無法辨識物體/面孔）
    - **Placidity**（情緒淡漠、無恐懼）
    - **Hypermetamorphosis**（過度探索環境）

## 九、腦室系統與腦脊髓液（Ventricular System & CSF）

### 9.1 腦室系統

- **Lateral ventricles（側腦室）**（2 個，各一）→ **Interventricular foramen（Monro 孔）** → **Third ventricle** → **Cerebral aqueduct（Sylvian aqueduct）** → **Fourth ventricle** → Foramina of **Luschka**（2 lateral）和 **Magendie**（1 medial）→ **Subarachnoid space**
- CSF 在 **Arachnoid granulations（蛛網膜顆粒）** 被吸收回 → **Superior sagittal sinus**（靜脈竇）

### 9.2 CSF 產生

- 由 **Choroid plexus** 產生（位於各腦室內；最多在側腦室）
- 正常成人 CSF 量約 150 mL，每天產生約 500 mL
- 正常 CSF 壓力：70-180 mmH₂O

### 9.3 水腦症（Hydrocephalus）

| 類型 | 機制 | 特徵 |
|------|------|------|
| **Communicating（交通性）** | CSF 吸收障礙（Arachnoid granulations 阻塞）或 CSF 過度產生 | 所有腦室均擴大；原因：SAH 後、腦膜炎後、Choroid plexus papilloma（過度產生） |
| **Non-communicating（阻塞性）** | 腦室系統內阻塞 | 阻塞點上游腦室擴大；原因：**Cerebral aqueduct stenosis**（最常見先天性原因）、腫瘤壓迫第4腦室、Dandy-Walker malformation |
| **Normal pressure hydrocephalus（NPH）** | 慢性交通性水腦 | **Triad：Gait apraxia（步態異常）+ Urinary incontinence + Dementia** → 口訣："**Wet, Wacky, Wobbly**"；好發老年人；治療：VP shunt |
| **Hydrocephalus ex vacuo** | 腦萎縮後，CSF 被動填充 | 不是真正的水腦；腦室和腦溝均擴大 → Alzheimer's disease、aging |

### 9.4 重要阻塞部位與對應疾病

| 阻塞部位 | 擴大的腦室 | 常見原因 |
|----------|------------|----------|
| **Interventricular foramen（Monro 孔）** | 同側 Lateral ventricle | Colloid cyst（第三腦室前部） |
| **Cerebral aqueduct（Sylvian aqueduct）** | 雙側 Lateral ventricles + Third ventricle | 先天性 aqueductal stenosis；Pineal tumor 壓迫 |
| **Fourth ventricle outlets（Luschka/Magendie）** | 所有腦室 | **Dandy-Walker malformation**（posterior fossa cyst + cerebellar vermis hypoplasia + 第4腦室擴大） |

## 十、視覺路徑（Visual Pathway）

### 10.1 視覺路徑解剖

- **Retina** → **Optic nerve（CN II）** → **Optic chiasm** → **Optic tract** → **LGN（Lateral geniculate nucleus, Thalamus）** → **Optic radiation** → **Primary visual cortex（V1, Brodmann 17, Calcarine sulcus）**

### 10.2 Optic Chiasm 交叉規則

- **鼻側（Nasal）** retinal fibers → **交叉** 至對側 → 看到 **顳側（Temporal）** visual field
- **顳側（Temporal）** retinal fibers → **不交叉**，走同側 → 看到 **鼻側（Nasal）** visual field

### 10.3 視野缺損定位

| 損傷部位 | 視野缺損 | 常見原因 |
|----------|----------|----------|
| **Optic nerve（單側）** | **同側全盲（Monocular blindness）** | 視神經炎（MS）、外傷 |
| **Optic chiasm（中央交叉部位）** | **雙側顳側偏盲（Bitemporal hemianopia）** → 隧道視野 | **Pituitary adenoma**（從下方壓迫）、Craniopharyngioma |
| **Optic tract（單側）** | **對側同側偏盲（Contralateral homonymous hemianopia）** | — |
| **LGN** | 對側同側偏盲 | PCA territory stroke |
| **Meyer's loop（Temporal lobe, Optic radiation inferior fibers）** | **對側上象限同側偏盲（Contralateral superior quadrantanopia）** = "Pie in the sky" | Temporal lobectomy |
| **Dorsal optic radiation（Parietal lobe, superior fibers）** | **對側下象限同側偏盲（Contralateral inferior quadrantanopia）** = "Pie on the floor" | Parietal lobe lesion |
| **Primary visual cortex（Occipital lobe）** | 對側同側偏盲 **with macular sparing** | PCA stroke（Macular area 有 MCA collateral 供應） |

### 10.4 瞳孔反射路徑（補充）

- **Light reflex**：Retina → CN II → Pretectal nucleus（midbrain）→ **bilateral** Edinger-Westphal nucleus → CN III → Ciliary ganglion → **Sphincter pupillae（收縮）**
    - Bilateral → 直接反射 + 間接（consensual）反射
- **Accommodation reflex**：Near object → Visual cortex → Pretectal/EW nucleus → CN III → Ciliary muscle（lens 變凸）+ Sphincter pupillae（瞳孔縮小）+ Medial rectus（convergence）
- **Argyll Robertson pupil**：瞳孔對光反射消失，但調節反射保留（"Prostitute's pupil" → accommodates but doesn't react）→ **Neurosyphilis（Tertiary syphilis）**

## 十一、聽覺與前庭路徑（Auditory & Vestibular Pathways）

### 11.1 聽覺路徑

- **Cochlea（Organ of Corti）** → CN VIII（Cochlear division）→ **Cochlear nuclei**（ipsilateral, in Pons-Medulla junction）→ **大部分交叉**（Trapezoid body）→ **Superior olivary complex**（bilateral → 聲源定位）→ **Lateral lemniscus** → **Inferior colliculus**（midbrain）→ **MGN（Medial geniculate nucleus, Thalamus）** → **Auditory cortex（A1, Brodmann 41/42, Heschl's gyrus, Superior temporal gyrus）**
- **雙側投射**：因此 **單側皮質損傷不致全聾**；需雙側損傷才完全喪失聽覺
- **單側感音神經性聽力喪失** → 通常是 CN VIII 或 cochlea 損傷

### 11.2 聽力喪失分類

| | **傳導性（Conductive）** | **感音神經性（Sensorineural）** |
|--|-------------------------|-------------------------------|
| 問題部位 | 外耳/中耳 | 內耳（cochlea）/CN VIII/中樞 |
| 原因 | 中耳炎、耳硬化症（Otosclerosis）、鼓膜穿孔、膽脂瘤 | 噪音損傷、老年性聽損（presbycusis）、Ménière's disease、Acoustic neuroma（CN VIII Schwannoma）、藥物（aminoglycosides、cisplatin、loop diuretics） |
| **Rinne test** | **BC > AC**（abnormal Rinne = negative）→ 骨導 > 氣導 | AC > BC（normal Rinne = positive）→ 但兩者均下降 |
| **Weber test** | **偏向患耳**（lateralizes to affected ear） | **偏向健耳**（lateralizes to unaffected ear） |

### 11.3 前庭系統

- **Semicircular canals**（3 個）：偵測 **角加速度（angular acceleration）** → 旋轉動作
- **Utricle & Saccule**（耳石器官）：偵測 **線性加速度 + 頭部位置（gravity）**
    - Utricle → 水平線性加速
    - Saccule → 垂直線性加速
- **前庭路徑**：CN VIII → Vestibular nuclei（Medulla-Pons junction）→ 投射至小腦（flocculonodular lobe）、MLF、脊髓（vestibulospinal tract）、CN III/IV/VI nuclei
- **Vestibulo-ocular reflex（VOR）**：頭轉右 → 眼球向左代償 → 穩定視覺影像
    - 由 **MLF（Medial longitudinal fasciculus）** 連接 CN VI 核與對側 CN III 核

#### MLF 損傷 → Internuclear Ophthalmoplegia（INO）

- **損傷**：MLF（通常在 Pons）
- **臨床**：側向注視時 → **同側內收眼無法內收** + **對側外展眼 nystagmus**
    - 例：左 MLF 損傷 → 向右看時，左眼無法內收（MR 不動），右眼外展有 nystagmus
    - 會聚（convergence）通常保留
- **最常見原因**：年輕人 → **Multiple sclerosis（MS）**（雙側 INO 高度提示 MS）；老人 → 腦幹梗塞

## 十二、自主神經系統（Autonomic Nervous System, ANS）

### 12.1 交感 vs 副交感

| | **交感神經（Sympathetic）** | **副交感神經（Parasympathetic）** |
|--|---------------------------|--------------------------------|
| 來源 | **T1-L2** 脊髓側角 | **Cranial nerves（III, VII, IX, X）+ S2-S4** |
| 節前纖維 | 短 | **長** |
| 節後纖維 | **長** | 短 |
| 節前神經傳導物質 | **ACh（Nicotinic receptor）** | **ACh（Nicotinic receptor）** |
| 節後神經傳導物質 | **NE（Norepinephrine）**（adrenergic receptors）；汗腺例外 → **ACh（Muscarinic）** | **ACh（Muscarinic receptor）** |
| 神經節 | Paravertebral ganglia（sympathetic chain）、Prevertebral ganglia（celiac, superior/inferior mesenteric） | 在器官附近或器官壁內 |
| 功能 | Fight or Flight | Rest and Digest |

### 12.2 交感神經詳細

- **節前神經元**：T1-L2 lateral horn → 白交通支（White ramus communicans）→ Sympathetic chain
    - 可在同一節段 synapse
    - 可上行或下行至其他節段 synapse
    - 可穿過不 synapse → 到 Prevertebral ganglia synapse
- **重要交感神經節**：
    - **Superior cervical ganglion** → 頭面部交感（瞳孔散大、汗腺、血管）
    - **Stellate ganglion（inferior cervical + T1）** → 上肢
    - **Celiac ganglion** → 前腸器官
    - **Superior mesenteric ganglion** → 中腸器官
    - **Inferior mesenteric ganglion** → 後腸器官
- **Adrenal medulla**：功能等同於交感神經節後神經元 → 由節前纖維直接支配（ACh → Nicotinic）→ 分泌 **Epinephrine（80%）** 和 NE（20%）直接進入血液

### 12.3 副交感神經詳細

| 腦神經 | 神經節 | 支配器官 |
|--------|--------|----------|
| **CN III** | **Ciliary ganglion** | Sphincter pupillae（瞳孔收縮）、Ciliary muscle（調節） |
| **CN VII** | **Pterygopalatine ganglion** | 淚腺、鼻腔黏膜腺體 |
| **CN VII** | **Submandibular ganglion** | Submandibular & Sublingual glands |
| **CN IX** | **Otic ganglion** | **Parotid gland** |
| **CN X** | Ganglia in/near organ walls | 心臟（↓心率）、肺（支氣管收縮）、GI tract（增加蠕動、增加分泌）→ 至 **Splenic flexure（Left colic flexure）** |
| **S2-S4（Pelvic splanchnic n.）** | Ganglia in organ walls | 降結腸、直腸、膀胱（逼尿肌收縮）、生殖器（勃起 → **Point**） |

- 口訣：**Point and Shoot** → **P**arasympathetic = e**r**ection（**P**oint）；**S**ympathetic = ejaculation（**S**hoot）

### 12.4 Horner Syndrome（重複加深）

- **交感通路中斷**（三級神經元任一處）：
    1. **First order（中樞）**：Hypothalamus → 腦幹 → C8-T2 脊髓 intermediolateral column（ciliospinal center of Budge）
        - 原因：Lateral medullary syndrome（Wallenberg）、Syringomyelia
    2. **Second order（節前）**：C8-T2 → Superior cervical ganglion
        - 原因：**Pancoast tumor（肺尖腫瘤）**、頸部手術（thyroidectomy）、外傷
    3. **Third order（節後）**：Superior cervical ganglion → 沿 Internal carotid artery → 到眼
        - 原因：**Carotid artery dissection**、Cavernous sinus lesion、Cluster headache
- **臨床三聯征**：**Miosis（瞳孔縮小）+ Ptosis（輕度上眼瞼下垂，Müller muscle 失能）+ Anhidrosis（同側面部無汗，視損傷層級而異）**
    - Enophthalmos（眼球凹陷，臨床上微小）

## 十三、腦膜與腦血管

### 13.1 腦膜

- **Dura mater（硬腦膜）**：最外層、最厚、最強韌
    - **Periosteal layer**（外層）+ **Meningeal layer**（內層）
    - 兩層之間分離處形成 **靜脈竇（Dural venous sinuses）**
    - 重要 dural folds：
        - **Falx cerebri**：分隔左右大腦半球；附於 crista galli 前方 → Superior sagittal sinus（上緣）+ Inferior sagittal sinus（下緣游離）
        - **Tentorium cerebelli**：分隔大腦（幕上）與小腦（幕下）；Tentorial notch/incisura → **腦疝（Transtentorial herniation）** 時 CN III 受壓
        - **Falx cerebelli**：分隔小腦兩半球
- **Arachnoid mater（蛛網膜）**：薄、無血管
    - **Arachnoid granulations**：吸收 CSF → Superior sagittal sinus
- **Pia mater（軟膜）**：薄、緊貼腦/脊髓表面、有血管

### 13.2 腦疝（Brain Herniation）

| 類型 | 結構位移 | 臨床表現 |
|------|----------|----------|
| **Uncal herniation（顳葉鉤回疝）** | Medial temporal lobe（uncus）向內下壓迫 → 通過 Tentorial notch | **同側 CN III palsy**（瞳孔散大 → "blown pupil"）→ 同側後大腦動脈壓迫 → 對側同側偏盲 → 壓迫同側 cerebral peduncle → **對側偏癱**；Kernohan notch → 同側偏癱（False localizing sign）|
| **Subfalcine（Cingulate）herniation** | Cingulate gyrus 被推到 Falx cerebri 下方 | **ACA 壓迫** → 對側下肢無力 |
| **Tonsillar herniation** | 小腦扁桃體 → 通過 Foramen magnum | **壓迫延腦** → 呼吸/心血管中樞衰竭 → **致命** → Cushing triad（Hypertension + Bradycardia + Irregular respiration） |
| **Central（Transtentorial downward）** | 腦幹向下移位 | 逐漸意識喪失 → Duret hemorrhages（腦幹出血）→ 致命 |

### 13.3 靜脈竇（Dural Venous Sinuses）

| 靜脈竇 | 位置 | 引流 |
|--------|------|------|
| **Superior sagittal sinus** | Falx cerebri 上緣 | 接收 CSF（via arachnoid granulations）+ 大腦上表面靜脈 → Confluence of sinuses |
| **Inferior sagittal sinus** | Falx cerebri 下緣（游離緣） | → Great cerebral vein（of Galen）合併 → **Straight sinus** |
| **Straight sinus** | — | → Confluence of sinuses |
| **Transverse sinus** | Tentorium cerebelli 後緣 | → **Sigmoid sinus** → **Internal jugular vein** |
| **Cavernous sinus** | 蝶鞍兩側 | 接收 Superior/Inferior ophthalmic v.、Superficial middle cerebral v.；經 Superior/Inferior petrosal sinus 引流 |

- **Cavernous sinus thrombosis**：
    - 原因：Face infection（尤其 "**Danger triangle**" = 鼻與上唇區域 → 靜脈無瓣膜 → 逆流至 cavernous sinus）
    - 臨床：發燒、頭痛、眼球突出（proptosis）、CN III/IV/V₁/V₂/VI palsy、眼眶周圍水腫

## 十四、神經遞質與受體（Neurotransmitters & Receptors）

### 14.1 重要神經遞質總整理

| 神經遞質 | 主要來源 | 功能 | 臨床意義 |
|----------|----------|------|----------|
| **Acetylcholine（ACh）** | Basal nucleus of Meynert（前腦）；LMN（前角）；副交感 | 記憶、學習、肌肉收縮 | Alzheimer's（ACh↓ → Cholinesterase inhibitors）；Myasthenia gravis（Anti-AChR Ab）|
| **Dopamine** | **Substantia nigra pars compacta → Striatum**（Nigrostriatal）；VTA → NAc/Frontal（Mesolimbic/Mesocortical）；Arcuate n. → Pituitary（Tuberoinfundibular → 抑制 Prolactin） | 運動、獎勵、動機 | Parkinson's（↓ Nigrostriatal）；Schizophrenia（↑ Mesolimbic）；Antipsychotics（D2 blocker）→ 副作用 EPS、Prolactin↑ |
| **Norepinephrine（NE）** | **Locus coeruleus（Pons）** | 警覺、注意力、交感反應 | Depression（↓）→ SNRIs；PTSD、Anxiety |
| **Serotonin（5-HT）** | **Raphe nuclei（Pons/Medulla）** | 情緒、睡眠、食慾、疼痛調節 | Depression（↓）→ SSRIs；Migraine；Carcinoid syndrome |
| **GABA** | 廣泛分布（interneurons）；Striatum → GPi/SNr | **主要抑制性**神經遞質（CNS） | Seizure（↓）→ Benzodiazepines/Barbiturates 增強 GABA-A；Huntington's（GABA↓ in Striatum） |
| **Glutamate** | 廣泛分布（cortical pyramidal neurons）；STN | **主要興奮性**神經遞質（CNS） | 過度 → excitotoxicity（中風、癲癇）；NMDA receptor |
| **Glycine** | 脊髓 interneurons、腦幹 | **抑制性**（脊髓/腦幹） | Strychnine（Glycine antagonist）→ 痙攣 |
| **Endorphin / Enkephalin** | 下視丘、脊髓後角 | 內源性止痛 | Opioid receptor agonists |
| **Substance P** | 一級感覺神經元（C fibers）→ 脊髓後角 | 痛覺傳遞 | — |

### 14.2 多巴胺通路（Dopamine Pathways）

| 通路 | 起源 → 終點 | 功能 | 臨床 |
|------|-------------|------|------|
| **Nigrostriatal** | SNc → Striatum | 運動控制 | 退化 → **Parkinson's**；D2 blocker → **EPS（Extrapyramidal symptoms）** |
| **Mesolimbic** | VTA → Nucleus accumbens / Limbic | 獎勵、動機、愉悅 | 過度活化 → Schizophrenia（+symptoms）；成癮 |
| **Mesocortical** | VTA → Prefrontal cortex | 認知、動機、情感 | 低活性 → Schizophrenia（−symptoms：情感平淡、社交退縮） |
| **Tuberoinfundibular** | Arcuate nucleus → Median eminence / Pituitary | **抑制 Prolactin 分泌** | D2 blocker → Prolactin↑ → Galactorrhea、Amenorrhea |

## 十五、特殊感覺路徑補充

### 15.1 嗅覺路徑

- **嗅覺神經元**（位於鼻腔上部嗅上皮）→ 穿過 **Cribriform plate** → **Olfactory bulb** → **Olfactory tract** → 直接到 **Primary olfactory cortex（Piriform cortex, Temporal lobe）**
- **唯一不經過 Thalamus** 的感覺
- **Anosmia（嗅覺喪失）**：Cribriform plate 骨折（前顱窩骨折）→ CN I 撕裂；Olfactory groove meningioma；Kallmann syndrome（GnRH 缺乏 + anosmia）
- **Foster-Kennedy syndrome**：Olfactory groove meningioma → 同側 anosmia + 同側視神經萎縮（壓迫）+ 對側視乳頭水腫（顱內壓升高）

### 15.2 味覺路徑

- **舌前 2/3**：CN VII（Chorda tympani）→ Solitary nucleus
- **舌後 1/3**：CN IX → Solitary nucleus
- **Epiglottis**：CN X → Solitary nucleus
- **Solitary nucleus** → **VPM（Thalamus）** → **Gustatory cortex（Insular cortex, Frontal operculum）**

## 十六、神經血管臨床整合

### 16.1 中風定位速查

| 臨床表現 | 最可能的血管 |
|----------|-------------|
| 對側上肢 + 面部偏癱 > 下肢；Aphasia（左側）/ Neglect（右側） | **MCA** |
| 對側下肢偏癱 > 上肢 | **ACA** |
| 對側同側偏盲 with macular sparing；Thalamic syndrome | **PCA** |
| Pure motor hemiparesis（偏癱但無感覺異常） | **Lenticulostriate arteries**（Lacunar infarct → Internal capsule/Basal ganglia） |
| Wallenberg syndrome（交叉性痛溫覺喪失 + 吞嚥困難 + Horner） | **PICA / Vertebral a.** |
| Locked-in syndrome（意識清楚但除垂直眼動和眨眼外全身癱瘓） | **Basilar artery**（ventral pons infarct） |
| 眩暈 + 同側聽力喪失 + 同側面癱 + 小腦 ataxia | **AICA** |
| 同側小腦 ataxia（肢體 > 軀幹） | **SCA** |

### 16.2 顱內壓升高（Raised ICP）

- **症狀**：頭痛（晨間加重、咳嗽/用力時惡化）、嘔吐（噴射狀）、視乳頭水腫（papilledema）、意識改變
- **Cushing reflex/triad**：**Hypertension（Systolic↑）+ Bradycardia + Irregular respiration** → 腦幹壓迫的晚期徵象 → 即將腦疝
- **CN VI palsy**：顱內壓升高時常見的「假性定位徵象」（false localizing sign）→ 因 CN VI 走行最長，易受牽拉
