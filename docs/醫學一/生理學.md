## 一、細胞生理學（Cell Physiology）

### 1.1 細胞膜與物質運輸

- **細胞膜結構**：磷脂雙層（fluid mosaic model）+ 膽固醇（調節膜流動性）+ 蛋白質（通道、載體、受體、酶）
- **物質運輸方式**：

| 類型 | 機制 | 特色 | 範例 |
|------|------|------|------|
| **Simple diffusion** | 沿濃度梯度，直接穿過磷脂雙層 | 不耗能、不飽和 | O₂、CO₂、脂溶性分子、steroid hormones |
| **Facilitated diffusion** | 沿濃度梯度，經 carrier 或 channel | 不耗能、可飽和、有專一性 | **GLUT**（glucose transporter）；ion channels |
| **Primary active transport** | 直接消耗 ATP | 逆濃度梯度 | **Na⁺/K⁺-ATPase**（3Na⁺ out / 2K⁺ in）；Ca²⁺-ATPase；H⁺/K⁺-ATPase（胃壁細胞） |
| **Secondary active transport** | 利用 Na⁺ 濃度梯度驅動 | 間接耗能（依賴 Na⁺/K⁺-ATPase 建立梯度） | **SGLT**（Na⁺-glucose symport，小腸/腎 PCT）；Na⁺/Ca²⁺ exchanger（3Na⁺ in / 1Ca²⁺ out） |
| **Osmosis** | 水分子經 aquaporin 沿滲透壓梯度移動 | — | AQP-2（ADH 調控，集尿管） |

- **Na⁺/K⁺-ATPase**：維持細胞內高 K⁺、低 Na⁺；產生電化學梯度；是 **electrogenic pump**（淨排出正電荷 → 貢獻約 -4 mV 至靜止膜電位）
- **Digitalis（毛地黃）**：抑制 Na⁺/K⁺-ATPase → 細胞內 Na⁺↑ → Na⁺/Ca²⁺ exchanger 功能↓ → 細胞內 Ca²⁺↑ → 心肌收縮力↑

### 1.2 靜止膜電位與動作電位

#### 靜止膜電位（Resting Membrane Potential, RMP）

- 數值約 **-70 ~ -90 mV**（細胞內相對為負）
- 主要由 **K⁺ 的平衡電位** 決定（因靜止時膜對 K⁺ 通透性最高）
- **Nernst equation**：E_ion = (61/z) × log([ion]_out / [ion]_in)（37°C）
    - E_K ≈ -90 mV；E_Na ≈ +60 mV；E_Cl ≈ -70 mV
- **Goldman equation**：考慮多種離子的通透性 → 實際 RMP 約 -70 mV（略偏 E_K，因靜止時有少量 Na⁺ 通透）

#### 動作電位（Action Potential）

| 階段 | 機制 | 離子流 |
|------|------|--------|
| **靜止期** | K⁺ leak channel 開放 | K⁺ 外漏 |
| **去極化至閾值（Threshold）** | 膜電位達約 -55 mV | — |
| **快速去極化（Phase 0 / Upstroke）** | **Voltage-gated Na⁺ channel 開放**（快速開、快速關） | Na⁺ 內流 |
| **再極化初期（Phase 1）** | Na⁺ channel 不活化（inactivation gate 關閉）| Na⁺ 內流停止 |
| **再極化（Phase 3）** | **Voltage-gated K⁺ channel 開放**（延遲開） | K⁺ 外流 |
| **過極化（Undershoot）** | K⁺ channel 仍開 → 暫時超過 RMP | K⁺ 外流 |
| **回復** | K⁺ channel 關閉，Na⁺/K⁺-ATPase 恢復梯度 | — |

- **全有全無定律（All-or-none law）**：刺激達閾值 → 完整動作電位；未達閾值 → 無反應
- **不反應期（Refractory Period）**：
    - **Absolute refractory period**：Na⁺ channel 處於 inactivation 狀態 → 任何刺激都無法產生第二個 AP
    - **Relative refractory period**：部分 Na⁺ channel 恢復 → 需**更強刺激**才能產生 AP（振幅正常）

### 1.3 突觸傳遞（Synaptic Transmission）

- **化學突觸**：突觸前膜 AP → Ca²⁺ 內流 → 突觸囊泡與膜融合（exocytosis）→ 神經傳導物質釋放至突觸間隙 → 與突觸後受體結合
- **Excitatory postsynaptic potential（EPSP）**：去極化（如 glutamate → Na⁺ 內流）
- **Inhibitory postsynaptic potential（IPSP）**：過極化（如 GABA → Cl⁻ 內流；glycine → Cl⁻ 內流）
- **Temporal summation**：同一突觸連續釋放 → EPSP 疊加
- **Spatial summation**：多個突觸同時釋放 → EPSP 疊加

### 1.4 骨骼肌收縮（Skeletal Muscle Contraction）

- **Excitation-Contraction Coupling**：
    1. Motor neuron AP → ACh 釋放 → Nicotinic receptor（NMJ）→ **End-plate potential（EPP）** → 肌膜 AP
    2. AP 沿 T-tubule 傳入 → 活化 **dihydropyridine receptor（DHPR, voltage sensor）**
    3. DHPR 機械性開啟 **ryanodine receptor（RyR1）** on **SR**
    4. Ca²⁺ 從 SR 釋出至細胞質
    5. Ca²⁺ 結合 **Troponin C** → Troponin 構形改變 → 移開 Tropomyosin → 暴露 actin 上的 myosin 結合位
    6. **Cross-bridge cycling**：Myosin head 結合 actin → power stroke → ADP/Pi 釋放 → ATP 結合 → myosin 脫離 → ATP 水解 → 回到高能態
    7. **鬆弛**：Ca²⁺-ATPase（**SERCA**）將 Ca²⁺ pump 回 SR → Ca²⁺↓ → Troponin-Tropomyosin 蓋住結合位
- **Rigor mortis**：死後 ATP 耗盡 → myosin 無法從 actin 脫離 → 肌肉僵硬

#### 肌肉力學

| 概念 | 說明 |
|------|------|
| **Motor unit** | 一個 α-motor neuron + 其支配的所有肌纖維；精細動作（眼外肌）→ 小 motor unit |
| **Twitch** | 單一刺激的收縮 |
| **Tetanus** | 連續高頻刺激 → unfused（incomplete）→ fused（complete）tetanus |
| **Length-tension relationship** | 最適長度（optimal overlap of actin-myosin）→ 最大主動張力 |
| **Isometric** | 長度不變，張力改變 |
| **Isotonic** | 張力不變，長度改變 |

#### 肌肉纖維類型

| 特徵 | Type I（慢縮氧化型） | Type IIa（快縮氧化型） | Type IIb（快縮醣酵解型） |
|------|----------------------|------------------------|--------------------------|
| 收縮速度 | 慢 | 快 | 最快 |
| 疲勞 | 不易疲勞 | 中等 | 易疲勞 |
| 代謝 | 有氧 | 有氧+無氧 | 無氧（醣酵解） |
| Myoglobin | 多（紅肌） | 中 | 少（白肌） |
| 粒線體 | 多 | 中 | 少 |

### 1.5 平滑肌收縮

- 無 Troponin 系統
- 機制：Ca²⁺ 結合 **Calmodulin** → 活化 **Myosin Light Chain Kinase（MLCK）** → 磷酸化 myosin light chain → cross-bridge cycling
- 鬆弛：**Myosin Light Chain Phosphatase（MLCP）** 去磷酸化
- Ca²⁺ 來源：SR 釋出（IP₃ pathway）+ 細胞外 Ca²⁺ 經 voltage-gated/receptor-operated Ca²⁺ channel
- **Latch state**：去磷酸化後 myosin 仍附著 actin → 維持低耗能的持續收縮（如血管張力）

## 二、神經生理學（Neurophysiology）

### 2.1 神經纖維分類

| 纖維類型 | 直徑 | 傳導速度 | 功能 |
|----------|------|----------|------|
| **Aα** | 最粗 | **最快**（70-120 m/s） | 骨骼肌運動（α motor neuron）、本體感覺（Ia, Ib afferent） |
| **Aβ** | 粗 | 快 | 觸覺、壓覺 |
| **Aδ** | 細有髓鞘 | 中 | **快痛（sharp, well-localized）**、溫度覺 |
| **B** | 細有髓鞘 | 較慢 | 自主神經節前纖維 |
| **C** | 最細、**無髓鞘** | **最慢**（0.5-2 m/s） | **慢痛（dull, burning, diffuse）**、溫度覺、自主神經節後纖維 |

- **髓鞘（Myelin）的作用**：增加膜電阻、降低膜電容 → **跳躍式傳導（Saltatory conduction）** → 加快傳導速度
    - CNS 髓鞘：**Oligodendrocyte**
    - PNS 髓鞘：**Schwann cell**
- **傳導速度**與**纖維直徑**成正比、與髓鞘化程度成正比
- **局部麻醉藥（Lidocaine）**：阻斷 voltage-gated Na⁺ channel；先阻斷小纖維（C → Aδ → Aβ → Aα），故先失去痛覺

### 2.2 自主神經系統（Autonomic Nervous System, ANS）

#### 交感神經 vs 副交感神經

| 特徵 | **交感神經（Sympathetic）** | **副交感神經（Parasympathetic）** |
|------|---------------------------|----------------------------------|
| 起源 | **T1–L2**（thoracolumbar） | **Craniosacral**（CN III, VII, IX, X + S2-S4） |
| 節前纖維 | 短 | 長 |
| 節後纖維 | 長 | 短 |
| 節前 NT | **ACh**（Nicotinic receptor） | **ACh**（Nicotinic receptor） |
| 節後 NT | **NE**（Norepinephrine） | **ACh**（Muscarinic receptor） |
| 例外 | 汗腺節後 → ACh（muscarinic）；腎上腺髓質 → 直接受節前纖維支配（ACh → 釋放 Epi/NE） | — |

#### 腎上腺素受體（Adrenergic Receptors）

| 受體 | 機制 | 主要功能 |
|------|------|----------|
| **α₁** | Gq → PLC → IP₃ + DAG → Ca²⁺↑ | 血管收縮、瞳孔散大（mydriasis）、泌尿道括約肌收縮、肝醣分解 |
| **α₂** | Gi → cAMP↓ | 抑制 NE 釋放（節前負回饋）、抑制胰島素分泌、血小板聚集 |
| **β₁** | Gs → cAMP↑ | **心率↑、心收縮力↑、傳導速度↑**；腎素分泌↑（JG cells） |
| **β₂** | Gs → cAMP↑ | **支氣管擴張**、血管舒張（骨骼肌）、肝醣分解、子宮鬆弛；被 **Epinephrine** 活化（NE 作用弱） |
| **β₃** | Gs → cAMP↑ | 脂肪分解（lipolysis） |

#### 膽鹼受體（Cholinergic Receptors）

| 受體 | 類型 | 位置 | 功能 |
|------|------|------|------|
| **Nicotinic（Nn）** | Ligand-gated ion channel（Na⁺/K⁺） | 自主神經節、腎上腺髓質 | 節後神經元興奮、Epi/NE 釋放 |
| **Nicotinic（Nm）** | Ligand-gated ion channel | NMJ（神經肌肉接合處） | 骨骼肌收縮 |
| **Muscarinic（M₁）** | Gq → IP₃/DAG | CNS、胃壁細胞 | 胃酸分泌↑ |
| **Muscarinic（M₂）** | Gi → cAMP↓ | **心臟**（SA/AV node） | **心率↓、傳導↓** |
| **Muscarinic（M₃）** | Gq → IP₃/DAG | 平滑肌、腺體 | 支氣管收縮、腸蠕動↑、唾液/淚液分泌↑、瞳孔縮小（miosis）、膀胱逼尿肌收縮 |

#### 各器官的 ANS 作用

| 器官 | 交感神經 | 副交感神經 |
|------|----------|------------|
| **心臟** | HR↑、收縮力↑、傳導↑（β₁） | HR↓、傳導↓（M₂） |
| **血管** | 多數收縮（α₁）；骨骼肌血管舒張（β₂） | 少（主要間接經 NO） |
| **支氣管** | 擴張（β₂） | 收縮（M₃） |
| **瞳孔** | 散大（α₁，radial muscle 收縮） | 縮小（M₃，sphincter muscle 收縮） |
| **睫狀肌** | 鬆弛（看遠） | 收縮（看近，調節） |
| **GI 道** | 蠕動↓、括約肌收縮 | 蠕動↑、括約肌鬆弛 |
| **膀胱** | 逼尿肌鬆弛（β₂）、內括約肌收縮（α₁）→ **儲尿** | 逼尿肌收縮（M₃）、內括約肌鬆弛 → **排尿** |
| **汗腺** | 分泌↑（ACh/Muscarinic，例外！） | — |
| **腎上腺髓質** | Epi（80%）+ NE（20%）釋放 | — |

### 2.3 感覺系統

#### 體感覺路徑

| 路徑 | 傳遞的感覺 | 特色 |
|------|-----------|------|
| **Dorsal Column–Medial Lemniscus（DCML）** | 精細觸覺、振動覺、本體感覺、兩點辨別覺 | 同側上行至**延腦**才交叉（在 nucleus gracilis/cuneatus 換神經元 → 內側蹄系 → 對側 → 丘腦 VPL → 體感覺皮質） |
| **Anterolateral（Spinothalamic）** | **痛覺、溫度覺**、粗觸覺 | 進入脊髓後**在脊髓即交叉**至對側上行 → 丘腦 VPL → 體感覺皮質 |

- **Brown-Séquard syndrome（脊髓半切）**：
    - 病側（ipsilateral）：DCML 損傷 → 精細觸覺/振動覺/本體感覺喪失；UMN sign（corticospinal tract 損傷）
    - 對側（contralateral）：Spinothalamic 損傷 → **痛覺/溫度覺喪失**（比病灶低 1-2 節段開始）
- **Syringomyelia**：脊髓中央管擴大 → 先壓迫前交叉的 spinothalamic fibers → **雙側對稱的痛覺/溫度覺喪失（cape-like distribution）**，但觸覺/本體感覺保留

#### 痛覺生理

- **快痛（First pain）**：Aδ 纖維 → sharp、定位清楚
- **慢痛（Second pain）**：C 纖維 → dull、burning、定位模糊
- **Referred pain（轉移痛）**：內臟痛覺與皮膚感覺在脊髓同一節段匯聚（convergence theory）
    - 心肌梗塞 → 左肩/左臂/下巴痛
    - 膽囊 → 右肩痛（C3-C5，phrenic nerve territory）
    - 闌尾初期 → 臍周痛（T10）
- **Gate control theory**：Aβ（觸覺）纖維活動可在脊髓背角抑制 Aδ/C（痛覺）纖維 → 「搓揉止痛」的基礎
- **Endogenous opioid system**：Enkephalin、β-endorphin、Dynorphin → 作用於 μ/δ/κ 受體 → 抑制痛覺傳遞

### 2.4 運動系統

#### 上運動神經元（UMN） vs 下運動神經元（LMN）

| 特徵 | **UMN 損傷** | **LMN 損傷** |
|------|-------------|-------------|
| 肌張力 | **痙攣性增高（spasticity）** | 降低（flaccid） |
| 反射 | **亢進（hyperreflexia）** | 減弱/消失（hyporeflexia） |
| Babinski sign | **(+)** | (−) |
| 肌肉萎縮 | 輕度（廢用性） | **明顯萎縮** |
| 肌束顫動 | 無 | **Fasciculation(+)** |
| 典型疾病 | 中風、脊髓損傷、MS | 小兒麻痺、ALS（合併UMN+LMN）、周邊神經病變 |

#### 小腦（Cerebellum）

- 功能：運動**協調、平衡、肌肉張力調節、運動學習**
- 損傷表現（**同側**症狀，不交叉）：
    - **Ataxia**（運動失調）
    - **Intention tremor**（動作時震顫，指鼻試驗異常）
    - **Dysdiadochokinesia**（快速交替運動障礙）
    - **Dysmetria**（距離判斷障礙）
    - **Nystagmus**（眼球震顫）
    - **Scanning speech**（斷續式語言）
    - 肌張力**降低**（hypotonia）
- **Cerebellar peduncles**：
    - Superior：主要**輸出**至丘腦/紅核
    - Middle：最大，接收**對側橋腦**（pontine nuclei）的輸入
    - Inferior：接收脊髓/前庭的**輸入**

#### 基底核（Basal Ganglia）

- 組成：Caudate + Putamen（= Striatum）、Globus pallidus（internal GPi / external GPe）、Subthalamic nucleus（STN）、Substantia nigra（SNc/SNr）
- **Direct pathway**（促進運動）：Cortex → Striatum（D₁ receptor）→ 抑制 GPi → 解除對 Thalamus 的抑制 → 運動增加
- **Indirect pathway**（抑制運動）：Cortex → Striatum（D₂ receptor）→ 抑制 GPe → GPe 不抑制 STN → STN 興奮 GPi → GPi 抑制 Thalamus → 運動減少
- **Dopamine 來自 SNc**：
    - 活化 D₁（direct pathway）→ 促進運動
    - 抑制 D₂（indirect pathway）→ 也是促進運動
    - → Dopamine 整體效果：**促進運動**

| 疾病 | 病因 | 臨床 |
|------|------|------|
| **Parkinson's disease** | **SNc dopamine neuron 退化** → dopamine↓ | **Resting tremor（pill-rolling）**、Rigidity（cogwheel）、Bradykinesia、Postural instability |
| **Huntington's disease** | Striatum（caudate）退化 → GABA neuron↓ → indirect pathway↓ | **Chorea**（不自主舞蹈動作）、dementia、AD 遺傳（CAG repeat） |
| **Hemiballismus** | 對側 STN 損傷 → indirect pathway↓ | 對側肢體大幅度投擲動作 |

### 2.5 腦幹反射與高階功能

#### 腦神經重點

| 腦神經 | 功能 | 臨床重點 |
|--------|------|----------|
| **CN II** | 視覺 | Afferent limb of pupillary light reflex |
| **CN III** | 眼球運動（上/下/內直肌、下斜肌）、提上瞼肌、瞳孔縮小（副交感） | CN III palsy：ptosis + 眼球外下偏（down and out）+ mydriasis |
| **CN V** | 三叉：感覺（V₁V₂V₃）+ 咀嚼肌運動 | Afferent of corneal reflex |
| **CN VII** | 面部表情肌、味覺前 2/3、淚腺/唾液腺分泌 | Efferent of corneal reflex；UMN vs LMN facial palsy（前額是否受影響） |
| **CN VIII** | 聽覺、前庭功能 | Weber / Rinne test |
| **CN IX** | 咽部感覺、味覺後 1/3 | Afferent of gag reflex |
| **CN X** | 迷走：咽喉運動、副交感至胸腹臟器 | Efferent of gag reflex；Recurrent laryngeal nerve → 聲帶 |
| **CN XII** | 舌肌運動 | 損傷 → 舌偏向病側 |

#### 腦波（EEG）與睡眠

| 波型 | 頻率 | 狀態 |
|------|------|------|
| **β 波** | 最快（>13 Hz） | 清醒、專注、張眼 |
| **α 波** | 8-13 Hz | 清醒、放鬆、**閉眼** |
| **θ 波** | 4-7 Hz | 淺睡（Stage 1-2 NREM） |
| **δ 波** | 最慢（<4 Hz） | **深睡（Stage 3 NREM / Slow-wave sleep）** |

| 睡眠階段 | 特徵 |
|----------|------|
| **NREM Stage 1** | 入睡期，θ 波 |
| **NREM Stage 2** | **Sleep spindles** + **K-complexes**；最多佔比 |
| **NREM Stage 3** | **Slow-wave sleep（SWS）**，δ 波；GH 分泌最多；夢遊/夜驚 |
| **REM sleep** | **快速眼動、腦波近似清醒（去同步化）**；肌張力最低（atonia）；**做夢**；Erection；HR/BP 不規則 |

- 睡眠週期約 90 分鐘，一夜 4-6 個週期
- 前半夜：SWS 較多；後半夜：**REM 較多**
- **REM rebound**：REM 剝奪後，補眠時 REM 比例增加

### 2.6 腦脊髓液（CSF）

- 由**脈絡叢（choroid plexus）**（側腦室、第三腦室、第四腦室）產生
- 總量約 150 mL，每日產生約 500 mL（持續循環）
- 流向：側腦室 → interventricular foramen（Monro）→ 第三腦室 → cerebral aqueduct（Sylvius）→ 第四腦室 → foramen of Magendie/Luschka → subarachnoid space → arachnoid granulations（蛛網膜顆粒）→ 吸收入上矢狀竇（venous sinus）
- 功能：保護腦組織（緩衝）、營養、廢物清除
- **CSF vs 血漿**：CSF 的 protein 低、glucose 約血漿 60-70%、Na⁺/Cl⁻ 略高、K⁺ 較低

## 三、心臟生理學（Cardiovascular Physiology）

### 3.1 心肌電生理

#### 心肌動作電位

| 類型 | 細胞 | 特色 |
|------|------|------|
| **快反應細胞** | 心房肌、心室肌、His-Purkinje | Phase 0 靠 **快速 Na⁺ channel**（快速上升）；有明顯 plateau |
| **慢反應細胞** | **SA node、AV node** | Phase 0 靠 **L-type Ca²⁺ channel**（緩慢上升）；**無 Phase 1/2 plateau**；Phase 4 有 **spontaneous diastolic depolarization（自動去極化）** |

##### 快反應動作電位各 Phase

| Phase | 機制 |
|-------|------|
| **Phase 0** | 快速 Na⁺ 內流 → 快速去極化 |
| **Phase 1** | 暫時性 K⁺ 外流（I_to）→ 早期再極化 |
| **Phase 2（Plateau）** | **L-type Ca²⁺ 內流** ≈ K⁺ 外流 → 平衡 → **plateau**（心肌不反應期長的原因） |
| **Phase 3** | K⁺ 外流（I_Kr, I_Ks）>> Ca²⁺ 內流 → 再極化 |
| **Phase 4** | 靜止膜電位穩定（由 K⁺ leak channel 維持） |

##### 慢反應（Pacemaker）動作電位

| Phase | 機制 |
|-------|------|
| **Phase 4（Pacemaker potential）** | **I_f（funny current）**：Na⁺/K⁺ 混合內流 → 緩慢去極化；**T-type Ca²⁺** 也貢獻 |
| **Phase 0** | **L-type Ca²⁺ 內流**（非 Na⁺ channel） |
| **Phase 3** | K⁺ 外流 → 再極化 |

- **SA node 為正常 pacemaker**：自動節律最快（60-100 bpm）
- **Pacemaker hierarchy**：SA node > AV node（40-60 bpm）> His-Purkinje（20-40 bpm）

#### 傳導系統

SA node → atrial muscle → **AV node**（唯一心房至心室的傳導路徑；**傳導最慢** → 允許心房先收縮完畢再傳至心室）→ Bundle of His → left/right bundle branches → Purkinje fibers（**傳導最快**）→ ventricular muscle

#### 心電圖（ECG）基礎

| 波段 | 代表 |
|------|------|
| **P 波** | 心房去極化 |
| **PR interval** | 心房去極化 + **AV node 傳導時間**（正常 0.12-0.20 s） |
| **QRS complex** | **心室去極化**（正常 <0.12 s） |
| **ST segment** | 心室全部去極化（plateau 期） |
| **T 波** | 心室再極化 |
| **QT interval** | 心室去極化 + 再極化（代表心室 AP 總時間）；**QT prolongation → Torsades de Pointes 風險↑** |

### 3.2 心臟週期（Cardiac Cycle）

#### 各期的壓力-容積變化（以左心室為例）

| 時期 | 瓣膜狀態 | 事件 |
|------|----------|------|
| **心房收縮（Atrial systole）** | MV 開、AoV 關 | 心房收縮 → 補充心室充盈最後 15-25%（a wave in JVP）；P 波 |
| **等容收縮期（Isovolumetric contraction）** | **MV 關、AoV 關** | 心室壓力快速上升（容積不變）；**S₁ 心音**（MV+TV 關閉）；c wave in JVP |
| **快速射出期（Rapid ejection）** | MV 關、**AoV 開** | 心室壓超過主動脈壓 → 血液射出；T 波 |
| **緩慢射出期** | MV 關、AoV 開 | 射出速率減緩 |
| **等容舒張期（Isovolumetric relaxation）** | **MV 關、AoV 關** | 心室壓力快速下降（容積不變）；**S₂ 心音**（AoV+PV 關閉） |
| **快速充盈期（Rapid filling）** | **MV 開**、AoV 關 | 心室壓 < 心房壓 → 血液流入心室；**S₃ 心音**（可能）；y descent in JVP |
| **緩慢充盈期（Diastasis）** | MV 開、AoV 關 | 充盈速率減緩 |

#### 心音

| 心音 | 意義 |
|------|------|
| **S₁** | MV + TV 關閉 → 收縮期開始 |
| **S₂** | AoV + PV 關閉 → 舒張期開始；**Physiologic splitting**：吸氣時 → RV 回流↑ → PV 關閉延遲 → A₂P₂ 分裂 |
| **S₃** | 快速充盈期（心室壁振動）→ 年輕人正常，老年人 → **volume overload / HF** |
| **S₄** | 心房收縮期（心房對抗僵硬的心室）→ **diastolic dysfunction / LVH** |

### 3.3 心輸出量（Cardiac Output）

- **CO = HR × SV**（每分鐘心輸出量 = 心率 × 每搏輸出量）
- 正常 CO ≈ 5 L/min
- **Fick principle**：CO = VO₂ /（C_a O₂ − C_v O₂）

#### 前負荷（Preload）、後負荷（Afterload）、收縮力（Contractility）

| 決定因素 | 定義 | 影響 SV |
|----------|------|---------|
| **Preload** | 心室舒張末期容積/壓力（EDV/EDP） | ↑ Preload → ↑ SV（Frank-Starling mechanism） |
| **Afterload** | 心室射血時必須克服的壓力（≈ 動脈壓） | ↑ Afterload → ↓ SV |
| **Contractility** | 心肌內在收縮能力（與 preload/afterload 無關） | ↑ Contractility → ↑ SV（curve 左上移） |

- **Frank-Starling law**：在生理範圍內，EDV↑ → 肌小節拉伸 → 收縮力↑ → SV↑
- 增加 contractility 的因素：Catecholamine（β₁）、Digitalis、Ca²⁺
- 減少 contractility 的因素：Heart failure、β-blocker、CCB、acidosis、hypoxia

#### 壓力–容積環（Pressure-Volume Loop）

| 改變 | Loop 變化 |
|------|-----------|
| ↑ Preload | 右移（EDV↑），SV↑ |
| ↑ Afterload | 左移（ESV↑），SV↓；ESPVR 不變 |
| ↑ Contractility | ESPVR 左上移 → ESV↓ → SV↑ |

### 3.4 血壓與血流動力學

- **MAP = CO × TPR**（平均動脈壓 = 心輸出量 × 總周邊血管阻力）
- **MAP ≈ Diastolic BP + 1/3 × Pulse Pressure**（PP = SBP − DBP）
- **Poiseuille's law**：Q = ΔP × π × r⁴ / (8ηL) → 血管半徑（r）是最重要的決定因素，且為四次方關係
- **Arterioles**：調節 TPR 的主要部位（最大阻力）
- **Capillaries**：交換的主要部位；血流速度最慢（截面積最大）
- **Veins**：容量血管（capacitance vessels），儲存 60-70% 血液

#### 壓力感受器反射（Baroreceptor Reflex）

- 位於 **carotid sinus（CN IX, glossopharyngeal）** 和 **aortic arch（CN X, vagus）**
- 感受血管壁張力（stretch）→ 反映血壓
- **BP↑** → baroreceptor 活化 → 傳入 NTS（nucleus tractus solitarius）→ ↑ vagal tone + ↓ sympathetic → HR↓ + CO↓ + TPR↓ → BP↓
- **BP↓** → baroreceptor 活性↓ → ↓ vagal + ↑ sympathetic → HR↑ + CO↑ + TPR↑ + venoconstriction（preload↑） → BP↑
- **Carotid sinus massage**：模擬 BP↑ → 反射性 HR↓（用於 SVT）
- **Carotid body**：化學感受器 → 偵測 PaO₂↓、PaCO₂↑、pH↓ → 增加呼吸驅動

#### 微循環與 Starling Forces

- **Capillary exchange** 由四個力量決定（Starling equation）：
    - **P_c（capillary hydrostatic pressure）**：推水出去
    - **P_i（interstitial hydrostatic pressure）**：推水進來（通常很小或微負）
    - **π_c（capillary oncotic pressure）**：拉水回來（主要由 **albumin** 提供）
    - **π_i（interstitial oncotic pressure）**：拉水出去
- **Net filtration pressure = (P_c − P_i) − (π_c − π_i)**
- **Arteriolar end**：P_c > π_c → 濾出
- **Venular end**：P_c < π_c → 回收
- **水腫原因**：P_c↑（心衰竭）、π_c↓（低白蛋白，如 nephrotic syndrome、肝硬化）、淋巴回流阻塞、微血管通透性↑（發炎）

### 3.5 特殊循環

| 循環 | 特色 |
|------|------|
| **冠狀循環** | 左冠脈血流主要在**舒張期**（收縮期心肌壓迫冠脈）；代謝性調節為主（adenosine 為最重要的冠脈擴張物質）；O₂ 攝取率最高 |
| **腦循環** | **Autoregulation** 維持恆定血流（MAP 60-150 mmHg）；**PaCO₂ 是最強的調節因子**：CO₂↑ → 血管擴張 → CBF↑ |
| **肺循環** | 低壓系統；**Hypoxic pulmonary vasoconstriction（HPV）**：肺泡 PO₂↓ → 肺血管**收縮**（全身循環相反！）→ V/Q matching |
| **腎循環** | Autoregulation（MAP 80-180 mmHg）；Afferent/efferent arterioles 調控 GFR |
| **胎兒循環** | 高肺血管阻力；卵圓孔（foramen ovale）、動脈導管（ductus arteriosus）、靜脈導管（ductus venosus）分流 |

## 四、呼吸生理學（Respiratory Physiology）

### 4.1 肺容積與肺容量

| 容積 | 定義 | 備註 |
|------|------|------|
| **Tidal Volume（TV）** | 平靜呼吸時每次吸入/呼出的量 | ≈ 500 mL |
| **Inspiratory Reserve Volume（IRV）** | 平靜吸氣後再用力吸入的量 | — |
| **Expiratory Reserve Volume（ERV）** | 平靜呼氣後再用力呼出的量 | — |
| **Residual Volume（RV）** | 最大呼氣後仍留在肺內的量 | **無法用 spirometry 測量** → 用 **Body plethysmography** 或 **Helium dilution** |

| 容量 | 組成 |
|------|------|
| **Inspiratory Capacity（IC）** | TV + IRV |
| **Functional Residual Capacity（FRC）** | ERV + RV → 平靜呼氣末肺內殘餘量（胸壁外彈力 = 肺內彈力的平衡點） |
| **Vital Capacity（VC）** | TV + IRV + ERV |
| **Total Lung Capacity（TLC）** | VC + RV |

#### 阻塞型 vs 限制型肺疾病

| | **Obstructive** | **Restrictive** |
|--|----------------|-----------------|
| 疾病 | COPD（emphysema, chronic bronchitis）、Asthma | ILD（pulmonary fibrosis）、chest wall 疾病、neuromuscular 疾病 |
| FEV₁ | ↓↓ | ↓ |
| FVC | ↓ 或正常 | ↓↓ |
| **FEV₁/FVC** | **↓（<0.7）** | **正常或↑** |
| RV | ↑（air trapping） | ↓ |
| TLC | ↑（hyperinflation） | ↓ |

### 4.2 呼吸力學

#### 肺的彈性回縮力（Elastic Recoil）

- **Compliance（順應性）= ΔV / ΔP**
    - Compliance↑：肺容易擴張（如 emphysema → 彈性蛋白破壞）
    - Compliance↓：肺不易擴張（如 fibrosis、ARDS、pulmonary edema）
- **Surface tension**（由 alveolar fluid-air interface 產生）是肺回縮力的主要來源
- **Surfactant**（由 **Type II pneumocytes** 產生）：
    - 成分：**Dipalmitoylphosphatidylcholine（DPPC / Lecithin）**
    - 功能：降低 surface tension → ↑ compliance → 防止小肺泡塌陷（atelectasis）
    - **LaPlace's law**：P = 2T/r → 小肺泡（r 小）壓力高 → 易塌陷 → Surfactant 在小肺泡密度更高 → 降低 T 更多 → 穩定
    - **Surfactant 不足 → Neonatal Respiratory Distress Syndrome（NRDS）**（早產兒）
    - L/S ratio ≥ 2.0 → 肺成熟

#### 呼吸肌

| 肌肉 | 角色 |
|------|------|
| **Diaphragm** | **最重要的吸氣肌**（C3-C5, phrenic nerve）；收縮時下降 → 胸腔容積↑ → 肺內壓↓ → 空氣流入 |
| External intercostals | 輔助吸氣（提升肋骨） |
| Internal intercostals | 用力呼氣（壓低肋骨） |
| Abdominal muscles | 用力呼氣 |
| **平靜呼氣**：**被動過程**（肺彈性回縮 + 胸壁回復） | — |

#### 呼吸道阻力

- 主要位於**中等大小支氣管**（非最小支氣管 → 因為平行排列後截面積大）
- 副交感（ACh / M₃）→ 支氣管**收縮**
- 交感（Epinephrine / β₂）→ 支氣管**擴張**
- 肺容積↑ → 呼吸道被拉開 → 阻力↓

### 4.3 氣體交換

#### 死腔（Dead Space）

| 類型 | 定義 |
|------|------|
| **Anatomical dead space** | 傳導區（鼻腔至終末細支氣管）的容積，不參與氣體交換 ≈ 150 mL |
| **Physiological dead space** | Anatomical + **Alveolar dead space**（有通氣但無灌流的肺泡）；健康人 ≈ anatomical |

- **Bohr equation**：V_D / V_T = (PaCO₂ − PECO₂) / PaCO₂

#### 通氣灌流比（V/Q Ratio）

| 情況 | V/Q | 等效 | 範例 |
|------|-----|------|------|
| **Dead space** | ∞（V 有、Q 無） | 通氣正常但無血流 | Pulmonary embolism |
| **Normal** | ≈ 0.8 | 理想匹配 | 正常肺 |
| **Shunt** | 0（V 無、Q 有） | 血流通過但無通氣 | Atelectasis、肺實質化、ARDS |

- **Gravity effect on V/Q**（直立位）：
    - 肺**底部**：灌流多 > 通氣多 → V/Q 較低（≈ 0.6）
    - 肺**頂部**：通氣多 > 灌流多 → V/Q 較高（≈ 3.0）→ **肺結核好發肺尖**（高 PO₂ 環境適合 TB 菌）
    - 整體平均 V/Q ≈ 0.8

#### 氧氣運輸

- **Dissolved O₂**：PaO₂ × 0.003 mL/dL/mmHg → 少量
- **Hemoglobin-bound O₂**：Hb × 1.34 × SaO₂ → 主要形式
- **O₂ content = (Hb × 1.34 × SaO₂) + (0.003 × PaO₂)**

##### 氧合血紅素解離曲線（Oxyhemoglobin Dissociation Curve）

- **Sigmoid shape**：Hb 的 cooperative binding
- **P50**：SaO₂ = 50% 時的 PO₂（正常 ≈ **26.7 mmHg**）

| 右移（P50↑ → O₂ affinity↓ → 更易釋放 O₂ 至組織） | 左移（P50↓ → O₂ affinity↑ → 更不易釋放 O₂） |
|------|------|
| **↑ Temperature** | ↓ Temperature |
| **↑ PaCO₂** | ↓ PaCO₂ |
| **↓ pH（acidosis）**—**Bohr effect** | ↑ pH（alkalosis） |
| **↑ 2,3-DPG** | ↓ 2,3-DPG（stored blood） |
| 運動時、組織代謝旺盛 | CO 中毒（HbCO 左移 + 降低 O₂ 釋放）、**Fetal Hb（HbF）不結合 2,3-DPG → 左移** |

- **Bohr effect**：CO₂↑ / pH↓ → Hb 構形改變 → O₂ 親和力↓ → 組織端 O₂ 釋放↑（生理意義：代謝旺盛處更容易得到 O₂）
- **Haldane effect**：去氧 Hb 攜帶 CO₂ 的能力 > 氧合 Hb（在組織端 Hb 釋放 O₂ 後，更容易結合 CO₂ 帶回肺部）

#### CO₂ 運輸

| 形式 | 比例 | 說明 |
|------|------|------|
| **HCO₃⁻（bicarbonate）** | **~70%** | CO₂ + H₂O → H₂CO₃ → H⁺ + HCO₃⁻（由 RBC 內 **carbonic anhydrase** 催化）；HCO₃⁻ 經 **Cl⁻/HCO₃⁻ exchanger（chloride shift）** 出 RBC |
| **Carbaminohemoglobin** | ~23% | CO₂ 直接結合 Hb 的 amino terminal |
| **Dissolved CO₂** | ~7% | — |

### 4.4 呼吸調控

#### 呼吸中樞

| 中樞 | 位置 | 功能 |
|------|------|------|
| **Medullary respiratory center** | 延腦 | **基本節律產生器**：DRG（吸氣）+ VRG（吸氣+呼氣） |
| **Pneumotaxic center** | 橋腦上部 | **限制吸氣時間** → 調節呼吸頻率；抑制此中樞 → 吸氣延長（apneusis） |
| **Apneustic center** | 橋腦下部 | 促進吸氣 |

#### 化學感受器

| 受體 | 位置 | 刺激 | 特色 |
|------|------|------|------|
| **Central chemoreceptor** | 延腦腹外側 | **CSF 中的 H⁺**（由 CO₂ 擴散進入 CSF → H₂CO₃ → H⁺） | **PaCO₂ 是正常呼吸驅動最重要的刺激**；對 CO₂ 非常敏感 |
| **Peripheral chemoreceptor** | **Carotid body**（CN IX）、Aortic body（CN X） | PaO₂↓、PaCO₂↑、pH↓ | 對 **PaO₂↓** 的主要感受器；PaO₂ < 60 mmHg 才顯著刺激 |

- **COPD 患者**（chronic CO₂ retainer）：中樞對 CO₂ 鈍化 → 呼吸驅動靠 **hypoxic drive**（peripheral chemoreceptor）→ 若給予高濃度 O₂ → 消除 hypoxic drive → 呼吸抑制 → CO₂ narcosis
- **Hering-Breuer reflex**：肺膨脹 → stretch receptor → vagus → 抑制進一步吸氣 → 防止過度膨脹

### 4.5 高海拔與潛水生理

- **高海拔**：大氣壓↓ → PIO₂↓ → PAO₂↓ → PaO₂↓ → **hypoxic ventilatory response**（peripheral chemoreceptor → 過度換氣 → PaCO₂↓ → respiratory alkalosis）
    - 腎臟代償：排 HCO₃⁻ → 代償性 metabolic acidosis
    - Acclimatization：↑ 2,3-DPG → 促進 O₂ 釋放；↑ EPO → polycythemia；↑ capillary density
- **Alveolar gas equation**：PAO₂ = FiO₂ ×（P_atm − P_H₂O）− PaCO₂/R（R ≈ 0.8）
- **A-a gradient（PAO₂ − PaO₂）**：正常 5-15 mmHg
    - A-a gradient 正常的低氧血症：hypoventilation、high altitude
    - A-a gradient 增大：V/Q mismatch、shunt、diffusion impairment

## 五、腎臟生理學（Renal Physiology）

### 5.1 腎血流與腎絲球過濾

- **Renal Blood Flow（RBF）**：≈ 心輸出量的 20-25%（~1200 mL/min）
- **Glomerular Filtration Rate（GFR）**：≈ 125 mL/min（180 L/day）
- **Filtration Fraction（FF）** = GFR / RPF ≈ 20%

#### GFR 的 Starling Forces

- **Net Filtration Pressure = P_GC − P_BC − π_GC**
    - P_GC（glomerular capillary hydrostatic pressure）：促進過濾（≈ 60 mmHg）
    - P_BC（Bowman's capsule hydrostatic pressure）：對抗過濾（≈ 15 mmHg）
    - π_GC（glomerular capillary oncotic pressure）：對抗過濾（≈ 29 mmHg，沿 capillary 逐漸升高）
    - π_BC ≈ 0（正常 filtrate 幾乎無 protein）

#### Autoregulation

- 維持 GFR 和 RBF 恆定（MAP 80-180 mmHg）
- 兩大機制：
    1. **Myogenic mechanism**：血管壁平滑肌感受壓力變化 → 自動收縮/舒張
    2. **Tubuloglomerular feedback（TGF）**：**Macula densa**（位於 thick ascending limb 與 afferent arteriole 交界處的 JGA）感受 distal tubule 中 NaCl 濃度
        - NaCl↑ → adenosine 釋放 → **afferent arteriole 收縮** → GFR↓
        - NaCl↓ → **renin 釋放** → angiotensin II → efferent arteriole 收縮 → GFR 維持

#### Afferent vs Efferent Arteriole 調控

| 變化 | GFR | RPF | FF |
|------|-----|-----|----|
| **Afferent 收縮** | ↓ | ↓ | 不變 |
| **Afferent 擴張** | ↑ | ↑ | 不變 |
| **Efferent 收縮** | ↑ | ↓ | ↑ |
| **Efferent 擴張** | ↓ | ↑ | ↓ |
| **ACEi / ARB** | ↓（efferent 擴張） | ↑ | ↓ |
| **NSAIDs** | ↓（afferent 收縮，因 PG 被抑制） | ↓ | — |

### 5.2 腎小管功能

#### 各段功能摘要

| 節段 | 主要功能 | 特色 |
|------|----------|------|
| **Proximal Convoluted Tubule（PCT）** | **再吸收 65-70% Na⁺、水、HCO₃⁻**；幾乎全部 glucose、amino acids、uric acid | **Isotonic** reabsorption（水跟著走 → osmolality 不變）；**Na⁺/H⁺ exchanger（NHE3）**；SGLT2（glucose）；carbonic anhydrase 回收 HCO₃⁻ |
| **Thin descending limb of Henle** | **水再吸收**（水通透性高）；Na⁺ 不通透 | 小管液濃縮 |
| **Thin ascending limb** | NaCl 被動再吸收；**不通透水** | — |
| **Thick Ascending Limb（TAL）** | **25% Na⁺ 再吸收**；**Na⁺/K⁺/2Cl⁻ cotransporter（NKCC2）** | **不通透水**（diluting segment）→ 小管液變稀；Furosemide 作用點；產生正電位 → paracellular Mg²⁺、Ca²⁺ 再吸收 |
| **Distal Convoluted Tubule（DCT）** | **Na⁺/Cl⁻ cotransporter（NCC）** | **不通透水**；**Thiazide** 作用點；**PTH 促進 Ca²⁺ 再吸收**（TRPV5 channel） |
| **Collecting Duct（CD）** | Na⁺ 再吸收（ENaC）；K⁺ 分泌；H⁺ 分泌 | **Aldosterone** 作用點 → ↑ ENaC → Na⁺ 再吸收↑ / K⁺ 分泌↑；Amiloride / Spironolactone 作用點 |
| **Collecting Duct（medullary CD）** | **ADH 調控水再吸收** | ADH → V₂ receptor → cAMP → **AQP-2** 插入 apical membrane → 水通透性↑ → 尿液濃縮 |

#### 重要轉運體與藥物

| 轉運體 | 位置 | 利尿劑 |
|--------|------|--------|
| **Carbonic anhydrase** | PCT | **Acetazolamide**（CA inhibitor）→ HCO₃⁻ 排出↑ → metabolic acidosis |
| **NKCC2（Na⁺/K⁺/2Cl⁻）** | TAL | **Furosemide（Loop diuretic）** → 最強效利尿；也抑制 Ca²⁺/Mg²⁺ paracellular reabsorption → 高尿鈣、低血鎂 |
| **NCC（Na⁺/Cl⁻）** | DCT | **Thiazide** → 低血鉀、低血鈉、高血鈣（因促進 Ca²⁺ 再吸收）、高尿酸 |
| **ENaC** | CD（Principal cell） | **K⁺-sparing diuretics**：Amiloride、Triamterene（直接阻斷 ENaC）；Spironolactone、Eplerenone（Aldosterone antagonist） |

### 5.3 濃縮與稀釋機制

#### Countercurrent Multiplication（逆流倍增）

- 由 **TAL 的 NKCC2** 主動將 NaCl 泵入髓質間質 → 建立**髓質高滲透壓梯度**（皮質 300 → 內髓質 1200 mOsm/kg）
- **Urea recycling**：ADH 也增加 inner medullary CD 對 urea 的通透性 → urea 回到髓質間質 → 貢獻約 50% 的髓質滲透壓

#### Countercurrent Exchange（逆流交換）

- **Vasa recta**：直血管，維持髓質梯度不被沖走（U-型血管 → 下行吸 Na⁺/排水、上行排 Na⁺/吸水）
- 不建立梯度，只是維持

#### ADH 的作用

| ADH | 水通透性 | 尿量 | 尿液滲透壓 |
|-----|----------|------|------------|
| **有 ADH** | CD 通透水↑ → 水回收 | ↓ | ↑（濃縮，最高 ≈ 1200 mOsm/kg） |
| **無 ADH** | CD 不通透水 | ↑ | ↓（稀釋，最低 ≈ 50 mOsm/kg） |

- **Diabetes Insipidus（DI）**：
    - Central DI：ADH 分泌不足 → desmopressin（ADH analog）有效
    - Nephrogenic DI：腎臟對 ADH 無反應（V₂ receptor 或 AQP-2 異常）→ desmopressin 無效；常見原因：鋰鹽、低血鉀、高血鈣
- **SIADH**：ADH 過度分泌 → 水滯留 → 稀釋性低血鈉（euvolemic hyponatremia）

### 5.4 酸鹼平衡

#### 腎臟的酸鹼調節

- **HCO₃⁻ 回收**（PCT 為主，~85%）：
    - Tubular cell 分泌 H⁺（NHE3）→ H⁺ + HCO₃⁻（腔內）→ H₂CO₃ → CO₂ + H₂O（CA 催化）→ CO₂ 擴散入 cell → CO₂ + H₂O → H₂CO₃ → H⁺ + HCO₃⁻ → HCO₃⁻ 回到血液
- **新 HCO₃⁻ 產生**（distal nephron）：
    - **Titratable acid（H₂PO₄⁻）**：H⁺ + HPO₄²⁻ → H₂PO₄⁻（排出）
    - **NH₄⁺ 排泄**（最重要的可調節機制）：Glutamine → NH₃ + H⁺ → NH₄⁺ 排出；慢性酸中毒時 NH₄⁺ 產生大幅增加

#### 酸鹼失衡

| 失衡 | pH | 原發變化 | 代償 |
|------|------|----------|------|
| **Metabolic acidosis** | ↓ | HCO₃⁻↓ | 呼吸代償：過度換氣 → PCO₂↓（**Winter's formula**：expected PCO₂ = 1.5 × HCO₃⁻ + 8 ± 2） |
| **Metabolic alkalosis** | ↑ | HCO₃⁻↑ | 呼吸代償：換氣↓ → PCO₂↑ |
| **Respiratory acidosis** | ↓ | PCO₂↑ | 腎代償：HCO₃⁻↑（急性每 ↑10 mmHg CO₂ → HCO₃⁻↑1；慢性 → HCO₃⁻↑3.5） |
| **Respiratory alkalosis** | ↑ | PCO₂↓ | 腎代償：HCO₃⁻↓ |

#### Anion Gap（AG）

- **AG = Na⁺ − (Cl⁻ + HCO₃⁻)**；正常 8-12 mEq/L
- **High AG metabolic acidosis（MUDPILES）**：Methanol、Uremia、DKA、Propylene glycol、INH/Iron、Lactic acidosis、Ethylene glycol、Salicylates
- **Normal AG（Hyperchloremic）metabolic acidosis**：Diarrhea（HCO₃⁻ loss）、RTA type I/II/IV、Acetazolamide、Normal saline overuse

#### 腎小管酸中毒（Renal Tubular Acidosis, RTA）

| | **Type I（Distal）** | **Type II（Proximal）** | **Type IV** |
|--|---------------------|------------------------|-------------|
| 缺陷 | Distal tubule 無法分泌 H⁺ | PCT 無法再吸收 HCO₃⁻ | Aldosterone 缺乏/抗性 |
| 尿 pH | **>5.5**（無法酸化） | **<5.5**（遠端功能正常） | **<5.5** |
| 血鉀 | **低血鉀** | **低血鉀** | **高血鉀** |
| 特色 | 腎結石（Ca²⁺ phosphate）、Sjögren's、Amphotericin B | Fanconi syndrome（全面 PCT 功能障礙）；Acetazolamide | DM 最常見原因（hyporeninemic hypoaldosteronism）；ACEi/ARB/K⁺-sparing diuretics |

### 5.5 鉀的平衡

- 體內 K⁺ 98% 在細胞內（由 Na⁺/K⁺-ATPase 維持）
- **K⁺ 進入細胞**（降低血鉀）：Insulin、β₂-agonist、Alkalosis
- **K⁺ 離開細胞**（升高血鉀）：β-blocker、Acidosis（無機酸）、高滲透壓、Digitalis toxicity、Exercise、Cell lysis

#### 腎臟 K⁺ 處理

- PCT 再吸收約 65%（paracellular，跟隨 Na⁺/H₂O）
- TAL 再吸收約 25%（NKCC2 + paracellular）
- **Principal cells（CD）**：**K⁺ 分泌**（為主要調節部位）
    - Aldosterone↑ → ENaC↑ → Na⁺ 再吸收↑ → lumen 負電位↑ → K⁺ 分泌↑
    - 高 distal tubular flow rate → K⁺ 分泌↑
- **Intercalated cells（α-type, CD）**：K⁺ 再吸收（H⁺/K⁺-ATPase）→ 低鉀時活化

### 5.6 鈣磷代謝

#### 三大荷爾蒙

| 荷爾蒙 | 來源 | 對 Ca²⁺ | 對 PO₄³⁻ | 機制 |
|--------|------|---------|----------|------|
| **PTH** | 副甲狀腺 | **↑ 血鈣** | **↓ 血磷** | ↑ 骨吸收（osteoclast）；腎：↑ Ca²⁺ 再吸收（DCT）、↓ PO₄³⁻ 再吸收（PCT）、↑ 1α-hydroxylase → ↑ 1,25-(OH)₂D |
| **1,25-(OH)₂D（Calcitriol）** | 腎 PCT（1α-hydroxylase） | **↑ 血鈣** | **↑ 血磷** | ↑ 腸道 Ca²⁺ 和 PO₄³⁻ 吸收；↑ 骨吸收（與 PTH 協同）；↑ 腎 Ca²⁺ 再吸收 |
| **Calcitonin** | 甲狀腺 C 細胞 | ↓ 血鈣 | ↓ 血磷 | 抑制 osteoclast → ↓ 骨吸收；臨床意義較小 |

- **FGF-23**（骨細胞分泌）：↓ PO₄³⁻ 再吸收、↓ 1α-hydroxylase → 降低血磷和 Vit D

## 六、消化生理學（Gastrointestinal Physiology）

### 6.1 唾液腺

- **唾液成分**：α-amylase（澱粉初步消化）、Lingual lipase（脂肪初步消化）、HCO₃⁻（中和酸）、IgA、Mucin
- **調控**：主要由**副交感神經**（CN VII, IX）→ 大量稀薄的漿液性唾液
    - 交感神經 → 少量濃稠黏液性唾液
    - **ACh（M₃）→ 唾液分泌↑**
- 唾液為 **低張液**（Na⁺、Cl⁻ 被導管回收；HCO₃⁻、K⁺ 分泌入唾液）
- 流速↑ → 離子修飾時間↓ → 更接近血漿成分

### 6.2 胃

#### 胃酸分泌

| 細胞 | 位置 | 分泌物 |
|------|------|--------|
| **Parietal cell（壁細胞）** | 胃體/底部 | **HCl**（H⁺/K⁺-ATPase）；**Intrinsic factor**（B₁₂ 吸收必需） |
| **Chief cell（主細胞）** | 胃體/底部 | **Pepsinogen** → 被 HCl 活化為 pepsin（蛋白質消化） |
| **G cell** | **胃竇** | **Gastrin** → 刺激 parietal cell 分泌 HCl |
| **D cell** | 胃竇/十二指腸 | **Somatostatin** → 抑制 gastrin 和 HCl 分泌 |
| **ECL cell** | 胃體 | **Histamine** → 經 **H₂ receptor** 刺激 parietal cell 分泌 HCl |
| **Mucous neck cell** | 全胃 | Mucus、HCO₃⁻ → 保護胃壁 |

#### Parietal Cell 受體與 HCl 分泌

- **三大刺激**：
    1. **ACh（M₃）** → Gq → IP₃/Ca²⁺
    2. **Histamine（H₂）** → Gs → cAMP（**最重要的放大因子**）
    3. **Gastrin（CCK-B）** → Gq → IP₃/Ca²⁺
- **H⁺/K⁺-ATPase（proton pump）**：位於 parietal cell apical membrane → 分泌 H⁺ 到胃腔
    - **PPI（Omeprazole 等）**：不可逆抑制 H⁺/K⁺-ATPase → 最強效抑酸
    - **H₂ blocker（Ranitidine、Famotidine）**：競爭性阻斷 H₂ receptor

#### 胃酸分泌的三個時期

| 時期 | 刺激 | 機制 |
|------|------|------|
| **Cephalic phase** | 看/想/聞/嚐食物 | Vagus nerve（ACh）→ 直接刺激 parietal cell + G cell |
| **Gastric phase** | 食物進入胃 → 胃擴張 + 蛋白質消化產物 | Gastrin 分泌↑ → HCl↑；local reflexes |
| **Intestinal phase** | 食物進入十二指腸 | 初期輕微刺激 → 之後**抑制為主**（secretin、CCK、GIP → 負回饋抑制 gastrin 和 HCl） |

### 6.3 胰臟外分泌

| 成分 | 來源 | 功能 |
|------|------|------|
| **NaHCO₃** | Ductal cells | 中和十二指腸的胃酸，提供 pH 適合胰酶作用；受 **Secretin**（S cell）刺激 |
| **Trypsinogen** | Acinar cells | 被 **Enterokinase（腸激酶，duodenal brush border）** 活化為 **Trypsin** → trypsin 再活化其他酶 |
| **Lipase** | Acinar cells | 脂肪消化（不需活化）；需 **Colipase** 協助（抵消 bile salt 的抑制） |
| **Amylase** | Acinar cells | 澱粉消化（不需活化） |
| **Chymotrypsinogen、Proelastase、Procarboxypeptidase** | Acinar cells | 蛋白質消化；由 trypsin 活化 |

- **CCK（Cholecystokinin）**（I cell，十二指腸/空腸）：
    - 刺激 **acinar cell 分泌酶**
    - 刺激 **膽囊收縮 + Oddi 括約肌鬆弛** → 膽汁排入十二指腸
    - 抑制胃排空
- **Secretin**（S cell，十二指腸）：
    - 刺激胰管 **HCO₃⁻ 分泌**
    - 抑制 gastrin 和 HCl
    - 刺激膽管 HCO₃⁻ 分泌

### 6.4 肝膽

#### 膽汁（Bile）

- 由**肝細胞**持續產生；儲存於**膽囊**（濃縮吸收水和電解質）
- 主要成分：**Bile salts（膽鹽）**、Phospholipids（lecithin）、Cholesterol、Bilirubin、HCO₃⁻
- **Bile salts 功能**：乳化脂肪（形成 micelle）→ 促進 lipase 消化脂肪 → 促進脂肪及脂溶性維生素（A、D、E、K）吸收
- **Enterohepatic circulation**：>95% bile salts 在 **terminal ileum** 被回收 → portal vein → 肝臟再利用
    - Terminal ileum 疾病/切除 → bile salt malabsorption → 脂肪痢（steatorrhea）、脂溶性維生素缺乏

#### Bilirubin 代謝

1. Hb → Heme → **Biliverdin** → **Unconjugated bilirubin（indirect, 非水溶性）** → 與 albumin 結合運送至肝臟
2. 肝細胞：UDP-glucuronosyltransferase → **Conjugated bilirubin（direct, 水溶性）**
3. 排入膽管 → 腸道 → 細菌轉化為 **Urobilinogen** → 大部分氧化為 **Stercobilin**（糞便棕色）；一部分回收至肝臟；少部分經腎排出為 **Urobilin**（尿液黃色）

### 6.5 小腸消化吸收

#### 碳水化合物

- 口腔：Salivary amylase → 澱粉 → maltose、oligosaccharides
- 小腸：Pancreatic amylase → maltose、isomaltose
- Brush border enzymes：Maltase、Isomaltase、Sucrase、Lactase → **Monosaccharides**（Glucose、Galactose、Fructose）
- 吸收：
    - **Glucose、Galactose**：**SGLT1**（Na⁺-glucose symport, apical）→ **GLUT2**（basolateral）
    - **Fructose**：**GLUT5**（facilitated diffusion, apical）→ GLUT2（basolateral）
- **Lactase deficiency**：乳糖不耐 → 未消化 lactose 進入結腸 → 細菌發酵 → 腹脹、脹氣、腹瀉

#### 蛋白質

- 胃：Pepsin → polypeptides
- 小腸：Trypsin、Chymotrypsin、Elastase、Carboxypeptidase → oligopeptides、amino acids
- Brush border：Aminopeptidase、Dipeptidase
- 吸收：amino acids 經 Na⁺-dependent cotransporters；di/tripeptides 經 **PepT1（H⁺-peptide cotransporter）**

#### 脂肪

- 胃：Lingual lipase + Gastric lipase → 少量水解
- 十二指腸：**Bile salts 乳化** → **Pancreatic lipase + Colipase** → 2-monoglyceride + FFAs
- **Micelle formation**：膽鹽 + monoglyceride + FFAs + cholesterol + 脂溶性 vitamins → 跨越水層到達 brush border
- 吸收：diffusion 入 enterocyte → 重新合成 TG → 與 apolipoprotein 形成 **Chylomicron** → exocytosis → 進入 **lacteals（淋巴管）**
- **Medium-chain FA**：不需 micelle，直接吸收入 portal vein

#### 鐵

- **Fe²⁺（ferrous）**由 **DMT1（apical）** 吸收（duodenum 為主）
- 細胞內 Fe 儲存為 Ferritin；經 **Ferroportin**（basolateral）輸出
- **Hepcidin**（肝臟產生）：抑制 Ferroportin → ↓ 鐵吸收和釋放；發炎時 hepcidin↑ → anemia of chronic disease

#### 維生素 B₁₂ 吸收

1. 食物中 B₁₂ 結合 **R-protein（salivary）**
2. 胃酸 + pepsin 將 B₁₂ 從食物蛋白釋出
3. 十二指腸：胰酶分解 R-protein → B₁₂ 轉而結合 **Intrinsic factor（IF，parietal cell 產生）**
4. **IF-B₁₂ complex** 在 **terminal ileum** 被 cubilin/megalin 受體吸收
- **Pernicious anemia**：自體免疫破壞 parietal cell / anti-IF Ab → IF↓ → B₁₂ 吸收障礙

### 6.6 大腸

- 主要功能：**水和電解質吸收**、儲存糞便
- **Na⁺ 吸收**（ENaC，受 aldosterone 調控）、**K⁺ 分泌**
- 細菌發酵未消化的碳水化合物 → **短鏈脂肪酸（SCFA）**：butyrate（結腸細胞能量來源）、acetate、propionate
- 合成 Vitamin K（由腸道菌群）

### 6.7 GI 荷爾蒙整理

| 荷爾蒙 | 來源 | 刺激 | 功能 |
|--------|------|------|------|
| **Gastrin** | G cell（胃竇） | 蛋白質、vagal stimulation、胃擴張 | ↑ HCl、↑ mucosal growth；被 somatostatin、低 pH 抑制 |
| **CCK** | I cell（十二指腸/空腸） | FA、AA | ↑ 胰酶分泌、↑ 膽囊收縮、↓ 胃排空 |
| **Secretin** | S cell（十二指腸） | 酸（pH < 4.5） | ↑ 胰管 HCO₃⁻、↓ HCl、↓ gastrin |
| **GIP** | K cell（十二指腸/空腸） | Glucose、FA | **↑ Insulin 分泌**（incretin）；↓ HCl |
| **GLP-1** | L cell（ileum/colon） | Nutrients | **↑ Insulin、↓ Glucagon**（incretin）；↓ 胃排空、↑ 飽足感 |
| **Motilin** | M cell（十二指腸/空腸） | 空腹 | 啟動 **Migrating Motor Complex（MMC）**—空腹期的腸蠕動；Erythromycin 為 motilin agonist |
| **Somatostatin** | D cell | 多種刺激 | **全面抑制**：↓ gastrin、↓ insulin、↓ glucagon、↓ GH、↓ secretin |
| **VIP** | 腸道神經 | — | ↑ 腸道水和電解質分泌、血管擴張、鬆弛平滑肌；VIPoma → watery diarrhea |

### 6.8 GI 運動

- **Slow waves**：由 **Interstitial Cells of Cajal（ICC）** 產生；為 GI 平滑肌的基本節律電位（不一定引發收縮，但設定最大頻率）
    - Stomach：3/min；Duodenum：12/min；Ileum：8/min
- 只有當 slow wave 達到閾值產生 spike potentials（AP）時才有收縮
- **Peristalsis**：Ascending contraction（oral side）+ Descending relaxation（aboral side）→ 推進內容物
- **Segmentation**：交替收縮 → 混合內容物（不推進）
- **MMC（Migrating Motor Complex）**：空腹時每 90 分鐘週期性強蠕動，清除殘渣（house-keeping function）；受 **Motilin** 調控；進食後被抑制

#### 吞嚥反射

- Voluntary phase → Pharyngeal phase（involuntary，CN IX/X）→ Esophageal phase
- **Upper esophageal sphincter（UES）**：骨骼肌（cricopharyngeus）
- **Lower esophageal sphincter（LES）**：平滑肌；Tonic contraction 防止 GERD
    - LES 壓力↑：ACh、α-agonist、Motilin、Gastrin
    - LES 壓力↓：**VIP、NO**、Progesterone、Secretin、CCK、Alcohol、Chocolate、Caffeine

#### 嘔吐反射

- **Vomiting center**：延腦
- **Chemoreceptor Trigger Zone（CTZ / Area postrema）**：位於第四腦室底部，**無 BBB** → 可偵測血中催吐物質
    - 受體：**D₂（dopamine）**、5-HT₃（serotonin）、NK₁（substance P）、H₁、M₁
    - Antiemetics：Ondansetron（5-HT₃ antagonist）、Metoclopramide（D₂ antagonist）、Aprepitant（NK₁ antagonist）

### 6.9 胃排空

- **促進**：Distension、Motilin、Parasympathetic（vagus）
- **抑制**：Duodenal factors（脂肪 → CCK；酸 → Secretin；高滲透壓 → 反射）；Sympathetic activation
- **Gastroparesis**：常見於 DM（vagal neuropathy）→ 嘔心/嘔吐/早飽；治療：Metoclopramide（D₂ antagonist + 5-HT₄ agonist）

## 七、內分泌生理學（Endocrine Physiology）

### 7.1 下視丘–腦下垂體軸（Hypothalamus-Pituitary Axis）

| **GHRH** | ↑ GH |

| **Dopamine（Prolactin Inhibiting Factor）** | ↓ Prolactin（**tonic inhibition**）；→ 切斷 stalk → Prolactin↑（所有其他 anterior pituitary hormones↓） |

#### 前葉（Anterior Pituitary）荷爾蒙

| 荷爾蒙 | 來源細胞 | 靶器官 |

| **LH** | Gonadotroph | 卵巢/睪丸 |

#### 後葉（Posterior Pituitary）荷爾蒙

| 荷爾蒙 | 來源 | 功能 |
|--------|------|------|
| **ADH（Vasopressin）** | Supraoptic nucleus → 沿 axon 運至後葉 | V₂ receptor（腎 CD）→ 水再吸收↑；V₁ receptor（血管）→ vasoconstriction |
| **Oxytocin** | Paraventricular nucleus → 沿 axon 運至後葉 | 子宮收縮（分娩）；乳汁噴出反射（let-down reflex）；**Positive feedback** |

- **ADH 分泌刺激**：↑ Plasma osmolality（>280 mOsm/kg，最敏感刺激）、↓ Blood volume/BP（via baroreceptor）、Nausea、Pain、Stress
- **ADH 分泌抑制**：↓ Osmolality、Alcohol、ANP

### 7.2 生長激素（Growth Hormone, GH）

- **分泌模式**：Pulsatile；**sleep（SWS）時分泌最多**；Exercise、Hypoglycemia、Amino acids（Arginine）、GHRH → ↑ GH
- **抑制**：Somatostatin、IGF-1（negative feedback）、Hyperglycemia、Obesity
- **作用**：
    - **Direct（anti-insulin）**：↑ Lipolysis、↑ Hepatic glucose output（→ 升血糖）、↓ Glucose uptake（insulin resistance）
    - **Indirect（via IGF-1, liver 產生）**：↑ 蛋白質合成、↑ Linear growth（長骨生長板軟骨增生）、↑ Organ growth
- **GH 過多**：
    - 兒童（生長板未閉合）→ **Gigantism**
    - 成人（生長板已閉合）→ **Acromegaly**：肢端肥大、大下巴、大手大腳、Organomegaly、DM、HTN
    - Screening：**IGF-1**；Confirmation：**Oral Glucose Tolerance Test（OGTT）→ GH 未抑制**
- **GH 缺乏**：兒童 → 身材矮小、骨齡延遲

### 7.3 甲狀腺（Thyroid）

#### 甲狀腺素合成

1. **Iodide trapping**：Na⁺/I⁻ symporter（NIS）將 I⁻ 從血液運入甲狀腺細胞（basolateral）
2. I⁻ 經 Pendrin 運至 colloid（apical）
3. **Thyroid peroxidase（TPO）**催化：
    - I⁻ 氧化為 I₂
    - **Organification**：I₂ + Thyroglobulin（Tg）上的 Tyrosine → MIT、DIT
    - **Coupling**：MIT + DIT → **T₃**；DIT + DIT → **T₄**
4. Tg 被 endocytosis 回細胞 → lysosomal proteolysis → T₃、T₄ 釋出入血
5. MIT、DIT 被 **Dehalogenase** 回收 I⁻（再利用）

- **T₄**：產量最多（90%），但活性較弱 → 在周邊被 **5'-deiodinase（Type 1/2）** 轉化為 **T₃**（活性最強）
- **Reverse T₃（rT₃）**：由 **5-deiodinase（Type 3）** 產生 → 無活性
- **T₃/T₄ 在血中**：大部分與 **Thyroxine-Binding Globulin（TBG）** 結合；游離態（Free T₃/T₄）才有活性
    - TBG↑（Estrogen/OCP、pregnancy、Hepatitis）→ Total T₄↑ 但 Free T₄ 正常
    - TBG↓（Androgens、Nephrotic syndrome、Glucocorticoid）→ Total T₄↓ 但 Free T₄ 正常

#### 甲狀腺素作用

| 系統 | 效果 |
|------|------|
| **代謝** | ↑ BMR、↑ O₂ consumption、↑ Heat production（calorigenic effect） |
| **心血管** | ↑ HR（↑ β₁ receptor expression）、↑ CO、↓ TPR |
| **CNS** | 胎兒/新生兒：腦部發育（缺乏 → **Cretinism**）；成人：精神活動 |
| **骨** | ↑ Bone turnover |
| **脂肪** | ↑ Lipolysis、↑ LDL receptor → ↓ Cholesterol |
| **Carbohydrate** | ↑ Gluconeogenesis、↑ Glycogenolysis |
| **GI** | ↑ Motility |
| **Growth** | Permissive for GH → 正常生長 |

#### Wolff-Chaikoff Effect vs Jod-Basedow Effect

| | Wolff-Chaikoff | Jod-Basedow |
|--|---------------|-------------|
| 刺激 | 大量 I⁻ | 大量 I⁻ |
| 結果 | 暫時抑制 organification → T₃/T₄↓ | 甲狀腺功能亢進（在有基礎甲狀腺疾病者） |
| 機制 | 正常調控，保護機制 | 病理性，Iodine-induced hyperthyroidism |

### 7.4 腎上腺（Adrenal Gland）

#### 腎上腺皮質（Cortex）

| 層 | 荷爾蒙 | 調控 | 功能 |
|----|--------|------|------|
| **Zona Glomerulosa** | **Aldosterone** | **RAAS（Angiotensin II）**、**K⁺↑** | Na⁺ 再吸收↑、K⁺/H⁺ 分泌↑（ENaC, CD） |
| **Zona Fasciculata** | **Cortisol** | **ACTH**（HPA axis） | 見下 |
| **Zona Reticularis** | **DHEA / Androstenedione** | ACTH | 弱雄性素 |

- 記憶口訣：**GFR = Glomerulosa（salt）、Fasciculata（sugar）、Reticularis（sex）**

##### Cortisol 的作用

| 系統 | 效果 |
|------|------|
| **代謝** | ↑ Gluconeogenesis（liver）、↑ Proteolysis（muscle）、↑ Lipolysis → **升血糖**（anti-insulin / 糖尿病效應）；但 truncal obesity（redistribute fat） |
| **免疫** | **Anti-inflammatory** + **Immunosuppressive**：↓ lymphocyte、↓ eosinophil、↑ neutrophil（demargination）、↓ IL-2、↓ NF-κB |
| **骨** | ↓ Osteoblast → 骨質疏鬆 |
| **血管** | Permissive for catecholamine action（維持血管張力 → 抗休克） |
| **CNS** | Euphoria/Depression（mood change）、↓ REM sleep |
| **腎** | ↑ GFR、↑ Free water clearance |
| **GI** | ↑ HCl、↓ Mucus → peptic ulcer 風險 |

##### Cortisol 分泌特徵

- **Diurnal rhythm（circadian）**：早晨最高（6-8 AM）、午夜最低
- CRH → ACTH → Cortisol → 負回饋抑制 CRH 和 ACTH

##### RAAS（Renin-Angiotensin-Aldosterone System）

1. **Renin**（JG cells，afferent arteriole）釋放刺激：↓ Renal perfusion pressure、↓ NaCl at macula densa、Sympathetic（β₁）
2. Renin 裂解 Angiotensinogen（liver）→ **Angiotensin I**
3. **ACE**（肺內皮細胞最多）→ **Angiotensin II**
4. Angiotensin II 作用：
    - **Vasoconstriction**（直接）→ ↑ TPR → ↑ BP
    - **Aldosterone 分泌**（zona glomerulosa）→ Na⁺/H₂O 再吸收 → ↑ Blood volume
    - **ADH 分泌↑** → H₂O 再吸收
    - **Thirst↑**
    - **Efferent arteriole constriction** → 維持 GFR
    - **Proximal tubule Na⁺ 再吸收↑**（stimulate NHE3）
5. ACE 也降解 **Bradykinin**（vasodilator）→ ACEi 副作用：Bradykinin↑ → 乾咳、angioedema

#### 腎上腺髓質（Medulla）

- 來源：Neural crest（修飾過的交感節後神經元）
- 分泌：**Epinephrine（80%）** + Norepinephrine（20%）
- 刺激：ACh（nicotinic receptor）→ 直接受交感節前纖維支配
- Catecholamine 合成：Tyrosine →（tyrosine hydroxylase，**rate-limiting**）→ DOPA → Dopamine → NE →（PNMT，需 cortisol）→ Epinephrine
- Catecholamine 降解：**MAO**（intracellular）+ **COMT**（extracellular）→ 代謝物：**VMA（尿液）**、Metanephrine
    - **Pheochromocytoma**：診斷 → Plasma free metanephrines 或 24-hr urine VMA/metanephrines/catecholamines

### 7.5 胰臟內分泌

#### 胰島細胞

| 細胞 | 比例 | 荷爾蒙 |
|------|------|--------|
| **β cell** | 最多（~70%） | **Insulin** |
| **α cell** | ~20% | **Glucagon** |
| **δ cell** | ~5% | Somatostatin |
| **PP cell** | 少 | Pancreatic polypeptide |

#### Insulin

- **Insulin 分泌機制（β cell）**：
    1. Glucose → GLUT2 → 進入 β cell → 代謝 → ATP↑
    2. ATP↑ → **K_ATP channel 關閉** → 去極化
    3. Voltage-gated **Ca²⁺ channel 開放** → Ca²⁺ 內流 → insulin exocytosis
    - **Sulfonylurea**：直接關閉 K_ATP channel → insulin 分泌↑
- **Insulin 分泌刺激**：↑ Blood glucose（最重要）、AA（Arg, Leu）、GIP/GLP-1（incretin effect）、Vagus（ACh）、β₂-agonist
- **Insulin 分泌抑制**：α₂-agonist、Somatostatin、Sympathetic（α₂ > β₂ → net inhibition during stress）

##### Insulin 作用

| 靶組織 | 效果 |
|--------|------|
| **肝臟** | ↑ Glycogen synthesis、↑ Lipogenesis、↑ Protein synthesis；↓ Gluconeogenesis、↓ Glycogenolysis、↓ Ketogenesis |
| **肌肉** | ↑ GLUT4 → Glucose uptake↑；↑ Glycogen synthesis；↑ Protein synthesis；↑ K⁺ uptake |
| **脂肪** | ↑ GLUT4 → Glucose uptake↑；↑ Lipogenesis（TG storage）；↓ Lipolysis（↓ hormone-sensitive lipase） |

- **Insulin 整體效果**：**降血糖、降血鉀、合成代謝**
- **Insulin receptor**：Tyrosine kinase receptor → IRS-1 → PI3K/Akt pathway → GLUT4 translocation

#### Glucagon

- **分泌刺激**：Hypoglycemia（最重要）、AA（Arg, Ala）、Sympathetic（β₂）、Exercise
- **分泌抑制**：Hyperglycemia、Insulin、Somatostatin
- **作用（主要在肝臟）**：↑ Glycogenolysis、↑ Gluconeogenesis、↑ Ketogenesis → **升血糖**
- **Glucagon receptor**：Gs → cAMP → PKA

#### 血糖調控總結

| 荷爾蒙 | 對血糖 | 類別 |
|--------|--------|------|
| **Insulin** | **唯一降血糖荷爾蒙** | 降血糖 |
| Glucagon | ↑ | 升血糖 |
| Epinephrine | ↑ | 升血糖 |
| Cortisol | ↑ | 升血糖 |
| GH | ↑ | 升血糖 |
| T₃/T₄ | ↑ | 升血糖 |

### 7.7 內分泌信號傳遞

| 受體類型 | 機制 | 荷爾蒙範例 |
|----------|------|-----------|
| **Intracellular（Nuclear）receptor** | 脂溶性荷爾蒙穿膜 → 結合受體 → 調控 gene transcription | **Steroid hormones**（Cortisol, Aldosterone, Estrogen, Testosterone）、**Thyroid hormones（T₃/T₄）**、Vitamin D、Retinoic acid |

## 八、生殖生理學（Reproductive Physiology）

### 8.1 男性生殖

#### 睪丸功能

| 細胞 | 位置 | 荷爾蒙調控 | 功能 |
|------|------|-----------|------|
| **Leydig cell** | 間質 | **LH** | 產生 **Testosterone** |
| **Sertoli cell** | 曲細精管 | **FSH** | 支持精子發育；產生 **Inhibin B**（負回饋 FSH）；產生 **Androgen-Binding Protein（ABP）**；形成 **Blood-Testis Barrier**；分泌 **Anti-Müllerian Hormone（AMH）** |

#### Testosterone 作用

- 性徵發育：陰莖、前列腺、精囊、體毛、變聲
- 蛋白質合成↑、肌肉量↑
- **精子生成（spermatogenesis）**：需要 testosterone（局部高濃度，ABP 維持）
- **5α-reductase** 將 testosterone 轉化為 **DHT（Dihydrotestosterone）**：
    - DHT 活性更強，負責：前列腺生長、男性禿、外生殖器發育
    - 5α-reductase deficiency → 表現型：出生時外生殖器模糊（assigned female）→ 青春期 testosterone↑ → 男性化
- **Aromatase** 將 testosterone 轉化為 **Estradiol**：骨骺閉合、骨密度

### 8.2 女性生殖

#### 卵巢功能

| 細胞 | 荷爾蒙調控 | 功能 |
|------|-----------|------|
| **Theca cell** | **LH** | 產生 **Androstenedione**（→ 轉移至 granulosa cell） |
| **Granulosa cell** | **FSH** | **Aromatase** 將 androstenedione → **Estradiol**（E₂）；分泌 **Inhibin B**（follicular phase）和 **Inhibin A**（luteal phase）→ 負回饋 FSH |

- **Two-cell, two-gonadotropin model**：
    - Theca（LH → Cholesterol → Androgen）+ Granulosa（FSH → Aromatase → Estrogen）

#### 月經週期（28 天）

##### Follicular Phase（Day 1-14）

| 時間 | 事件 |
|------|------|
| Day 1-5 | **Menstruation**；GnRH pulsatile → FSH↑ → 多個 follicle 開始發育 |
| Day 5-13 | **Dominant follicle** 被選出；Estrogen 逐漸↑ → 負回饋抑制 FSH → 其他 follicle 萎縮（atresia） |
| Day 12-13 | Estrogen 達到高峰並維持（>200 pg/mL，持續 >48 hr）→ 轉為 **正回饋** → **LH surge** |
| **Day 14** | **LH surge → Ovulation（排卵）** |

##### Luteal Phase（Day 15-28）

| 時間 | 事件 |
|------|------|
| Post-ovulation | 破裂的 follicle → **Corpus luteum（黃體）** → 分泌 **Progesterone**（為主）+ Estrogen |
| Day 15-28 | Progesterone → 子宮內膜分泌期；體溫↑（thermogenic effect）；**維持妊娠**所必需 |
| Day 28 | 若未受孕 → Corpus luteum 退化 → Progesterone/Estrogen↓ → **子宮內膜脫落（月經）** → FSH↑ → 新週期 |

- **若受孕**：Trophoblast 分泌 **hCG** → 維持 corpus luteum → 持續分泌 progesterone 直到胎盤接手（~8-10 weeks）

##### 子宮內膜變化

| 時期 | 荷爾蒙 | 內膜 |
|------|--------|------|
| **Proliferative phase** | **Estrogen** | 內膜增厚、腺體增生、螺旋動脈發育 |
| **Secretory phase** | **Progesterone** | 腺體分泌糖原、螺旋動脈更捲曲 → 準備著床 |
| **Menstruation** | Progesterone/Estrogen 撤退 | 螺旋動脈痙攣 → 缺血 → 內膜脫落 |

#### Estrogen vs Progesterone 作用

| 作用 | Estrogen | Progesterone |
|------|----------|-------------|
| 子宮內膜 | 增生（proliferative） | 分泌（secretory） |
| 子宮肌 | 興奮性↑ | 興奮性↓（鬆弛） |
| 子宮頸黏液 | 稀薄、拉絲性好（有利精子通過） | 黏稠（阻擋精子） |
| 體溫 | — | ↑（Thermogenic）；排卵後基礎體溫上升 0.5°C |
| 乳房 | 導管發育 | 腺泡發育 |
| 骨 | 維持骨密度（↓ osteoclast） | — |
| 脂質 | HDL↑、LDL↓ | — |
| 回饋 | 低濃度 → 負回饋 FSH/LH；持續高濃度 → **正回饋 → LH surge** | 主要負回饋 LH（pulsatility↓） |

### 8.3 妊娠生理

#### 胎盤荷爾蒙

| 荷爾蒙 | 功能 |
|--------|------|
| **hCG** | 維持 corpus luteum → progesterone 分泌；妊娠試驗標的 |
| **hPL（Human Placental Lactogen）** | 類似 GH/Prolactin → ↑ maternal insulin resistance → 確保 glucose 供給胎兒；促進乳房發育 |
| **Progesterone** | 維持子宮平靜（抑制收縮）、子宮內膜分泌期維持 |
| **Estrogen（Estriol, E₃）** | 子宮血流↑、乳房發育；合成需要 fetal adrenal DHEA-S |

#### 妊娠母體生理變化

| 系統 | 變化 |
|------|------|
| **血液** | 血漿量↑（>RBC↑）→ **生理性貧血（稀釋性）**；Hypercoagulable state（凝血因子↑） |
| **心血管** | CO↑（30-50%）、HR↑、TPR↓、BP 輕微↓（中孕最低）；Supine hypotension syndrome（仰臥時子宮壓迫 IVC） |
| **呼吸** | Tidal volume↑ → Minute ventilation↑ → **Respiratory alkalosis**（PaCO₂↓ ≈ 30 mmHg）；FRC↓（膈肌上抬） |
| **腎** | GFR↑（50%）→ BUN/Cr↓ |
| **代謝** | Insulin resistance↑（hPL、Cortisol、Progesterone）→ **Gestational DM** 風險 |

### 8.4 泌乳（Lactation）

- 妊娠期間：Estrogen + Progesterone → 促進乳腺發育，但**抑制 Prolactin 對乳腺的作用**
- **產後**：Estrogen/Progesterone 驟降 → Prolactin 得以作用 → **乳汁合成**
- **吸吮刺激** → ↑ Prolactin（乳汁合成）+ ↑ Oxytocin（**Let-down reflex，乳汁噴出**）
- Prolactin 也**抑制 GnRH** → 哺乳期抑制排卵（不完全避孕）

## 九、血液生理學（Hematology Physiology）

### 9.1 紅血球生成（Erythropoiesis）

- **EPO（Erythropoietin）**：**腎臟**（peritubular interstitial cells）產生 → 刺激骨髓 erythroid progenitors
    - 刺激 EPO 分泌：**Hypoxia**（altitude, anemia, lung disease）
    - CKD → EPO↓ → **Anemia of CKD**
- 紅血球壽命：~120 天 → 老化 RBC 在**脾臟**被破壞（extravascular hemolysis）
- **2,3-DPG**：Glycolysis 中間產物，↑ O₂ unloading（右移）

### 9.2 止血（Hemostasis）

#### 初級止血（Primary Hemostasis）— 血小板

1. **Blood vessel injury** → Collagen 暴露 → **vWF** 橋接 collagen 和 platelet（**GPIb**）→ **Adhesion**
2. Platelet **Activation** → Shape change、Release granules（ADP, TXA₂, Serotonin）、表面表達 **GPIIb/IIIa**
3. **Aggregation**：**Fibrinogen** 橋接 platelet 上的 GPIIb/IIIa → 形成 **Platelet plug**

- **vWF**：由 endothelium 和 megakaryocyte 產生；攜帶 Factor VIII
    - vWF disease：最常見遺傳性出血疾患；↑ Bleeding time、正常 PT、↑ PTT
- **Aspirin**：不可逆抑制 **COX-1** → ↓ TXA₂ → 抑制 platelet aggregation
- **Clopidogrel**：阻斷 **ADP receptor（P2Y₁₂）** → 抑制 platelet activation
- **GPIIb/IIIa inhibitors**（Abciximab）：阻斷最終共同通路 → 最強效抗血小板

#### 次級止血（Secondary Hemostasis）— 凝血級聯

| 途徑 | 因子 | 監測 |
|------|------|------|
| **Extrinsic pathway** | **TF（Tissue Factor）→ Factor VII** | **PT（Prothrombin Time）/ INR** |
| **Intrinsic pathway** | XII → XI → IX → VIII | **aPTT** |
| **Common pathway** | **X → V → II（Prothrombin）→ Thrombin → Fibrinogen → Fibrin** | PT 和 aPTT 都受影響 |
| **Fibrin 穩定** | Factor **XIII** → Cross-link fibrin | — |

- **Thrombin 的多重作用**：
    - 活化 I → Fibrin
    - 活化 V、VIII、XI、XIII（正回饋放大）
    - 活化 Protein C（via Thrombomodulin → 負回饋抗凝）
    - 活化 platelets

- **Vitamin K-dependent factors**：II、VII、IX、X、**Protein C、Protein S**
    - Warfarin 抑制 Vitamin K epoxide reductase → 抑制這些因子 → 抗凝
    - **Factor VII 半衰期最短** → PT 先延長

#### 抗凝與纖溶

| 抗凝系統 | 機制 |
|----------|------|
| **Antithrombin III（AT-III）** | 抑制 Thrombin、Xa、IXa；被 **Heparin** 增強效果約 1000 倍 |
| **Protein C / Protein S** | Thrombin + Thrombomodulin → 活化 Protein C → 降解 Va、VIIIa；Protein S 是 Protein C 的 cofactor |
| **TFPI** | 抑制 TF-VIIa complex |
| **Prostacyclin（PGI₂）** | Endothelium 產生；抑制 platelet aggregation + vasodilation |
| **NO** | Endothelium 產生；抑制 platelet adhesion + vasodilation |
| **tPA** | 活化 Plasminogen → **Plasmin** → 分解 Fibrin（纖維蛋白溶解） |

- **D-dimer**：Fibrin degradation product → 代表有 thrombus 形成 + 纖溶進行中（DIC、DVT/PE 的 marker）

### 9.3 血型

- **ABO 系統**：
    - Type A：有 A antigen、有 anti-B Ab
    - Type B：有 B antigen、有 anti-A Ab
    - Type AB：有 A+B antigen、無 Ab（**universal recipient**）
    - Type O：無 antigen、有 anti-A + anti-B Ab（**universal donor — 紅血球**）
    - ABO 不合 → **急性溶血性輸血反應**（Type II hypersensitivity，intravascular hemolysis）
- **Rh 系統**：
    - Rh(−) 母親 × Rh(+) 胎兒 → 第一胎致敏 → 第二胎起 anti-D IgG 穿過胎盤 → **Hemolytic Disease of the Newborn（HDN / Erythroblastosis fetalis）**
    - 預防：**RhoGAM（anti-D Ig）** 給 Rh(−) 母親（28 週 + 產後 72 小時內）

## 十、重要整合主題

### 10.1 體溫調節

- **體溫調節中樞**：**下視丘（Anterior hypothalamus）**
- **散熱機制**：皮膚血管擴張、排汗（eccrine glands，ACh/Muscarinic）、輻射、對流、蒸發
- **產熱機制**：發抖（shivering，骨骼肌不自主收縮）、皮膚血管收縮、非發抖性產熱（brown fat — 新生兒，UCP-1 / Thermogenin）、Thyroid hormone、Sympathetic activity
- **Fever（發燒）**：
    - 細菌 LPS → Macrophage → IL-1、IL-6、TNF-α → **下視丘 set point↑** → PGE₂ 介導
    - **Antipyretics（NSAIDs、Acetaminophen）**：抑制 COX → ↓ PGE₂ → 降低 set point
- **Malignant hyperthermia**：Ryanodine receptor（RyR1）突變 → inhalation anesthetics（Halothane）或 Succinylcholine → 大量 Ca²⁺ 釋出 → 肌肉僵硬 + 極度高熱；治療：**Dantrolene**（抑制 RyR → ↓ Ca²⁺ release）

### 10.2 運動生理學摘要

- **Exercise 時的生理變化**：
    - CO↑（HR↑ + SV↑）
    - Skeletal muscle blood flow↑↑（local metabolites → vasodilation）
    - TPR↓（net，因骨骼肌血管大幅擴張 > 其他區域收縮）
    - SBP↑（CO↑）；DBP 不變或輕微↓
    - Ventilation↑
    - Catecholamines↑ → Glycogenolysis、Lipolysis
    - K⁺ 暫時性↑（肌肉釋放）
    - Lactic acid↑（anaerobic threshold 以上）→ metabolic acidosis → 呼吸代償

### 10.3 酸鹼與電解質快速複習表

| 失衡 | 常見原因 | 血鉀 |
|------|----------|------|
| **Metabolic Acidosis（AG↑）** | DKA、Lactic acidosis、Uremia、Toxins | 常↑（H⁺ 入細胞 / K⁺ 出） |
| **Metabolic Acidosis（AG 正常）** | Diarrhea、RTA | Type I/II → 低 K⁺；Type IV → 高 K⁺ |
| **Metabolic Alkalosis** | Vomiting、Diuretics（loop/thiazide）、Hyperaldosteronism | 常 ↓ |
| **Respiratory Acidosis** | COPD、Hypoventilation、CNS depression | — |
| **Respiratory Alkalosis** | Anxiety、PE、High altitude、Aspirin（early）、Pregnancy | — |
