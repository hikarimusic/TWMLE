## 一、胺基酸與蛋白質

### 1.1 胺基酸分類

- **必需胺基酸（9 種）**：Val、Leu、Ile、Phe、Trp、Met、Thr、His、Lys

| 分類 | 胺基酸 | 特色 |
|------|--------|------|
| **非極性** | Gly、Ala、Val、Leu、Ile、Pro、Phe、Trp、Met | 傾向位於蛋白質內部 |
| **極性不帶電** | Ser、Thr、Cys、Tyr、Asn、Gln | Ser/Thr/Tyr 可被磷酸化 |
| **帶正電（鹼性）** | **Lys、Arg、His** | His 常於酵素活性位點 |
| **帶負電（酸性）** | **Asp、Glu** | Glu 是重要的 amino group donor |

### 1.2 特殊胺基酸功能

| 胺基酸 | 特殊功能 |
|--------|----------|
| **Glycine** | 最小胺基酸；合成 heme、glutathione、purine、collagen；抑制性神經傳導物 |
| **Proline** | 打斷 α-helix；collagen 中 Pro 經 hydroxylation 形成 Hydroxyproline |
| **Cysteine** | 含硫氫基（-SH）→ 形成 **disulfide bond（S-S）**；組成 glutathione |
| **Methionine** | 轉譯起始胺基酸（AUG）；甲基供體前驅物（→ **SAM**） |
| **Tryptophan** | 合成 **serotonin（5-HT）**、**melatonin**、**niacin（NAD⁺）**；吸收 280 nm UV |
| **Tyrosine** | 合成 **catecholamines**（DA、NE、Epi）、**thyroid hormones**、**melanin** |
| **Glutamate** | 興奮性神經傳導物；轉胺反應中心角色；合成 **GABA** |
| **Arginine** | 尿素循環關鍵；**NO** 前驅物 |
| **Histidine** | 脫羧後成 **histamine** |

### 1.3 蛋白質結構

| 層級 | 描述 | 穩定力 |
|------|------|--------|
| **一級結構** | 胺基酸序列（peptide bond） | 共價鍵（peptide bond） |
| **二級結構** | α-helix、β-sheet、β-turn | **氫鍵**（backbone NH…O=C） |
| **三級結構** | 單一多肽鏈的 3D 折疊 | 疏水交互作用（最重要）、H-bond、離子鍵、disulfide bond、van der Waals |
| **四級結構** | 多條亞基組合（如 Hb α₂β₂） | 同三級結構 |

- **α-helix**：右旋螺旋，每圈 3.6 個殘基；**Pro 和 Gly 破壞 α-helix**
- **β-sheet**：平行或反平行的延伸鏈，氫鍵在鏈間

### 1.4 蛋白質折疊與相關疾病

- **Chaperones**：協助蛋白質正確折疊
    - **Hsp70**：結合新生多肽，防止聚集
    - **Hsp60（chaperonin）**：提供隔離空間讓蛋白質折疊
- **Ubiquitin-proteasome pathway**：標記錯誤折疊蛋白質降解
- **蛋白質錯誤折疊疾病**：

| 疾病 | 錯誤蛋白 | 特色 |
|------|----------|------|
| **Prion disease（CJD、Kuru）** | PrPˢᶜ（由 PrPᶜ 轉變） | 感染性蛋白質，無核酸；spongiform encephalopathy |
| **Alzheimer's disease** | Amyloid-β、Tau | Senile plaque、neurofibrillary tangle |
| **Parkinson's disease** | α-synuclein | Lewy bodies |
| **Huntington's disease** | Huntingtin | CAG repeat；AD 遺傳 |
| **Amyloidosis** | 各類 amyloid 沉積 | AL（light chain）、AA（SAA）、ATTR（transthyretin） |

### 1.5 膠原蛋白（Collagen）

- **結構**：(Gly-X-Y)n，每三個殘基一個 Gly
- **合成**：
    1. 胞內合成 preprocollagen → 切除信號肽
    2. **Hydroxylation**：Prolyl hydroxylase 和 Lysyl hydroxylase（需 **Vitamin C**）
    3. **Glycosylation**：hydroxylysine 上加 galactose
    4. 形成 triple helix（procollagen）→ 分泌到胞外
    5. 胞外 procollagen peptidase 切除 N- 和 C-端前肽 → tropocollagen
    6. **Lysyl oxidase**（需 **Cu²⁺**）催化 cross-linking → 成熟膠原纖維
- **膠原蛋白相關疾病**：

| 疾病 | 缺陷 | 特色 |
|------|------|------|
| **Scurvy（壞血病）** | Vitamin C 缺乏 → hydroxylation 障礙 | 牙齦出血、傷口癒合差、瘀青、毛囊角化 |
| **Osteogenesis imperfecta** | **Type I collagen** 基因突變（COL1A1/COL1A2） | 骨脆（brittle bone）、**藍色鞏膜**、聽力喪失；AD |
| **Ehlers-Danlos syndrome** | 多種 collagen 或 processing enzyme 缺陷 | 皮膚過度延展、關節過度活動、血管脆弱（Type III collagen 缺陷） |
| **Alport syndrome** | **Type IV collagen** α5 chain 突變 | 腎炎 + 感音性聽力喪失 + 眼異常；**X-linked** 最常見 |
| **Menkes disease** | Cu²⁺ 吸收障礙 → lysyl oxidase↓ | 捲髮（kinky hair）、智力障礙、血管異常 |

- **彈性蛋白相關疾病**：

| 疾病 | 缺陷 | 特色 |
|------|------|------|
| **Marfan syndrome** | **Fibrillin-1（FBN1）**基因突變 → elastin scaffold 異常、TGF-β↑ | 身材高瘦、蜘蛛指、晶狀體向上外側脫位、主動脈根部擴張／剝離；**AD** |

## 二、酵素學（Enzymology）

### 2.1 酵素動力學

- **Michaelis-Menten equation**：v = Vmax[S] / (Km + [S])
    - **Km**：達到 1/2 Vmax 的基質濃度 → **反映酵素對基質的親和力（Km 越小，親和力越高）**
    - **Vmax**：所有酵素被飽和時的最大反應速率 → 與酵素濃度成正比
- **Lineweaver-Burk plot（double-reciprocal plot）**：1/v vs 1/[S]

| 抑制類型 | Vmax 變化 | Km 變化 | Lineweaver-Burk 特徵 |
|----------|-----------|---------|----------------------|
| **Competitive** | 不變 | **↑** | 交於 y 軸（相同 1/Vmax） |
| **Non-competitive** | **↓** | 不變 | 交於 x 軸（相同 -1/Km） |
| **Uncompetitive** | **↓** | **↓** | 平行線 |
| **Mixed** | **↓** | 改變 | 不交於任何軸 |

### 2.2 酵素調控

- **Allosteric regulation**：效應物結合於非活性位點 → 改變酵素構型
    - Positive effectors → 增加活性（T → R state）
    - Negative effectors → 降低活性（R → T state）
- **Covalent modification**：
    - **磷酸化**：最常見；kinase 加磷酸 / phosphatase 去磷酸
    - **Acetylation、Methylation、Ubiquitination**
- **Zymogen activation（proenzyme → active enzyme）**：
    - Pepsinogen → Pepsin（by HCl）
    - Trypsinogen → Trypsin（by enterokinase）
    - Chymotrypsinogen → Chymotrypsin（by trypsin）
    - Proelastase → Elastase（by trypsin）
    - Coagulation factors：凝血瀑布
- **Feedback inhibition**：
    - 代謝途徑的**終產物抑制上游酵素**，通常為 rate-limiting enzyme
    - 可避免終產物過度生成及能量浪費
    - 例：ATP、citrate 抑制 **PFK-1**

## 三、醣類代謝

### 3.1 糖解作用（Glycolysis）

- **位置**：細胞質（cytoplasm）
- **淨產物**：Glucose → 2 Pyruvate + 2 ATP + 2 NADH
- **三個不可逆步驟（調控酵素）**：

| 步驟 | 酵素 | 活化因子 | 抑制因子 |
|------|------|----------|----------|
| Glucose → G6P | **Hexokinase**（全身）/ **Glucokinase**（肝、β cell） | — | G6P |
| F6P → F1,6BP | **PFK-1**（**最重要的速率限制酵素**） | **AMP、F2,6BP** | **ATP、citrate** |
| PEP → Pyruvate | **Pyruvate kinase** | F1,6BP | ATP、Alanine |

- **Glucokinase vs Hexokinase**：

| | Hexokinase | Glucokinase |
|--|------------|-------------|
| 分布 | 所有組織 | 肝臟、胰島β cell |
| Km | 低（高親和力） | **高（低親和力）** |
| Vmax | 低 | 高 |
| G6P 抑制 | 有 | **無** |
| 功能 | 維持基本糖解 | **血糖感應器**：高血糖時才大量作用 |

- **PFK-2 / FBPase-2**：
    - **Insulin**（進食）→ PFK-2 活化 → **F2,6BP↑** → 刺激 PFK-1 → 促進糖解
    - **Glucagon**（空腹）→ FBPase-2 活化 → **F2,6BP↓** → 抑制 PFK-1 → 減少糖解

- **Pyruvate 的命運**：
    - 有氧：→ Acetyl-CoA（經 pyruvate dehydrogenase）→ 進 TCA cycle
    - 缺氧：→ **Lactate**（經 lactate dehydrogenase，NADH → NAD⁺ 再生）
    - 糖質新生：→ Oxaloacetate（經 pyruvate carboxylase）

### 3.2 丙酮酸脫氫酶複合體（Pyruvate Dehydrogenase Complex）

- **反應**：Pyruvate + CoA + NAD⁺ → **Acetyl-CoA** + CO₂ + NADH
- **不可逆**（Acetyl-CoA 不能回到 glucose）
- **輔因子**（5 種）：
    1. **TPP**（Thiamine / B1）
    2. **FAD**（Riboflavin / B2）
    3. **NAD⁺**（Niacin / B3）
    4. **CoA**（Pantothenic acid / B5）
    5. **Lipoic acid**
- **調控**：
    - 活化：**NAD⁺、CoA、ADP**；PDH phosphatase（去磷酸化 → 活化）
    - 抑制：**NADH、Acetyl-CoA、ATP**；PDH kinase（磷酸化 → 不活化）
- **PDH 缺乏**：
    - Pyruvate 堆積 → 轉成 **lactate** → **lactic acidosis**
    - 也轉成 **alanine**（經 ALT）
    - 治療：高脂/低碳水飲食（ketogenic diet）、補充 thiamine

### 3.3 檸檬酸循環（TCA Cycle / Krebs Cycle）

- **位置**：**粒線體基質（mitochondrial matrix）**
- **每一圈 Acetyl-CoA 產生**：3 NADH + 1 FADH₂ + 1 GTP + 2 CO₂
- **速率限制酵素**：**Isocitrate dehydrogenase**
    - 活化：ADP
    - 抑制：ATP、NADH
- 其他調控點：Citrate synthase（抑制：ATP、citrate、NADH）、α-KG dehydrogenase（抑制：succinyl-CoA、NADH）
- **α-KG dehydrogenase** 所需輔因子同 PDH（TPP, FAD, NAD⁺, CoA, lipoic acid）
- **Anaplerotic reactions（回補反應）**：
    - **Pyruvate → OAA**（Pyruvate carboxylase，需 **biotin**）
    - Glutamate → α-KG
    - Aspartate → OAA

### 3.4 氧化磷酸化（Oxidative Phosphorylation）

- **位置**：**粒線體內膜（inner mitochondrial membrane）**
- **電子傳遞鏈（ETC）**：

| 複合體 | 功能 | 抑制劑 |
|--------|------|--------|
| **Complex I**（NADH dehydrogenase） | NADH → CoQ；pumps H⁺ | **Rotenone**、Barbiturates |
| **Complex II**（Succinate dehydrogenase） | FADH₂ → CoQ；**不 pumps H⁺** | Malonate |
| **Complex III**（Cytochrome bc1） | CoQ → Cyt c；pumps H⁺ | **Antimycin A** |
| **Complex IV**（Cytochrome c oxidase） | Cyt c → O₂；pumps H⁺ | **CO、CN⁻**、H₂S |
| **Complex V**（ATP synthase） | H⁺ 流回 → ADP + Pi → ATP | **Oligomycin** |

- **NADH → 約 2.5 ATP**（經 Complex I → III → IV）
- **FADH₂ → 約 1.5 ATP**（經 Complex II → III → IV）
- **1 Glucose 完全氧化 → 約 30–32 ATP**
- **NADH shuttle systems**：
    - **Malate-aspartate shuttle**（心、肝）→ NADH 進粒線體 → 2.5 ATP/NADH
    - **Glycerol-3-phosphate shuttle**（骨骼肌、腦）→ FADH₂ 進粒線體 → 1.5 ATP/NADH

- **解偶聯劑（Uncouplers）**：H⁺ 不經 Complex V 即回流 → 能量以熱散失，不合成 ATP
    - **UCP1（Thermogenin）**：棕色脂肪中的天然 uncoupler → 新生兒非顫抖性產熱
    - **2,4-DNP**、**Aspirin（高劑量）**、**甲狀腺素（T3/T4）**

- **氰化物中毒**：
    - 機制：抑制 Complex IV → ETC 停擺 → 組織無法利用 O₂ → 細胞缺氧
    - 治療：**Hydroxocobalamin**（首選）或 **Nitrite + Thiosulfate**

### 3.5 糖質新生（Gluconeogenesis）

- **位置**：主要在**肝臟**（少量在腎臟），細胞質 + 粒線體
- **前驅物**：Lactate、Amino acids（尤其 Alanine）、Glycerol、Propionyl-CoA
- **不能作為前驅物**：**偶數碳脂肪酸**（→ Acetyl-CoA → 無法淨產生 glucose）、**Leucine、Lysine**（purely ketogenic）
- **四個繞道反應（bypass reactions）**：

| Glycolysis 酵素 | Gluconeogenesis 繞道酵素 | 位置 |
|-----------------|--------------------------|------|
| Pyruvate kinase | **Pyruvate carboxylase**（需 biotin）+ **PEP carboxykinase（PEPCK）** | 粒線體 / 細胞質 |
| PFK-1 | **Fructose-1,6-bisphosphatase（FBPase-1）** | 細胞質 |
| Hexokinase/Glucokinase | **Glucose-6-phosphatase（G6Pase）** | ER 膜 |

- **Pyruvate carboxylase**：需 **Biotin（B7）**；被 **Acetyl-CoA allosteric 活化**
- **G6Pase 僅存在於肝和腎** → 骨骼肌、腦無法釋出游離 glucose

- **Cori cycle**：肌肉 glucose → lactate → 血液 → 肝臟 → glucose（gluconeogenesis）→ 血液 → 肌肉
- **Cahill cycle**：肌肉 pyruvate + amino group → alanine → 血液 → 肝臟 → pyruvate（gluconeogenesis）+ NH₃（→ urea）

### 3.6 肝醣代謝（Glycogen Metabolism）

- **肝醣合成（Glycogenesis）**：
    - 關鍵酵素：**Glycogen synthase**（α-1,4 linkage）
    - Branching enzyme（α-1,6 linkage）
    - **Insulin → 活化 Glycogen synthase（經去磷酸化）**
- **肝醣分解（Glycogenolysis）**：
    - 關鍵酵素：**Glycogen phosphorylase**（斷 α-1,4，產生 G1P）
    - Debranching enzyme（斷 α-1,6，釋放游離 glucose）
    - **Glucagon / Epinephrine → 活化 Glycogen phosphorylase（經磷酸化）**

- **調控核心**：
    - Glucagon → cAMP↑ → PKA → 磷酸化 phosphorylase kinase → 磷酸化 glycogen phosphorylase（**活化**） + 磷酸化 glycogen synthase（**不活化**）→ 促進分解
    - Insulin → protein phosphatase → 去磷酸化 → 促進合成

### 3.7 肝醣儲積症（Glycogen Storage Diseases）

| Type | 名稱 | 缺陷酵素 | 特色 |
|------|------|----------|------|
| **Ia** | **Von Gierke** | **Glucose-6-phosphatase** | **最常見 hepatic GSD**；嚴重空腹低血糖、hepatomegaly、高乳酸血症、高尿酸血症、高脂血症、doll face |
| **II** | **Pompe** | **Acid α-glucosidase（lysosomal acid maltase）** | **唯一的 lysosomal GSD**；嬰兒型：心肌肥大、肌張力低下 → 死亡；成人型：proximal myopathy |
| **III** | **Cori** | Debranching enzyme | 類似 Von Gierke 但較輕微；空腹低血糖可由蛋白質改善（gluconeogenesis 正常） |
| **IV** | **Andersen** | Branching enzyme | 肝硬化、肝衰竭（異常長鏈肝醣如 amylopectin） |
| **V** | **McArdle** | **Muscle glycogen phosphorylase** | 運動不耐、肌肉痙攣、**myoglobinuria**；second wind phenomenon |

### 3.8 五碳磷酸路徑（Pentose Phosphate Pathway / HMP Shunt）

- **位置**：細胞質
- **功能**：
    1. 產生 **NADPH**（用於脂肪酸合成、cholesterol 合成、glutathione 還原、P-450 反應、呼吸爆發 → ROS）
    2. 產生 **Ribose-5-phosphate**（用於核苷酸合成）
- **兩個階段**：
    - **氧化階段（不可逆）**：G6P → 6-phosphogluconate → Ribulose-5-P，產生 **2 NADPH**
        - 速率限制酵素：**Glucose-6-phosphate dehydrogenase（G6PD）**
        - 活化：**NADP⁺**（即 NADPH 被消耗時）
    - **非氧化階段（可逆）**：Ribulose-5-P ↔ Ribose-5-P、Xylulose-5-P
        - 酵素：Transketolase（需 **TPP / B1**）、Transaldolase
        - 可與糖解中間產物互通（F6P、G3P）

- **G6PD 缺乏症**：
    - **X-linked recessive**，全球最常見的酵素缺乏症
    - NADPH↓ → 無法維持 **glutathione（GSH）** → RBC 易受氧化傷害 → **溶血**
    - 誘發因子：**蠶豆（fava beans）**、感染、藥物（Primaquine、Sulfonamides、Dapsone、Nitrofurantoin）
    - 血液抹片：**Heinz bodies**（變性 Hb 沉澱）、**bite cells**（脾臟去除 Heinz body 後）
    - 急性期避免檢測 G6PD（溶血後新生 RBC 的 G6PD 較高 → 可能假正常）
    - 保護效果：對 **Plasmodium falciparum** 瘧疾有部分保護

### 3.9 果糖代謝（Fructose Metabolism）

| 疾病 | 缺陷酵素 | 特色 |
|------|----------|------|
| **Essential fructosuria** | **Fructokinase** | 良性，無症狀，尿中有果糖 |
| **Hereditary fructose intolerance** | **Aldolase B** | 攝取果糖/蔗糖後：**低血糖**（F1P 堆積 → 抑制 glycogenolysis & gluconeogenesis）、嘔吐、肝衰竭；避免果糖/蔗糖/sorbitol |

### 3.10 半乳糖代謝（Galactose Metabolism）

| 疾病 | 缺陷酵素 | 特色 |
|------|----------|------|
| **Galactokinase deficiency** | **Galactokinase** | 良性：**白內障**（galactitol 堆積於水晶體）；無智力障礙 |
| **Classic galactosemia** | **Galactose-1-phosphate uridylyltransferase** | 新生兒餵奶後：黃疸、肝腫大、白內障、**智力障礙**、E. coli sepsis（newborn）；避免乳糖/半乳糖 |

### 3.11 乳糖不耐症（Lactose Intolerance）

- **Lactase deficiency** → 乳糖無法分解 → 細菌發酵 → 腹脹、腹瀉、脹氣
- 成人型最常見（乳糖酶活性隨年齡下降）
- 診斷：**Hydrogen breath test**（細菌發酵產 H₂）

### 3.12 山梨醇代謝（Sorbitol Metabolism）

- **Aldose reductase**：Glucose → Sorbitol（用 NADPH）
- **Sorbitol dehydrogenase**：Sorbitol → Fructose（產 NADH）
- 不含 sorbitol dehydrogenase 的組織：Sorbitol 易堆積影響細胞
- **DM 慢性併發症的機制之一**：
    - **Lens**（白內障）
    - **Schwann cells**（周邊神經病變）
    - **Retina pericytes**（視網膜病變）
    - **Kidney**（腎病變）

## 四、脂質代謝

### 4.1 脂肪酸合成（Fatty Acid Synthesis）

- **位置**：**細胞質**
- **前驅物**：Acetyl-CoA（來自 citrate shuttle）
- **速率限制酵素**：**Acetyl-CoA carboxylase**
    - 反應：Acetyl-CoA → Malonyl-CoA（需 **Biotin、ATP**）
    - 活化：**Insulin、Citrate**
    - 抑制：**Glucagon、Epinephrine、Palmitoyl-CoA**
- **合成酶**：**Fatty acid synthase**
    - 使用 **NADPH**（來自 PPP）
    - 產物：**Palmitate（C16:0）**

### 4.2 脂肪酸 β-氧化（β-Oxidation）

- **位置**：**粒線體基質**
- 長鏈脂肪酸需 **Carnitine shuttle** 進入粒線體：
    - **Carnitine palmitoyltransferase I**（外膜）：速率限制步驟
    - 受 **Malonyl-CoA 抑制**（進食時不做 β-oxidation）
- **每一輪 β-oxidation**：切下 2C（Acetyl-CoA），產生 1 NADH + 1 FADH₂
- **奇數碳脂肪酸**：最後產生 **Propionyl-CoA** → Methylmalonyl-CoA → **Succinyl-CoA**（需 **B12**）→ 進入 TCA cycle → **可生糖**
- **極長鏈脂肪酸（≥C22）**：先在 **peroxisome** 初步氧化
    - 缺陷 → **X-linked Adrenoleukodystrophy**：VLCFA 堆積
    - **Zellweger syndrome**：peroxisome 完全缺失
- **Carnitine deficiency**：無法運送長鏈脂肪酸進入粒線體 → **低酮性低血糖**、肌病變、心肌病變
- **MCAD deficiency**：無法分解中鏈脂肪酸 → 空腹時**低酮性低血糖**，C6–C10 acylcarnitine↑

### 4.3 酮體代謝（Ketone Body Metabolism）

- **合成位置**：**肝臟粒線體**
- **原料**：Acetyl-CoA（脂肪酸 β-oxidation 過量時）
- **速率限制酵素**：**HMG-CoA synthase**
- **三種酮體**：Acetoacetate、**β-hydroxybutyrate**（血中最多）、Acetone（呼氣排出）
- **肝臟合成但無法利用**（缺乏 **thiophorase**）
- **利用組織**：心臟、骨骼肌、腎臟、**腦（長期飢餓時）**
- **臨床意義**：
    - **Diabetic ketoacidosis（DKA）**：Type 1 DM → insulin↓ → lipolysis↑ → β-oxidation↑ → 酮體↑ → metabolic acidosis with **increased anion gap**
    - **Starvation ketosis**：長期飢餓時腦利用酮體以節省 glucose

### 4.4 膽固醇代謝（Cholesterol Metabolism）

- **合成位置**：肝臟（主要）、腸道、腎上腺、生殖腺；**細胞質 + ER**
- **前驅物**：Acetyl-CoA
- **速率限制酵素**：**HMG-CoA reductase**
    - 反應：HMG-CoA → **Mevalonate**（用 2 NADPH）
    - 活化：**Insulin**
    - 抑制：**Glucagon、Cholesterol、Statins**
- **膽固醇的功能**：
    - 細胞膜成分
    - 合成 **bile acids**（在肝臟，7α-hydroxylase 為速率限制步驟）
    - 合成 **steroid hormones**（cortisol、aldosterone、androgens、estrogens）
    - 合成 **Vitamin D**

### 4.5 脂蛋白（Lipoproteins）

| 脂蛋白 | 來源 | 主要成分 | 主要 Apolipoprotein | 功能 |
|--------|------|----------|---------------------|------|
| **Chylomicron** | 腸道 | 飲食 TG | **ApoB-48**、ApoC-II、ApoE | 運送飲食脂肪 → 周邊組織 |
| **VLDL** | 肝臟 | 內源性 TG | **ApoB-100**、ApoC-II、ApoE | 運送肝合成 TG → 周邊 |
| **IDL** | VLDL 代謝 | Cholesterol + TG | ApoB-100、ApoE | VLDL → IDL → LDL |
| **LDL** | IDL 代謝 | **Cholesterol**（最多） | **ApoB-100** | 運送膽固醇 → 周邊組織；**「壞的」膽固醇** |
| **HDL** | 肝臟、腸道 | Cholesterol、phospholipid | **ApoA-I** | 逆向膽固醇運送至肝臟；**「好的」膽固醇** |

- **重要 Apolipoproteins**：

| Apo | 功能 |
|-----|------|
| **ApoB-100** | LDL receptor 的配體（被肝臟回收） |
| **ApoB-48** | Chylomicron 組裝 |

- **Lipoprotein lipase（LPL）**：位於血管內皮，水解 TG → FFA + glycerol
- **Hepatic lipase**：位於肝臟，將 IDL → LDL

### 4.6 高脂血症（Dyslipidemias）

| 類型 | 缺陷 | 特色 |
|------|------|------|
| **Type I（Familial LPL deficiency / ApoC-II deficiency）** | LPL 或 ApoC-II | **Chylomicron↑↑** → 嚴重高 TG → **急性胰臟炎**、**eruptive xanthoma**、lipemia retinalis |

| **Type III（Familial dysbetalipoproteinemia）** | ApoE2 | IDL 及 chylomicron remnant↑ → **palmar xanthoma**、tuberoeruptive xanthoma |
| **Type IV** | VLDL↑ | **TG↑**、常與代謝症候群相關 |

- **Familial Hypercholesterolemia（FH）**：
    - **Heterozygote**：LDL 約 300–500 mg/dL → 冠心病 30–50 歲
    - **Homozygote**：LDL > 600 mg/dL → 冠心病 <20 歲、MI 可於兒童期

## 五、胺基酸代謝

### 5.1 轉胺與脫胺（Transamination & Deamination）

- **Transamination**：胺基酸 + α-KG ↔ α-keto acid + Glutamate
    - 酵素：**Aminotransferases（ALT、AST）**
    - 輔酶：**Pyridoxal phosphate（PLP, Vitamin B6）**
- **Oxidative deamination**：Glutamate → α-KG + **NH₄⁺**
    - 酵素：**Glutamate dehydrogenase**（粒線體）
    - 產生的 NH₄⁺ → 進入 urea cycle
- **NH₃ 運輸**：
    - 大多數組織：**Glutamine** → 血液 → 肝臟 → Glutamate + NH₄⁺
    - 肌肉：**Alanine** → 血液 → 肝臟 → Pyruvate + NH₃

### 5.2 尿素循環（Urea Cycle）

- **位置**：**肝臟**（粒線體及細胞質）
- **功能**：將有毒的 NH₃ 轉化為無毒的 urea 由腎臟排出
- **步驟**：
    1. **Carbamoyl phosphate synthetase I**：**NH₃** + CO₂ + 2ATP → Carbamoyl phosphate
        - 速率限制酵素；**N-acetylglutamate** 為 allosteric activator
    2. **Ornithine transcarbamylase**：Carbamoyl phosphate + Ornithine → Citrulline
    3. Argininosuccinate synthetase：Citrulline + **Aspartate** → Argininosuccinate
    4. Argininosuccinate lyase：Argininosuccinate → Arginine + Fumarate
    5. Arginase：Arginine → **Urea** + Ornithine
- **尿素循環缺陷**
    - **共同表現**：**高血氨（Hyperammonemia）** → 嘔吐、嗜睡、腦水腫、seizure、coma
    - **Ornithine transcarbamylase deficiency**：**最常見**，**X-linked**；**orotic acid↑**（carbamoyl phosphate 轉入 pyrimidine 合成途徑） 
    - **治療原則**：低蛋白飲食、**Lactulose**（促 NH₃ 排出）、**Benzoate**（結合 Glycine）

### 5.3 個別胺基酸代謝異常

| 疾病 | 缺陷 | 堆積/缺乏 | 特色 |
|------|------|-----------|------|
| **Phenylketonuria（PKU）** | **Phenylalanine hydroxylase**（最常見）或 BH4 缺乏 | Phe↑、Tyr↓ | **智力障礙**、musty/mousy body odor、fair skin/hair（melanin↓）、eczema；**新生兒篩檢**；治療：**低 Phe 飲食 + Tyr 補充**；**母體 PKU** → 胎兒小頭、心臟缺損 |
| **Maple Syrup Urine Disease（MSUD）** | **Branched-chain α-ketoacid dehydrogenase** | Ile、Leu、Val 及其 α-keto acids↑ | 楓糖漿尿味、CNS damage、feeding difficulty；治療：限制 branched-chain AA 攝取 + **Thiamine（B1）**（部分 variant 有反應） |
| **Homocystinuria** | （見 5.4） | Homocysteine↑ | （見 5.4） |
| **Cystinuria** | 腎小管 dibasic AA 再吸收缺陷（Cys、Orn、Lys、Arg） | 尿中 cystine↑ | **Cystine 腎結石**（六角形結晶）；治療：大量飲水、尿液鹼化、Penicillamine |
| **Alkaptonuria** | **Homogentisic acid oxidase** | Homogentisic acid↑ | 尿液暴露空氣後**變黑**；**Ochronosis**（色素沉積於軟骨/結締組織）；退化性關節炎 |
| **Albinism** | **Tyrosinase**（oculocutaneous type） | Melanin↓ | 皮膚/毛髮/眼睛色素缺乏、畏光、↑皮膚癌風險 |
| **Hartnup disease** | 腸道/腎小管中性 AA 再吸收缺陷（尤其 Trp） | 尿中中性 AA↑、Niacin↓ | Pellagra-like symptoms（3D: Dermatitis, Diarrhea, Dementia）；治療：**Niacin 補充** |
| **Histidinemia** | Histidase | Histidine↑ | 通常良性、無症狀 |

### 5.4 Homocysteine 代謝與 Homocystinuria

- **Homocysteine 代謝有兩條路徑**：
    1. **Remethylation**：Homocysteine → Methionine（需 **B12** 和 **Folate** / methionine synthase）
    2. **Transsulfuration**：Homocysteine → Cystathionine → Cysteine（需 **Cystathionine β-synthase（CBS）** + **B6**）

- **Homocystinuria 原因**：

| 原因 | 特色 |
|------|------|
| **CBS deficiency**（最常見） | Homocysteine↑、Methionine↑；**Marfanoid habitus、ectopia lentis（downward lens subluxation，與 Marfan 的 upward 相反）、智力障礙、骨質疏鬆、血栓**；治療：**B6（pyridoxine）**（部分有反應）+ 低 Met 飲食 + Cysteine 補充 |
| **B12 deficiency** | Homocysteine↑、Methylmalonic acid↑ |
| **Folate deficiency** | Homocysteine↑、MMA 正常 |

- **高 Homocysteine 血症**：獨立的心血管疾病風險因子 → 動脈粥狀硬化、血栓

### 5.5 生物胺合成

| 前驅胺基酸 | 產物 | 關鍵酵素 | 輔因子 |
|------------|------|----------|--------|
| **Tryptophan** | Serotonin（5-HT） → Melatonin | Tryptophan hydroxylase → AADC | **BH4**、B6 |
| **Tyrosine** | DOPA → Dopamine → NE → Epinephrine | Tyrosine hydroxylase（**速率限制**）→ AADC → DβH → PNMT | **BH4**、B6、Vit C、SAM |
| **Histidine** | Histamine | Histidine decarboxylase | B6 |
| **Glutamate** | GABA | Glutamic acid decarboxylase（GAD） | **B6** |

- **BH4（Tetrahydrobiopterin）**：Phe hydroxylase、Tyr hydroxylase、Trp hydroxylase 的輔因子
- **BH4 deficiency** → PKU-like + 神經傳導物缺乏（嚴重神經症狀）→ 需補充 BH4 + L-DOPA + 5-HTP

## 六、核苷酸代謝

### 6.1 Purine 合成

- **De novo synthesis**：
    - 在 **Ribose-5-P** 骨架上逐步建構
    - 速率限制酵素：**PRPP amidotransferase**（Glutamine → 提供 N）
        - 抑制：AMP、GMP、IMP（feedback inhibition）
    - **PRPP synthetase**：Ribose-5-P + ATP → **PRPP**
- **Purine ring 原子來源**：
    - **Glycine**：C4、C5、N7
    - **Glutamine**：N3、N9
    - **Aspartate**：N1
    - **CO₂**：C6
    - **N¹⁰-formyl-THF**：C2、C8
- **Salvage pathway**：
    - **HGPRT（Hypoxanthine-Guanine Phosphoribosyltransferase）**：Hypoxanthine → IMP、Guanine → GMP
    - **APRT**：Adenine → AMP
    - **HGPRT 缺乏 → Lesch-Nyhan syndrome**

### 6.2 Purine 降解

- AMP / GMP → Hypoxanthine → **Xanthine** → **Uric acid**
- 最後兩步由 **Xanthine oxidase** 催化
- 尿酸為人類 purine 代謝終產物（人類缺乏 uricase）
- **Gout（痛風）**：尿酸↑ → monosodium urate（MSU）結晶沉積
    - 急性治療：NSAIDs、Colchicine、Corticosteroid
    - 降尿酸：**Allopurinol**（xanthine oxidase inhibitor，注意 HLA-B*5801）、**Febuxostat**、**Probenecid**（uricosuric）、**Pegloticase**（recombinant uricase）

### 6.3 Lesch-Nyhan Syndrome

- **HGPRT 完全缺乏**（X-linked recessive）
- Purine salvage↓ → de novo↑ → 尿酸↑↑
- **表現**：**自殘行為（self-mutilation，咬手指/嘴唇）**、智力障礙、痛風、腎結石、choreaoathetosis
- 治療：Allopurinol（降尿酸，但不改善神經症狀）

### 6.4 Pyrimidine 合成

- **De novo synthesis**：
    - 先合成 **ring**（Carbamoyl phosphate + Aspartate → Orotate），再接上 Ribose-5-P
    - 注意：此處的 **CPS II 在細胞質**，用 **Glutamine**（不同於 urea cycle 的 CPS I 在粒線體用 NH₃）
    - 速率限制酵素：**CPS II**（in mammals）
    - Orotate + PRPP → OMP → UMP → UTP → CTP
- **Pyrimidine ring 原子來源**：
    - **Aspartate**：N1、C4、C5、C6
    - **CO₂**：C2
    - **Glutamine（經 CPS II）**：N3
- **dTMP 合成**：
    - dUMP → dTMP（經 **Thymidylate synthase**），需 **N⁵,N¹⁰-methylene-THF** 作為 one-carbon donor
    - THF 再生：Dihydrofolate reductase（**DHFR**）：DHF → THF
- **重要藥物靶點**：

| 藥物 | 靶點 | 用途 |
|------|------|------|
| **Methotrexate（MTX）** | **DHFR**（抑制 THF 再生） | 癌症、RA、ectopic pregnancy |
| **5-Fluorouracil（5-FU）** | **Thymidylate synthase**（經 FdUMP） | 大腸癌等 |
| **Trimethoprim** | Bacterial DHFR | 抗菌 |
| **Pyrimethamine** | Protozoan DHFR | 抗瘧、弓漿蟲 |
| **Hydroxyurea** | **Ribonucleotide reductase** | Sickle cell disease、CML |
| **Mycophenolate（MMF）** | **IMP dehydrogenase**（→ GMP↓） | 免疫抑制 |
| **Azathioprine（6-MP prodrug）** | Purine synthesis（多步驟） | 免疫抑制 |
| **Leflunomide** | **DHODH**（Dihydroorotate dehydrogenase） | RA |

### 6.5 Pyrimidine 降解

- Pyrimidine → 最終可完全降解（不像 purine → uric acid）
- 產物：β-alanine（from CTP/UMP）、β-aminoisobutyrate（from TMP）→ → CO₂ + NH₃

### 6.6 Orotic Aciduria

| 原因 | Orotic acid | 其他特色 |
|------|-------------|----------|
| **Hereditary Orotic aciduria** | ↑↑ | UMP synthase 缺陷（orotate phosphoribosyltransferase + OMP decarboxylase）；**巨幼紅細胞性貧血（megaloblastic anemia，對 B12/Folate 無反應）**；治療：**Uridine 補充** |
| **OTC deficiency** | ↑ | Urea cycle defect → carbamoyl phosphate 溢入 pyrimidine pathway；**高血氨** |

## 七、血紅素與卟啉代謝（Heme & Porphyrin）

### 7.1 Heme 合成

- **位置**：粒線體（第一步和最後幾步）+ 細胞質（中間步驟）
- **主要組織**：骨髓（紅血球系）、肝臟

| 步驟 | 酵素 | 位置 | 備註 |
|------|------|------|------|
| Succinyl-CoA + Glycine → δ-ALA | **ALA synthase（ALAS）** | 粒線體 | **速率限制步驟**；需 **B6（PLP）**；Heme feedback 抑制 |
| 2 δ-ALA → Porphobilinogen（PBG） | **ALA dehydratase** | 細胞質 | **鉛抑制** |
| 4 PBG → Hydroxymethylbilane → ... → Coproporphyrinogen III | 多步驟 | 細胞質 | — |
| ... → Protoporphyrin IX → **Heme** | **Ferrochelatase** | 粒線體 | **鉛抑制**；插入 **Fe²⁺** |

### 7.2 Porphyrias（紫質症）

| 疾病 | 缺陷酵素 | 遺傳 | 類型 | 特色 |
|------|----------|------|------|------|
| **Acute Intermittent Porphyria（AIP）** | **Porphobilinogen deaminase（=HMB synthase）** | **AD** | **急性肝型** | **最常見的急性 porphyria**；腹痛（最常見）、神經精神症狀（焦慮、seizure、周邊神經病變）、**無皮膚症狀**；尿液暴露光/空氣後**變紅/棕**（port wine urine）；**↑ALA、↑PBG**（尿中）；誘發：藥物（barbiturates、sulfonamides）、飢餓、酒精、月經 |
| **Porphyria Cutanea Tarda（PCT）** | **Uroporphyrinogen decarboxylase** | 多數後天 | **慢性皮膚型** | **最常見的 porphyria 總體**；光敏感性皮膚 → 水泡、瘢痕、多毛；與 HCV、酒精、鐵過量、HIV 相關；**Tea-colored urine**；↑uroporphyrin |
| **Erythropoietic Protoporphyria** | Ferrochelatase | AD | 紅血球型 | 光敏感（急性灼痛）；protoporphyrin↑（RBC 和 stool） |
| **Congenital Erythropoietic Porphyria（Günther's）** | Uroporphyrinogen III synthase | AR | 紅血球型 | 嚴重光敏感、紅色牙齒（erythrodontia）、溶血性貧血 |

- **AIP 治療**：避免誘發因子 + 高碳水化合物飲食（抑制 ALAS）+ **Hemin（heme arginate）** IV
- **PCT 治療**：避免誘發因子 + **phlebotomy**（降低鐵）+ **Hydroxychloroquine（低劑量）**

### 7.3 鉛中毒（Lead Poisoning）

- **抑制酵素**：**ALA dehydratase** 和 **Ferrochelatase**
- **結果**：ALA↑、Protoporphyrin↑（→ Zinc protoporphyrin↑ / FEP↑）、Heme↓
- **臨床**：
    - **兒童**：鉛漆、土壤；irritability、腹痛、腦病變（encephalopathy）、學習障礙、**basophilic stippling of RBC**、**Burton lines（牙齦藍線）**、wrist/foot drop
    - **成人**：職業暴露；腹絞痛、周邊神經病變（wrist drop）、腎毒性、貧血
- **診斷**：血中鉛濃度↑、FEP/ZPP↑、basophilic stippling、ringed sideroblasts
- **治療**：
    - 兒童 encephalopathy：**Dimercaprol（BAL）+ EDTA（CaNa₂EDTA）**
    - 輕度：**Succimer（DMSA）**（口服，兒童首選）

### 7.4 Heme 降解（Bilirubin 代謝）

- **Heme → Biliverdin → Unconjugated bilirubin（UCB，indirect）**
    - Heme oxygenase（RES：脾、肝）
    - UCB 與 **albumin** 結合運送至肝
- **肝臟 conjugation**：UCB → **Conjugated bilirubin（CB，direct）**
    - 酵素：**UDP-glucuronosyltransferase（UGT1A1）**
- CB 排入膽管 → 腸道 → 細菌作用 → **Urobilinogen** → 大部分 → **Stercobilin**（糞便棕色）；少量回吸收 → 腎臟 → **Urobilin**（尿液黃色）

- **黃疸鑑別**：

| 類型 | Unconjugated↑ | Conjugated↑ | 尿中 bilirubin | 尿中 urobilinogen |
|------|---------------|-------------|----------------|-------------------|
| **Prehepatic（溶血）** | ↑↑ | 正常 | (−) | ↑ |
| **Hepatocellular** | ↑ | ↑ | (+) | ↑或正常 |
| **Obstructive（膽道阻塞）** | 正常 | ↑↑ | (+)（dark urine） | ↓或(−)（pale stool） |

- **遺傳性黃疸**：

| 疾病 | 缺陷 | Bilirubin 型 | 特色 |
|------|------|-------------|------|
| **Gilbert syndrome** | UGT1A1 活性↓（mild） | **Unconjugated** | **最常見**；良性；壓力/空腹時輕度黃疸；無治療需要 |
| **Crigler-Najjar Type I** | UGT1A1 **完全缺乏** | Unconjugated | 嚴重 neonatal jaundice → **kernicterus**；Phenobarbital 無效；需**光療 + 肝移植** |
| **Crigler-Najjar Type II** | UGT1A1 活性**嚴重降低** | Unconjugated | 較 Type I 輕；**Phenobarbital 有效**（誘導殘餘 UGT） |
| **Dubin-Johnson** | Conjugated bilirubin **排出**（MRP2）缺陷 | **Conjugated** | 良性；肝臟**黑色素沉積（grossly black liver）** |
| **Rotor syndrome** | Conjugated bilirubin **儲存/排出**缺陷 | Conjugated | 良性；肝臟外觀正常（無色素沉積） |

- **Neonatal jaundice**：
    - 生理性：UGT1A1 不成熟 → unconjugated↑ → 2–3 天出現，通常 1–2 週消退
    - 危險：unconjugated bilirubin 通過 BBB → **Kernicterus**（膽紅素腦病變）→ basal ganglia、腦幹損傷
    - 治療：**光療（phototherapy）**（將 UCB 轉為水溶性異構物排出）；嚴重 → **換血**
    - **Breast milk jaundice**：β-glucuronidase 重新去結合 → unconjugated↑；通常良性

## 八、分子生物學

### 8.1 DNA 結構與複製

- **DNA 雙螺旋**：反平行（antiparallel）、右旋（B-form）
    - **A-T：2 個氫鍵**；**G-C：3 個氫鍵**（GC 含量越高，Tm 越高）
    - 5' → 3' 方向合成
- **DNA 複製**：

| 步驟 | 酵素 / 蛋白質 | 功能 |
|------|---------------|------|
| 解旋 | **Helicase** | 解開雙股 |
| 穩定 | **SSB（single-strand binding protein）** | 防止重新配對 |
| 解除超螺旋張力 | **Topoisomerase I**（切單股）、**Topoisomerase II（= DNA gyrase in bacteria）**（切雙股） | Fluoroquinolones 抑制 bacterial DNA gyrase/Topo IV |
| 引子合成 | **Primase** | 合成 RNA primer |
| 延伸 | **DNA Pol III**（原核，主要）/ **DNA Pol δ/ε**（真核） | 5' → 3' polymerase activity；3' → 5' **proofreading（exonuclease）** |
| 去除引子 / 填補 | **DNA Pol I**（原核）/ **RNase H + DNA Pol δ**（真核） | 5' → 3' exonuclease（僅 Pol I） |
| 連接 | **DNA Ligase** | 連接 Okazaki fragments |

- **Leading strand**：連續合成（5' → 3' 方向同複製叉移動方向）
- **Lagging strand**：不連續合成 → **Okazaki fragments** → DNA Pol I 去引子 → Ligase 連接
- **Telomerase**：RNA-dependent DNA polymerase（reverse transcriptase 活性）
    - 維持端粒長度（stem cells、germ cells、cancer cells 活性高）
    - 體細胞 telomerase 低 → 隨分裂端粒縮短 → 細胞老化

### 8.2 DNA 修復

| 修復機制 | 辨識/處理 | 相關疾病 |
|----------|-----------|----------|
| **Nucleotide Excision Repair（NER）** | 修復 **bulky lesions**（如 thymine dimer / UV damage） | **Xeroderma Pigmentosum（XP）**：UV 敏感、皮膚癌↑↑ |
| **Base Excision Repair（BER）** | 修復小型 base damage（deamination、oxidation）；**DNA glycosylase** 辨認切除、AP endonuclease | — |
| **Mismatch Repair（MMR）** | 修復 replication errors（base mismatches） | **Lynch syndrome（HNPCC）**：大腸癌、子宮內膜癌；MSI↑ |
| **Nonhomologous End Joining（NHEJ）** | 修復 DSB（雙股斷裂），不需模板 → 易出錯 | — |
| **Homologous Recombination（HR）** | 修復 DSB，需 sister chromatid 模板 → 精確 | **BRCA1/BRCA2 缺陷** → 乳癌、卵巢癌 |

- **Deamination products**：
    - Cytosine → **Uracil**（被 BER 修復：uracil DNA glycosylase）
    - 5-methylcytosine → **Thymine**（C→T transition，較難修復，是常見突變）
    - Adenine → Hypoxanthine

### 8.3 突變類型

| 突變 | 說明 | 例子 |
|------|------|------|
| **Silent** | 密碼子改變但胺基酸不變（同義突變） | — |
| **Missense** | 一個胺基酸改為另一個 | **Sickle cell disease**（Glu → Val，HbS）；Conservative vs Non-conservative |
| **Nonsense** | 產生 stop codon → 截短蛋白 | — |
| **Frameshift** | 插入或缺失（非 3 的倍數）→ 讀框改變 | **Tay-Sachs**、DMD |
| **Splice site** | 影響 intron/exon 邊界剪接 | 部分 β-thalassemia |
| **Trinucleotide repeat expansion** | 重複序列擴增 → 異常蛋白或基因沉默 | **Huntington**（CAG）、**Fragile X**（CGG）、**Myotonic dystrophy**（CTG）、**Friedreich ataxia**（GAA） |
| **Transition** | Purine↔Purine 或 Pyrimidine↔Pyrimidine | 較常見 |
| **Transversion** | Purine↔Pyrimidine | 較少見 |

### 8.4 轉錄（Transcription）

- **RNA Polymerase（真核）**：

| RNA Pol | 產物 | 抑制劑 |
|---------|------|--------|
| **RNA Pol I** | **rRNA**（28S, 18S, 5.8S） | — |
| **RNA Pol II** | **mRNA、snRNA、miRNA** | **α-Amanitin**（鵝膏毒素，低劑量即抑制） |
| **RNA Pol III** | **tRNA、5S rRNA** | α-Amanitin（高劑量） |

- **原核 RNA Pol**：只有一種，**σ factor** 辨識啟動子；**Rifampin** 抑制

- **mRNA 加工（真核）**：
    1. **5' capping**：加 7-methylguanosine cap → 保護、ribosome 辨識、翻譯起始
    2. **3' polyadenylation**：加 poly-A tail（100–250 A）→ 保護、穩定、核輸出
    3. **Splicing**：去除 introns、連接 exons
        - **Spliceosome**（snRNPs，U1/U2/U4/U5/U6）
        - **Alternative splicing** → 一個基因可產生多種蛋白
        - **Intron 邊界**：5' GU ... AG 3'（口訣：**GU-AG rule**）

### 8.5 基因調控

- **Lac operon（原核模型）**：
    - **Lac repressor**：結合 operator → 阻斷轉錄；**allolactose** 結合 repressor → 解除抑制
    - **CAP（catabolite activator protein）+ cAMP**：glucose↓ → cAMP↑ → CAP-cAMP 結合 promoter → 促進轉錄
    - 最大轉錄：**glucose↓ + lactose↑**
- **真核基因調控**：
    - **Enhancers / Silencers**：可在很遠的位置調控轉錄（透過 DNA looping + Mediator complex）
    - **Epigenetics**：
        - **DNA methylation**（CpG islands）→ 通常**抑制**轉錄
        - **Histone acetylation**（HAT）→ **活化**轉錄（鬆開 chromatin）
        - **Histone deacetylation**（HDAC）→ 抑制轉錄（壓緊 chromatin）
        - **Histone methylation**：視位置而定，可活化或抑制

### 8.6 翻譯（Translation / Protein Synthesis）

- **遺傳密碼特性**：
    - **Degeneracy（簡併性）**：多個 codon 編碼同一 AA（第三位 wobble position）
    - **Unambiguous**：一個 codon 只編碼一個 AA
    - **Universal**（少數例外：mitochondria、部分原生動物）
    - **Start codon**：**AUG（Met）**
    - **Stop codons**：**UAA、UAG、UGA**（口訣：U Are Annoying、U Are Gone、U Go Away）

- **tRNA**：
    - **Aminoacyl-tRNA synthetase**：將正確 AA 接到 tRNA（需 ATP → AMP + PPi）
    - **Anticodon** 與 mRNA codon 反平行配對
    - **Wobble position**：anticodon 的第一個核苷酸（5' 端）可以不嚴格配對

- **翻譯過程（原核 vs 真核）**：

| | 原核 | 真核 |
|--|------|------|
| Ribosome | **70S**（30S + 50S） | **80S**（40S + 60S） |
| 起始 AA | **fMet**（formyl-Met） | Met |
| Shine-Dalgarno | 有 | 無（用 Kozak sequence） |
| 同時轉錄翻譯 | 有（coupled） | 無（核內轉錄、細胞質翻譯） |

- **翻譯步驟**：
    1. **Initiation**：小亞基 + mRNA + initiator tRNA → 大亞基加入
    2. **Elongation**：
        - **A site**：Aminoacyl-tRNA 進入（EF-Tu in prokaryotes）
        - **P site**：Peptidyl-tRNA（肽鍵形成，**peptidyl transferase** = 23S rRNA，**ribozyme**）
        - **E site**：Exit
        - Translocation：EF-G（prokaryotes）/ eEF-2（eukaryotes）
    3. **Termination**：Stop codon → Release factors

- **翻譯後修飾（Post-translational Modification）**：
    - **N-linked glycosylation**：在 **ER**（Asn 殘基）
    - **O-linked glycosylation**：在 **Golgi**（Ser/Thr 殘基）
    - Phosphorylation、Acetylation、Ubiquitination、Hydroxylation、Carboxylation

- **蛋白質翻譯相關藥物**：

| 藥物 | 靶點 | 作用 |
|------|------|------|
| **Aminoglycosides**（Gentamicin） | **30S**（misread） | 殺菌 |
| **Tetracyclines** | **30S**（阻止 tRNA 結合 A site） | 抑菌 |
| **Chloramphenicol** | **50S**（抑制 peptidyl transferase） | 抑菌；bone marrow toxicity |
| **Macrolides**（Erythromycin） | **50S**（阻止 translocation） | 抑菌 |
| **Clindamycin** | **50S** | 抑菌 |
| **Linezolid** | **50S**（阻止 initiation complex） | — |
| **Diphtheria toxin** | **EF-2**（ADP-ribosylation） | 抑制真核翻譯 |
| **Pseudomonas exotoxin A** | **EF-2** | 同上 |
| **Cycloheximide** | **Eukaryotic 60S** | 實驗室用 |
| **Ricin / Shiga toxin** | **60S（28S rRNA）** | 去嘌呤化 → 阻止翻譯 |

### 8.7 重要分子生物學技術

| 技術 | 用途 |
|------|------|
| **PCR** | 擴增特定 DNA 片段（需 primers、Taq polymerase、dNTPs） |
| **RT-PCR** | RNA → cDNA → PCR（偵測 RNA 表現量，如 viral load） |
| **Southern blot** | 偵測 **DNA** 片段（restriction enzyme 切割 → 電泳 → transfer → DNA probe） |
| **Northern blot** | 偵測 **RNA** |
| **Western blot** | 偵測 **蛋白質**（SDS-PAGE → transfer → antibody probe）；確認 **HIV** |
| **ELISA** | 偵測 antibody 或 antigen；HIV 篩檢 |
| **Sanger sequencing** | DNA 定序（ddNTPs 終止法） |
| **Next-generation sequencing（NGS）** | 高通量定序 |
| **FISH** | 螢光原位雜交 → 偵測染色體異常（如 t(9;22) BCR-ABL） |
| **Microarray** | 同時偵測大量基因表現 |
| **CRISPR-Cas9** | 基因編輯（guide RNA + Cas9 endonuclease → DSB → NHEJ 或 HDR） |
| **Karyotyping** | 染色體分析（數目/結構異常） |

## 十、礦物質與微量元素

### 10.1 鐵代謝（Iron Metabolism）

- **吸收**：十二指腸及近端空腸；**Fe²⁺（ferrous）** 被吸收（**Vit C 促進 Fe³⁺ → Fe²⁺**）
- **運輸**：**Transferrin**（血中結合 Fe³⁺）
- **儲存**：**Ferritin**（細胞內）、Hemosiderin（過量鐵沉積）
- **調控**：**Hepcidin**（肝臟產生）
    - Hepcidin↑ → 抑制 Ferroportin → 鐵無法從腸道/巨噬細胞釋出 → 血清鐵↓
    - **發炎時 Hepcidin↑** → 慢性病貧血（ACD）
    - **鐵過量時 Hepcidin↑**（負回饋）
    - **缺鐵/缺氧/EPO↑ 時 Hepcidin↓**

- **缺鐵性貧血**：microcytic hypochromic；Ferritin↓、TIBC↑、Serum iron↓、Transferrin saturation↓
- **慢性病貧血**：Ferritin↑（acute phase reactant）、TIBC↓、Serum iron↓
- **Hemochromatosis**：**HFE 基因突變（C282Y）**、AR → Hepcidin↓ → 鐵過量吸收 → 肝硬化、DM（bronze diabetes）、心肌病變、關節炎、皮膚色素沉著；治療：Phlebotomy、Deferoxamine

### 10.2 銅代謝

- **Wilson disease**：**ATP7B** 基因突變（AR）→ 銅無法經膽汁排出 + ceruloplasmin 合成↓
    - 肝臟：肝炎、肝硬化
    - 腦：基底核沉積 → 運動障礙（tremor、dysarthria、dystonia）、精神症狀
    - 眼：**Kayser-Fleischer rings**（角膜 Descemet 膜銅沉積）
    - 實驗室：Ceruloplasmin↓、Serum free copper↑、24-hr urine copper↑
    - 治療：**Penicillamine**（copper chelator）、**Trientine**；**Zinc**（阻止腸道銅吸收）
- **Menkes disease**：ATP7A 突變（X-linked）→ 腸道銅吸收障礙 → 銅缺乏 → lysyl oxidase↓ → connective tissue abnormalities
    - 表現：kinky hair（鋼絲狀毛髮）、智力障礙、hypothermia

### 10.3 鋅（Zinc）

- 功能：>300 酵素的輔因子（如 Carbonic anhydrase、Alcohol dehydrogenase、Collagenase）；免疫功能；傷口癒合
- 缺乏：**Acrodermatitis enteropathica**（AR；鋅吸收缺陷）→ 皮膚炎（口周、肛周、四肢末端）、腹瀉、脫髮；免疫力↓；味覺障礙

## 十一、訊號傳遞與荷爾蒙生化

### 11.1 細胞訊號傳遞

| 受體類型 | 機制 | 代表配體 |
|----------|------|----------|
| **Gαs-coupled（cAMP↑）** | Gs → Adenylyl cyclase↑ → **cAMP↑** → **PKA** | **β-adrenergic、Glucagon、ACTH、TSH、FSH/LH、PTH、D1、H2、V2、PGI2** |
| **Gαi-coupled（cAMP↓）** | Gi → Adenylyl cyclase↓ → cAMP↓ | **α2-adrenergic、M2 muscarinic、D2、Somatostatin** |
| **Gαq-coupled（IP3/DAG）** | Gq → PLC → **PIP2 → IP3 + DAG**；IP3 → ER Ca²⁺ release；DAG → **PKC** | **α1-adrenergic、M1/M3 muscarinic、H1、V1、AT1、5-HT2** |
| **Receptor Tyrosine Kinase（RTK）** | Ligand → dimerization → autophosphorylation → **Ras-MAPK pathway** 或 **PI3K-Akt** | **Insulin、IGF-1、EGF、PDGF、FGF、VEGF** |
| **Non-receptor Tyrosine Kinase（JAK-STAT）** | Ligand → JAK phosphorylation → STAT dimerization → 核轉錄 | **GH、Prolactin、EPO、Cytokines（IL-2, IL-6, IFN）** |
| **Intracellular / Nuclear receptor** | 脂溶性配體穿膜 → 結合核受體 → 直接調控基因轉錄 | **Steroid hormones（Cortisol、Aldosterone、Estrogen、Testosterone）、Thyroid hormones、Vitamin D、Retinoic acid** |
| **Intrinsic Guanylyl Cyclase** | 配體結合 → **cGMP↑** | **ANP、BNP、NO（活化 soluble guanylyl cyclase）** |

- **Cholera toxin**：永久活化 **Gs** → cAMP↑↑ → 腸道 Cl⁻/H₂O 分泌↑↑ → 大量水瀉
- **Pertussis toxin**：永久抑制 **Gi** → cAMP↑↑ → 相關症狀
- **cAMP 降解**：**Phosphodiesterase（PDE）** → Caffeine/Theophylline/Sildenafil 抑制 PDE

### 11.2 Insulin 訊號

- **Insulin receptor**：Receptor Tyrosine Kinase → IRS-1 磷酸化 → PI3K → Akt
- **Insulin 作用**：
    - ↑ Glucose uptake（GLUT4 translocation → muscle/adipose）
    - ↑ Glycogen synthesis（glycogen synthase 活化）
    - ↑ Protein synthesis
    - ↑ Fatty acid synthesis（ACC 活化）
    - ↑ LPL activity
    - ↓ Gluconeogenesis
    - ↓ Glycogenolysis
    - ↓ Lipolysis（hormone-sensitive lipase 抑制）
    - ↓ Ketogenesis

- **Glucose transporters**：

| GLUT | 組織 | 特色 |
|------|------|------|
| **GLUT1** | RBC、BBB、大多數組織 | 基礎攝取 |
| **GLUT2** | 肝、β cell、腎、小腸 | 高 Km（低親和力）→ **glucose sensor** |
| **GLUT3** | 腦 | 低 Km（高親和力）→ 確保腦供糖 |
| **GLUT4** | 骨骼肌、脂肪 | **Insulin-dependent**（insulin → GLUT4 移至膜面） |
| **GLUT5** | 小腸（腸腔面） | Fructose transporter |
| **SGLT1** | 小腸 | Na⁺-glucose co-transporter |
| **SGLT2** | 近端腎小管 | Na⁺-glucose co-transporter；**SGLT2 inhibitors**（Dapagliflozin 等） |

### 11.3 重要荷爾蒙生化

- **Steroid hormones 合成**：
    - 前驅物：**Cholesterol** → Pregnenolone（經 **cholesterol desmolase / CYP11A1**，側鏈切割酵素；在粒線體內膜；受 **ACTH 經 StAR protein** 調控）
    - **17α-hydroxylase**：Pregnenolone → 17-OH-Pregnenolone（→ DHEA → Androgen pathway）
    - **21-hydroxylase（CYP21A2）**：需要合成 Cortisol 和 Aldosterone
    - **11β-hydroxylase（CYP11B1）**：最後步驟合成 Cortisol（11-deoxycortisol → Cortisol）

- **先天性腎上腺增生（Congenital Adrenal Hyperplasia, CAH）**：

| 缺陷酵素 | 結果 | 臨床 |
|----------|------|------|
| **21-hydroxylase deficiency**（**最常見 >90%**） | Cortisol↓ → ACTH↑ → adrenal hyperplasia；Aldosterone↓；**Androgens↑↑**（17-OHP↑） | **女嬰外生殖器模糊（virilization）**；男嬰可能有鹽分流失危象（salt-wasting）；17-OHP↑ 為篩檢標記 |
| **11β-hydroxylase deficiency** | Cortisol↓；**11-deoxycorticosterone↑**（有 mineralocorticoid 活性）→ **HTN + hypokalemia**；Androgens↑ | Virilization + **高血壓**（與 21-hydroxylase 不同） |
| **17α-hydroxylase deficiency** | Cortisol↓、Androgens↓、Estrogens↓；**Mineralocorticoids↑** | **HTN + hypokalemia**；**XY：phenotypic female**（男性假性兩性畸形）；XX：primary amenorrhea、infantile external genitalia |

## 十二、其他重要代謝主題

### 12.1 一碳代謝（One-Carbon Metabolism）與 Folate/B12

- **Tetrahydrofolate（THF）**：攜帶一碳單位（methyl、methylene、formyl groups）
- **關鍵反應**：
    - **dUMP → dTMP**（Thymidylate synthase；N⁵,N¹⁰-methylene-THF → DHF）→ **DHFR** 再生 THF
    - **Homocysteine → Methionine**（Methionine synthase；N⁵-methyl-THF → THF；需 **B12**）
    - Purine synthesis：N¹⁰-formyl-THF 提供 C2、C8
- **Folate trap hypothesis**：B12 缺乏 → methionine synthase 無法運作 → N⁵-methyl-THF 堆積無法回到 THF pool → **THF 不足** → DNA synthesis↓ → megaloblastic anemia
- **鑑別 B12 vs Folate 缺乏**：

| | B12 deficiency | Folate deficiency |
|--|----------------|-------------------|
| Megaloblastic anemia | Yes | Yes |
| Neurological sx | **Yes**（subacute combined degeneration） | No |
| Homocysteine | ↑ | ↑ |
| **MMA** | **↑** | Normal |

### 12.2 S-Adenosylmethionine（SAM）

- **Methionine + ATP → SAM**（甲基供體之王）
- **SAM 的甲基化反應**：
    - NE → Epinephrine（PNMT）
    - Norepinephrine synthesis
    - DNA methylation（epigenetics）
    - Phosphatidylethanolamine → Phosphatidylcholine
    - Creatine synthesis
    - Melatonin synthesis
- **SAM → SAH → Homocysteine** → Methionine（remethylation，需 B12/Folate）或 → Cysteine（transsulfuration，需 B6）

### 12.3 Glutathione（GSH）

- **組成**：γ-Glu-Cys-Gly
- **功能**：**抗氧化**、保護 RBC 免受 H₂O₂ 傷害、解毒（conjugation via GST）
- **GSH regeneration**：GSSG + **NADPH** → 2 GSH（由 **Glutathione reductase** 催化）
- **NADPH 主要來自 PPP（G6PD）**
- **G6PD deficiency → NADPH↓ → GSH↓ → RBC oxidative damage → hemolysis**
- **Acetaminophen（APAP）toxicity**：
    - 正常代謝：大部分 glucuronidation / sulfation 排出
    - 過量時 CYP450（CYP2E1）→ **NAPQI**（toxic metabolite）→ 正常由 **GSH** 解毒
    - GSH 耗竭 → NAPQI 與肝細胞蛋白結合 → **肝細胞壞死**
    - 治療：**N-Acetylcysteine（NAC）**（補充 GSH 前驅物 Cysteine）

### 12.4 Ethanol Metabolism

- **步驟**：
    1. Ethanol → **Acetaldehyde**（**Alcohol dehydrogenase, ADH**；NAD⁺ → NADH）
    2. Acetaldehyde → **Acetate**（**Aldehyde dehydrogenase, ALDH**；NAD⁺ → NADH）
    3. Acetate → Acetyl-CoA
- **NADH/NAD⁺ ratio↑** 的代謝效應：
    - **Pyruvate → Lactate↑**（LDH）→ **lactic acidosis**；Lactate 抑制尿酸排泄 → 高尿酸 → gout
    - **OAA → Malate↑** → **gluconeogenesis↓ → 低血糖**（尤其空腹飲酒）
    - **DHAP → Glycerol-3-P↑** → TG 合成↑ → **脂肪肝**
    - **Acetyl-CoA 堆積** → 酮體合成↑ → **ketoacidosis**
- **Disulfiram**：抑制 ALDH → Acetaldehyde 堆積 → 噁心、嘔吐、頭痛（厭酒效果）
- **Fomepizole**：抑制 ADH → 用於 **Methanol / Ethylene glycol** 中毒

### 12.5 Methanol & Ethylene Glycol 中毒

| | Methanol | Ethylene glycol |
|--|----------|-----------------|
| 代謝產物 | **Formic acid（甲酸）** | **Oxalic acid（草酸）**、Glycolic acid |
| 毒性 | **視神經損傷 → 失明**；metabolic acidosis | **腎衰竭**（calcium oxalate crystals）；metabolic acidosis |
| 治療 | **Fomepizole（首選）** 或 Ethanol（competitive inhibitor of ADH）+ **Folinic acid（leucovorin）** | **Fomepizole** 或 Ethanol + **Thiamine + Pyridoxine** |

### 12.6 Fed vs Fasted State 代謝整合

| | **Fed state（Insulin↑）** | **Fasted state（Glucagon↑）** |
|--|--------------------------|------------------------------|
| 肝臟 | Glycolysis↑、Glycogenesis↑、FA synthesis↑、Protein synthesis↑ | Glycogenolysis↑、Gluconeogenesis↑、β-oxidation↑、Ketogenesis↑ |
| 骨骼肌 | Glucose uptake↑（GLUT4）、Glycogenesis↑、Protein synthesis↑ | Proteolysis↑（供 AA 給肝臟做 gluconeogenesis）、FA oxidation↑ |
| 脂肪組織 | Glucose uptake↑、LPL↑、TG synthesis↑ | Lipolysis↑（HSL 活化 by glucagon/epi → FFA + glycerol 釋出） |
| 腦 | Glucose 為主要燃料 | 長期飢餓：**Ketone bodies** 可供約 2/3 能量需求 |

- **Prolonged starvation**（>2–3 天）：
    - 肝醣耗竭 → gluconeogenesis（初期用 AA，中期用 glycerol）
    - FFA → β-oxidation → ketone bodies↑↑ → 腦適應使用 ketone bodies → **減少肌肉蛋白分解（protein sparing）**
    - Metabolic rate↓（T3↓）

### 12.7 Kwashiorkor vs Marasmus

| | **Kwashiorkor** | **Marasmus** |
|--|-----------------|-------------|
| 缺乏 | **蛋白質**（熱量可能足夠） | **整體熱量（蛋白質+熱量）** |
| 外觀 | 水腫（albumin↓ → oncotic pressure↓）、肝腫大（fatty liver，因 apolipoprotein↓ → VLDL↓） | 極度消瘦、「皮包骨」 |
| 皮膚/頭髮 | 色素沉著不均（flaky paint dermatosis）、flag sign（頭髮變色）、易脫髮 | 皮膚鬆弛、皺紋 |
| 免疫 | ↓↓ | ↓ |
| 年齡 | 較大嬰兒/幼童（斷奶後） | 嬰兒 |

## 十三、遺傳代謝疾病補充整理（高頻考點）

### 13.1 Lysosomal Storage Diseases 速覽

- 共同特徵：**AR 遺傳**（Fabry 為 **X-linked**）、酵素缺陷 → 基質堆積 → 器官損傷
- 診斷：酵素活性測定、基因檢測

### 13.2 Mucopolysaccharidoses（MPS）

| 疾病 | 缺陷酵素 | 堆積 GAG | 特色 |
|------|----------|----------|------|
| **Hurler（MPS I H）** | α-L-iduronidase | Heparan sulfate + Dermatan sulfate | 嚴重；corneal clouding、智力障礙、hepatosplenomegaly、dysostosis multiplex、gargoylism |
| **Hunter（MPS II）** | Iduronate sulfatase | 同上 | **X-linked**（唯一）；**無 corneal clouding**（與 Hurler 鑑別）；aggressive behavior |
| **Sanfilippo（MPS III）** | 多種（Heparan sulfate 降解相關） | Heparan sulfate | 嚴重 CNS 退化、行為異常 |
| **Morquio（MPS IV）** | N-acetylgalactosamine-6-sulfatase 等 | Keratan sulfate | 嚴重骨骼異常（短軀幹、pectus carinatum）、**智力正常**、corneal clouding |

### 13.3 I-cell Disease（Mucolipidosis Type II）

- 缺陷：**N-acetylglucosamine-1-phosphotransferase**（無法合成 **Mannose-6-phosphate tag**）
- 結果：lysosomal enzyme 無法被標記 → 分泌到胞外而非進入 lysosome → 所有基質堆積
- 臨床：類似嚴重 Hurler → coarse facies、skeletal abnormalities、restricted joint mobility；**Inclusion bodies in fibroblasts**

| **Refsum disease** | Phytanoyl-CoA hydroxylase（α-oxidation） | Phytanic acid↑ → 周邊神經病變、retinitis pigmentosa、cerebellar ataxia、↑CSF protein |

### 14.1 原癌基因（Proto-oncogenes / Oncogenes）

- **Gain-of-function mutations**（顯性，一個 allele 突變即可致癌）

| Oncogene | 功能 | 相關腫瘤 |
|----------|------|----------|
| **RAS（KRAS, HRAS, NRAS）** | GTPase（信號傳遞） | Pancreatic ca（KRAS，>90%）、CRC、Lung |

| **L-MYC** | 轉錄因子 | Small cell lung ca |
| **BCR-ABL** | Tyrosine kinase | **CML**（t(9;22) Philadelphia chromosome）；**Imatinib** 靶點 |
| **HER2/neu（ERBB2）** | RTK | Breast ca；**Trastuzumab** |
| **RET** | RTK | MEN 2A/2B、Medullary thyroid ca |
| **c-KIT** | RTK | GIST；**Imatinib** |
| **RAF（BRAF）** | Serine/Threonine kinase | Melanoma（V600E）、Papillary thyroid ca；**Vemurafenib** |

### 14.2 腫瘤抑制基因（Tumor Suppressors）

- **Loss-of-function mutations**（隱性，通常需 **兩個 alleles 都失去** → **Knudson's two-hit hypothesis**）

| Gene | 功能 | 相關腫瘤 |
|------|------|----------|
| **p53（TP53）** | **"Guardian of the genome"**；G1/S arrest、DNA repair、apoptosis | **Li-Fraumeni syndrome**（AD）；>50% 人類癌症有 p53 突變 |
| **Rb（RB1）** | G1→S checkpoint（hypophosphorylated Rb 抑制 E2F → 阻止 S phase） | **Retinoblastoma**（AD）；Osteosarcoma |
| **APC** | Wnt/β-catenin pathway 的 negative regulator | **FAP**（Familial Adenomatous Polyposis）→ 大腸癌 |
| **BRCA1 / BRCA2** | DNA DSB repair（homologous recombination） | Breast ca、Ovarian ca |
| **VHL** | HIF 降解（ubiquitination） | **Von Hippel-Lindau**：Renal cell carcinoma（clear cell）、Hemangioblastoma、Pheochromocytoma |
| **WT1** | 轉錄因子 | Wilms tumor |
| **NF1（Neurofibromin）** | Ras-GAP（抑制 Ras） | Neurofibromatosis Type 1 |
| **NF2（Merlin）** | Cytoskeleton regulator | Neurofibromatosis Type 2（bilateral acoustic neuroma） |
| **TSC1/TSC2** | mTOR pathway 抑制 | Tuberous sclerosis |
| **PTEN** | PI3K/Akt pathway 抑制 | Endometrial ca、Glioblastoma；Cowden syndrome |

### 14.3 Cell Cycle Checkpoints

- **G1/S checkpoint**：**p53** → p21（CDK inhibitor）→ 阻止 Rb 磷酸化 → E2F 被抑制 → 不進入 S phase
- **G2/M checkpoint**：確認 DNA 完成複製且無損傷
- **CDK inhibitors**：p21（p53 下游）、p27、p16（INK4a，抑制 CDK4/6）
- **Pharmacological CDK4/6 inhibitors**：**Palbociclib、Ribociclib** → breast cancer
