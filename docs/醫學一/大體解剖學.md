# 大體解剖學

## 一、背部（Back）

### 1.1 脊椎（Vertebral Column）

- **共 33 塊**：頸椎 7、胸椎 12、腰椎 5、薦椎 5（融合）、尾椎 4（融合）
- **曲度**：
    - **Primary curvature**（胎兒即有，凹向前 = kyphosis）：胸曲、薦曲
    - **Secondary curvature**（出生後，凸向前 = lordosis）：**頸曲**（抬頭，約 3 個月）、**腰曲**（站立行走，約 1 歲）

| 椎骨 | 辨識特徵 |
|------|----------|
| **頸椎（典型）** | **Foramen transversarium**（C1–C6 有 **vertebral a.** 通過；C7 通常只有 vertebral v.）；**bifid spinous process**（C2–C6）；uncinate process；椎孔大、三角形 |
| **C1（Atlas）** | **無 body、無 spinous process**；anterior / posterior arch + lateral mass；與 occipital condyle 形成 **atlanto-occipital joint（點頭 "yes"）** |
| **C2（Axis）** | **Dens（odontoid process）**；**atlanto-axial joint（轉頭 "no"）**；dens 由 **transverse ligament of atlas** 固定；alar ligament、tectorial membrane |
| **C7（Vertebra prominens）** | 最長、不分叉的 spinous process → 體表標誌 |
| **胸椎** | **Costal facets**（body 與 transverse process）；心形 body；spinous process 長且向下；圓形椎孔；關節面呈 **coronal** → 利於**旋轉** |
| **腰椎** | 腎形大 body；spinous process 短、寬、水平（斧狀）；**mammillary process**、accessory process；關節面呈 **sagittal** → 利於**屈伸**、限制旋轉 |
| **薦椎** | 5 塊融合；**sacral promontory**；**sacral hiatus**（S5 未癒合，caudal epidural anesthesia 入口）、sacral cornua；前後各 4 對 sacral foramina |

### 1.2 椎間關節與韌帶

- **Intervertebral disc**：
    - **Annulus fibrosus**（纖維軟骨）+ **Nucleus pulposus**（**notochord** 衍生）
    - 突出最常見方向：**後外側**（PLL 窄，後外側無韌帶加強）
    - 最常見部位：**L4–L5、L5–S1**；其次 C5–C6、C6–C7
    - **腰椎**：L4/L5 disc 後外側突出 → 壓迫 **L5 神經根**（壓「下一個」）
    - **頸椎**：C5/C6 disc → 壓迫 **C6 神經根**（頸神經從同號椎骨「上方」穿出）

| 韌帶 | 位置 | 功能 / 特色 |
|------|------|------------|
| **Anterior longitudinal lig.** | 椎體前面 | 寬而強；限制**過度伸展** |
| **Posterior longitudinal lig.** | 椎體後面（椎管內） | 窄；限制**過度屈曲** |
| **Ligamentum flavum** | 連接相鄰 **laminae** | **彈性纖維**（黃色）；腰椎穿刺會穿過；肥厚 → spinal stenosis |
| **Interspinous / Supraspinous lig.** | Spinous process 之間 / 尖端 | Supraspinous 在頸部延續為 **ligamentum nuchae** |

- **腰椎穿刺（Lumbar puncture）**：
    - 位置：**L3–L4 或 L4–L5**；**兩側 iliac crest 最高點連線（supracristal plane）約通過 L4 spinous process**
    - 穿過順序：Skin → Superficial fascia → **Supraspinous lig.** → **Interspinous lig.** → **Ligamentum flavum** → Epidural space → Dura → Arachnoid → **Subarachnoid space**（抽 CSF）
    - **Conus medullaris** 終止：成人 **L1–L2**；新生兒約 **L3**
    - **Dural sac** 終止：**S2**；**Filum terminale** 附著於 coccyx

### 1.3 背部肌肉

| 層次 | 肌肉 | 神經 | 備註 |
|------|------|------|------|
| **淺層（extrinsic，上肢動作）** | **Trapezius** | **CN XI**（+ C3–C4 本體感覺） | 上提、後縮、上旋肩胛 |
| | **Latissimus dorsi** | **Thoracodorsal n.**（C6–C8） | 伸展、內收、內旋肱骨 |
| | **Levator scapulae** | **Dorsal scapular n.** + C3–C4 | 上提肩胛 |
| | **Rhomboid major / minor** | **Dorsal scapular n.**（C5） | 後縮肩胛 |
| **中層（呼吸）** | Serratus posterior superior / inferior | Intercostal nn. | — |
| **深層（intrinsic，固有背肌）** | Splenius capitis / cervicis；**Erector spinae**；Transversospinalis（semispinalis、multifidus、rotatores）；interspinales、intertransversarii | **Dorsal rami（脊神經後支）** | 維持姿勢、伸展脊柱 |

- **Erector spinae** 由外至內：**Iliocostalis → Longissimus → Spinalis**（口訣：**I Love Spine**）

### 1.4 背部重要三角

| 三角 | 邊界 | 內容 / 意義 |
|------|------|-------------|
| **Suboccipital triangle** | 內上：**Rectus capitis posterior major**；外上：**Obliquus capitis superior**；下：**Obliquus capitis inferior**；底：posterior atlanto-occipital membrane、posterior arch of atlas | **Vertebral a.**（第 3 段）、**Suboccipital n.（C1 dorsal ramus，純運動）**；**Greater occipital n.（C2 dorsal ramus）** 繞 inferior oblique 下緣上行 |
| **Triangle of auscultation** | Trapezius 外下緣、Latissimus dorsi 上緣、Rhomboid major（肩胛內側緣） | 肌肉最薄 → 聽診肺部 |
| **Lumbar triangle（of Petit）** | Iliac crest、Latissimus dorsi、External oblique | 腰疝（lumbar hernia） |

## 二、上肢（Upper Limb）

### 2.1 骨骼重點

- **Clavicle**：
    - **第一塊骨化**（膜內骨化為主）、**最常骨折的骨頭**
    - 骨折點：**中 1/3 與外 1/3 交界**
    - 內側段被 **SCM** 向上拉；外側段因上肢重量 + pectoralis major 向下、向內
- **Scapula**：Superior angle **T2**、Spine root **T3**、Inferior angle **T7**
    - **Suprascapular notch**：上方有 superior transverse scapular lig.
        - **Suprascapular a. 走韌帶上方、suprascapular n. 走下方**（口訣：**Army over Navy**）
- **Humerus** 骨折與受傷神經：

| 骨折部位 | 受傷神經 | 受傷血管 |
|----------|----------|----------|
| **Surgical neck** | **Axillary n.** | Posterior circumflex humeral a. |
| **Midshaft（radial groove）** | **Radial n.** | **Profunda brachii a.** |
| **Supracondylar** | **Median n.** | **Brachial a.**（→ Volkmann ischemic contracture） |
| **Medial epicondyle** | **Ulnar n.** | — |

- **Carpal bones**（外側 → 內側）：
    - 近排：**Scaphoid、Lunate、Triquetrum、Pisiform**
    - 遠排：**Trapezium、Trapezoid、Capitate、Hamate**
    - 口訣：**Some Lovers Try Positions That They Can't Handle**
    - **Scaphoid**：**最常骨折的腕骨**；血流由遠端進入 → **近端 avascular necrosis**；anatomical snuffbox 壓痛
    - **Lunate**：**最常脫位的腕骨** → 壓迫 carpal tunnel（median n.）
    - **Capitate**：最大腕骨
    - **Pisiform**：sesamoid bone（位於 FCU 肌腱內）
    - **Hook of hamate**：骨折 → 傷及 Guyon canal 內 ulnar n.

### 2.2 臂神經叢（Brachial Plexus）

- **組成**：**C5–T1 ventral rami**
- **Roots → Trunks → Divisions → Cords → Branches**（口訣：**Randy Travis Drinks Cold Beer**）
    - **Trunks**：Upper（C5–6）、Middle（C7）、Lower（C8–T1）
    - **Divisions**：位於 clavicle 後方；**posterior divisions 全部 → posterior cord**
    - **Cords**：以與 **axillary a. 第 2 段** 的位置命名（lateral、posterior、medial）
- **位置**：Roots / trunks 位於 posterior triangle，穿過 **anterior 與 middle scalene 之間**；cords 位於 axilla

| 來源 | 分支 | 神經根 | 支配 |
|------|------|--------|------|
| **Roots** | **Dorsal scapular n.** | C5 | Rhomboids、levator scapulae |
| | **Long thoracic n.** | **C5–C7** | **Serratus anterior** |
| **Upper trunk** | **Suprascapular n.** | C5–C6 | **Supraspinatus、Infraspinatus** |
| | N. to subclavius | C5–C6 | Subclavius |
| **Lateral cord** | **Lateral pectoral n.** | C5–C7 | Pectoralis major |
| **Medial cord** | **Medial pectoral n.** | C8–T1 | **Pectoralis major & minor** |
| | Medial brachial / antebrachial cutaneous n. | C8–T1 | 上臂 / 前臂內側皮膚 |
| **Posterior cord** | Upper subscapular n. | C5–C6 | Subscapularis |
| | **Thoracodorsal n.** | C6–C8 | **Latissimus dorsi** |
| | Lower subscapular n. | C5–C6 | Subscapularis、**Teres major** |
| **終末分支** | **Musculocutaneous n.** | C5–C7 | Lateral cord |
| | **Axillary n.** | C5–C6 | Posterior cord |
| | **Radial n.** | C5–T1 | Posterior cord |
| | **Median n.** | C5–T1 | Lateral + Medial cord |
| | **Ulnar n.** | C8–T1 | Medial cord |

- **注意**：Lateral pectoral n. 雖出自 lateral cord，但支配位置較 medial pectoral n. 更「內側（medial）」的 pectoralis major 部分 → 名稱依 cord 而非位置

| 損傷 | 神經根 | 原因 | 表現 |
|------|--------|------|------|
| **Erb–Duchenne palsy** | **Upper trunk（C5–C6）** | 難產頭肩過度分離、肩部著地 | **Waiter's tip**：上臂內收內旋、肘伸直、前臂旋前、腕屈曲 |
| **Klumpke palsy** | **Lower trunk（C8–T1）** | 上肢過度外展（抓樹枝、分娩手臂上拉）、**Pancoast tumor**、cervical rib | **Claw hand**（全手內在肌癱瘓）；可合併 **Horner syndrome**（T1 交感纖維） |
| **Long thoracic n. 損傷** | C5–C7 | 乳癌腋下淋巴結廓清、刀傷 | **Winged scapula**；手臂無法上舉超過水平 |

### 2.3 上肢終末神經

| 神經 | 運動支配 | 皮膚感覺 | 常見損傷 | 表現 |
|------|----------|----------|----------|------|
| **Axillary（C5–C6）** | **Deltoid、Teres minor** | 上臂外上（regimental badge area） | **Surgical neck 骨折**、**肩關節前下脫位** | 外展 15–90° 無力、肩部扁平 |
| **Musculocutaneous（C5–C7）** | **Coracobrachialis（穿過此肌）、Biceps、Brachialis** | 延續為 **lateral antebrachial cutaneous n.** → 前臂外側 | 少見 | 屈肘、旋後無力 |
| **Radial（C5–T1）** | 上臂：**Triceps**、anconeus；前臂：**Brachioradialis、ECRL**；**Deep branch（PIN）穿過 supinator** → 前臂後側伸肌群 | 上臂後、前臂後、**手背外側 3½ 指（不含指尖）** | 腋下（crutch palsy）；**midshaft humerus**；radial head 脫位（PIN） | **Wrist drop**；腋下受損時 triceps 亦癱瘓 |
| **Median（C5–T1）** | 前臂屈肌（**除 FCU 及 FDP 內側半**）；手：**LOAF**（Lateral 2 lumbricals、Opponens pollicis、Abductor pollicis brevis、Flexor pollicis brevis） | **掌側外側 3½ 指 + 該指背側指尖** | **Supracondylar 骨折**（近端）；**Carpal tunnel**（腕部） | 近端：**Hand of benediction**（握拳時 2、3 指無法屈曲）、ape hand；腕部：thenar atrophy |
| **AIN（median 分支）** | **FPL、FDP 外側半、Pronator quadratus** | **無** | — | 無法比 **OK sign** |
| **Ulnar（C8–T1）** | **FCU、FDP 內側半**；手：hypothenar、**medial 2 lumbricals、全部 interossei、adductor pollicis**、FPB deep head | **內側 1½ 指** | **Medial epicondyle**（近端）；**Hook of hamate / Guyon canal**（遠端） | **Claw hand**（4、5 指 MCP 過伸、IP 屈曲）；**Froment sign**（adductor pollicis 無力 → 以 FPL 代償） |

- **Ulnar paradox**：近端 ulnar n. 受損 → FDP 內側半也癱瘓 → 手指無法屈曲 → **claw 較不明顯**；遠端受損 claw 反而明顯
- **Median n. palmar cutaneous branch** 走在 flexor retinaculum **上方** → **carpal tunnel syndrome 時手掌中央感覺保留**
- **Recurrent branch of median n.**（"million dollar nerve"）：支配 thenar 肌，位置淺、易受傷

### 2.4 胸肩部肌肉

| 肌肉 | 起點 | 止點 | 神經 | 作用 / 考點 |
|------|------|------|------|-------------|

| **Subclavius** | 第 1 肋 | Clavicle 下面 | N. to subclavius | 穩定 clavicle |
| **Deltoid** | 外 1/3 clavicle、acromion、spine of scapula | **Deltoid tuberosity** | **Axillary** | 外展 15–90° |

- **Intertubercular sulcus**：外側唇 pec major、底 latissimus dorsi、內側唇 teres major（口訣：**a lady between two majors**）；溝內有 **biceps long head tendon**
- **肩外展分段**：0–15° **Supraspinatus** → 15–90° **Deltoid** → > 90° **Trapezius + Serratus anterior**（上旋肩胛）

| 空間 | 邊界 | 內容 |
|------|------|------|
| **Quadrangular space** | 上 teres minor、下 teres major、內 triceps long head、外 humerus surgical neck | **Axillary n. + Posterior circumflex humeral a.** |
| **Triangular space** | 上 teres minor、下 teres major、外 triceps long head | **Circumflex scapular a.** |
| **Triangular interval** | 上 teres major、內 triceps long head、外 humerus（lateral head） | **Radial n. + Profunda brachii a.** |

### 2.7 腋窩與血管

- **Axilla 邊界**：
    - 前壁：Pectoralis major & minor、clavipectoral fascia
    - 後壁：Subscapularis、teres major、latissimus dorsi
    - 內側壁：**Serratus anterior**、第 1–4 肋
    - 外側壁：Intertubercular sulcus
    - 頂（cervicoaxillary canal）：**Clavicle、第 1 肋、scapula 上緣**
- **Subclavian a.**：
    - 右側來自 **brachiocephalic trunk**；左側直接來自 **aortic arch**
    - 被 **anterior scalene** 分三段
    - 分支（口訣 **VIT C & D**）：**V**ertebral、**I**nternal thoracic、**T**hyrocervical trunk（inferior thyroid、suprascapular、transverse cervical）、**C**ostocervical trunk（deep cervical、supreme intercostal）、**D**orsal scapular
    - **Subclavian v. 在 anterior scalene 前方**；**subclavian a. 與 brachial plexus 在 anterior 與 middle scalene 之間**
- **Axillary a.**：從**第 1 肋外緣**到 **teres major 下緣**；被 **pectoralis minor** 分三段，第 1、2、3 段分別有 1、2、3 個分支

| 段 | 分支 |
|----|------|
| **第 1 段** | Superior thoracic a. |
| **第 2 段** | **Thoracoacromial a.**、**Lateral thoracic a.** |
| **第 3 段** | **Subscapular a.**（→ circumflex scapular、thoracodorsal）、**Anterior & Posterior circumflex humeral a.** |

- 口訣：**S**crew **T**he **L**awyer **S**ave **A** **P**atient
- **Brachial a.**：teres major 下緣起；分支 **profunda brachii**（伴 radial n.）、superior & inferior ulnar collateral；於 **cubital fossa（radius neck 高度）分為 radial a. 與 ulnar a.**
    - Ulnar a. → **common interosseous a.** → anterior & posterior interosseous a.
- **手部動脈弓**：
    - **Superficial palmar arch**：主要 **ulnar a.**；位置較遠端
    - **Deep palmar arch**：主要 **radial a.**；位置較近端
    - **Allen test**：檢測兩動脈側支循環
- **Scapular anastomosis**：**Suprascapular a.**、**dorsal scapular a.**、**circumflex scapular a.** → 結紮 axillary a.（在 thyrocervical 與 subscapular 之間）時提供側支循環
- **淺層靜脈**：
    - **Cephalic v.**：外側；走 **deltopectoral groove** → 穿 clavipectoral fascia → **axillary v.**
    - **Basilic v.**：內側；上臂中段穿深筋膜 → 與 brachial v. 匯合 → 於 teres major 下緣成 **axillary v.**
    - **Median cubital v.**：連接兩者 → 抽血常用
- **Cubital fossa**：
    - 邊界：上 = 兩 epicondyle 連線；內 **pronator teres**；外 **brachioradialis**；底 brachialis、supinator；頂 **bicipital aponeurosis**
    - 內容（外 → 內）：**(Radial n.)、Biceps tendon、Brachial a.、Median n.**
- **上肢淋巴**：
    - 內側（basilic 區）→ **cubital（supratrochlear）nodes** → lateral axillary nodes
    - 外側（cephalic 區）→ deltopectoral nodes → apical axillary nodes
    - **Axillary nodes 5 群**：Pectoral（anterior，接收大部分乳房淋巴）、Lateral（humeral）、Subscapular（posterior）、Central、**Apical**（最後匯集 → subclavian trunk）

- **Femoral a.**：external iliac a. 經 inguinal lig. 下方延續（**mid-inguinal point**：ASIS 與 pubic symphysis 中點）

    - **Profunda femoris** → **medial & lateral circumflex femoral a.**、**4 條 perforating a.**
    - 經 adductor hiatus → **Popliteal a.** → genicular aa. → 分為：
        - **Anterior tibial a.**：穿過 interosseous membrane → 前腔室 → 踝前延續為 **dorsalis pedis a.**（兩 malleoli 中點、**EHL 肌腱外側**觸脈）
        - **Posterior tibial a.**：分出 **fibular a.** → 經 **medial malleolus 後方**（觸脈）→ medial & lateral plantar a.
- **髖部吻合**：
    - **Trochanteric anastomosis**：superior gluteal、**medial & lateral circumflex femoral** → 主要供應股骨頭
    - **Cruciate anastomosis**：inferior gluteal、medial & lateral circumflex femoral、第 1 perforating

    - **Great saphenous v.**：**medial malleolus 前方** → 小腿內側 → femur medial condyle 後方 → **saphenous opening** → femoral v.；伴 saphenous n.；**CABG 取材**
    - **Small saphenous v.**：**lateral malleolus 後方** → 伴 **sural n.** → **popliteal v.**

    - **Popliteal nodes**：接收 small saphenous 區域（足外側、小腿後外側）

### 3.9 下肢關節

**Hip joint**

- 球窩關節；**acetabular labrum**；穩定性高
- 韌帶：
    - **Iliofemoral lig.（Y lig. of Bigelow）**：**最強**；防止過度伸展
    - Pubofemoral lig.、Ischiofemoral lig.
    - Ligament of head of femur（內含 artery of lig. teres）
- **Posterior dislocation（最常見）**：患肢**縮短、內收、內旋**；易傷 **sciatic n.**
- **Femoral neck 骨折**：患肢**縮短、外旋**

**Knee joint**

- 人體**最大**關節；包含 2 個 femorotibial + 1 個 femoropatellar 關節

| 結構 | 附著 | 功能 / 考點 |
|------|------|-------------|
| **ACL** | Tibia **前** intercondylar area → femur **lateral condyle 內面** | 防 tibia **前移**；**Anterior drawer、Lachman test**；較弱、較常斷 |
| **PCL** | Tibia **後** intercondylar area → femur **medial condyle 外面** | 防 tibia **後移**；較強 |
| **MCL（tibial collateral）** | 扁平，**與 medial meniscus 相連** | 抗 **valgus**（外翻）力 |
| **LCL（fibular collateral）** | 索狀，**不與 lateral meniscus 相連**（中間隔 popliteus tendon） | 抗 **varus** 力 |
| **Medial meniscus** | **C 形**；附著 MCL → 活動度低 | **較常受傷** |
| **Lateral meniscus** | **O 形**（近圓形）；活動度高 | — |

- **Unhappy triad**：膝外側受撞擊 → **ACL + MCL + medial meniscus**
- **Locking（screw-home）**：伸直末段 femur 在 tibia 上**內旋**
- **Unlocking**：**Popliteus** 使 femur **外旋**（足固定時）
- **Bursae**：
    - **Suprapatellar bursa**：**與關節腔相通**
    - **Prepatellar bursa**：跪地工作 → housemaid's knee
    - **Infrapatellar bursa**：clergyman's knee

**Ankle joint（talocrural）**

- Hinge 關節；**背屈時最穩定**（talus 前寬後窄）
- **Lateral ligaments**：**Anterior talofibular lig.（ATFL，最常受傷 → 內翻扭傷）**、Calcaneofibular、Posterior talofibular
- **Medial（deltoid）lig.**：強韌
- **內翻 / 外翻** 發生於 **subtalar** 與 **transverse tarsal joint**，不在 ankle joint

**足底肌肉 4 層**（淺 → 深）

| 層 | 肌肉 |
|----|------|
| **1** | Abductor hallucis、**FDB**、Abductor digiti minimi |
| **2** | **Quadratus plantae**、Lumbricals、FDL & FHL 肌腱 |
| **3** | FHB、**Adductor hallucis**、FDM |
| **4** | Interossei、**Fibularis longus & tibialis posterior 肌腱** |

## 四、胸部（Thorax）

### 4.1 胸壁

- **Sternum**：Manubrium、Body、Xiphoid process
    - **Jugular notch**：T2–T3
    - **Sternal angle（of Louis）**：**T4/T5 椎間盤**、**第 2 肋軟骨**
    - **Xiphisternal joint**：T9
- **Sternal angle 平面的重要結構**：
    - 上/下縱膈分界

    - **Trachea 分叉（carina）**
    - **Azygos v. 匯入 SVC**

    - **Thoracic duct 由右向左跨越**

- **Ribs**：
    - **True ribs（1–7）**：直接接 sternum

    - **Atypical ribs**：1、2、10、11、12

    - **典型肋骨 costal groove**：由上而下 **V**ein、**A**rtery、**N**erve（**VAN**）→ 胸腔穿刺**沿下位肋骨上緣**進針
- **Intercostal muscles**：

- **Intercostal nerves**：T1–T11 ventral rami；**T12 = subcostal n.**；T7–T11 延續至腹壁（thoracoabdominal nn.）

### 4.2 乳房（Breast）

- 範圍：**第 2–6 肋**、sternum 外緣至 midaxillary line；**Axillary tail（of Spence）**
- **Suspensory lig.（Cooper's lig.）**：乳癌浸潤 → 皮膚凹陷、**peau d'orange**
- **Retromammary space**：位於 pectoral fascia 前，使乳房可移動
- **動脈**：**Internal thoracic a.**（medial mammary branches，最主要）、**lateral thoracic a.**、thoracoacromial a.、posterior intercostal a.
- **淋巴**：
    - **> 75% → Axillary nodes**（主要 **pectoral group**）
    - 內側象限 → **Parasternal（internal thoracic）nodes**
    - 少量 → 對側乳房、腹部（下象限）
- **乳頭**：**T4 皮節**；男性約第 4 肋間

    - **Pulmonary ligament**：肺根下方胸膜延伸
- **Recesses**：**Costodiaphragmatic recess**（最深，積液處）、Costomediastinal recess

    - **右肺**：**Bronchus 在最上後方**（eparterial bronchus = 右上葉支氣管位於 pulmonary a. 上方）
    - **左肺**：**Pulmonary a. 在最上方**
    - 口訣 **RALS**：**R**ight **A**nterior（pulmonary a. 在右側位於 bronchus 前方）、**L**eft **S**uperior
    - **Pulmonary veins**：兩側皆位於**最前、最下**
- **右主支氣管**：**較寬、較短（約 2.5 cm）、較垂直** → **異物吸入多在右側**

### 4.4 縱膈（Mediastinum）

| 分區 | 內容 |
|------|------|
| **Superior**（sternal angle 平面以上） | **Thymus**、**Aortic arch 及三分支**、**Brachiocephalic vv.**、SVC 上半、**Trachea**、**Esophagus**、**Thoracic duct**、**Vagus**、**Phrenic**、**Left recurrent laryngeal n.** |
| **Anterior** | Thymus 殘餘（兒童較大）、淋巴結、脂肪、sternopericardial ligaments |
| **Middle** | **Heart & pericardium**、Ascending aorta、**Pulmonary trunk**、SVC 下半、Azygos arch 末端、**Main bronchi**、**Phrenic n.**、pericardiacophrenic vessels |
| **Posterior** | **Descending thoracic aorta**、**Esophagus**、**Thoracic duct**、**Azygos / hemiazygos vv.**、**Vagus（esophageal plexus）**、**Thoracic splanchnic nn.**、posterior mediastinal nodes |

**主動脈**

- **Aortic arch**：起止皆在 **sternal angle（T4/T5）** 平面
    - 分支（右 → 左）：**Brachiocephalic trunk**（→ right subclavian + right common carotid）、**Left common carotid**、**Left subclavian**
    - **Ligamentum arteriosum**：連接 **left pulmonary a. 起始處** 與 aortic arch 下面
    - **Left recurrent laryngeal n.** 繞 **aortic arch**（ligamentum arteriosum 外後方）；**Right recurrent laryngeal n.** 繞 **right subclavian a.**
- **Thoracic aorta 分支**：Posterior intercostal（3–11）、Subcostal、**Bronchial**、Esophageal、Pericardial、Mediastinal、**Superior phrenic**；經 **aortic hiatus（T12）** 入腹

**食道（Esophagus）**

- 長約 25 cm；**C6（cricopharyngeus）→ T11（cardia）**；**T10** 穿過 diaphragm
- **狹窄處**（異物、腐蝕傷、癌症好發）：
    1. **起始處**（cricopharyngeus，C6，距門齒約 15 cm，**最窄**）
    2. **Aortic arch 跨越處**（T4，約 22.5 cm）
    3. **Left main bronchus 跨越處**（T5，約 27.5 cm）
    4. **Esophageal hiatus**（T10，約 40 cm）
- **肌肉**：上 1/3 **骨骼肌**、中 1/3 混合、下 1/3 **平滑肌**
- **動脈**：上段 **inferior thyroid a.**；中段 **aorta esophageal branches**、bronchial a.；下段 **left gastric a.**（+ left inferior phrenic）
- **靜脈**：下段 **left gastric v.（portal）↔ esophageal v. → azygos（systemic）** → **食道靜脈曲張**
- **神經**：上段 recurrent laryngeal n.；esophageal plexus（vagus）
    - **Anterior vagal trunk = 主要來自 left vagus**；**Posterior vagal trunk = 主要來自 right vagus**（口訣 **LARP**；因胃旋轉）

**胸管（Thoracic Duct）**

- 起始：**Cisterna chyli（L1–L2）**
- 經 **aortic hiatus（T12）** → posterior mediastinum：位於 **aorta（左）與 azygos v.（右）之間**、esophagus 後方
- 約 **T4–T5（sternal angle）由右側跨到左側** → 沿 esophagus 左側上行
- 終止：**Left venous angle**（left subclavian v. + left internal jugular v. 交會處）
- 引流**全身除右上 1/4**（右頭頸、右上肢、右胸）→ 右上 1/4 由 **right lymphatic duct** 引流

**奇靜脈系統（Azygos System）**

- **Azygos v.**：由 right ascending lumbar v. + right subcostal v. 形成 → 沿脊柱右側上行 → **T4 跨過右主支氣管（右肺根）上方** → **SVC**
- **Hemiazygos v.**：約 T9 跨中線 → azygos
- **Accessory hemiazygos v.**：約 T7–T8 跨中線 → azygos
- **意義**：IVC 與 SVC 間的側支循環

**神經**

- **Phrenic n.（C3–C5）**："C3, 4, 5 keeps the diaphragm alive"
    - 頸部：沿 **anterior scalene 前面**下行（由外向內）
    - 胸部：**肺根前方**；與 **pericardiacophrenic vessels** 走在 fibrous pericardium 與 mediastinal pleura 之間
    - 運動：diaphragm（唯一運動神經）；感覺：中央 diaphragm、pericardium、mediastinal pleura → **轉移痛至肩（C4 supraclavicular n.）**
- **Vagus n.**：**肺根後方** → pulmonary plexus、esophageal plexus
- **交感神經**：
    - **White rami** 僅 **T1–L2**；**Gray rami** 至所有脊神經
    - **Greater splanchnic n.（T5–T9）** → **celiac ganglion**
    - **Lesser splanchnic n.（T10–T11）** → **aorticorenal ganglion**
    - **Least splanchnic n.（T12）** → **renal plexus**
    - 三者穿過 **diaphragm crura**
    - **Lumbar splanchnic（L1–L2）**：交感；**Pelvic splanchnic（S2–S4）**：**副交感**（易混淆！）
- **Thymus**：superior + anterior mediastinum；青春期後退化；血供 internal thoracic a.、inferior thyroid a.

### 4.5 心包（Pericardium）

- **Fibrous pericardium**：與 **diaphragm central tendon** 融合；與大血管外膜相連
- **Serous pericardium**：Parietal layer + Visceral layer（= **epicardium**）
- **神經**：Fibrous 與 parietal serous 層由 **phrenic n.**（痛覺）；visceral 層由 cardiac plexus
- **血供**：**Pericardiacophrenic a.**（internal thoracic a. 分支）

| 竇 | 位置 | 意義 |
|----|------|------|
| **Transverse pericardial sinus** | **Ascending aorta & pulmonary trunk 後方**；**SVC、atria 前方** | 心臟手術時可由此夾住大動脈 |
| **Oblique pericardial sinus** | **Left atrium 後方**；由 pulmonary vv. 與 IVC 圍成的盲囊 | — |

- **Pericardiocentesis**：**左側 xiphisternal angle（subxiphoid）** 進針

### 4.6 心臟（Heart）

**方位與表面**

- **Apex**：**左第 5 肋間、midclavicular line**
- **表面**：

| 表面 / 邊緣 | 主要構成 |
|-------------|----------|
| **Anterior（sternocostal）surface** | **Right ventricle**（主要） |
| **Diaphragmatic（inferior）surface** | **Left ventricle**（主要）+ 部分 RV |
| **Base（posterior surface）** | **Left atrium**（主要） |
| **Right border** | **Right atrium** |
| **Left border** | **Left ventricle**（+ left auricle） |
| **Inferior border** | **Right ventricle** |

- **最後方的腔室 = LA** → 擴大時壓迫 **esophagus**（吞嚥困難）、**left recurrent laryngeal n.**（聲音沙啞，Ortner syndrome）
- **最前方的腔室 = RV** → 胸前刺傷最易受傷

**腔室構造**

| 腔室 | 重要構造 |
|------|----------|
| **Right atrium** | **Crista terminalis**（分隔平滑的 **sinus venarum**〔源自 sinus venosus〕與粗糙的 **pectinate muscles**〔原始心房〕）；外部對應 sulcus terminalis；開口：SVC、IVC（valve of IVC）、**coronary sinus**（位於 IVC 與 tricuspid 之間）；**Fossa ovalis** + limbus（septum secundum） |
| **Right ventricle** | Trabeculae carneae；papillary muscles（**anterior 最大**、posterior、septal）；**Septomarginal trabecula（moderator band）**：攜帶 **right bundle branch** 至 anterior papillary muscle；**Supraventricular crest** 分隔流入道與流出道（**conus arteriosus / infundibulum**，平滑） |
| **Left atrium** | **4 條 pulmonary veins**（平滑壁）；left auricle 含 pectinate muscles |
| **Left ventricle** | **壁最厚**（RV 的 2–3 倍）；anterior & posterior papillary muscles；aortic vestibule 平滑 |

**瓣膜**

| 瓣膜 | 瓣葉 | 解剖投影 | 聽診位置 |
|------|------|----------|----------|
| **Pulmonary** | Anterior、Right、Left | 左第 3 肋軟骨後（**最高**） | **左第 2 肋間胸骨旁** |
| **Aortic** | Right、Left、Posterior（noncoronary） | 胸骨左側第 3 肋間後 | **右第 2 肋間胸骨旁** |
| **Mitral（bicuspid）** | Anterior、Posterior | 左第 4 肋軟骨後 | **左第 5 肋間 midclavicular line（apex）** |
| **Tricuspid** | Anterior、Posterior、Septal | 胸骨後第 4 肋間 | **左第 4–5 肋間胸骨下緣** |

- **Right / Left aortic sinus** → 分別發出 **RCA / LCA**
- **Fibrous skeleton**：支撐瓣膜、**電性隔絕心房與心室**（僅 bundle of His 穿過）

**冠狀動脈**

| 動脈 | 走向 | 分支 | 供應範圍 |
|------|------|------|----------|
| **RCA** | 起於 **right aortic sinus** → 右 coronary（AV）sulcus | **SA nodal branch（約 60%）**、**Right marginal a.**、**AV nodal branch（約 80%）**、**Posterior interventricular a.（PDA，右優勢時）** | RA、大部分 RV、LV 橫膈面、**IV septum 後 1/3**、SA node、AV node |
| **LCA** | 起於 **left aortic sinus** → 經 pulmonary trunk 與 left auricle 之間 | **LAD（anterior interventricular a.）**：diagonal、septal perforators；**Circumflex a.**：left marginal a.、（SA nodal branch 約 40%） | LA、大部分 LV、**IV septum 前 2/3**、**apex**、**bundle branches** |

- **Dominance**：由**誰發出 PDA**決定；**右優勢最常見（約 70%）**、左優勢約 10%、共同優勢約 20%
- **最常阻塞**：**LAD**
- LV 冠狀血流主要在**舒張期**

**心臟靜脈**

| 靜脈 | 伴行動脈 | 注入 |
|------|----------|------|
| **Great cardiac v.** | **LAD** → 沿 AV groove | **Coronary sinus** |
| **Middle cardiac v.** | **PDA** | Coronary sinus |
| **Small cardiac v.** | Right marginal a. | Coronary sinus |
| **Anterior cardiac vv.** | — | **直接入 RA** |
| **Smallest（Thebesian）vv.** | — | **直接入各腔室** |
| **Oblique v. of LA（Marshall）** | — | Coronary sinus；**left SVC 遺跡** |

- **Coronary sinus** 位於 **posterior AV groove** → 開口於 RA

**傳導系統**

- **SA node**（RA 壁、SVC 開口附近、crista terminalis 上端）→ **AV node**（interatrial septum 下部，**Koch triangle**：tendon of Todaro、tricuspid septal cusp、coronary sinus 開口）→ **Bundle of His**（穿 fibrous skeleton、membranous IV septum）→ **Right & left bundle branches** → **Purkinje fibers**

**神經支配**

- **Cardiac plexus**：
    - **交感**（cervical + **T1–T4/T5**）：心率↑、收縮力↑、冠狀動脈擴張
    - **副交感**（vagus）：心率↓、冠狀動脈收縮
- **心臟痛覺**：經交感神經 → **T1–T4** → **轉移痛至左胸、左臂內側**

**胎兒循環遺跡（常與解剖合考）**

| 胎兒結構 | 成人遺跡 |
|----------|----------|
| **Umbilical vein** | **Ligamentum teres hepatis**（round lig. of liver，於 falciform lig. 游離緣） |

| **Ductus arteriosus** | **Ligamentum arteriosum** |

| **Allantois（urachus）** | **Median umbilical ligament** |
| **Notochord** | **Nucleus pulposus** |

| **Medial umbilical folds** | **閉鎖的 umbilical aa.** | **Medial inguinal fossa**（direct hernia） |
| **Lateral umbilical folds** | **Inferior epigastric vessels** | **Lateral inguinal fossa**（deep ring，indirect hernia） |

### 5.2 腹股溝管（Inguinal Canal）

- 長約 4 cm；由 **deep ring** 走向 **superficial ring**
    - **Deep ring**：transversalis fascia 外翻處；**inferior epigastric vessels 外側**；inguinal lig. 中點上方約 1.25 cm
    - **Superficial ring**：EO 腱膜裂孔；**pubic tubercle 外上方**
- **管壁**（口訣 **MALT**，各兩個）：

| 壁 | 構成 |
|----|------|
| **上（頂）** | **M**uscles：IO 與 TA 的弓狀纖維 |
| **前** | **A**poneuroses：**EO 腱膜**（+ 外側 IO） |
| **下（底）** | **L**igaments：**Inguinal lig.** + 內側 **lacunar lig.** |
| **後** | **T**ransversalis fascia + 內側 **conjoint tendon** |

- **內容物**：
    - 男性：**Spermatic cord** + **ilioinguinal n.**
    - 女性：**Round ligament of uterus** + **ilioinguinal n.**
- **Spermatic cord 被膜**：

| 被膜 | 來源 |
|------|------|
| **External spermatic fascia** | **External oblique** |
| **Cremaster muscle & fascia** | **Internal oblique** |
| **Internal spermatic fascia** | **Transversalis fascia** |
| *Tunica vaginalis*（包睪丸） | *Processus vaginalis（腹膜）* |

- **Spermatic cord 內容**：**Ductus deferens**、**testicular a.**、**artery of ductus deferens**、cremasteric a.、**pampiniform plexus**、**genital branch of genitofemoral n.**、交感神經、淋巴管（→ **lumbar / para-aortic nodes**）

| 疝氣 | 路徑 | 與 IEV 關係 | 特色 |
|------|------|-------------|------|
| **Indirect inguinal** | 經 **deep ring** → 沿 spermatic cord | **外側** | **最常見**；先天 **processus vaginalis 未閉**；被三層 spermatic fascia 包覆；可入陰囊 |
| **Direct inguinal** | 經 **Hesselbach triangle** 直接穿出後壁 | **內側** | 後天、老年男性；**不在 internal spermatic fascia 內** |
| **Femoral** | 經 **femoral ring** | — | **Inguinal lig. 下方、pubic tubercle 外下**；**女性較多**；**最易絞窄** |

- **Hesselbach（inguinal）triangle**：外 **inferior epigastric vessels**；內 **rectus abdominis 外緣**；下 **inguinal lig.**
- 口訣：**MD's don't LIe** → **M**edial **D**irect、**L**ateral **I**ndirect
- **睪丸血管**：
    - **Testicular a.**：起於 **aorta（L2）**
    - **Right testicular v.** → **IVC**；**Left testicular v.** → **left renal v.**（直角注入 → **左側 varicocele 較常見**）

### 5.3 腹膜（Peritoneum）

- **後腹膜器官**（口訣 **SAD PUCKER**）：
    - **S**uprarenal glands
    - **A**orta & IVC
    - **D**uodenum（**第 2–4 段**；第 1 段近端 2 cm 為腹膜內）
    - **P**ancreas（**除 tail**；tail 位於 splenorenal lig.）
    - **U**reters
    - **C**olon（**ascending & descending**）
    - **K**idneys
    - **E**sophagus（腹段）
    - **R**ectum（中、下 1/3）
- **腹膜內器官**：Stomach、duodenum 第 1 段近端、jejunum、ileum、cecum、appendix、**transverse colon**、**sigmoid colon**、liver、spleen、pancreas tail

| 結構 | 組成 / 內容 |
|------|-------------|
| **Lesser omentum** | **Hepatogastric lig.** + **Hepatoduodenal lig.** |
| **Hepatoduodenal lig.（游離緣）** | **Portal triad**：**CBD（右前）**、**Proper hepatic a.（左前）**、**Portal v.（後）** → **Pringle maneuver** |
| **Greater omentum** | Gastrocolic、gastrosplenic、gastrophrenic lig. |
| **Falciform lig.** | **Ligamentum teres hepatis**（umbilical v. 遺跡）、paraumbilical vv. |
| **Gastrosplenic lig.** | **Short gastric aa.**、**left gastroepiploic a.** |
| **Splenorenal lig.** | **Splenic vessels**、**pancreas tail** |
| **Phrenicocolic lig.** | 限制左側 paracolic gutter 往上 |

- **Epiploic foramen（of Winslow）**：通往 lesser sac

| 邊界 | 結構 |
|------|------|
| **前** | **Hepatoduodenal lig.**（portal triad） |
| **後** | **IVC**（+ right crus） |
| **上** | **Caudate lobe of liver** |
| **下** | **Duodenum 第 1 段** |

- **腹膜腔低處**：
    - **平躺時最低**：**Hepatorenal recess（Morison's pouch）**
    - **直立時最低**：男 **Rectovesical pouch**；女 **Rectouterine pouch（of Douglas）**
- **Paracolic gutters**：右側與肝下空間相通；左側被 phrenicocolic lig. 阻擋
- **Root of mesentery**：約 15 cm，由 **DJ flexure（L2 左側）→ 右 sacroiliac joint**；跨越 duodenum 第 3 段、aorta、IVC、右 ureter、右 psoas
- **Sigmoid mesocolon**：倒 V 字頂點位於**左 ureter 與 common iliac a. 分叉**上方

- **Stomach**：Cardia（T11）、Fundus、Body、Pyloric antrum、Pyloric canal、Pylorus（L1）；lesser curvature 上有 **angular incisure**

| **Greater curvature** | **Right gastroepiploic a.** | **Gastroduodenal a.** |
| | **Left gastroepiploic a.** | **Splenic a.** |
| **Fundus** | **Short gastric aa.** | **Splenic a.** |
| **後壁** | Posterior gastric a. | Splenic a. |

- **Posterior gastric ulcer** → 侵蝕 **splenic a.**；**Posterior duodenal ulcer** → 侵蝕 **gastroduodenal a.**
- **Stomach bed**：left kidney、left suprarenal、**pancreas**、spleen、splenic a.、transverse mesocolon、left crus

| 十二指腸段 | 椎體 | 考點 |
|------------|------|------|
| **第 1 段（superior）** | L1 | **Duodenal cap / bulb**（近端腹膜內）；後方：**GDA**、**CBD**、portal v.；**潰瘍最常見** |
| **第 2 段（descending）** | L1–L3 | **Major duodenal papilla**（**hepatopancreatic ampulla of Vater**、**sphincter of Oddi**，位於後內側壁）；其上方 **minor papilla**（accessory pancreatic duct）；後方右腎門 |

### 5.5 小腸與大腸

| | **Jejunum** | **Ileum** |
|--|-------------|-----------|
| 位置 | 左上腹 | 右下腹 |
| 管徑 / 管壁 | **較寬、較厚**、較紅 | 較窄、較薄 |
| **Vasa recta** | **長** | **短** |
| **Arterial arcades** | **少（1–2 層）、大** | **多（4–5 層）、短** |
| **Plicae circulares** | **高、密集** | 低、稀疏（末端消失） |
| 腸繫膜脂肪 | 少 | **多** |
| **Peyer patches** | 少 | **多** |

- **Meckel diverticulum**：**vitelline duct** 遺跡；位於 **ileum 對腸繫膜緣（antimesenteric border）**；**rule of 2s**：2% 人口、距 ileocecal valve **2 呎（約 60 cm）**、長 2 吋、2 種異位黏膜（**胃、胰**）、2 歲前發病、男:女 2:1
- **大腸特徵**：
    - **Teniae coli（3 條）**：於 **appendix 根部匯合**
    - **Haustra**
    - **Omental appendices**：**cecum、appendix、rectum 無**
- **Appendix**：
    - **McBurney point**：ASIS 與臍連線的外 1/3
    - 最常見位置：**retrocecal**
    - **Appendicular a.**（ileocolic a. 分支）位於 mesoappendix
    - 早期痛：**T10 臍周**（visceral）
- **Rectum**：
    - 始於 **S3**；**無 teniae coli**（擴散成完整縱肌）
    - **Transverse rectal folds（Houston valves）3 個**；中間者在右側、最恆定
- **Anal canal — Pectinate（dentate）line**：

| | **Pectinate line 以上** | **Pectinate line 以下** |
|--|-------------------------|-------------------------|
| 胚胎 | **Endoderm**（hindgut） | **Ectoderm**（proctodeum） |
| 上皮 | **Simple columnar** | **Stratified squamous** |
| 動脈 | **Superior rectal a.（IMA）** | **Inferior rectal a.（internal pudendal）** |
| 靜脈 | Superior rectal v. → IMV → **portal** | Inferior rectal v. → internal pudendal → **IVC（systemic）** |
| 淋巴 | **Internal iliac**、inferior mesenteric nodes | **Superficial inguinal nodes** |
| 神經 | 內臟（自主）→ **不痛** | **Inferior rectal n.（pudendal）**→ **痛** |
| 痔瘡 | **Internal hemorrhoid（無痛）** | **External hemorrhoid（疼痛）** |
| 癌症 | **Adenocarcinoma** | **Squamous cell carcinoma** |

- **Middle rectal a.**：internal iliac a.
- **Internal anal sphincter**：平滑肌、不隨意；**External anal sphincter**：骨骼肌、**inferior rectal n.**
- **Puborectalis**：形成 U 形吊帶 → 維持 **anorectal angle**（控便最重要）

### 5.6 肝臟、膽道、胰臟、脾臟

**肝臟（Liver）**

- **解剖分葉**：以 falciform lig. 分 right / left lobe；另有 **caudate lobe**、**quadrate lobe**
- **功能分葉**：**Cantlie line**（gallbladder fossa → IVC）分左右；**middle hepatic v.** 沿此線
- **Couinaud segments**：

| Segment | 位置 |
|---------|------|
| **I** | **Caudate lobe**（**獨立血供，直接引流至 IVC**） |
| **II、III** | 左外側（II 上、III 下） |
| **IV（a/b）** | 左內側（= **quadrate lobe** 為 IVb） |
| **V–VIII** | 右葉：V 前下、VI 後下、VII 後上、VIII 前上 |

- **Bare area**：無腹膜覆蓋，直接貼 diaphragm；由 **coronary lig.** 圍成
- **Porta hepatis**（前 → 後）：**Hepatic ducts → Proper hepatic a.（分支）→ Portal v.**
- **Hepatic veins**（right、middle、left）→ **IVC**
- **血流**：**75% portal v.**、25% hepatic a.（但供氧約一半）

**膽道（Biliary Tree）**

- Right & left hepatic duct → **Common hepatic duct** + **Cystic duct**（**spiral valve of Heister**）→ **CBD** → 經 duodenum 第 1 段後方、胰頭後方/內 → 與 **main pancreatic duct** 會合 → **Hepatopancreatic ampulla（Vater）** → **Major duodenal papilla**；周圍 **sphincter of Oddi**
- **Gallbladder**：
    - Fundus：**右第 9 肋軟骨尖**（右 midclavicular line / rectus 外緣）
    - Neck 有 **Hartmann pouch**
    - **Cystic a.**：通常來自 **right hepatic a.**
    - 膽囊痛：上腹 / **右肩胛**（T7–T9）；發炎刺激橫膈 → **右肩**（phrenic n.）
- **Calot triangle（cystohepatic triangle）**：
    - 內：**Common hepatic duct**
    - 下：**Cystic duct**
    - 上：**肝臟下面**（原始定義為 cystic a.）
    - 內容：**Cystic a.**、right hepatic a.、Calot node

**胰臟（Pancreas）**

| 部位 | 考點 |
|------|------|
| **Head** | 位於 duodenum C 形內；**Uncinate process** 位於 **SMV / SMA 後方** |
| **Neck** | 位於 **portal v. 形成處（SMV + splenic v.）前方**（L1–L2） |
| **Body** | 跨越 aorta、L2 |
| **Tail** | 位於 **splenorenal lig.**；達 splenic hilum（**唯一腹膜內部分**） |

- **Main pancreatic duct（Wirsung）** → major papilla；**Accessory duct（Santorini）** → minor papilla
- **血供**：Head：**superior（GDA）& inferior（SMA）pancreaticoduodenal aa.**；Body / tail：**splenic a. 分支**（dorsal pancreatic、great pancreatic、caudal pancreatic）
- **胰頭癌** → 壓迫 CBD → **無痛性黃疸**、**Courvoisier sign**（可觸及膽囊）

**脾臟（Spleen）**

- 位於左上腹、**第 9–11 肋**，長軸沿**第 10 肋**
- 口訣 **1, 3, 5, 7, 9, 11**：1 吋厚、3 吋寬、5 吋長、7 盎司、位於第 9–11 肋
- 上緣有 **notch**（腫大時可觸及）
- **Splenic a.**：celiac 最大分支、迂曲、沿 pancreas 上緣
- 第 9–11 肋骨折 → 脾臟破裂 → **左肩痛（Kehr sign）**

- **Abdominal aorta**：**T12 aortic hiatus** 進入 → **L4 分叉**

| 類別 | 分支 | 椎體 |
|------|------|------|

| **成對（體壁）** | **Inferior phrenic** | T12 |

| 動脈 | 供應範圍 | 分支 |
|------|----------|------|

- **吻合**：**Marginal artery（of Drummond）**、Arc of Riolan
- **Watershed areas**（缺血性腸炎）：
    - **Splenic flexure（Griffiths point）**：SMA 與 IMA 交界
    - **Rectosigmoid junction（Sudeck point）**：sigmoid a. 與 superior rectal a. 交界

### 5.8 腹部靜脈與門脈系統

- **IVC**：
    - **L5** 由左右 common iliac v. 形成（位於 aorta 右側、**right common iliac a. 後方**）
    - 經 **caval foramen（T8）** 穿過 central tendon
    - 屬支：common iliac、lumbar、**right gonadal**、renal、**right suprarenal**、inferior phrenic、hepatic vv.
    - **Left renal v.**：較長，跨過 aorta 前方（SMA 下方）；收 **left gonadal、left suprarenal、left inferior phrenic v.** → **活體捐腎多取左腎**
- **Portal vein**：
    - **Pancreas neck 後方（L1–L2）** 由 **SMV + splenic v.** 形成（**IMV 通常注入 splenic v.**）
    - 於 hepatoduodenal lig. 中位於 **bile duct 與 hepatic a. 後方**
    - 屬支：left & right gastric v.、cystic v.、paraumbilical vv.

| 門體吻合部位 | Portal 側 | Systemic 側 | 臨床表現 |
|--------------|-----------|-------------|----------|
| **食道下段** | **Left gastric v.** | **Esophageal v. → Azygos** | **食道靜脈曲張**（最危險） |
| **臍周** | **Paraumbilical vv.** | **Superficial & inferior epigastric vv.** | **Caput medusae** |
| **直腸 / 肛門** | **Superior rectal v.** | **Middle & inferior rectal vv.** | 肛門直腸靜脈曲張 |
| **後腹膜** | Colic vv. | Retroperitoneal / lumbar vv.（Retzius） | — |
| **肝 bare area** | 肝內小靜脈 | Phrenic、intercostal vv. | — |

- **腹部淋巴**：
    - Celiac、superior mesenteric、inferior mesenteric（**preaortic**）nodes → **intestinal trunk** → **cisterna chyli**
    - **Lumbar（para-aortic）nodes** → lumbar trunks；**睪丸 / 卵巢 → para-aortic nodes（L1–L2）**

### 5.9 橫膈與後腹壁

**橫膈（Diaphragm）**

| 開口 | 椎體 | 位置 | 通過結構 |

| **Esophageal hiatus** | **T10** | **Right crus 肌纖維**包圍（生理性括約肌） | **Esophagus**、**anterior & posterior vagal trunks**、left gastric vessels 食道支 |
| **Aortic hiatus** | **T12** | **Median arcuate lig. 後方**（不在橫膈內） | **Aorta**、**Thoracic duct**、（azygos v.） |

- **其他穿過結構**：
    - **Crura**：greater、lesser、least splanchnic nn.；hemiazygos（左 crus）
    - **Medial arcuate lig.**（psoas 上）：**sympathetic trunk**
    - **Lateral arcuate lig.**（quadratus lumborum 上）：**subcostal n. & vessels**
    - **Sternocostal triangle（foramen of Morgagni）**：**superior epigastric vessels**
    - Left phrenic n.：直接穿過左 dome

- **Congenital hernia**：**Bochdalek**（後外側，**左側**最常見）；**Morgagni**（前方胸骨旁）

### 5.10 腎臟、輸尿管、腎上腺

**腎臟（Kidney）**

- 位置：**T12–L3**；**右腎較低**（肝臟壓迫，約低 1–2 cm）；腎門約 L1
- **被膜**（內 → 外）：**Fibrous capsule → Perirenal fat → Renal（Gerota）fascia → Pararenal fat**
- **腎門排列（前 → 後）**：**Renal Vein → Renal Artery → Renal Pelvis（Ureter）**（口訣 **VAU**）
- **Segmental arteries（5 條）**：Superior（apical）、Anterosuperior、Anteroinferior、Inferior、**Posterior**（走 renal pelvis 後方）→ **end arteries**（無吻合）
- **Right renal a.** 較長，走 **IVC 後方**；**Left renal v.** 較長

| 關係 | 右腎 | 左腎 |
|------|------|------|
| **前方** | **Liver**、**十二指腸第 2 段**、**right colic flexure**、（adrenal） | **Stomach**、**spleen**、**pancreas tail**、jejunum、**left colic flexure**、（adrenal） |
| **後方** | Diaphragm、**psoas**、**quadratus lumborum**、transversus abdominis；**subcostal、iliohypogastric、ilioinguinal nn.**；**第 12 肋**（左腎另有第 11 肋） | 同左 |

- **Horseshoe kidney**：下極融合 → 上升時卡在 **IMA** 下方

**輸尿管（Ureter）**

- 長約 25 cm；後腹膜、沿 **psoas** 下行
- **三處狹窄（結石卡住處）**：
    1. **Ureteropelvic junction**
    2. **跨越 pelvic brim / common iliac a. 分叉處**
    3. **Ureterovesical junction（最窄）**
- **跨越關係**：
    - 腹部：**gonadal vessels 從前方跨越 ureter**
    - 男性骨盆：**ductus deferens 從上方跨越 ureter**
    - 女性骨盆：**uterine a. 從上方跨越 ureter**（距 cervix 外側約 2 cm）→ **"Water under the bridge"** → **子宮切除術易誤紮**
- 血供：renal、gonadal、aorta、common iliac、internal iliac 分支（vesical、uterine）
- 疼痛：**T11–L2**（腰 → 鼠蹊）

- **交通**：superior / inferior ophthalmic vv.、pterygoid plexus、facial v.（經 ophthalmic v.）→ **臉部危險三角**感染 → **cavernous sinus thrombosis**
- **Carotid-cavernous fistula** → **搏動性突眼**

### 7.3 臉部（Face）

- **顏面表情肌**：**全部第 2 鰓弓、CN VII 支配**
    - **Orbicularis oculi**（閉眼；palpebral & orbital parts）、**Orbicularis oris**、**Buccinator**、**Platysma**、Occipitofrontalis、Zygomaticus major / minor、Levator labii superioris、Risorius、Depressor anguli oris、Mentalis
    - **Buccinator**：被 **parotid duct** 穿過（上第 2 臼齒對側）；運動 CN VII；**buccal n.（V3）只負責頰部感覺**
    - **Levator palpebrae superioris 不是表情肌**（CN III）
- **Facial n. 腮腺內分支**：**T**emporal、**Z**ygomatic、**B**uccal、**M**arginal mandibular、**C**ervical（口訣：**To Zanzibar By Motor Car**）
- **臉部感覺**：
    - **V1（ophthalmic）**：前額、上眼瞼、鼻背（nasociliary 的 external nasal branch → 鼻尖疱疹 = **Hutchinson sign**）
    - **V2（maxillary）**：下眼瞼、頰、上唇、鼻翼
    - **V3（mandibular）**：下唇、下巴、顳部（auriculotemporal）
    - **下頜角**：**C2–C3（great auricular n.）**，非 CN V
- **Facial a.**（ECA）：迂曲；於 **masseter 前緣跨越下頜骨**（可觸脈）→ angular a.（與 ophthalmic a. 的 dorsal nasal 吻合）
- **Facial v.**：**無瓣膜**；經 **superior ophthalmic v.** 及 deep facial v. → pterygoid plexus 與 **cavernous sinus** 相通

### 7.4 唾液腺

| 腺體 | 性質 | 導管 | 副交感路徑 |
|------|------|------|------------|
| **Parotid** | **最大**、**純漿液性** | **Stensen duct**：跨 masseter → 穿 **buccinator** → 開口於**上第 2 臼齒**對側 | **CN IX** → tympanic n.（Jacobson）→ tympanic plexus → **lesser petrosal n.** → **otic ganglion** → **auriculotemporal n.（V3）** |
| **Submandibular** | 混合（**漿液為主**） | **Wharton duct** → **sublingual caruncle**；**lingual n. 繞過導管**（外 → 下 → 內） | **CN VII** → **chorda tympani** → 加入 lingual n. → **submandibular ganglion** |
| **Sublingual** | 混合（**黏液為主**）、**最小** | 多條小導管（Rivinus）開口於 sublingual fold | 同 submandibular |

- **Parotid gland**：
    - 被膜來自 **investing layer of deep cervical fascia** → 腮腺炎（mumps）時劇痛
    - **腺體內結構（淺 → 深）**：**Facial n.** → **Retromandibular v.** → **ECA**（分為 maxillary & superficial temporal a.）；另有 auriculotemporal n.
    - 腮腺切除後 → **Frey syndrome**（味覺性出汗）
- **Submandibular gland**：分淺、深兩部，**繞 mylohyoid 後緣**

### 7.6 眼眶（Orbit）

| 壁 | 構成 | 考點 |
|----|------|------|
| **Roof** | Frontal（orbital plate）、lesser wing of sphenoid | — |
| **Floor** | Maxilla、zygomatic、palatine | **Blowout fracture**：infraorbital n. 受損、**inferior rectus 卡住** |
| **Medial** | **Ethmoid（lamina papyracea）**、lacrimal、maxilla、sphenoid | **最薄** → ethmoid sinusitis → orbital cellulitis |
| **Lateral** | **Zygomatic**、greater wing of sphenoid | **最厚、最強** |

- **Common tendinous ring（annulus of Zinn）**：**4 條直肌**起點
- **Superior oblique**：起於 sphenoid body；經 **trochlea** 轉向
- **Inferior oblique**：起於 **orbital floor 前方（maxilla）** → **唯一不從眶尖起始**的眼外肌
- **Levator palpebrae superioris**：起於 lesser wing

| 肌肉 | 神經 | 主要作用 | 次要 | 第三 | 臨床檢查 |
|------|------|----------|------|------|----------|
| **Medial rectus** | III | 內收 | — | — | — |
| **Lateral rectus** | **VI** | 外展 | — | — | — |
| **Superior rectus** | III | **上轉** | 內旋 | 內收 | **外展位**向上看 |
| **Inferior rectus** | III | **下轉** | 外旋 | 內收 | **外展位**向下看 |
| **Superior oblique** | **IV** | **內旋** | 下轉 | 外展 | **內收位**向下看 |
| **Inferior oblique** | III | **外旋** | 上轉 | 外展 | **內收位**向上看 |

- 口訣：**LR6 SO4**，其餘為 III
- **神經麻痺**：
    - **CN III**：眼球**向下外（down and out）**、**眼瞼下垂**、**瞳孔放大**
    - **CN IV**：垂直複視、**頭向健側傾斜**、**下樓梯困難**
    - **CN VI**：**內斜視**、無法外展
- **神經與 common tendinous ring**：
    - **環內**：**N**asociliary、**O**culomotor（上、下支）、**A**bducens（**NOA**）
    - **環外**：**L**acrimal、**F**rontal、**T**rochlear（**LFT**）、superior ophthalmic v.
- **Ciliary ganglion**：CN III（inferior division，經 n. to inferior oblique）→ **short ciliary nn.** → **sphincter pupillae**、**ciliary muscle**
- **交感**（superior cervical ganglion）→ **dilator pupillae**、**superior tarsal（Müller）muscle**
- **角膜感覺**：**Long ciliary nn.（V1 nasociliary）** → **corneal reflex：傳入 V1、傳出 VII**
- **Ophthalmic a.**（**ICA 第一分支**）：經 optic canal（optic n. 下外側）；分支：**central retinal a.**（**end artery**；阻塞 → 失明、cherry-red spot）、lacrimal、supraorbital、supratrochlear、ethmoidal、dorsal nasal、long & short posterior ciliary
- **淚液路徑**：Lacrimal gland（外上方）→ 眼表 → **lacrimal puncta** → canaliculi → **lacrimal sac** → **nasolacrimal duct** → **inferior meatus**

### 7.7 鼻腔與鼻竇

- **Nasal septum**：**Perpendicular plate of ethmoid**、**Vomer**、**Septal cartilage**
- **Kiesselbach（Little's）area**（鼻中隔前下）：**anterior ethmoidal a.**（ophthalmic）、**sphenopalatine a.**、**greater palatine a.**（maxillary）、**septal branch of superior labial a.**（facial）→ **前鼻出血最常見處**
- **後鼻出血**：**Sphenopalatine a.**
- **鼻甲**：Superior & middle concha 屬 **ethmoid**；**inferior concha 為獨立骨**

| 開口位置 | 引流 |
|----------|------|
| **Sphenoethmoidal recess** | **Sphenoid sinus** |
| **Superior meatus** | **Posterior ethmoidal cells** |
| **Middle meatus** | **Frontal sinus**（frontonasal duct → infundibulum / hiatus semilunaris）、**Maxillary sinus**（hiatus semilunaris）、**Anterior ethmoidal cells**（hiatus semilunaris）、**Middle ethmoidal cells**（ethmoidal bulla） |
| **Inferior meatus** | **Nasolacrimal duct** |

- **Maxillary sinus**：**最大**；開口位置高 → 引流不良；底部鄰近**上臼齒/前臼齒牙根**；頂部有 infraorbital n.
- **Sphenoid sinus**：上方 **pituitary**；外側 **cavernous sinus、ICA**、optic n.
- **出生時**：maxillary、ethmoid 已存在；**frontal、sphenoid 出生後發育**
- **鼻腔神經**：嗅覺 CN I；一般感覺前方 **anterior ethmoidal n.（V1）**、後方 **V2**（nasopalatine、posterior superior nasal）；腺體分泌 CN VII（pterygopalatine ganglion）

### 7.8 口腔、舌、腭、扁桃體

**舌（Tongue）**

| | **前 2/3** | **後 1/3** | **舌根 / 會厭區** |
|--|------------|------------|-------------------|
| **一般感覺** | **Lingual n.（V3）** | **CN IX** | **CN X（internal laryngeal）** |

| **胚胎** | **1st arch** | **3rd arch** | 4th arch |

- **舌肌**：**全部 CN XII**，**除 palatoglossus（CN X）**
    - **Genioglossus**：伸舌；**單側 XII 下運動神經元損傷 → 伸舌偏向患側**
    - **Hyoglossus**：下壓、後縮
    - **Styloglossus**：後縮、上提
    - **Palatoglossus**：上提舌根
- **Hyoglossus 關係**：**lingual a. 走其深面**；**lingual n.、XII、submandibular duct 走其淺面**
- **舌淋巴**：舌尖 → **submental**；前外側 → **submandibular**；後 1/3 → **deep cervical**（**jugulo-omohyoid node**）

**腭（Palate）**

| 肌肉 | 神經 | 作用 |

| **Levator veli palatini** | **X** | 上提軟腭 |
| **Palatoglossus** | X | — |
| **Palatopharyngeus** | X | — |
| **Musculus uvulae** | X | — |

- **CN X 損傷** → **懸雍垂偏向健側**（偏離患側）
- **腭感覺（V2）**：**greater palatine n.**（硬腭）、**nasopalatine n.**（門齒後硬腭）、**lesser palatine n.**（軟腭）
- **牙齒**：乳牙 20、恆牙 32；上牙 **superior alveolar nn.（V2）**；下牙 **inferior alveolar n.（V3）**

**扁桃體**

    - 血供：主要 **tonsillar branch of facial a.**
    - 術後出血：**paratonsillar（external palatine）v.**
    - 深面有 **CN IX** → 扁桃體切除易傷 → 舌後 1/3 味覺喪失；扁桃體炎轉移痛至耳
- **Waldeyer ring**：Pharyngeal（adenoid）、tubal、palatine、lingual tonsils

### 7.10 喉（Larynx）

| 軟骨 | 數目 | 種類 | 考點 |
|------|------|------|------|
| **Thyroid** | 1 | Hyaline | **Laryngeal prominence**；C4–C5 |
| **Cricoid** | 1 | Hyaline | **唯一完整環狀軟骨**；**C6** |
| **Epiglottis** | 1 | **Elastic** | — |

| **Corniculate、Cuneiform** | 2、2 | **Elastic** | — |

- **膜與韌帶**：
    - **Thyrohyoid membrane**：被 **internal laryngeal n.** 與 **superior laryngeal a.** 穿過
    - **Cricothyroid membrane（median cricothyroid lig.）**：**緊急環甲膜切開**
    - **Conus elasticus**：上游離緣 = **vocal ligament**
    - **Quadrangular membrane**：下游離緣 = **vestibular ligament**
- **喉腔**：Vestibule（vestibular folds / false cords 以上）→ Ventricle → Infraglottic cavity
- **最窄處**：成人 **rima glottidis**；嬰兒 **subglottic（cricoid）**

| 喉肌 | 神經 | 作用 |
|------|------|------|
| **Cricothyroid** | **External branch of SLN** | **拉緊聲帶**（thyroid 前傾）→ 高音 |
| **Posterior cricoarytenoid** | RLN | **唯一外展肌**（打開聲門） |
| **Lateral cricoarytenoid** | RLN | 內收 |
| **Transverse & oblique arytenoid** | RLN | 內收（關閉後部） |
| **Thyroarytenoid（vocalis）** | RLN | 放鬆、縮短聲帶 |

- **喉感覺**：**聲帶以上 → internal laryngeal n.（SLN）**（咳嗽反射）；**聲帶以下 → RLN**
- **SLN**：X 的 inferior ganglion 發出
    - **Internal branch**：感覺 + 分泌；穿 thyrohyoid membrane
    - **External branch**：cricothyroid、部分 inferior constrictor；**伴 superior thyroid a.** → 甲狀腺手術結紮上極血管時易傷 → **無法發高音、聲音單調**
- **RLN**：
    - **右**繞 **right subclavian a.**；**左**繞 **aortic arch**（ligamentum arteriosum 後外側）
    - 沿 **tracheoesophageal groove** 上行；於甲狀腺下極附近與 **inferior thyroid a.** 交錯 → 甲狀腺手術易傷
    - **單側** → 聲音沙啞；**雙側** → 聲帶居中 → **呼吸道阻塞**
    - **左 RLN 較長** → 易受胸腔病變影響（主動脈瘤、肺癌、LA 擴大）

### 7.11 頸部（Neck）

- **Erb's point（nerve point）**：SCM 後緣中點，cervical plexus 皮支穿出：
    - **Lesser occipital（C2）**
    - **Great auricular（C2–C3）**
    - **Transverse cervical（C2–C3）**
    - **Supraclavicular（C3–C4）**

**頸部肌肉**

| 肌肉 | 起點 | 止點 | 神經 | 作用 |

    - 後支 + posterior auricular v. → **EJV** → 跨越 SCM 表面 → **subclavian v.**

### 7.12 耳（Ear）

**外耳**

- **Auricle**：**elastic cartilage**（耳垂除外）
- **External acoustic meatus**：約 2.5 cm；**外 1/3 軟骨、內 2/3 骨性**；S 形 → 成人檢查時**向上後拉**、兒童**向下後拉**
- **外耳感覺**：**Auriculotemporal n.（V3）**、**Great auricular n.（C2–C3）**、**Auricular branch of vagus（Arnold n.）**（外耳道後壁 → 掏耳朵咳嗽反射）、CN VII 少量
- **Tympanic membrane**：
    - **外面**：V3（auriculotemporal）+ **X**；**內面**：**CN IX**（tympanic n.）
    - **Cone of light**：**前下方**
    - **Pars flaccida**（malleus lateral process 上方）、**Pars tensa**
    - **Umbo**：malleus 柄尖端
    - 切開避開**後上象限**（ossicles、chorda tympani）

**中耳（Tympanic Cavity）六壁**

| 壁 | 構造 |
|----|------|
| **Roof（tegmental）** | **Tegmen tympani** → 上方為 **middle cranial fossa** |
| **Floor（jugular）** | **IJV bulb**；tympanic n. 由此進入 |
| **Lateral（membranous）** | **Tympanic membrane**；epitympanic recess 外側為 squama |
| **Medial（labyrinthine）** | **Promontory**（cochlea 基底迴、tympanic plexus）、**oval window**（stapes footplate）、**round window**（secondary tympanic membrane）、prominence of facial canal、prominence of lateral semicircular canal |
| **Anterior（carotid）** | **ICA**；**auditory tube 開口**；tensor tympani 管 |
| **Posterior（mastoid）** | **Aditus to mastoid antrum**、**pyramidal eminence**（stapedius 肌腱） |

- **聽小骨**：
    - **Malleus**：柄附於鼓膜；**tensor tympani（V3）** 附著
    - **Incus**
    - **Stapes**：footplate 於 oval window；**stapedius（VII）** 附著 → 麻痺 → **hyperacusis**
- **Chorda tympani**：跨越鼓膜內面（malleus 與 incus 之間）→ 經 **petrotympanic fissure** 出顱 → 加入 lingual n.
- **Auditory（pharyngotympanic / Eustachian）tube**：約 36 mm；**外 1/3 骨性、內 2/3 軟骨**；由 **tensor veli palatini**（+ levator veli palatini、salpingopharyngeus）打開；**兒童較短、較水平** → 易中耳炎

**Facial n. 在顳骨內的走行**

1. **IAM** → facial canal
2. **Labyrinthine segment** → **Geniculate ganglion**：分出 **greater petrosal n.**（淚腺、鼻腺、腭腺分泌）
3. **Tympanic segment**（水平，內側壁 oval window 上方）
4. **Mastoid segment**（垂直）：分出 **n. to stapedius** → **chorda tympani**（stylomastoid foramen 上約 6 mm）
5. **Stylomastoid foramen** → posterior auricular n.、n. to posterior belly of digastric、n. to stylohyoid → **parotid plexus**

| 損傷位置 | 表情肌癱瘓 | 淚液↓ | Hyperacusis | 舌前 2/3 味覺↓ |
|----------|-----------|-------|-------------|---------------|
| **Geniculate ganglion 近端** | + | **+** | + | + |
| **Geniculate 與 stapedius branch 之間** | + | − | **+** | + |
| **Stapedius 與 chorda tympani 之間** | + | − | − | **+** |
| **Stylomastoid foramen（Bell's palsy 典型）** | + | − | − | − |

**內耳**：Bony labyrinth（vestibule、semicircular canals、**cochlea 2¾ 圈**繞 modiolus）含 **perilymph**；membranous labyrinth 含 **endolymph**
