    藥理學

    一、藥理學總論（General Pharmacology）

    1.1 藥物動力學（Pharmacokinetics）— ADME

    吸收（Absorption）

    • 大多數藥物經被動擴散吸收，取決於：脂溶性、分子量、解離度（pKa）
    • 弱酸性藥物（如 Aspirin, pKa ≈ 3.5）：在酸性環境（胃）中呈非解離態 → 較易吸收
    • 弱鹼性藥物（如 Morphine）：在鹼性環境（小腸）中呈非解離態 → 較易吸收
    • Ion trapping：弱酸在鹼性環境中解離被困住（如 aspirin 中毒 → 鹼化尿液加速排除）
    • 生體可用率（Bioavailability, F）：口服藥物到達全身循環的比例
      • IV 給藥 F = 100%
      • 首渡效應（First-pass effect）：經肝臟代謝後 F 降低（如 Nitroglycerin 口服 F 極低 → 改用舌下）

    分布（Distribution）

    • 血漿蛋白結合：Albumin（結合酸性藥物）、α1-acid glycoprotein（結合鹼性藥物）
      • 高蛋白結合率的藥物（如 Warfarin >99%）→ 被其他藥物競爭置換時游離濃度↑ → 藥效↑/毒性↑
    • 分布體積（Vd）：Vd = 藥量 / 血漿濃度
      • Vd 小（<10 L）→ 藥物留在血漿中（如 Warfarin、Heparin）
      • Vd 大（>40 L）→ 藥物廣泛分布到組織（如 Chloroquine Vd ≈ 13,000 L）
    • 血腦障壁（BBB）：脂溶性高者可通過（如 Diazepam）；P-glycoprotein 會將藥物泵出

    代謝（Metabolism）

    • Phase I（functionalization）：氧化、還原、水解 → 引入或暴露官能基
      • 最重要：Cytochrome P450（CYP）系統（肝臟微粒體）
      • 重要亞型：CYP3A4（代謝最多藥物）、CYP2D6、CYP2C9、CYP2C19、CYP1A2、CYP2E1
    • Phase II（conjugation）：glucuronidation（最常見）、sulfation、acetylation、methylation、glutathione conjugation
      • Acetylation 多態性：慢乙醯化者 → INH 毒性↑（周邊神經炎）、Procainamide → drug-induced lupus↑
    • 酵素誘導劑（CYP inducers）：加速代謝 → 藥效↓
      • 口訣：Chronic alcoholism、Rifampin、Barbiturates、Phenytoin、Carbamazepine、St. John's Wort、Griseofulvin
      • Rifampin 是最強的 CYP inducer
    • 酵素抑制劑（CYP inhibitors）：減慢代謝 → 藥效/毒性↑
      • 口訣：Acute alcohol、Cimetidine、Ketoconazole/Itraconazole、Erythromycin/Clarithromycin、Grapefruit juice、Ciprofloxacin、Ritonavir、Fluoxetine/Fluvoxamine、Verapamil/Diltiazem、Amiodarone、Valproate、Isoniazid

    排泄（Excretion）

    • 腎臟排泄：
      • 腎絲球過濾：游離（未結合蛋白）的藥物
      • 腎小管主動分泌：有機陰離子轉運體（OAT）→ 如 Penicillin、Methotrexate、Uric acid；Probenecid 競爭 OAT → 延長 Penicillin 半衰期
      • 腎小管再吸收：脂溶性藥物被動再吸收
      • 鹼化尿液（NaHCO₃）→ 加速弱酸排除（Aspirin、Barbiturate、MTX）
      • 酸化尿液（NH₄Cl）→ 加速弱鹼排除（Amphetamine）
    • 膽汁排泄：部分藥物經膽汁排入腸道 → 可能被腸肝循環再吸收（如 Estrogen、Digoxin、Morphine）

    1.2 藥效學（Pharmacodynamics）

    • 效力（Potency）：達到相同效果所需劑量 → 由 EC₅₀（半最大效應濃度）決定
    • 效能（Efficacy）：藥物能達到的最大效應 → 由 Emax 決定
    • Agonist：與受體結合並活化
      • Full agonist：產生最大反應（Emax = 1）
      • Partial agonist：即使占滿所有受體，也只能產生次最大反應 → 在有 full agonist 存在時可表現為拮抗劑
    • Antagonist：
      • Competitive（可逆性）：與 agonist 競爭同一結合位 → 右移劑量反應曲線，但 Emax 不變（可被增加 agonist 濃度克服）
      • Non-competitive（不可逆性）：結合不同位點或共價結合 → 降低 Emax，無法被增加 agonist 克服
    • 治療指數（Therapeutic Index, TI）：TI = TD₅₀ / ED₅₀（或 LD₅₀ / ED₅₀）→ TI 越大越安全
      • 窄治療指數藥物：Warfarin、Digoxin、Lithium、Theophylline、Aminoglycosides、Phenytoin、Carbamazepine、Valproic acid、Cyclosporine

    1.3 特殊藥理學概念

    • Tachyphylaxis：快速耐受性（如 Ephedrine 反覆使用後效果↓，因 NE 耗竭）
    • Tolerance：長期使用後效果減弱（如 Opioids、Benzodiazepines、Nitrates）
    • Spare receptors（受體儲備）：不需佔滿所有受體即可達到最大效應
    • Up-regulation / Down-regulation：長期拮抗 → 受體上調（如 β-blocker 突然停藥 → rebound tachycardia）；長期激動 → 受體下調

    2.2 Adrenergic 受體

    受體 位置 功能 臨床意義
    α₁ 血管平滑肌、瞳孔擴張肌、膀胱括約肌、攝護腺 血管收縮 → BP↑；散瞳（mydriasis）；膀胱頸/攝護腺收縮 α₁-blocker（Prazosin）→ 降壓、BPH 治療
    α₂ 突觸前膜、CNS 負回饋抑制 NE 釋放；中樞降壓 Clonidine（α₂ agonist）→ 降壓、戒斷治療
    β₁ 心臟 心跳↑、收縮力↑、傳導↑、腎素分泌↑ β₁-blocker → 降壓、心衰、抗心律不整
    β₂ 支氣管平滑肌、子宮、血管、肝/骨骼肌 支氣管擴張、子宮鬆弛、血管擴張、肝醣分解↑ β₂-agonist（Salbutamol）→ 氣喘急性期
    β₃ 脂肪組織、膀胱逼尿肌 脂肪分解↑、膀胱鬆弛 Mirabegron → 膀胱過動症

    2.3 Muscarinic 受體

    受體 位置 功能
    M₁ CNS、胃壁細胞 認知；胃酸分泌↑
    M₂ 心臟（SA node、AV node） 心跳↓、傳導↓
    M₃ 平滑肌、腺體、血管內皮 支氣管收縮、腸蠕動↑、唾液/淚液分泌↑、瞳孔縮小（miosis）、睫狀肌收縮（近視調節）、內皮 NO 釋放 → 血管擴張

    2.4 擬交感神經藥（Sympathomimetics）

    直接作用型

    藥物 受體選擇性 臨床用途 重要備註
    Epinephrine（Adrenaline） α₁ = α₂ > β₁ = β₂ Anaphylaxis 首選、心跳停止（ACLS）、與局麻合用延長作用 低劑量 β₂ 為主（血管擴張）→ 高劑量 α₁ 為主（血管收縮）
    Norepinephrine α₁ = α₂ > β₁；β₂ 弱 Septic shock 首選升壓藥 強血管收縮；反射性心搏過緩
    Isoproterenol β₁ = β₂（無 α） 心搏過緩（歷史用途） 不縮血管，BP↓（β₂ 擴張）
    Phenylephrine α₁ 選擇性 鼻充血解除、升壓、散瞳 反射性心搏過緩
    Dobutamine β₁ 選擇性 急性心衰（cardiogenic shock） 強心不強縮血管
    Dopamine 劑量依賴：低 D₁ → 中 β₁ → 高 α₁ 休克升壓 低劑量：腎血管擴張（D₁）→ 中劑量：心臟↑（β₁）→ 高劑量：血管收縮（α₁）
    Salbutamol（Albuterol） β₂ 選擇性 急性氣喘首選 SABA；副作用：tremor、tachycardia、hypokalemia
    Salmeterol / Formoterol β₂ 長效 氣喘/COPD 維持治療 LABA；需搭配 ICS 使用，不可單用
    Terbutaline β₂ 安胎（子宮鬆弛） —
    Clonidine α₂ 選擇性 降壓（中樞作用）、opioid 戒斷、ADHD 突然停藥 → rebound hypertension
    Brimonidine α₂ 青光眼（降低房水分泌） —
    Midodrine α₁ 姿勢性低血壓 —
    Mirabegron β₃ 膀胱過動症 逼尿肌鬆弛

    間接作用型及混合型

    藥物 機制 臨床意義
    Amphetamine 促進 NE/DA 釋放 + 抑制再回收 + 抑制 MAO ADHD、嗜睡症；濫用風險
    Ephedrine 促進 NE 釋放 + 微弱直接作用 低血壓；tachyphylaxis（NE 耗竭）
    Cocaine 阻斷 NE/DA/5-HT 再回收 局部麻醉（唯一具血管收縮的局麻藥）；濫用 → 冠狀動脈痙攣/心肌梗塞（禁用 β-blocker，改用 Phentolamine + BZD + NTG）
    Tyramine 促進 NE 釋放（食物中存在） 使用 MAO inhibitor 時食用含 tyramine 食物 → 高血壓危象（cheese reaction）

    2.5 抗腎上腺素藥（Adrenergic Antagonists）

    α-Blockers

    藥物 選擇性 臨床用途 重要副作用
    Phentolamine α₁ = α₂（非選擇性） Pheochromocytoma 診斷/術前、NE 外滲、Cocaine 中毒 反射性心搏過速（因 α₂ 也被阻斷 → NE 釋放↑）
    Phenoxybenzamine α₁ = α₂（不可逆） Pheochromocytoma 術前準備首選 持續性低血壓、鼻塞
    Prazosin / Doxazosin / Terazosin α₁ 選擇性 高血壓、BPH 首劑低血壓（first-dose syncope）
    Tamsulosin α₁A 選擇性 BPH（攝護腺/膀胱頸選擇性高） 較少血壓降低；術中虹膜鬆弛症候群（IFIS）
    • Pheochromocytoma 手術順序：先 α-blocker（Phenoxybenzamine）→ 再 β-blocker → 手術
      • 絕不可先用 β-blocker（α 未阻斷時，阻斷 β₂ → 失去血管擴張 → 惡性高血壓）

    β-Blockers

    藥物 選擇性 特色 臨床用途
    Propranolol β₁ = β₂（非選擇性） 脂溶性高 → 穿越 BBB；膜穩定作用 高血壓、甲亢症狀控制、essential tremor、migraine 預防、portal HTN（降低門脈壓）、焦慮
    Metoprolol / Atenolol / Bisoprolol β₁ 選擇性 較少支氣管收縮 高血壓、心衰（Metoprolol succinate, Bisoprolol）、MI 後
    Carvedilol α₁ + β₁ + β₂ 血管擴張 + 抗氧化 心衰（與 Metoprolol succinate、Bisoprolol 並列心衰首選）
    Labetalol α₁ + β₁ + β₂ α：β = 1：3 妊娠高血壓/子癇前症首選 IV 降壓藥
    Nebivolol β₁ 高選擇性 促進 NO 釋放 → 血管擴張 高血壓
    Esmolol β₁ 選擇性，超短效 半衰期約 9 分鐘 術中心搏過速、SVT 急性控制
    Timolol 非選擇性 眼用製劑 青光眼（降低房水分泌）
    Sotalol 非選擇性 + Class III 抗心律不整（K⁺ channel blocker） 延長 QT 心房/心室心律不整
    Pindolol 非選擇性 + ISA 具 partial agonist 活性 → 休息時心跳不太降 —
    • β-blocker 共同副作用：心搏過緩、低血壓、支氣管痙攣（非選擇性 → 氣喘禁忌）、遮蔽低血糖症狀（tachycardia）、脂質代謝異常（TG↑、HDL↓）、性功能障礙、疲倦、抑鬱
    • β-blocker 突然停藥 → rebound tachycardia / 心絞痛加重 / MI（受體上調）→ 需漸減

    2.6 擬副交感神經藥（Cholinomimetics）

    直接作用型

    藥物 特色 臨床用途
    Bethanechol M₃ 選擇性，不被 AChE 水解 術後尿滯留、神經性膀胱
    Carbachol M + N，不被 AChE 水解 青光眼（眼用）
    Pilocarpine M₃ 青光眼（縮瞳 → 打開 Schlemm's canal）；口乾（Sjögren's）
    Methacholine M 選擇性，被 AChE 緩慢水解 支氣管激發試驗（診斷氣喘）

    間接作用型（AChE inhibitors）

    藥物 可逆/不可逆 臨床用途
    Neostigmine 可逆 重症肌無力（MG）治療、術後腸麻痺/尿滯留、神經肌肉阻斷劑拮抗
    Pyridostigmine 可逆 MG 長期治療首選（作用較長）
    Edrophonium 可逆（超短效） MG 診斷（Tensilon test，已少用）
    Physostigmine 可逆，穿越 BBB Atropine 中毒解毒（因可進入 CNS）
    Donepezil / Rivastigmine / Galantamine 可逆 Alzheimer's disease
    有機磷（Organophosphates） 不可逆 殺蟲劑/神經毒氣中毒
    • 有機磷中毒：
      • DUMBBELSS：Diarrhea、Urination、Miosis、Bradycardia、Bronchospasm/Bronchorrhea、Emesis、Lacrimation、Salivation、Sweating
      • 治療：Atropine（阻斷 muscarinic 症狀）+ Pralidoxime（2-PAM）（在 aging 前重新活化 AChE）
      • Pralidoxime 必須在中毒後 24–48 小時內使用（aging 後無效）

    2.7 抗副交感神經藥（Anticholinergics / Parasympatholytics）

    藥物 選擇性 臨床用途

    三、心血管藥理學（Cardiovascular Pharmacology）

    3.1 抗高血壓藥物

    ACE Inhibitors（-pril）

    • 代表：Captopril、Enalapril、Lisinopril、Ramipril
    • 機制：抑制 ACE → Angiotensin II↓ + Bradykinin↑ → 血管擴張 + 醛固酮↓
    • 用途：高血壓、心衰（HFrEF 首選之一）、糖尿病腎病變（首選腎保護）、MI 後
    • 副作用：
      • 乾咳（bradykinin 累積，最常見副作用）
      • 高血鉀（醛固酮↓）
      • 血管性水腫（bradykinin 媒介，antihistamine 無效）
      • 急性腎衰竭（雙側腎動脈狹窄禁忌）
      • 致畸性 → 孕婦絕對禁忌

    ARBs（-sartan）

    • 代表：Losartan、Valsartan、Candesartan、Irbesartan、Telmisartan
    • 機制：阻斷 AT₁ receptor → 效果類似 ACEi
    • 優點：不引起乾咳（不影響 bradykinin）；血管性水腫罕見
    • 副作用：高血鉀、孕婦禁忌（同 ACEi）
    • Losartan 額外促進尿酸排泄

    ARNI

    • Sacubitril / Valsartan：Sacubitril 抑制 Neprilysin → BNP/ANP 不被降解 → 利鈉利尿、血管擴張
    • 用途：HFrEF（優於單用 ACEi）
    • 注意：不可與 ACEi 併用（血管性水腫風險↑）；須停 ACEi 36 小時後才可換用

    Calcium Channel Blockers（CCBs）

    類別 藥物 作用 用途
    Dihydropyridines（-dipine） Nifedipine、Amlodipine、Felodipine 血管平滑肌選擇性 > 心肌 → 血管擴張為主 高血壓、Raynaud's；Nifedipine 短效型 → 反射性心搏過速（少用）
    Non-dihydropyridines Verapamil 心肌選擇性 > 血管 → 負變時/負變力 SVT（首選之一）、心絞痛、高血壓；便秘（最常見副作用）
    Diltiazem 介於中間 SVT、心絞痛、高血壓
    • Verapamil / Diltiazem 禁忌：HFrEF（負變力加重心衰）、與 β-blocker 併用（嚴重心搏過緩/AV block）
    • Amlodipine 可安全用於心衰（血管選擇性高，不影響心肌）

    其他降壓藥

    藥物 機制 特色
    Hydralazine 直接血管擴張（動脈） 常合併 Isosorbide dinitrate 用於 HFrEF（尤其非裔）；副作用：drug-induced lupus、反射性心搏過速
    Minoxidil K⁺ channel opener → 動脈擴張 嚴重高血壓；副作用：多毛症（外用治禿髮）、鈉水滯留、心包膜積液
    Nitroprusside 釋放 NO → 動脈 + 靜脈擴張 高血壓急症 IV 首選；副作用：氰化物中毒（長期使用）→ 解毒：Thiosulfate、Hydroxocobalamin
    Fenoldopam D₁ receptor agonist 高血壓急症（維持腎灌流）
    Methyldopa 中樞 α₂ agonist 妊娠高血壓口服首選；副作用：Coombs'(+) hemolytic anemia、肝毒性

    類別 藥物 作用位置 機制 效力 副作用
    Carbonic anhydrase inhibitor Acetazolamide PCT 抑制 CA → HCO₃⁻ 排泄↑ 弱 代謝性酸中毒、低血鉀；用於：青光眼、高山症、代謝性鹼中毒

      • Loop → 低鉀低鈣（Loops Lose calcium）
      • Thiazide → 低鉀高鈣（Thiazide：鈣 reabsorption↑）
      • K⁺-sparing → 高鉀

    3.3 抗心絞痛藥（Anti-Anginal Drugs）

    類別 藥物 機制 備註
    Nitrates Nitroglycerin（NTG）、Isosorbide dinitrate/mononitrate 釋放 NO → 靜脈擴張為主 → preload↓ → 心肌耗氧↓ 舌下或 IV 用於急性心絞痛；頭痛（最常見副作用）；Nitrate tolerance → 需留 nitrate-free interval（8–12 hr）；禁忌：併用 PDE5 inhibitor（Sildenafil）→ 嚴重低血壓

    3.4 心衰藥物

    HFrEF 四大支柱（Quadruple Therapy / GDMT）

    類別 藥物 降低死亡率
    ARNI（或 ACEi/ARB） Sacubitril/Valsartan ✓
    β-Blocker Carvedilol、Metoprolol succinate、Bisoprolol ✓
    MRA Spironolactone、Eplerenone ✓
    SGLT2 inhibitor Dapagliflozin、Empagliflozin ✓

    其他心衰藥物

    藥物 機制 用途
    Digoxin 抑制 Na⁺/K⁺-ATPase → 胞內 Na⁺↑ → NCX 反轉 → Ca²⁺↑ → 正性肌力；迷走神經↑ 心衰症狀改善（不降死亡率）、心房顫動心率控制
    Hydralazine + ISDN 血管擴張 ACEi/ARB 不耐受或非裔美國人
    Ivabradine 抑制 If current（SA node）→ 心跳↓（不影響收縮力） 竇性心律 HR ≥70 且已用最大耐受 β-blocker
    Milrinone PDE3 inhibitor → cAMP↑ → 正性肌力 + 血管擴張 急性失代償心衰（inotrope + vasodilator）；長期使用增加死亡率
    Vericiguat sGC stimulator → cGMP↑ 慢性心衰 worsening
    • Digoxin 重點：
      • 治療指數極窄（0.5–2.0 ng/mL）
      • 中毒危險因子：低血鉀（最重要！）、低血鎂、高血鈣、腎功能不全、藥物交互作用（Amiodarone、Verapamil、Quinidine 增加 Digoxin 濃度）
      • 中毒表現：消化道（噁心嘔吐最常見）、心律不整（任何心律不整皆可能，典型：PAT with block、bidirectional VT）、視覺異常（黃視）
      • 中毒處理：停藥、補鉀（若低血鉀）、Digoxin-specific antibody Fab fragments（Digibind/DigiFab）
      • 低血鉀促進 Digoxin 中毒的原因：K⁺ 與 Digoxin 競爭 Na⁺/K⁺-ATPase 結合位

    3.5 抗心律不整藥（Vaughan-Williams Classification）

    Class 機制 藥物 備註
    Ia Na⁺ channel blocker（中等阻斷）+ K⁺ channel blocker → 延長 AP 和 QT Quinidine、Procainamide、Disopyramide Quinidine：腹瀉、金雞納反應、延長 QT → TdP；Procainamide：drug-induced lupus（anti-histone Ab）；Disopyramide：負性肌力最強（禁用 HFrEF）、anticholinergic
    Ib Na⁺ channel blocker（弱阻斷）→ 縮短 AP Lidocaine、Mexiletine Lidocaine：急性 VT/VF 的替代選擇（IV only）；對缺血心肌選擇性高；CNS 毒性（seizure）；Mexiletine：口服 Lidocaine 類似物
    Ic Na⁺ channel blocker（強阻斷）→ 對 AP 影響小 Flecainide、Propafenone 禁用於結構性心臟病/CAD（CAST trial：增加 MI 後死亡率）；用於正常心臟的 AF/SVT
    II β-Blocker Metoprolol、Esmolol、Propranolol 等 降低 SA/AV node 自動性和傳導
    III K⁺ channel blocker → 延長 AP 和 QT Amiodarone、Sotalol、Dofetilide、Ibutilide 見下方詳述
    IV Non-DHP CCB Verapamil、Diltiazem 降低 AV node 傳導 → SVT/AF rate control

    Amiodarone 重點

    • 兼具 Class I/II/III/IV 所有作用 → 最廣效的抗心律不整藥
    • 用途：幾乎所有心律不整（AF、VT、VF），心臟停止時 VF/pVT 用藥
    • 半衰期極長（40–55 天）
    • 副作用（幾乎影響每個器官）：
      • 肺纖維化（最嚴重，需定期 CXR/PFT）
      • 甲狀腺：甲亢或甲低（含碘量高，Wolff-Chaikoff / Jod-Basedow effect）
      • 肝毒性
      • 角膜微沉積（corneal microdeposits，幾乎所有人都有，通常無症狀）
      • 皮膚光敏感 → 藍灰色皮膚變色
      • 周邊神經病變
      • 延長 QT（但 TdP 發生率相對低）
      • 增加 Digoxin 和 Warfarin 濃度（CYP inhibition）

    其他 Class III

    • Sotalol：β-blocker + K⁺ channel blocker；延長 QT → TdP 風險；腎排泄
    • Dofetilide：純 K⁺ channel blocker；延長 QT → TdP；需住院起始 + 監測 QTc
    • Ibutilide：IV 用於 AF/Flutter 急性轉復；延長 QT → TdP

      • 通常在使用 Heparin 5–10 天後（或曾暴露者 <24 hr）
      • 血小板下降 >50%
      • 處理：立即停所有 Heparin（包括 flush）→ 替代抗凝：Argatroban（direct thrombin inhibitor，肝代謝）或 Bivalirudin（直接凝血酶抑制劑）或 Fondaparinux
      • 不可用 Warfarin 作為初始治療（加重血栓/壞死）→ 待血小板回復後才可轉換

    血栓溶解劑（Fibrinolytics）

    藥物 特色
    Alteplase（tPA） 纖維蛋白選擇性 → 選擇性溶解血栓中的 fibrin；STEMI、急性缺血性中風（4.5 hr 內）、大面積 PE
    Tenecteplase 改良型 tPA → 更長半衰期、可單次 bolus
    Streptokinase 非選擇性；免疫原性 → 過敏反應；不可重複使用
    Urokinase 非選擇性
    • 禁忌：活動性出血、近期手術/外傷、顱內出血史、主動脈剝離、血小板 <100,000
    • 共同副作用：出血
    • 解毒：Aminocaproic acid / Tranexamic acid（抗纖溶藥，抑制 plasminogen → plasmin）

    藥物 機制 備註
    Methimazole（MMI） 抑制 TPO → T3/T4 合成↓ 首選（除懷孕第一孕期外）；副作用：顆粒球缺乏症（agranulocytosis）（最嚴重，需衛教發燒喉嚨痛立即就醫）、皮疹
    Propylthiouracil（PTU） 抑制 TPO + 抑制周邊 T4→T3 轉換 懷孕第一孕期首選（MMI 致畸：aplasia cutis）；副作用：agranulocytosis、肝毒性（比 MMI 嚴重）

    Ketamine NMDA antagonist；唯一增加 BP/HR 的 IV 麻醉劑 → 適合 hypovolemic shock 患者；解離性麻醉；止痛效果佳；副作用：emergence reaction（惡夢、幻覺）→ 合併 BZD 預防；顱內壓↑

    7.11 局部麻醉藥

    • 機制：阻斷 Na⁺ channel → 阻斷動作電位傳導
    • Esters：Procaine、Tetracaine、Cocaine、Benzocaine → 被 pseudocholinesterase 水解 → 過敏較常見（PABA 代謝物）
    • Amides：Lidocaine、Bupivacaine、Ropivacaine、Mepivacaine、Prilocaine → 肝臟代謝 → 過敏罕見
    • 記法：Amides 有兩個 "i"（Lidocaine, Bupivacaine）
    • 阻斷順序：先阻斷小纖維（痛覺/溫覺 → C fiber, Aδ fiber）→ 後阻斷大纖維（觸覺/運動）
    • 毒性：CNS 先興奮後抑制（tinnitus → seizure → coma → respiratory arrest）；心臟毒性（Bupivacaine 心臟毒性最強 → 解毒：Intralipid（lipid emulsion））
    • Prilocaine → methemoglobinemia → 治療：Methylene blue
    • Cocaine：唯一具有血管收縮作用（抑制 NE 再回收）

    8.1 細胞壁合成抑制劑

    β-Lactams

    類別 代表藥物 抗菌譜 備註

    Cephalosporins

    世代 代表 特色
    1st Cefazolin（IV）、Cephalexin（PO） MSSA、Strep；手術預防感染首選（Cefazolin）
    2nd Cefoxitin、Cefuroxime + H. flu；Cefoxitin 抗 anaerobe（用於腹腔感染）
    3rd Ceftriaxone、Cefotaxime、Ceftazidime 廣效 GNR；Ceftriaxone：穿越 BBB → 細菌性腦膜炎首選（N. meningitidis, S. pneumoniae, H. flu）；Ceftazidime：anti-Pseudomonas
    4th Cefepime 3rd + Pseudomonas + GPC
    5th Ceftaroline MRSA（唯一 Cephalosporin 有效對抗 MRSA） + community-acquired pneumonia pathogens
    • Cephalosporin 過敏交叉反應：Penicillin 過敏者約 1–2% 交叉反應（低風險可用；嚴重 PCN anaphylaxis → 避免或先做 skin test）

    Carbapenems

    • Imipenem（+ Cilastatin）、Meropenem、Ertapenem、Doripenem
    • 最廣效 β-lactam：幾乎所有 G(+)/G(−)/anaerobes（除 MRSA、Atypicals）
    • Imipenem 需 Cilastatin（抑制腎臟 dehydropeptidase → 防止分解）；Imipenem 降低 seizure threshold（CNS 感染較不推薦 → 改用 Meropenem）
    • Ertapenem：不涵蓋 Pseudomonas
    • Carbapenem-resistant organisms（CRE） → 使用 Ceftazidime-avibactam、Meropenem-vaborbactam、Cefiderocol

    Monobactam

    • Aztreonam：僅對 GNR（包括 Pseudomonas）有效；對 GPC 和 anaerobes 無效
    • Penicillin 嚴重過敏者可安全使用（無交叉反應）

    Glycopeptides

    • Vancomycin：抑制 cell wall 合成（結合 D-Ala-D-Ala）
      • 抗菌譜：MRSA（首選 IV）、C. difficile（口服 Vancomycin 用於 CDI）
      • 副作用：Red man syndrome（histamine 釋放 → 非過敏 → 減慢輸注速度 + Antihistamine 預防）；腎毒性（與 Aminoglycosides 協同腎毒性↑）；耳毒性
      • 需監測 trough level
    • Teicoplanin：類似 Vancomycin
    • VRE（Vancomycin-Resistant Enterococcus）→ 治療：Linezolid 或 Daptomycin

    其他細胞壁相關

    • Daptomycin：脂肪肽 → 插入細菌細胞膜 → 去極化 → 死亡
      • 用途：MRSA 菌血症、VRE
      • 注意：被 surfactant 不活化 → 不可用於肺炎
      • 副作用：CPK↑（myopathy） → 需監測
    • Fosfomycin：抑制 MurA → 口服用於 uncomplicated UTI（單劑）

    十一、NSAIDs 與止痛藥

    11.1 NSAIDs

    • 機制：抑制 COX（Cyclooxygenase） → Prostaglandin 合成↓
      • COX-1：constitutive → 胃黏膜保護、血小板 TXA₂、腎血流維持
      • COX-2：inducible → 發炎、疼痛、發燒
    藥物 選擇性 特色
    Aspirin COX-1 = COX-2（不可逆） 低劑量：抗血小板；中劑量：止痛解熱；高劑量：抗發炎；副作用：GI出血、Reye syndrome（兒童禁忌）、呼吸性鹼中毒 → 代謝性酸中毒（中毒）；過敏者可能有 aspirin-exacerbated respiratory disease（AERD / Samter's triad：asthma + nasal polyps + aspirin sensitivity）
    Ibuprofen 非選擇性 OTC 止痛解熱；closure of PDA
    Naproxen 非選擇性 半衰期較長；心血管風險相對較低
    Indomethacin 非選擇性（COX-1偏重） Gout 急性發作；PDA closure；副作用較多（GI、CNS）
    Ketorolac 非選擇性 最強止痛 NSAID（IV/IM）；僅短期使用（≤5 天）；GI 出血風險高
    Diclofenac 非選擇性 外用/口服；肝毒性（需監測 LFT）
    Piroxicam 非選擇性 長效；GI 副作用多
    Meloxicam COX-2 偏重 RA/OA
    Celecoxib COX-2 選擇性 較少 GI 副作用（但非零風險）；心血管風險↑（sulfa allergy 禁忌）
    • NSAIDs 共同副作用：
      • GI：胃潰瘍/出血（COX-1 保護胃黏膜↓）→ 預防：PPI、Misoprostol
      • 腎臟：急性腎損傷（腎血流依賴 PG 者：心衰、肝硬化、脫水）；間質性腎炎；Analgesic nephropathy
      • 心血管：MI/stroke 風險↑（COX-2 選擇性更明顯 → rofecoxib 下架）；高血壓；鈉水滯留
      • 血小板：出血風險↑（非選擇性）
      • 過敏/pseudoallergic：aspirin-exacerbated respiratory disease
      • 孕婦：第三孕期禁用（PDA 早閉）

    11.2 Acetaminophen（Paracetamol）

    • 不具抗發炎作用（非 NSAID）→ 中樞 COX 抑制為主
    • 用途：止痛、解熱（兒童/孕婦安全選擇）
    • 過量 → 肝臟壞死：
      • 機制：CYP2E1 產生 NAPQI → 消耗 Glutathione → 肝細胞壞死
      • 解毒：N-Acetylcysteine（NAC） → 補充 Glutathione
      • Rumack-Matthew nomogram 判斷治療需要
